# 3.3 Consequences of the Axioms

[Probability](../README.md) / [Module 03: Axioms of Probability](README.md) / 3.3 Consequences of the Axioms

**Level:** 1 (Zero) · **Time:** about 45 minutes · **Before this:** [3.2 Kolmogorov Axioms](3.2-Kolmogorov-Axioms.md)

> **Big idea:** The everyday rules of probability, such as "the chance of NOT A is 1 minus the chance of A", are not extra assumptions; each one can be proved from the three axioms in a few lines.

---

## Why It Matters

The three axioms are short, but alone they are not handy. In this topic we prove
the rules you will use every day: $P(\varnothing) = 0$, the **complement rule**,
**monotonicity**, and $P(A) \le 1$. The complement rule is the standard trick for
"at least one" questions, which appear everywhere: at least one failure in a
system, at least one collision in a hash table, at least one six in four rolls.

## Intuition

Go back to the 1 kg of sand from [3.2](3.2-Kolmogorov-Axioms.md). If the event "rain"
holds 0.3 kg of sand, then all the rest, "no rain", must hold $1 - 0.3 = 0.7$ kg.
That is the complement rule.

If event $A$ sits completely inside event $B$, then every grain of sand on $A$ is also
on $B$. So $B$ has at least as much sand as $A$. That is monotonicity. For example,
"the server is down for more than 1 hour today" sits inside "the server is down at
some time today", so the first can never be more likely than the second.

The empty event $\varnothing$ ("nothing at all happens") has no outcomes, so it holds
no sand: $P(\varnothing) = 0$. None of this is surprising. The surprising part is
that the three axioms are enough to prove all of it.

## Picture

```text
      Complement rule                 Monotonicity (A inside B)
  +------------------------+      +------------------------------+
  |  +-------+             |      |  B                           |
  |  |   A   |     A^c     |      |   +---------+                |
  |  +-------+             |      |   |    A    |    B \ A       |
  |                        |      |   +---------+                |
  +------------------------+      +------------------------------+
    P(A) + P(A^c) = 1               P(B) = P(A) + P(B \ A) >= P(A)
```

Both rules come from cutting a set into two pieces that do not overlap and adding
their probabilities.

## Definition

For any events $A$ and $B$ in a probability space, these rules hold:

$$
\begin{aligned}
&\text{1. Empty event:} && P(\varnothing) = 0 \\
&\text{2. Finite additivity:} && P(A_1 \cup \dots \cup A_n) = P(A_1) + \dots + P(A_n) \ \text{ for disjoint } A_1, \dots, A_n \\
&\text{3. Complement rule:} && P(A^c) = 1 - P(A) \\
&\text{4. Difference rule:} && P(B \setminus A) = P(B) - P(A \cap B) \\
&\text{5. Monotonicity:} && A \subseteq B \implies P(A) \le P(B) \\
&\text{6. Upper bound:} && P(A) \le 1
\end{aligned}
$$

Here $A^c$ is the **complement** of $A$ (all outcomes not in $A$), and $B \setminus A$
is the **difference** "B but not A" (outcomes in $B$ and not in $A$). These set
operations are from [1.4 Set Operations on Events](../01-SETS-SAMPLE-SPACES-AND-EVENTS/1.4-Set-Operations-on-Events.md).

**In words:** nothing has probability 0; disjoint pieces add; "not A" has whatever
probability A leaves over; removing A from B removes the shared part's probability;
a smaller event is never more likely than a bigger one that contains it; and no
probability is above 1.

When $A \subseteq B$, we have $A \cap B = A$, so the difference rule becomes
$P(B \setminus A) = P(B) - P(A)$.

## Why It Is True

We use only Axiom 1 ($P \ge 0$), Axiom 2 ($P(\Omega) = 1$) and Axiom 3 (countable
additivity for disjoint events), plus each rule proved before it.

**Rule 1: the empty event.** Let $c = P(\varnothing)$. Take the infinite list
$A_1 = \Omega$ and $A_2 = A_3 = \dots = \varnothing$. They are pairwise disjoint (the
empty set shares nothing with anything), and their union is $\Omega$. By Axiom 3:

$$
\begin{aligned}
P(\Omega) &= P(\Omega) + c + c + c + \dots && \text{(Axiom 3)} \\
1 &= 1 + (c + c + c + \dots) && \text{(Axiom 2)} \\
0 &= c + c + c + \dots && \text{(subtract 1)}
\end{aligned}
$$

By Axiom 1, $c \ge 0$. If $c$ were positive, the infinite sum $c + c + \dots$ would
grow without limit, not equal 0. So $c = 0$.

**Rule 2: finite additivity.** Given disjoint $A_1, \dots, A_n$, extend the list with
$A_{n+1} = A_{n+2} = \dots = \varnothing$. The list is still pairwise disjoint, with the
same union. By Axiom 3 and Rule 1:

$$
P(A_1 \cup \dots \cup A_n) = P(A_1) + \dots + P(A_n) + 0 + 0 + \dots = P(A_1) + \dots + P(A_n)
$$

**Rule 3: complement.** $A$ and $A^c$ are disjoint and $A \cup A^c = \Omega$:

$$
\begin{aligned}
1 &= P(\Omega) && \text{(Axiom 2)} \\
&= P(A \cup A^c) && \text{(}A \cup A^c = \Omega\text{)} \\
&= P(A) + P(A^c) && \text{(Rule 2, disjoint)}
\end{aligned}
$$

So $P(A^c) = 1 - P(A)$.

**Rule 4: difference.** Cut $B$ into the part inside $A$ and the part outside $A$:
$B = (A \cap B) \cup (B \setminus A)$. The two parts are disjoint, so by Rule 2,
$P(B) = P(A \cap B) + P(B \setminus A)$. Move $P(A \cap B)$ to the other side.

**Rule 5: monotonicity.** If $A \subseteq B$, then $A \cap B = A$, and Rule 4 gives:

$$
\begin{aligned}
P(B) &= P(A) + P(B \setminus A) && \text{(Rule 4 with } A \cap B = A \text{)} \\
&\ge P(A) && \text{(Axiom 1: } P(B \setminus A) \ge 0 \text{)}
\end{aligned}
$$

**Rule 6: upper bound.** Every event satisfies $A \subseteq \Omega$, so by Rule 5,
$P(A) \le P(\Omega) = 1$.

Together with Axiom 1, Rule 6 gives $0 \le P(A) \le 1$. In
[1.1](../01-SETS-SAMPLE-SPACES-AND-EVENTS/1.1-What-is-Probability.md) this was true
for counting; now it is true for **every** probability.

## Worked Examples

### Example 1: The Gambler's First Bet

**Problem.** In 17th-century Paris, the gambler Chevalier de Méré bet that he would
get at least one six in 4 rolls of a fair die. Find the probability that he wins.

**Solution.**

1. "At least one six" has many cases (one six, two sixes, ...). Its complement is
   simpler: "no six at all".
2. The sample space is all sequences of 4 rolls. There are $6^4 = 1296$ equally
   likely sequences.
3. Sequences with no six use only the faces 1 to 5: there are $5^4 = 625$ of them. So:

$$
P(\text{no six}) = \frac{625}{1296} \approx 0.4823
$$

4. By the complement rule:

$$
P(\text{at least one six}) = 1 - \frac{625}{1296} = \frac{671}{1296} \approx 0.5177
$$

**Answer.** About $0.5177$, a bit more than one half, so the bet is good for him in
the long run.

**Check.** The simulation below gives $0.5175$. Note that the "obvious" answer
$4 \times \frac{1}{6} \approx 0.667$ is wrong: it counts sequences with two or more
sixes more than once.

### Example 2: The Gambler's Second Bet

**Problem.** De Méré also bet on at least one **double six** in 24 rolls of two dice.
He thought it should be as good as the first bet. Was it?

**Solution.**

1. One roll of two dice has $36$ equally likely pairs. Exactly one of them, $(6, 6)$,
   is a double six, so $35$ are not.
2. A sequence of 24 rolls has $36^{24}$ equally likely possibilities. Those with no
   double six number $35^{24}$.
3. By the complement rule:

$$
P(\text{at least one double six}) = 1 - \frac{35^{24}}{36^{24}} = 1 - \left( \frac{35}{36} \right)^{24} \approx 1 - 0.5086 = 0.4914
$$

**Answer.** About $0.4914$, a bit **less** than one half. The second bet loses money in
the long run.

**Check.** De Méré noticed that he was losing and asked Blaise Pascal why. Pascal's
letters with Pierre de Fermat about such questions in 1654 are often called the
birth of probability theory.

### Example 3: Server Response Times

**Problem.** For a web server, $P(\text{response takes more than 100 ms}) = 0.20$ and
$P(\text{response takes more than 500 ms}) = 0.03$. Find the probability that a
response takes more than 100 ms but at most 500 ms, and the probability that it
takes at most 100 ms.

**Solution.**

1. Let $A = \lbrace \text{more than 500 ms} \rbrace$ and $B = \lbrace \text{more than 100 ms} \rbrace$.
   Any response slower than 500 ms is also slower than 100 ms, so $A \subseteq B$.
2. "More than 100 ms but at most 500 ms" is $B \setminus A$. By the difference rule
   with $A \subseteq B$:

$$
P(B \setminus A) = P(B) - P(A) = 0.20 - 0.03 = 0.17
$$

3. "At most 100 ms" is $B^c$. By the complement rule:

$$
P(B^c) = 1 - P(B) = 1 - 0.20 = 0.80
$$

**Answer.** $0.17$ and $0.80$.

**Check.** The three pieces "at most 100", "100 to 500", "more than 500" are disjoint
and cover everything, and $0.80 + 0.17 + 0.03 = 1$.

## Simulate It

We play both of de Méré's bets a million times each.

```python
import numpy as np

rng = np.random.default_rng(42)
n_trials = 1_000_000

# Bet 1: at least one six in 4 rolls of one die.
rolls = rng.integers(1, 7, size=(n_trials, 4))
bet1 = np.mean(np.any(rolls == 6, axis=1))
print(f"Bet 1: simulation {bet1:.4f}, exact {1 - (5 / 6) ** 4:.4f}")

# Bet 2: at least one double six in 24 rolls of two dice.
die1 = rng.integers(1, 7, size=(n_trials, 24))
die2 = rng.integers(1, 7, size=(n_trials, 24))
bet2 = np.mean(np.any((die1 == 6) & (die2 == 6), axis=1))
print(f"Bet 2: simulation {bet2:.4f}, exact {1 - (35 / 36) ** 24:.4f}")
```

Output:

```text
Bet 1: simulation 0.5175, exact 0.5177
Bet 2: simulation 0.4915, exact 0.4914
```

The first bet wins slightly more than half the time, and the second slightly less,
exactly as the complement rule predicts.

## Common Mistakes

- **Adding to get "at least one".** $4 \times \frac{1}{6}$ is not the chance of at least
  one six in 4 rolls. With 7 rolls this method would give $\frac{7}{6} \gt 1$, which is
  impossible. Use $1 - P(\text{none})$.
- **Taking the wrong complement.** The complement of "at least one six" is "no six",
  not "exactly one six" and not "all sixes". The complement of "all servers are up"
  is "at least one server is down".
- **Using $P(B) - P(A)$ when A is not inside B.** The rule
  $P(B \setminus A) = P(B) - P(A)$ needs $A \subseteq B$. In general, subtract
  $P(A \cap B)$ instead.
- **Judging "A and B" as more likely than "A".** Since $A \cap B \subseteq A$,
  monotonicity says $P(A \cap B) \le P(A)$, always. People break this rule when a
  detailed story sounds more believable (see
  [22.11 Conjunction Fallacy](../22-PROBABILITY-FOR-LIFE/22.11-Conjunction-Fallacy.md)).
- **Reading Rule 1 backwards.** $P(\varnothing) = 0$, but $P(A) = 0$ does not mean
  $A$ is empty. A random point in $[0, 1]$ lands exactly on $0.5$ with probability 0,
  yet it is possible (see [3.9 Continuity of Probability](3.9-Continuity-of-Probability.md)).

## Where It Is Used

- **AI and machine learning:** accuracy is $1 - \text{error rate}$. For a binary
  classifier, $P(\text{class 0}) = 1 - P(\text{class 1})$, which is why one output
  (a sigmoid) is enough.
- **Computer science:** the chance of at least one hash collision is
  $1 - P(\text{no collision})$, the idea behind the
  [birthday problem](../02-COUNTING/2.11-Classic-Counting-Problems/2.11.1-Birthday-Problem.md).
- **Reliability engineering:** "the system fails" is the complement of "every part
  works", so $P(\text{fail}) = 1 - P(\text{all work})$.
- **Security:** the chance that an attacker succeeds in at least one of many tries
  is found with the complement rule.
- **Everyday life:** monotonicity is a fast sanity check. A plan that needs five
  things to go right is never more likely than a plan that needs only one of them.

## Practice

**1. (Easy)** The chance of rain tomorrow is $0.35$. What is the chance of no rain?

<details>
<summary>Answer</summary>

By the complement rule:

$$P(\text{no rain}) = 1 - 0.35 = 0.65$$

</details>

**2. (Easy)** Events satisfy $A \subseteq B$, $P(A) = 0.3$ and $P(B) = 0.5$. Find
$P(B \setminus A)$ and $P(B^c)$. Could a different model have $P(A) = 0.6$ with the
same $B$ and $P(B) = 0.5$?

<details>
<summary>Answer</summary>

$$P(B \setminus A) = P(B) - P(A) = 0.5 - 0.3 = 0.2$$

$$P(B^c) = 1 - 0.5 = 0.5$$

No. Monotonicity says $A \subseteq B$ forces $P(A) \le P(B) = 0.5$, so $0.6$ is
impossible.

</details>

**3. (Medium)** A 4-digit PIN (0000 to 9999) is chosen at random. What is the
probability that at least one digit appears more than once?

<details>
<summary>Answer</summary>

The complement is "all 4 digits are different". There are $10 \cdot 9 \cdot 8 \cdot 7 = 5040$
such PINs out of $10^4 = 10000$ equally likely PINs:

$$P(\text{some repeat}) = 1 - \frac{5040}{10000} = 1 - 0.504 = 0.496$$

So almost half of all random PINs repeat a digit.

</details>

**4. (Medium)** Use monotonicity to show that for any events $A$ and $B$,
$P(A \cap B) \le \min(P(A), P(B))$ and $P(A \cup B) \ge \max(P(A), P(B))$.

<details>
<summary>Answer</summary>

$A \cap B \subseteq A$ and $A \cap B \subseteq B$, so by monotonicity
$P(A \cap B) \le P(A)$ and $P(A \cap B) \le P(B)$. Being below both numbers means
being below the smaller one.

$A \subseteq A \cup B$ and $B \subseteq A \cup B$, so $P(A) \le P(A \cup B)$ and
$P(B) \le P(A \cup B)$. Being above both means being above the larger one.

</details>

**5. (Hard)** Prove from the axioms and the rules in this topic: if $P(A) = 1$, then
$P(A \cap B) = P(B)$ for every event $B$.

<details>
<summary>Answer</summary>

By the complement rule, $P(A^c) = 1 - 1 = 0$. Cut $B$ into two disjoint parts,
$B = (B \cap A) \cup (B \cap A^c)$, so by finite additivity:

$$P(B) = P(B \cap A) + P(B \cap A^c)$$

Now $B \cap A^c \subseteq A^c$, so by monotonicity and Axiom 1:

$$0 \le P(B \cap A^c) \le P(A^c) = 0$$

So $P(B \cap A^c) = 0$, and $P(B) = P(B \cap A)$. In words: an event of probability 1
can be added to any condition without changing its probability.

</details>

**6. (Simulate)** Check your answer to Problem 3 with a simulation of 1,000,000
random PINs.

<details>
<summary>Answer</summary>

```python
import numpy as np

rng = np.random.default_rng(42)
n_trials = 1_000_000
pins = rng.integers(0, 10, size=(n_trials, 4))      # 4 random digits
sorted_pins = np.sort(pins, axis=1)
has_repeat = np.any(sorted_pins[:, 1:] == sorted_pins[:, :-1], axis=1)
print(f"Simulation: {np.mean(has_repeat):.4f}")
print(f"Exact:      {1 - 5040 / 10000:.4f}")
```

Output:

```text
Simulation: 0.4966
Exact:      0.4960
```

After sorting, a repeated digit shows up as two equal neighbors.

</details>

## Summary

- Every rule here is proved from the three axioms; nothing new is assumed.
- $P(\varnothing) = 0$, and finite additivity follows from countable additivity.
- Complement rule: $P(A^c) = 1 - P(A)$. Use it for every "at least one" question.
- Monotonicity: if $A \subseteq B$, then $P(A) \le P(B)$. So $0 \le P(A) \le 1$ always.
- Difference rule: $P(B \setminus A) = P(B) - P(A \cap B)$.

The one formula to remember:

$$
\boxed{P(A^c) = 1 - P(A)}
$$
