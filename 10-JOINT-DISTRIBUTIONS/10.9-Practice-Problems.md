# 10.9 Practice Problems

[Probability](../README.md) / [Module 10: Joint Distributions](README.md) / 10.9 Practice Problems

**Level:** 3 (Many Variables) · **Time:** about 3 hours · **Before this:** [10.8 Mixture Distributions](10.8-Mixture-Distributions.md)

> **Big idea:** Every question about several random variables starts from the joint distribution: add or integrate it to get marginals, slice and rescale it to get conditionals, and compare it with the product of the marginals to test independence.

## Warm-Up

**W1. (Easy, 10.1)** Let $X, Y \in \lbrace 0, 1 \rbrace$ with joint PMF
$p(x, y) = c(x + y + 1)$. Find $c$ and $P(X = 1)$.

<details>
<summary>Answer</summary>

The four cells are $p(0, 0) = c$, $p(0, 1) = 2c$, $p(1, 0) = 2c$, $p(1, 1) = 3c$. They must add to 1:

$$c + 2c + 2c + 3c = 8c = 1 \implies c = \tfrac{1}{8}$$

$$P(X = 1) = p(1, 0) + p(1, 1) = \tfrac{2}{8} + \tfrac{3}{8} = \tfrac{5}{8}$$

</details>

**W2. (Easy, 10.3 and 10.5)** For the table below, find both marginals. Are $X$ and
$Y$ independent?

| | $Y = 0$ | $Y = 1$ |
|---|---|---|
| $X = 0$ | 0.10 | 0.20 |
| $X = 1$ | 0.30 | 0.40 |

<details>
<summary>Answer</summary>

Row sums: $p_X(0) = 0.30$, $p_X(1) = 0.70$. Column sums: $p_Y(0) = 0.40$, $p_Y(1) = 0.60$. Test one cell:

$$p_X(0) \thinspace p_Y(0) = 0.30 \times 0.40 = 0.12 \ne 0.10 = p(0, 0)$$

So $X$ and $Y$ are **not** independent. Also $P(Y = 1 \mid X = 1) = \frac{0.40}{0.70} \approx 0.571$, while $P(Y = 1) = 0.60$.

</details>

**W3. (Easy, 10.2)** A point is uniform on the unit square, so $F(x, y) = xy$ for
$0 \le x, y \le 1$. Use the rectangle rule to find $P(0.2 \lt X \le 0.5, \ 0.1 \lt Y \le 0.6)$.

<details>
<summary>Answer</summary>

$$F(0.5, 0.6) - F(0.2, 0.6) - F(0.5, 0.1) + F(0.2, 0.1) = 0.30 - 0.12 - 0.05 + 0.02 = 0.15$$

Check: the rectangle has sides $0.3$ and $0.5$, so its area is $0.15$, and the density is 1.

</details>

**W4. (Easy, 10.6)** Three batteries have IID lifetimes $\text{Exp}(0.5)$ in years
(rate $0.5$ per year, mean 2 years). What is the probability that all three last at
least 2 years?

<details>
<summary>Answer</summary>

One battery lasts past 2 years with probability $e^{-0.5 \times 2} = e^{-1}$. By independence:

$$P(\text{all three} \gt 2) = (e^{-1})^3 = e^{-3} \approx 0.0498$$

</details>

**W5. (Easy, 10.8)** With probability $0.5$, $X \sim \text{Unif}(0, 1)$; otherwise
$X \sim \text{Unif}(1, 3)$. Write the density of $X$ and find $E[X]$.

<details>
<summary>Answer</summary>

$$f(x) = 0.5 \times 1 = 0.5 \text{ for } 0 \lt x \lt 1, \qquad f(x) = 0.5 \times \tfrac{1}{2} = 0.25 \text{ for } 1 \lt x \lt 3$$

$$E[X] = 0.5 \times 0.5 + 0.5 \times 2 = 0.25 + 1 = 1.25$$

</details>

## Core

**C1. (Medium, 10.1, 10.3, 10.4, 10.5)** A team counts bugs found in code review
($X$) and bugs found later in testing ($Y$) for each new feature:

| | $Y = 0$ | $Y = 1$ | $Y = 2$ |
|---|---|---|---|
| $X = 0$ | 0.20 | 0.10 | 0.05 |
| $X = 1$ | 0.10 | 0.15 | 0.10 |
| $X = 2$ | 0.05 | 0.10 | 0.15 |

(a) Find both marginals. (b) Find the conditional distribution of $Y$ given $X = 2$.
(c) Find $P(X = Y)$ and $P(Y \gt X)$. (d) Are $X$ and $Y$ independent?

<details>
<summary>Answer</summary>

(a) Rows: $p_X = (0.35, 0.35, 0.30)$. Columns: $p_Y = (0.35, 0.35, 0.30)$.

(b) Divide the $X = 2$ row by its sum $0.30$:

$$P(Y = 0 \mid X = 2) = \tfrac{0.05}{0.30} = \tfrac{1}{6}, \quad P(Y = 1 \mid X = 2) = \tfrac{0.10}{0.30} = \tfrac{1}{3}, \quad P(Y = 2 \mid X = 2) = \tfrac{0.15}{0.30} = \tfrac{1}{2}$$

(c) The diagonal and the cells above it:

$$P(X = Y) = 0.20 + 0.15 + 0.15 = 0.50, \qquad P(Y \gt X) = 0.10 + 0.05 + 0.10 = 0.25$$

(d) No: $p_X(0) \thinspace p_Y(0) = 0.35 \times 0.35 = 0.1225 \ne 0.20$. Features with many review bugs tend to have many testing bugs too.

</details>

**C2. (Medium, 10.3)** A point is uniform on the upper half of the unit disk,
$\lbrace (x, y) : x^2 + y^2 \le 1, \ y \ge 0 \rbrace$. Find the joint density and both
marginal densities.

<details>
<summary>Answer</summary>

The half disk has area $\frac{\pi}{2}$, so $f(x, y) = \frac{2}{\pi}$ on it. For a fixed $x \in [-1, 1]$, $y$ runs from 0 to $\sqrt{1 - x^2}$. For a fixed $y \in [0, 1]$, $x$ runs from $-\sqrt{1 - y^2}$ to $\sqrt{1 - y^2}$:

$$f_X(x) = \int_0^{\sqrt{1 - x^2}} \tfrac{2}{\pi} \thinspace dy = \tfrac{2}{\pi} \sqrt{1 - x^2}, \qquad f_Y(y) = \int_{-\sqrt{1 - y^2}}^{\sqrt{1 - y^2}} \tfrac{2}{\pi} \thinspace dx = \tfrac{4}{\pi} \sqrt{1 - y^2}$$

Check: $\int_0^1 \sqrt{1 - y^2} \thinspace dy = \frac{\pi}{4}$ (a quarter of the unit disk), so $\int_0^1 f_Y = 1$.

</details>

**C3. (Medium, 10.1, 10.3, 10.4)** Let $f(x, y) = 6x$ on the triangle
$0 \lt x \lt y \lt 1$. Check that it is a valid density, find both marginals, find
$f_{X \mid Y}(x \mid y)$, and find $P(X \le \frac{1}{2} \mid Y = 1)$.

<details>
<summary>Answer</summary>

For a fixed $x$, $y$ runs from $x$ to 1. For a fixed $y$, $x$ runs from 0 to $y$:

$$f_X(x) = \int_x^1 6x \thinspace dy = 6x(1 - x), \qquad f_Y(y) = \int_0^y 6x \thinspace dx = 3y^2$$

Since $\int_0^1 3y^2 \thinspace dy = 1$, the joint density is valid. The conditional:

$$f_{X \mid Y}(x \mid y) = \frac{6x}{3y^2} = \frac{2x}{y^2}, \quad 0 \lt x \lt y$$

$$P(X \le \tfrac{1}{2} \mid Y = 1) = \int_0^{1/2} 2x \thinspace dx = \tfrac{1}{4}$$

</details>

**C4. (Medium, 10.5)** For each joint density, decide whether $X$ and $Y$ are
independent: (a) $6xy^2$ on the unit square; (b) $2$ on the triangle
$0 \lt x \lt y \lt 1$; (c) $e^{-x-y}$ for $x, y \gt 0$.

<details>
<summary>Answer</summary>

(a) $6xy^2 = (2x)(3y^2)$ on a square: **independent**, with $f_X(x) = 2x$ and $f_Y(y) = 3y^2$.

(b) The constant 2 factors, but the support is a triangle: **dependent**. For example, given $Y = 0.1$, $X$ must be below $0.1$.

(c) $e^{-x-y} = e^{-x} e^{-y}$ on $(0, \infty) \times (0, \infty)$: **independent**, each $\text{Exp}(1)$.

</details>

**C5. (Medium, 10.7)** The number of exclamation marks in an email is $\text{Pois}(4)$
for spam and $\text{Pois}(0.5)$ for normal email (the parameter is the mean). 30% of
emails are spam. An email has exactly 3 exclamation marks. Find $P(\text{spam} \mid Y = 3)$.

<details>
<summary>Answer</summary>

Likelihood times prior for each class (the $3!$ cancels, so leave it out):

$$\text{spam: } 0.3 \times e^{-4} \times 4^3 \approx 0.3 \times 1.1722 = 0.3517, \qquad \text{normal: } 0.7 \times e^{-0.5} \times 0.5^3 \approx 0.7 \times 0.07582 = 0.0531$$

$$P(\text{spam} \mid Y = 3) = \frac{0.3517}{0.3517 + 0.0531} \approx 0.869$$

</details>

**C6. (Medium, 10.2 and 10.6)** Let $U_1, U_2, U_3 \overset{\text{iid}}{\sim} \text{Unif}(0, 1)$
and $M = \max(U_1, U_2, U_3)$. Find the CDF and density of $M$, and $P(M \gt 0.9)$.

<details>
<summary>Answer</summary>

$M \le t$ means all three are at most $t$. This is the joint CDF at $(t, t, t)$, and by independence:

$$F_M(t) = P(U_1 \le t, U_2 \le t, U_3 \le t) = t^3, \qquad f_M(t) = 3t^2, \quad 0 \le t \le 1$$

$$P(M \gt 0.9) = 1 - 0.9^3 = 1 - 0.729 = 0.271$$

</details>

## Challenge

**H1. (Hard, 10.4, proof)** Emails arrive in an hour: $N \sim \text{Pois}(\lambda)$.
Each one is spam with probability $p$, independently, so given $N = n$, the number of
spam emails is $S \sim \text{Bin}(n, p)$. Prove that $S \sim \text{Pois}(\lambda p)$.

<details>
<summary>Answer</summary>

Use the multiplication rule and sum out $N$. For $S = k$ we need $N \ge k$. Write $n = k + m$:

$$P(S = k) = \sum_{n=k}^{\infty} e^{-\lambda} \frac{\lambda^n}{n!} \binom{n}{k} p^k (1 - p)^{n-k} = e^{-\lambda} \frac{(\lambda p)^k}{k!} \sum_{m=0}^{\infty} \frac{(\lambda (1 - p))^m}{m!}$$

Here we used $\frac{1}{n!} \binom{n}{k} = \frac{1}{k! \thinspace m!}$ and $\lambda^n = \lambda^k \lambda^m$. The last sum is the series for $e^{\lambda(1 - p)}$:

$$P(S = k) = e^{-\lambda} \frac{(\lambda p)^k}{k!} e^{\lambda - \lambda p} = e^{-\lambda p} \frac{(\lambda p)^k}{k!}$$

This is the $\text{Pois}(\lambda p)$ PMF. This fact is called **Poisson thinning**.

</details>

**H2. (Hard, 10.4 and 10.5, proof)** Let $X$ and $Y$ be discrete. Prove that $X \perp Y$
if and only if the conditional PMF $p_{Y \mid X}(y \mid x)$ is the same for every $x$
with $p_X(x) \gt 0$.

<details>
<summary>Answer</summary>

**If independent, then the conditionals are equal.** $p_{Y \mid X}(y \mid x) = \frac{p_X(x) p_Y(y)}{p_X(x)} = p_Y(y)$, which does not depend on $x$.

**If the conditionals are equal, then independent.** Say $p_{Y \mid X}(y \mid x) = q(y)$ for every such $x$. By the law of total probability:

$$p_Y(y) = \sum_{x} p_{Y \mid X}(y \mid x) \thinspace p_X(x) = q(y) \sum_{x} p_X(x) = q(y)$$

So $q = p_Y$, and by the multiplication rule $p(x, y) = p_X(x) \thinspace p_{Y \mid X}(y \mid x) = p_X(x) \thinspace p_Y(y)$ for every $x$ with $p_X(x) \gt 0$. If $p_X(x) = 0$, both sides are 0. So $X \perp Y$.

</details>

**H3. (Hard, 10.7)** A coin has unknown heads probability $p \sim \text{Unif}(0, 1)$.
In $n$ flips you see $k$ heads. Show that the posterior is $\text{Beta}(k + 1, n - k + 1)$
and that $E[p \mid \text{data}] = \frac{k + 1}{n + 2}$. You may use
$\int_0^1 p^a (1 - p)^b \thinspace dp = \frac{a! \thinspace b!}{(a + b + 1)!}$ for whole numbers $a, b$.

<details>
<summary>Answer</summary>

Posterior $\propto$ likelihood times prior $= \binom{n}{k} p^k (1 - p)^{n-k} \times 1 \propto p^k (1 - p)^{n-k}$. This is the shape of $\text{Beta}(k + 1, n - k + 1)$. The posterior mean is a ratio of two integrals of that shape:

$$E[p \mid \text{data}] = \frac{\int_0^1 p^{k+1} (1 - p)^{n-k} \thinspace dp}{\int_0^1 p^k (1 - p)^{n-k} \thinspace dp} = \frac{(k + 1)! \thinspace (n - k)! / (n + 2)!}{k! \thinspace (n - k)! / (n + 1)!} = \frac{k + 1}{n + 2}$$

This is **Laplace's rule of succession**. With 7 heads in 10 flips it gives $\frac{8}{12} = \frac{2}{3}$, as in [10.7](10.7-Bayes-for-Random-Variables.md). With 10 heads in 10 flips it gives $\frac{11}{12}$, not 1: a few flips never make you certain.

</details>

**H4. (Hard, 10.1 and 10.5)** Two friends arrive at a cafe at independent uniform
times between 12:00 and 13:00. Each waits 15 minutes for the other, then leaves.
What is the probability that they meet?

<details>
<summary>Answer</summary>

Measure time in hours after 12:00, so $X, Y \overset{\text{iid}}{\sim} \text{Unif}(0, 1)$ and, by independence, the joint density is $1$ on the unit square. They meet when $\lvert X - Y \rvert \le \frac{1}{4}$. The region where they do **not** meet is two corner triangles, $y \gt x + \frac{1}{4}$ and $y \lt x - \frac{1}{4}$, each with legs of length $\frac{3}{4}$. With density 1, probability = area:

$$P(\text{meet}) = 1 - 2 \cdot \tfrac{1}{2} \left( \tfrac{3}{4} \right)^2 = 1 - \tfrac{9}{16} = \tfrac{7}{16} = 0.4375$$

</details>

## Simulation Projects

**S1. (10.1, 10.3, 10.4, 10.5)** Sample one million features from the bug table of
C1. Estimate both marginals, the conditional distribution of $Y$ given $X = 2$, and
$P(X = Y)$. Then compare $P(X = 0, Y = 0)$ with $P(X = 0) P(Y = 0)$.

<details>
<summary>Answer</summary>

```python
import numpy as np

rng = np.random.default_rng(42)
n_trials = 1_000_000

# Joint table of (bugs found in review X, bugs found in testing Y).
table = np.array([[0.20, 0.10, 0.05],
                  [0.10, 0.15, 0.10],
                  [0.05, 0.10, 0.15]])
cell = rng.choice(9, size=n_trials, p=table.ravel())
x, y = cell // 3, cell % 3                     # row index, column index

print("p_X simulated:", np.round(np.bincount(x) / n_trials, 4), " exact:", table.sum(axis=1))
print("p_Y simulated:", np.round(np.bincount(y) / n_trials, 4), " exact:", table.sum(axis=0))
cond = np.bincount(y[x == 2], minlength=3) / np.sum(x == 2)
print("Y | X=2 simulated:", np.round(cond, 4), " exact:", np.round(table[2] / table[2].sum(), 4))
print(f"P(X = Y): simulation {np.mean(x == y):.4f}, exact {np.trace(table):.4f}")
print(f"P(X=0, Y=0) = {np.mean((x == 0) & (y == 0)):.4f}, "
      f"P(X=0) P(Y=0) = {np.mean(x == 0) * np.mean(y == 0):.4f}")
```

Output:

```text
p_X simulated: [0.3499 0.35   0.3   ]  exact: [0.35 0.35 0.3 ]
p_Y simulated: [0.3501 0.3502 0.2997]  exact: [0.35 0.35 0.3 ]
Y | X=2 simulated: [0.1665 0.3338 0.4997]  exact: [0.1667 0.3333 0.5   ]
P(X = Y): simulation 0.5000, exact 0.5000
P(X=0, Y=0) = 0.1999, P(X=0) P(Y=0) = 0.1225
```

The last line shows the dependence: the joint cell is far from the product of the marginals.

</details>

**S2. (10.4)** Check the Poisson thinning result of H1 with $\lambda = 10$ and
$p = 0.3$: compare the simulated PMF of $S$ with $\text{Pois}(3)$ for $k = 0, \dots, 6$.

<details>
<summary>Answer</summary>

```python
import numpy as np
from scipy.stats import poisson

rng = np.random.default_rng(42)
n_trials = 1_000_000
lam, p = 10, 0.3

# N emails arrive, each one is spam with probability p, independently.
n_emails = rng.poisson(lam, n_trials)
n_spam = rng.binomial(n_emails, p)

print(" k   simulated   Pois(3) exact")
for k in range(7):
    print(f"{k:2d}   {np.mean(n_spam == k):.4f}      {poisson.pmf(k, lam * p):.4f}")
```

Output:

```text
 k   simulated   Pois(3) exact
 0   0.0499      0.0498
 1   0.1498      0.1494
 2   0.2246      0.2240
 3   0.2235      0.2240
 4   0.1678      0.1680
 5   0.1007      0.1008
 6   0.0502      0.0504
```

</details>
