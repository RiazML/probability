# 10.5 Independence of Random Variables

[Probability](../README.md) / [Module 10: Joint Distributions](README.md) / 10.5 Independence of Random Variables

**Level:** 3 (Many Variables) · **Time:** about 45 minutes · **Before this:** [10.4 Conditional Distributions](10.4-Conditional-Distributions.md)

> **Big idea:** Two random variables are independent when their joint distribution is the product of their marginals, so learning one tells you nothing about the other.

---

## Why It Matters

Independence is the assumption that makes many-variable problems easy. If the
variables are independent, the joint distribution is just the product of the
marginals, so you need only one-variable facts. Almost every model you will meet
assumes it somewhere: repeated coin flips, independent errors in measurements, the
"naive" in naive Bayes. Knowing how to **check** it, and how it can fail, keeps you
from using a wrong model.

## Intuition

You flip a coin and roll a die. Knowing the coin shows heads does not change the
chance that the die shows 6: it is still $\frac{1}{6}$. In the joint table of (coin,
die), every row looks the same after rescaling. So each cell is "row probability
times column probability": $\frac{1}{2} \times \frac{1}{6} = \frac{1}{12}$.

Now go back to the shop. Among customers with 1 item, 33% pay. Among customers with
3 items, 86% pay. The rows of the table look very different, so knowing $X$ changes
what you expect about $Y$. Cart size and paying are **dependent**.

So there are two ways to say the same thing. **Knowing $X$ does not change the
distribution of $Y$.** Or: **every cell equals its row total times its column total.**

## Picture

```text
   INDEPENDENT (cell = row total x column total)

              Y = 0   Y = 1  | P(X = x)
          +-------+-------+  |
   X = 1  | 0.12  | 0.18  |  |  0.30      0.12 = 0.30 x 0.40
   X = 2  | 0.14  | 0.21  |  |  0.35      0.21 = 0.35 x 0.60
   X = 3  | 0.14  | 0.21  |  |  0.35      every row is 40 : 60
          +-------+-------+  |
   P(Y=y)   0.40    0.60

   DEPENDENT (the real shop table, same margins)

              Y = 0   Y = 1  | P(X = x)
          +-------+-------+  |
   X = 1  | 0.20  | 0.10  |  |  0.30      0.20 is not 0.30 x 0.40 = 0.12
   X = 2  | 0.15  | 0.20  |  |  0.35      rows are 67:33, 43:57, 14:86
   X = 3  | 0.05  | 0.30  |  |  0.35
          +-------+-------+  |
   P(Y=y)   0.40    0.60
```

Both tables have the same marginals. Only in the top one is every cell the product of its margins.

## Definition

Random variables $X$ and $Y$ are **independent**, written $X \perp Y$, if for all
sets $A$ and $B$ of real numbers:

$$
P(X \in A, \ Y \in B) = P(X \in A) \thinspace P(Y \in B)
$$

**In words:** every event about $X$ is independent of every event about $Y$, in the
sense of [4.7 Independence](../04-CONDITIONAL-PROBABILITY-AND-BAYES/4.7-Independence.md).

In practice you check one of these equivalent conditions:

| Case | $X \perp Y$ if and only if, for all $x$ and $y$ |
|---|---|
| Any variables | $F_{X,Y}(x, y) = F_X(x) \thinspace F_Y(y)$ |
| Discrete | $p_{X,Y}(x, y) = p_X(x) \thinspace p_Y(y)$ |
| Continuous | $f_{X,Y}(x, y) = f_X(x) \thinspace f_Y(y)$ |
| Using conditionals | $p_{Y \mid X}(y \mid x) = p_Y(y)$, or $f_{Y \mid X}(y \mid x) = f_Y(y)$ |

(For densities, "for all" may ignore a set of zero area, which does not change any
probability.)

**In words:** the joint is the product of the marginals, or, the same thing,
conditioning on $X$ does not change the distribution of $Y$.

**The factorization test.** For a joint density (or PMF), if you can write

$$
f_{X,Y}(x, y) = g(x) \thinspace h(y) \quad \text{for all } x \text{ and } y
$$

for some functions $g$ and $h$, then $X \perp Y$. Here, *for all* $x$ and $y$
includes the points where $f = 0$. So the **support** (the region where $f \gt 0$)
must be a rectangle, possibly infinite, such as $(0, \infty) \times (0, \infty)$.

To show **dependence**, one pair $(x, y)$ where $f_{X,Y}(x, y) \ne f_X(x) f_Y(y)$ is
enough (for a density, it must fail on a region with positive area).

## Why It Is True

**Conditionals.** If $p_{X,Y} = p_X \thinspace p_Y$, then for every $x$ with $p_X(x) \gt 0$:
$p_{Y \mid X}(y \mid x) = \frac{p_X(x) p_Y(y)}{p_X(x)} = p_Y(y)$. The steps also run
backward, so the two conditions are the same.

**The factorization test.** Suppose $f(x, y) = g(x) h(y)$ everywhere. Let
$G = \int g(x) \thinspace dx$ and $H = \int h(y) \thinspace dy$. Then:

$$
\begin{aligned}
1 &= \iint g(x) h(y) \thinspace dx \thinspace dy = G H && \text{(total probability)} \\
f_X(x) &= \int g(x) h(y) \thinspace dy = g(x) H && \text{(marginal of } X \text{)} \\
f_Y(y) &= \int g(x) h(y) \thinspace dx = h(y) G && \text{(marginal of } Y \text{)} \\
f_X(x) f_Y(y) &= g(x) h(y) \cdot GH = g(x) h(y) = f(x, y) && \text{(since } GH = 1 \text{)}
\end{aligned}
$$

So the joint is the product of the marginals. Note where the rectangle shape was
used: the integral over $y$ in the second line ran over the same range for every $x$.

**Functions of independent variables are independent.** If $X \perp Y$, then
$g(X) \perp h(Y)$ for any functions $g$ and $h$. The event $\lbrace g(X) \in A \rbrace$ is
an event about $X$: it is $\lbrace X \in A' \rbrace$ where $A' = \lbrace x : g(x) \in A \rbrace$.
In the same way $\lbrace h(Y) \in B \rbrace = \lbrace Y \in B' \rbrace$. By the definition,
$P(X \in A', Y \in B') = P(X \in A') P(Y \in B')$. For example, $X^2$ and $e^Y$ are
independent when $X$ and $Y$ are.

## Worked Examples

### Example 1: Checking a Table

**Problem.** In the 2 by 2 table $p(0, 0) = 0.10$, $p(0, 1) = 0.20$,
$p(1, 0) = 0.30$, $p(1, 1) = 0.40$, are $X$ and $Y$ independent?

**Solution.**

1. Marginals: $p_X(0) = 0.10 + 0.20 = 0.30$, $p_X(1) = 0.70$; $p_Y(0) = 0.10 + 0.30 = 0.40$, $p_Y(1) = 0.60$.
2. Test the first cell:

$$
p_X(0) \thinspace p_Y(0) = 0.30 \times 0.40 = 0.12 \ne 0.10 = p(0, 0)
$$

**Answer.** One cell fails, so $X$ and $Y$ are **dependent**.

**Check.** With conditionals: $P(Y = 1 \mid X = 0) = \frac{0.20}{0.30} \approx 0.667$ but
$P(Y = 1 \mid X = 1) = \frac{0.40}{0.70} \approx 0.571$. Knowing $X$ changes the chance
that $Y = 1$.

### Example 2: Two Servers Racing

**Problem.** Two servers answer the same request. Their response times (in seconds)
have joint density $f(x, y) = 6e^{-2x - 3y}$ for $x, y \gt 0$. Are $X$ and $Y$
independent? Find the probability that server 1 answers first.

**Solution.**

1. Factor the density: $6e^{-2x - 3y} = \left( 2e^{-2x} \right) \left( 3e^{-3y} \right)$. The support
   $(0, \infty) \times (0, \infty)$ is a rectangle. By the factorization test, $X \perp Y$,
   with $X \sim \text{Exp}(2)$ and $Y \sim \text{Exp}(3)$ (rates 2 and 3, so means $\frac{1}{2}$
   and $\frac{1}{3}$ second).
2. "Server 1 first" is $X \lt Y$. For a fixed $x$, use independence:
   $P(Y \gt x) = e^{-3x}$. Then integrate over $x$:

$$
P(X \lt Y) = \int_0^{\infty} 2e^{-2x} \cdot e^{-3x} \thinspace dx = 2 \int_0^{\infty} e^{-5x} \thinspace dx = \frac{2}{5} = 0.4
$$

**Answer.** Yes, they are independent, and server 1 wins with probability $0.4$.

**Check.** Server 2 is faster on average (rate 3 against rate 2), so server 1 should
win less than half the time. In general, for independent exponentials,
$P(X \lt Y) = \frac{\lambda_1}{\lambda_1 + \lambda_2}$.

### Example 3: Two Traps

**Problem.** Are $X$ and $Y$ independent for (a) $f(x, y) = 8xy$ on the triangle
$0 \lt y \lt x \lt 1$, (b) a uniform point on the unit disk?

**Solution.**

1. (a) The formula $8xy$ looks like $g(x) h(y)$, but the support is a triangle, not a
   rectangle. From [10.3](10.3-Marginal-Distributions.md), $f_X(x) = 4x^3$ and
   $f_Y(y) = 4y(1 - y^2)$. At the point $(0.5, 0.25)$:

$$
f_X(0.5) f_Y(0.25) = 0.5 \times 0.9375 = 0.46875 \ne 1 = 8 \times 0.5 \times 0.25 = f(0.5, 0.25)
$$

   Also, near the point $(0.25, 0.5)$ the joint is 0 (it is above the diagonal), but
   the product of the marginals is positive. So they are dependent.
2. (b) Take the square $0.75 \lt x, y \lt 1$. Its points have $x^2 + y^2 \gt 0.5625 + 0.5625 = 1.125 \gt 1$,
   so it lies outside the disk and $P(X \gt 0.75, Y \gt 0.75) = 0$. But
   $P(X \gt 0.75) \gt 0$ and $P(Y \gt 0.75) \gt 0$, so their product is positive.

**Answer.** Both pairs are **dependent**.

**Check.** In both cases the shape of the region links the variables: on the triangle
$Y \lt X$, and on the disk a large $\lvert X \rvert$ forces a small $\lvert Y \rvert$.
A support that is not a rectangle always means dependence.

## Simulate It

The code compares the joint probability with the product of the marginals, for the
independent servers of Example 2 and for the dependent disk of Example 3.

```python
import numpy as np

rng = np.random.default_rng(42)
n_trials = 1_000_000

# Independent: X ~ Exp(2) and Y ~ Exp(3), drawn separately.
x = rng.exponential(1 / 2, n_trials)
y = rng.exponential(1 / 3, n_trials)
joint = np.mean((x <= 0.5) & (y <= 0.2))
product = np.mean(x <= 0.5) * np.mean(y <= 0.2)
exact = (1 - np.exp(-1)) * (1 - np.exp(-0.6))
print(f"Exp pair:  P(X<=0.5, Y<=0.2) = {joint:.4f}, product = {product:.4f}, exact {exact:.4f}")
print(f"Exp pair:  P(X < Y) = {np.mean(x < y):.4f}, exact {2 / 5:.4f}")

# Dependent: a uniform point in the unit disk.
u = rng.uniform(-1, 1, n_trials)
v = rng.uniform(-1, 1, n_trials)
inside = u**2 + v**2 <= 1
u, v = u[inside], v[inside]
joint = np.mean((u > 0.75) & (v > 0.75))
product = np.mean(u > 0.75) * np.mean(v > 0.75)
print(f"Disk:      P(X>0.75, Y>0.75) = {joint:.4f}, product = {product:.4f}")
```

Output:

```text
Exp pair:  P(X<=0.5, Y<=0.2) = 0.2856, product = 0.2855, exact 0.2852
Exp pair:  P(X < Y) = 0.3992, exact 0.4000
Disk:      P(X>0.75, Y>0.75) = 0.0000, product = 0.0052
```

For the servers, joint and product agree. For the disk the joint is exactly 0 while
the product is about $0.005$, so the product rule fails.

## Common Mistakes

- **Checking only one cell and saying "independent".** One matching cell proves
  nothing. Independence needs **every** cell to match. Dependence needs only one
  failure.
- **Forgetting the support in the factorization test.** $8xy$ on a triangle is not
  independent, even though the formula splits. Check that the region is a rectangle.
- **Mixing up independent and mutually exclusive.** If two events cannot happen
  together, they are strongly **dependent**: learning one happened tells you the
  other did not.
- **Thinking "uncorrelated" means "independent".** Independence is much stronger
  than zero covariance. See
  [11.4 Uncorrelated vs Independent](../11-COVARIANCE-AND-CORRELATION/11.4-Uncorrelated-vs-Independent.md).
- **Assuming independence because it is convenient.** Two servers in the same data
  center may fail together (same power, same network). Check with data.

## Where It Is Used

- **AI and machine learning:** naive Bayes assumes the features are independent
  given the class
  ([21.1.1 Probabilistic Classifiers and Naive Bayes](../21-APPLICATIONS-OF-PROBABILITY/21.1-AI-and-Machine-Learning/21.1.1-Probabilistic-Classifiers-and-Naive-Bayes.md)).
  This turns one huge joint table into many small ones.
- **Computer science:** a good hash function makes the bucket of each key behave
  like an independent random choice. Randomized algorithms use independent random bits.
- **Statistics:** many methods assume independent observations
  ([10.6 IID](10.6-IID.md)), and fail badly when the data are dependent.
- **Reliability:** redundant backups help only if their failures are close to
  independent.
- **Everyday life:** a coin has no memory. After five heads in a row, the next flip is
  still 50-50, because the flips are independent.

## Practice

**1. (Easy)** Is this table independent? $p(0, 0) = 0.12$, $p(0, 1) = 0.28$,
$p(1, 0) = 0.18$, $p(1, 1) = 0.42$.

<details>
<summary>Answer</summary>

Marginals: $p_X(0) = 0.40$, $p_X(1) = 0.60$, $p_Y(0) = 0.30$, $p_Y(1) = 0.70$. Check every cell:

$$0.40 \times 0.30 = 0.12, \quad 0.40 \times 0.70 = 0.28, \quad 0.60 \times 0.30 = 0.18, \quad 0.60 \times 0.70 = 0.42$$

All four match, so $X \perp Y$.

</details>

**2. (Easy)** $X$ and $Y$ are two independent fair dice. Find $P(X \le 2, Y \ge 5)$.

<details>
<summary>Answer</summary>

$$P(X \le 2, Y \ge 5) = P(X \le 2) \thinspace P(Y \ge 5) = \tfrac{2}{6} \cdot \tfrac{2}{6} = \tfrac{1}{9}$$

</details>

**3. (Medium)** Let $f(x, y) = 4xy$ on the unit square. Are $X$ and $Y$ independent?
Find $P(X \le \frac{1}{2}, Y \le \frac{1}{2})$.

<details>
<summary>Answer</summary>

$4xy = (2x)(2y)$ and the support is the square, so yes, with $f_X(x) = 2x$ and $f_Y(y) = 2y$. Then $P(X \le \frac{1}{2}) = \int_0^{1/2} 2x \thinspace dx = \frac{1}{4}$, and the same for $Y$:

$$P(X \le \tfrac{1}{2}, Y \le \tfrac{1}{2}) = \tfrac{1}{4} \cdot \tfrac{1}{4} = \tfrac{1}{16}$$

</details>

**4. (Medium)** A point is uniform on the triangle $0 \lt y \lt x \lt 1$ (density 2).
Show that $X$ and $Y$ are dependent in two different ways.

<details>
<summary>Answer</summary>

Way 1: the marginals are $f_X(x) = 2x$ and $f_Y(y) = 2(1 - y)$. At $(0.5, 0.25)$ their product is $1 \times 1.5 = 1.5$, but the joint is 2.

Way 2: given $X = 0.1$, $Y$ must be below $0.1$. Without the condition, $Y$ can be up to 1. Knowing $X$ changes the distribution of $Y$.

</details>

**5. (Hard)** Let $X$ and $Y$ be independent fair bits (0 or 1, each with probability
$\frac{1}{2}$), and let $Z$ be "X XOR Y": $Z = 1$ when exactly one of them is 1.
Show that $X \perp Z$. Is $Z$ independent of the pair $(X, Y)$?

<details>
<summary>Answer</summary>

$Z = 1$ happens for $(X, Y) = (0, 1)$ or $(1, 0)$, so $P(Z = 1) = \frac{1}{2}$. Now each cell of the $(X, Z)$ table has one $(X, Y)$ pair behind it. For example:

$$P(X = 1, Z = 1) = P(X = 1, Y = 0) = \tfrac{1}{4} = \tfrac{1}{2} \cdot \tfrac{1}{2} = P(X = 1) P(Z = 1)$$

The other three cells work the same way, so $X \perp Z$ (and by symmetry $Y \perp Z$). But $Z$ is **not** independent of the pair: given $X = 1$ and $Y = 1$, $Z = 0$ for sure. This is pairwise but not mutual independence, see [4.8 Pairwise vs Mutual Independence](../04-CONDITIONAL-PROBABILITY-AND-BAYES/4.8-Pairwise-vs-Mutual-Independence.md).

</details>

**6. (Simulate)** Check Practice 5 by simulation.

<details>
<summary>Answer</summary>

```python
import numpy as np

rng = np.random.default_rng(42)
n_trials = 1_000_000

# X and Y are independent fair bits; Z = X XOR Y.
x = rng.integers(0, 2, n_trials)
y = rng.integers(0, 2, n_trials)
z = x ^ y

for a in [0, 1]:
    for b in [0, 1]:
        print(f"P(X={a}, Z={b}) = {np.mean((x == a) & (z == b)):.4f}   (exact 0.2500)")
print(f"P(Z=1 | X=1, Y=1) = {np.mean(z[(x == 1) & (y == 1)] == 1):.4f}   (P(Z=1) = 0.5)")
```

Output:

```text
P(X=0, Z=0) = 0.2499   (exact 0.2500)
P(X=0, Z=1) = 0.2503   (exact 0.2500)
P(X=1, Z=0) = 0.2496   (exact 0.2500)
P(X=1, Z=1) = 0.2502   (exact 0.2500)
P(Z=1 | X=1, Y=1) = 0.0000   (P(Z=1) = 0.5)
```

</details>

## Summary

- $X \perp Y$ means every event about $X$ is independent of every event about $Y$.
- Test: the joint equals the product of the marginals for **every** pair $(x, y)$.
  Equivalently, the conditional of $Y$ given $X = x$ does not depend on $x$.
- Factorization test: $f(x, y) = g(x) h(y)$ on a **rectangle** support means independent.
- A support that is not a rectangle (a triangle, a disk) always means dependent.
- Functions of independent variables are independent.

The one formula to remember:

$$
\boxed{X \perp Y \iff f_{X,Y}(x, y) = f_X(x) \thinspace f_Y(y) \text{ for all } x, y}
$$
