# 14.2 Conditional Expectation as a Random Variable

[Probability](../README.md) / [Module 14: Conditional Expectation](README.md) / 14.2 Conditional Expectation as a Random Variable

**Level:** 3 (Many Variables) · **Time:** about 50 minutes · **Before this:** [14.1 Conditional Expectation Given a Value](14.1-Conditional-Expectation-Given-a-Value.md)

> **Big idea:** $E[Y \mid X]$ is the random variable you get by replacing $Y$, in every outcome, with the average of $Y$ over all outcomes that have the same value of $X$.

---

## Why It Matters

In [14.1](14.1-Conditional-Expectation-Given-a-Value.md) we computed one number,
$E[Y \mid X = x]$, for one value $x$. But before the experiment you do not know
which $x$ you will see. So your best average for $Y$ is itself uncertain: it
depends on the $X$ that will come out. Treating $E[Y \mid X]$ as a **random
variable** is the key step of this module. It lets us average it
([14.3](14.3-Law-of-Total-Expectation.md)), measure its spread
([14.4](14.4-Law-of-Total-Variance.md)) and use it as a prediction rule
([14.5](14.5-Best-Predictor-Under-Squared-Error.md)).

## Intuition

Roll a fair die. Let $Y$ be the roll. A friend will tell you only whether the roll
is even. Write $X = 1$ for even and $X = 0$ for odd. Here is every outcome:

| Outcome | Probability | $X$ (even?) | $Y$ (roll) | $E[Y \mid X]$ |
|---|---|---|---|---|
| 1 | 1/6 | 0 | 1 | 3 |
| 2 | 1/6 | 1 | 2 | 4 |
| 3 | 1/6 | 0 | 3 | 3 |
| 4 | 1/6 | 1 | 4 | 4 |
| 5 | 1/6 | 0 | 5 | 3 |
| 6 | 1/6 | 1 | 6 | 4 |

The last column is built in two steps:

1. Group the outcomes by $X$. The odd group is $\lbrace 1, 3, 5 \rbrace$, with average
   $3$. The even group is $\lbrace 2, 4, 6 \rbrace$, with average $4$.
2. In every row, write the average of the row's own group.

The last column is a new random variable. Like any random variable it gives a
number for each outcome. It takes the value 3 with probability $\frac{1}{2}$ and
the value 4 with probability $\frac{1}{2}$. And it depends on the outcome **only
through $X$**: rows with the same $X$ always get the same number. Here it is
$3 + X$.

Now change the information. Suppose the friend tells you instead whether the roll
is high: $W = 1$ for a roll of 4, 5 or 6 and $W = 0$ for 1, 2 or 3.

| Outcome | 1 | 2 | 3 | 4 | 5 | 6 |
|---|---|---|---|---|---|---|
| $W$ (high?) | 0 | 0 | 0 | 1 | 1 | 1 |
| $E[Y \mid W]$ | 2 | 2 | 2 | 5 | 5 | 5 |

The same $Y$ gives a different column, because the groups are different.
**$E[Y \mid X]$ depends on what you are told.**

## Picture

```text
   value          Y = roll                          E[Y | W]
     6 |                   #
     5 |                #  #                      #  #  #
     4 |             #  #  #                      #  #  #
     3 |          #  #  #  #                      #  #  #
     2 |       #  #  #  #  #             #  #  #  #  #  #
     1 |    #  #  #  #  #  #             #  #  #  #  #  #
       +----+--+--+--+--+--+--         +-+--+--+--+--+--+--
            1  2  3  4  5  6             1  2  3  4  5  6     outcome
            |- low -||- high-|           |- low -||- high-|
```

$E[Y \mid W]$ flattens $Y$ inside each group of $W$: the three low rolls all
become 2, and the three high rolls all become 5.

## Definition

Let $g(x) = E[Y \mid X = x]$ for each possible value $x$ of $X$. This $g$ is an
ordinary function. The **conditional expectation of $Y$ given $X$** is the random
variable

$$
E[Y \mid X] = g(X)
$$

where:

- $g(x) = E[Y \mid X = x]$ is computed as in [14.1](14.1-Conditional-Expectation-Given-a-Value.md), one number for each $x$,
- $g(X)$ means: run the experiment, see the value of $X$, and plug it into $g$.

**In words:** first find the average of $Y$ for every possible value of $X$; then
$E[Y \mid X]$ is the average that belongs to the value of $X$ that actually came out.

Keep these four objects apart. They look alike but they are different kinds of
things:

| Object | What it is | In the die example |
|---|---|---|
| $E[Y]$ | one number | $3.5$ |
| $E[Y \mid X = 1]$ | one number | $4$ |
| $g(x) = E[Y \mid X = x]$ | a function of $x$ | $g(0) = 3, \ g(1) = 4$, so $g(x) = 3 + x$ |
| $E[Y \mid X] = g(X)$ | a random variable | $3 + X$ |

The distribution of $E[Y \mid X]$ comes from the distribution of $X$, as for any
function of $X$ ([5.6 Functions of a Random Variable](../05-DISCRETE-RANDOM-VARIABLES/5.6-Functions-of-a-Random-Variable.md)):

$$
P\big(E[Y \mid X] = v\big) = \sum_{x : \thinspace g(x) = v} p_X(x)
$$

**In words:** $E[Y \mid X]$ takes the value $g(x)$ exactly as often as $X$ takes
the value $x$.

Four basic properties follow:

1. **It is a function of $X$.** It is constant on each set $\lbrace X = x \rbrace$.
2. **Independence gives a constant.** If $X$ and $Y$ are independent, then $E[Y \mid X] = E[Y]$.
3. **Known things stay.** For any function $h$, $E[h(X) \mid X] = h(X)$.
4. **Only the information matters.** If $\varphi$ is one-to-one, then $E[Y \mid \varphi(X)] = E[Y \mid X]$.

## Why It Is True

**1. A function of $X$.** By definition $E[Y \mid X] = g(X)$, and $g(X)$ is a
function of $X$. On the set $\lbrace X = x \rbrace$ it equals the fixed number $g(x)$.

**2. Independence.** If $X$ and $Y$ are independent, then
$P(Y = y \mid X = x) = P(Y = y)$ for every $x$
([10.5 Independence of Random Variables](../10-JOINT-DISTRIBUTIONS/10.5-Independence-of-Random-Variables.md)).
So, for every $x$:

$$
g(x) = \sum_{y} y \thinspace P(Y = y \mid X = x) = \sum_{y} y \thinspace P(Y = y) = E[Y]
$$

The function $g$ is the constant $E[Y]$, so $g(X) = E[Y]$. Knowing $X$ tells you
nothing about $Y$, so your average does not move.

**3. Known things stay.** Given $X = x$, the value $h(X)$ is the fixed number
$h(x)$, with conditional probability 1. The average of a constant is that
constant, so $E[h(X) \mid X = x] = h(x)$ for every $x$, which means
$E[h(X) \mid X] = h(X)$.

**4. Only the information matters.** Let $Z = \varphi(X)$ with $\varphi$ one-to-one.
Then the events $\lbrace Z = \varphi(x) \rbrace$ and $\lbrace X = x \rbrace$ are the
same event. So the averages over them are equal:
$E[Y \mid Z = \varphi(x)] = E[Y \mid X = x]$. In every outcome, $E[Y \mid Z]$ and
$E[Y \mid X]$ therefore give the same number. Relabeling the groups changes nothing.
(If $\varphi$ is **not** one-to-one, it merges groups, and the averages can change.
See Practice 5.)

## Worked Examples

### Example 1: The Larger of Two Dice

**Problem.** Roll two fair dice. Let $X$ be the first die and $M$ the larger of the
two. Find $E[M \mid X]$ as a formula in $X$, and give its distribution.

**Solution.**

1. Fix $X = x$. The second die $D$ is still uniform on 1 to 6. If $D \le x$
   (that happens for $x$ of the 6 faces), the maximum is $x$. If $D \gt x$, the
   maximum is $D$.
2. So the conditional average is

$$
g(x) = \frac{1}{6} \Big( x \cdot x + \sum_{k = x + 1}^{6} k \Big) = \frac{1}{6} \Big( x^2 + 21 - \frac{x(x + 1)}{2} \Big) = \frac{x^2 - x + 42}{12}
$$

   using $1 + 2 + \dots + x = \frac{x(x+1)}{2}$, so the sum from $x + 1$ to 6 is
   $21 - \frac{x(x+1)}{2}$.
3. Evaluate it at each $x$:

| $x$ | 1 | 2 | 3 | 4 | 5 | 6 |
|---|---|---|---|---|---|---|
| $g(x) = E[M \mid X = x]$ | 3.5 | 3.667 | 4 | 4.5 | 5.167 | 6 |

4. Each value of $X$ has probability $\frac{1}{6}$, and the six values of $g$ are
   different. So $E[M \mid X]$ takes each value in the table with probability $\frac{1}{6}$.

**Answer.** $E[M \mid X] = \dfrac{X^2 - X + 42}{12}$, a random variable with six
equally likely values from $3.5$ to $6$.

**Check.** If the first die shows 6, the maximum is surely 6: $g(6) = \frac{36 - 6 + 42}{12} = 6$.
If it shows 1, the maximum is just the second die, with mean $3.5$: $g(1) = \frac{42}{12} = 3.5$.

### Example 2: Who Pays at the Shop

**Problem.** In the shop of
[10.4](../10-JOINT-DISTRIBUTIONS/10.4-Conditional-Distributions.md), $X$ is the
number of items in the cart and $Y = 1$ if the customer pays. The joint table is:

| | $Y = 0$ | $Y = 1$ | $p_X(x)$ |
|---|---|---|---|
| $X = 1$ | 0.20 | 0.10 | 0.30 |
| $X = 2$ | 0.15 | 0.20 | 0.35 |
| $X = 3$ | 0.05 | 0.30 | 0.35 |

Find the random variable $E[Y \mid X]$ and its distribution.

**Solution.**

1. $Y$ is an indicator, so its conditional mean is a conditional probability:
   $g(x) = 0 \cdot P(Y = 0 \mid X = x) + 1 \cdot P(Y = 1 \mid X = x) = P(Y = 1 \mid X = x)$.
2. Divide the $Y = 1$ cell of each row by the row sum:

$$
g(1) = \frac{0.10}{0.30} = \frac{1}{3}, \qquad g(2) = \frac{0.20}{0.35} = \frac{4}{7}, \qquad g(3) = \frac{0.30}{0.35} = \frac{6}{7}
$$

3. $E[Y \mid X]$ takes these values exactly when $X$ takes $1, 2, 3$:

| Value of $E[Y \mid X]$ | $\frac{1}{3} \approx 0.333$ | $\frac{4}{7} \approx 0.571$ | $\frac{6}{7} \approx 0.857$ |
|---|---|---|---|
| Probability | 0.30 | 0.35 | 0.35 |

**Answer.** $E[Y \mid X] = P(Y = 1 \mid X)$, the chance that this customer pays
given the cart size. It has the distribution in the last table.

**Check.** Its mean is $0.30 \cdot \frac{1}{3} + 0.35 \cdot \frac{4}{7} + 0.35 \cdot \frac{6}{7} = 0.10 + 0.20 + 0.30 = 0.60$,
which equals $P(Y = 1) = 0.10 + 0.20 + 0.30$. This is the law of total
expectation of [14.3](14.3-Law-of-Total-Expectation.md).

### Example 3: A Group Average Column in Data

**Problem.** A shop has 8 customers from three cities. The amount each one spent
($Y$, in hundreds of taka) is in the table. Pick one customer at random. Let $X$ be
their city. Find the column $E[Y \mid X]$.

| Customer | 1 | 2 | 3 | 4 | 5 | 6 | 7 | 8 |
|---|---|---|---|---|---|---|---|---|
| City $X$ | Dhaka | Dhaka | Sylhet | Dhaka | Sylhet | Khulna | Sylhet | Khulna |
| Spent $Y$ | 30 | 50 | 20 | 40 | 40 | 60 | 30 | 40 |
| $E[Y \mid X]$ | 40 | 40 | 30 | 40 | 30 | 50 | 30 | 50 |

**Solution.**

1. Each customer has probability $\frac{1}{8}$, so a conditional average is a plain
   average inside the group.
2. Dhaka (customers 1, 2, 4): $\frac{30 + 50 + 40}{3} = \frac{120}{3} = 40$.
3. Sylhet (customers 3, 5, 7): $\frac{20 + 40 + 30}{3} = \frac{90}{3} = 30$.
4. Khulna (customers 6, 8): $\frac{60 + 40}{2} = \frac{100}{2} = 50$.
5. Write the group average in every row. That is the last row of the table.

**Answer.** $E[Y \mid X]$ is 40 for Dhaka customers, 30 for Sylhet and 50 for
Khulna. As a random variable it takes 40 and 30 with probability $\frac{3}{8}$
each, and 50 with probability $\frac{2}{8}$.

**Check.** The average of the last row is $\frac{3(40) + 3(30) + 2(50)}{8} = \frac{310}{8} = 38.75$.
The average of $Y$ is $\frac{30 + 50 + 20 + 40 + 40 + 60 + 30 + 40}{8} = \frac{310}{8} = 38.75$.
They agree. In machine learning this new column is called **target encoding**:
a city name is replaced by the average target of its group.

### Example 4: A Continuous Case

**Problem.** Let $X \sim \text{Unif}(0, 1)$ and, given $X = x$, let
$Y \sim \text{Unif}(0, x)$. Find $E[Y \mid X]$ and its distribution.

**Solution.**

1. From [14.1](14.1-Conditional-Expectation-Given-a-Value.md), Example 3, $g(x) = \frac{x}{2}$.
2. So $E[Y \mid X] = \frac{X}{2}$.
3. Halving a $\text{Unif}(0, 1)$ variable gives a $\text{Unif}(0, \frac{1}{2})$
   variable.

**Answer.** $E[Y \mid X] = \frac{X}{2} \sim \text{Unif}(0, \frac{1}{2})$.

**Check.** $Y$ itself is not uniform (its density is $-\ln y$, from 10.4). But its
conditional mean is a simple linear function of $X$. $E[Y \mid X]$ is smoother than
$Y$: it keeps only the part of $Y$ that $X$ can explain.

## Simulate It

The code builds the random variable $E[M \mid X]$ of Example 1 from data. It
estimates $g(x)$ by averaging $M$ inside each group, then plugs in each trial's $X$.

```python
import numpy as np

rng = np.random.default_rng(42)
n_trials = 1_000_000

# First die X, second die D, and the larger one M.
x = rng.integers(1, 7, size=n_trials)
d = rng.integers(1, 7, size=n_trials)
m = np.maximum(x, d)

# g(v) = E[M | X = v]: the average of M inside the group X = v.
values = np.arange(1, 7)
g_hat = np.array([m[x == v].mean() for v in values])
g_exact = (values**2 - values + 42) / 12
for v in values:
    print(f"E[M | X = {v}]: simulation {g_hat[v - 1]:.4f}, exact {g_exact[v - 1]:.4f}")

# The random variable E[M | X] = g(X): one number per trial, constant within groups.
cond_mean = g_hat[x - 1]
print(f"Distinct values of E[M | X]: {len(np.unique(cond_mean))}")
print(f"Mean of E[M | X]: {cond_mean.mean():.4f},  mean of M: {m.mean():.4f}")
```

Output:

```text
E[M | X = 1]: simulation 3.5061, exact 3.5000
E[M | X = 2]: simulation 3.6681, exact 3.6667
E[M | X = 3]: simulation 3.9980, exact 4.0000
E[M | X = 4]: simulation 4.4980, exact 4.5000
E[M | X = 5]: simulation 5.1653, exact 5.1667
E[M | X = 6]: simulation 6.0000, exact 6.0000
Distinct values of E[M | X]: 6
Mean of E[M | X]: 4.4715,  mean of M: 4.4715
```

The random variable $E[M \mid X]$ has only 6 values, one per group. Its mean equals
the mean of $M$, about $\frac{161}{36} \approx 4.472$. The next topic proves that this
always happens.

## Common Mistakes

- **Treating $E[Y \mid X]$ as a number.** $E[Y \mid X = 2]$ is a number;
  $E[Y \mid X]$ is a random variable. Before the experiment, you do not know its value.
- **Thinking $E[Y \mid X]$ is a function of $Y$.** It is a function of $X$ only. Two
  outcomes with the same $X$ always get the same value, even if their $Y$ values differ.
- **Swapping the roles.** $E[Y \mid X]$ is a function of $X$, while $E[X \mid Y]$ is
  a function of $Y$. In the dice example $E[X_1 \mid S] = \frac{S}{2}$, but
  $E[S \mid X_1] = X_1 + 3.5$.
- **Thinking a constant $E[Y \mid X]$ means independence.** Independence gives a
  constant, but the reverse is false (Practice 4).
- **Thinking any relabeling of $X$ is harmless.** A one-to-one relabeling keeps the
  groups. A function that merges groups, such as $X^2$, can change the answer.

## Where It Is Used

- **AI and machine learning:** the **regression function** $x \mapsto E[Y \mid X = x]$
  is what a model trained with squared error tries to learn. Target encoding of
  categories (Example 3) computes $E[Y \mid X]$ directly from data.
- **Reinforcement learning:** the **value function** $V(s) = E[\text{future reward} \mid \text{state} = s]$
  is a conditional expectation; $V(S)$ is a random variable because the state $S$ is random
  ([21.1.5 Reinforcement Learning](../21-APPLICATIONS-OF-PROBABILITY/21.1-AI-and-Machine-Learning/21.1.5-Reinforcement-Learning.md)).
- **Classification:** for a 0/1 label, $E[Y \mid X] = P(Y = 1 \mid X)$, the
  probability that a good classifier outputs (Example 2).
- **Finance:** the price of an asset today is often the conditional expectation
  of a future payoff given today's information, which changes from day to day.
- **Martingales:** a fair game is defined by $E[M_{n+1} \mid \text{past}] = M_n$
  ([20.8 Martingales](../20-ADVANCED-PROBABILITY/20.8-Martingales.md)).

## Practice

**1. (Easy)** For the laptop table of
[14.1](14.1-Conditional-Expectation-Given-a-Value.md) ($E[Y \mid X = 1] = 0.5$,
$E[Y \mid X = 2] = 1.2$, $p_X(1) = p_X(2) = 0.5$), write $E[Y \mid X]$ as a linear
formula in $X$ and give its distribution.

<details>
<summary>Answer</summary>

We need $a + b \cdot 1 = 0.5$ and $a + b \cdot 2 = 1.2$, so $b = 0.7$ and $a = -0.2$:

$$E[Y \mid X] = 0.7X - 0.2$$

It takes the values $0.5$ and $1.2$, each with probability $0.5$.

</details>

**2. (Easy)** $X$ is the number of emails you get today and $Y \sim \text{Pois}(3)$
is the number of phone calls (here 3 is the rate, which is also the mean). They are
independent. What is $E[Y \mid X]$?

<details>
<summary>Answer</summary>

By independence, $E[Y \mid X] = E[Y] = 3$. It is a constant random variable: knowing the number of emails does not change the average number of calls.

</details>

**3. (Medium)** Roll two fair dice $X_1, X_2$ and let $S = X_1 + X_2$. Find
$E[S \mid X_1]$ and $E[X_1 \mid S]$. What is $P(E[X_1 \mid S] = 3.5)$?

<details>
<summary>Answer</summary>

Given $X_1 = x$, $S = x + X_2$ with $X_2$ independent of $X_1$, so $E[S \mid X_1 = x] = x + 3.5$ and $E[S \mid X_1] = X_1 + 3.5$. From 14.1, $E[X_1 \mid S] = \frac{S}{2}$. It equals $3.5$ exactly when $S = 7$:

$$P(E[X_1 \mid S] = 3.5) = P(S = 7) = \frac{6}{36} = \frac{1}{6}$$

</details>

**4. (Medium)** $X$ is uniform on $\lbrace -1, 0, 1 \rbrace$ and $Y = X^2$. Find
$E[Y \mid X]$ and $E[X \mid Y]$. Are $X$ and $Y$ independent?

<details>
<summary>Answer</summary>

$Y$ is a function of $X$, so $E[Y \mid X] = X^2$. For the other one: given $Y = 0$, $X = 0$; given $Y = 1$, $X$ is $-1$ or $1$ with probability $\frac{1}{2}$ each, so the average is 0. Hence $E[X \mid Y] = 0$, a constant. But $X$ and $Y$ are **not** independent: $P(Y = 0 \mid X = 0) = 1$, while $P(Y = 0) = \frac{1}{3}$. A constant conditional mean does not imply independence.

</details>

**5. (Hard)** Let $X$ be uniform on $\lbrace -1, 1 \rbrace$ and $Y = X$. Compute
$E[Y \mid X]$, $E[Y \mid X^3]$ and $E[Y \mid X^2]$. Explain the difference using
groups of outcomes.

<details>
<summary>Answer</summary>

$E[Y \mid X] = X$ (property 3). The map $x \mapsto x^3$ is one-to-one, so the groups $\lbrace X = -1 \rbrace$ and $\lbrace X = 1 \rbrace$ stay the same and $E[Y \mid X^3] = X$ too. But $X^2 = 1$ always, so $X^2$ puts both outcomes into a single group. The average of $Y$ over that group is $\frac{-1 + 1}{2} = 0$:

$$E[Y \mid X^2] = 0$$

Merging groups throws away information, and the conditional mean becomes flatter.

</details>

**6. (Simulate)** Simulate Practice 4: draw $X$ uniform on $\lbrace -1, 0, 1 \rbrace$,
set $Y = X^2$, and estimate $E[X \mid Y = 0]$ and $E[X \mid Y = 1]$.

<details>
<summary>Answer</summary>

```python
import numpy as np

rng = np.random.default_rng(42)
x = rng.integers(-1, 2, size=1_000_000)   # uniform on -1, 0, 1
y = x**2
print(f"E[X | Y = 0]: simulation {x[y == 0].mean():.4f}, exact 0")
print(f"E[X | Y = 1]: simulation {x[y == 1].mean():.4f}, exact 0")
print(f"P(Y = 0 | X = 0) = {np.mean(y[x == 0] == 0):.4f}, but P(Y = 0) = {np.mean(y == 0):.4f}")
```

Output:

```text
E[X | Y = 0]: simulation 0.0000, exact 0
E[X | Y = 1]: simulation -0.0016, exact 0
P(Y = 0 | X = 0) = 1.0000, but P(Y = 0) = 0.3337
```

</details>

## Summary

- $g(x) = E[Y \mid X = x]$ is a function; $E[Y \mid X] = g(X)$ is a random variable.
- To build it: group the outcomes by $X$, average $Y$ in each group, and give every
  outcome its group's average.
- It depends on the outcome only through $X$, so it is constant on each group.
- If $X$ and $Y$ are independent, $E[Y \mid X] = E[Y]$. Always, $E[h(X) \mid X] = h(X)$.
- Different information (different groups) gives a different $E[Y \mid X]$.

The one formula to remember:

$$
\boxed{E[Y \mid X] = g(X), \quad \text{where } g(x) = E[Y \mid X = x]}
$$
