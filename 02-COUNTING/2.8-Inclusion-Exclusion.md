# 2.8 Inclusion-Exclusion

[Probability](../README.md) / [Module 02: Counting](README.md) / 2.8 Inclusion-Exclusion

**Level:** 1 (Zero) · **Time:** about 50 minutes · **Before this:** [2.7 Binomial Theorem and Pascal's Triangle](2.7-Binomial-Theorem-and-Pascals-Triangle.md)

> **Big idea:** To count a union of overlapping sets, add the sizes of the sets, subtract the pairwise overlaps, add back the triple overlaps, and keep alternating.

---

## Why It Matters

The addition rule from [2.1](2.1-Multiplication-and-Addition-Rules.md) works only when the
groups do not overlap. Real groups overlap all the time: numbers divisible by 2 or by
3, students who play cricket or football, servers that fail on Monday or on Tuesday.
**Inclusion-exclusion** fixes the double counting exactly. It is the key to the
[derangement problem](2.11-Classic-Counting-Problems/2.11.2-Derangements-and-Matching.md),
to counting "every box is used" outcomes, and, in probability form, to
[3.5 Inclusion-Exclusion for Probability](../03-AXIOMS-OF-PROBABILITY/3.5-Inclusion-Exclusion-for-Probability.md).

## Intuition

A class has 30 students. 18 play cricket, 15 play football, and 8 play both. How many
play at least one of the two?

If you add $18 + 15 = 33$, you get more than the class size, which is impossible. The
8 students who play both were counted **twice**: once with cricket and once with
football. Subtract them once: $33 - 8 = 25$. So 25 students play at least one sport,
and $30 - 25 = 5$ play neither.

With three sports the same idea needs one more step. Adding the three groups counts a
student who plays all three sports 3 times. Subtracting the three pairwise overlaps
removes that student 3 times, so now they are counted 0 times! We must **add back**
the triple overlap once. Include, exclude, include again: that is where the name
comes from.

## Picture

```text
    Ω
   +-------------------------------------+
   |      +-----------+                  |
   |      |  A    +---+-------+          |
   |      |       |A∩B|   B   |          |
   |      +-------+---+       |          |
   |              +-----------+          |
   +-------------------------------------+

   For three sets, follow ONE element through the formula:

   element is in    +|A|+|B|+|C|   -|A∩B|-|A∩C|-|B∩C|   +|A∩B∩C|   total
   --------------   ------------   ------------------   --------   -----
   exactly 1 set         1                 0                0        1
   exactly 2 sets        2                -1                0        1
   all 3 sets            3                -3               +1        1
```

The region $A \cap B$ is inside both circles, so $\lvert A \rvert + \lvert B \rvert$ counts it twice;
the table shows that the full formula counts every element of the union exactly once.

## Definition

The **principle of inclusion-exclusion** counts the elements of a union of finite
sets. Recall that $\lvert A \rvert$ is the number of elements of $A$.

**Two sets:**

$$
\lvert A \cup B \rvert = \lvert A \rvert + \lvert B \rvert - \lvert A \cap B \rvert
$$

**Three sets:**

$$
\lvert A \cup B \cup C \rvert = \lvert A \rvert + \lvert B \rvert + \lvert C \rvert - \lvert A \cap B \rvert - \lvert A \cap C \rvert - \lvert B \cap C \rvert + \lvert A \cap B \cap C \rvert
$$

**In general**, for sets $A_1, \dots, A_n$:

$$
\left\lvert \bigcup_{i=1}^{n} A_i \right\rvert = \sum_{i} \lvert A_i \rvert - \sum_{i \lt j} \lvert A_i \cap A_j \rvert + \sum_{i \lt j \lt k} \lvert A_i \cap A_j \cap A_k \rvert - \dots + (-1)^{n+1} \lvert A_1 \cap \dots \cap A_n \rvert
$$

where the $j$-th sum runs over all groups of $j$ different sets (there are $\binom{n}{j}$ such
groups), and its sign is $+$ for odd $j$ and $-$ for even $j$.

**In words:** add the single sets, subtract the overlaps of every pair, add the
overlaps of every triple, subtract the overlaps of every four sets, and so on.

Often we want the elements in **none** of the sets. With $\Omega$ as the full set, that is
$\lvert \Omega \rvert - \lvert A_1 \cup \dots \cup A_n \rvert$.

## Why It Is True

We show that every element of the union is counted exactly once by the right-hand
side, and elements outside the union are counted zero times.

Take an element $x$ that lies in exactly $m$ of the sets, with $m \ge 1$.

1. In the first sum (single sets), $x$ is counted once for each set that contains it:
   $m = \binom{m}{1}$ times.
2. In the second sum (pairs), $x$ is counted once for each pair of sets that both
   contain it: $\binom{m}{2}$ times.
3. In the $j$-th sum, $x$ is counted $\binom{m}{j}$ times (zero times when $j \gt m$).

With the signs, the total count for $x$ is:

$$
\begin{aligned}
\binom{m}{1} - \binom{m}{2} + \binom{m}{3} - \dots + (-1)^{m+1} \binom{m}{m} &= 1 - \sum_{j=0}^{m} (-1)^j \binom{m}{j} && \text{(move the } j = 0 \text{ term, which is } 1 \text{)} \\
&= 1 - (1 - 1)^m && \text{(binomial theorem)} \\
&= 1 - 0 = 1 && \text{(since } m \ge 1 \text{)}
\end{aligned}
$$

An element in none of the sets appears in no term, so it is counted 0 times. So the
right-hand side counts exactly the elements of the union. The middle step uses the
alternating row sum from [2.7](2.7-Binomial-Theorem-and-Pascals-Triangle.md).

## Worked Examples

### Example 1: Divisible by 2, 3 or 5

**Problem.** A whole number from 1 to 100 is picked at random. What is the probability
that it is divisible by 2, 3 or 5?

**Solution.**

1. Let $A$, $B$, $C$ be the numbers divisible by 2, 3 and 5. The multiples of $d$ up to
   100 number $\lfloor 100 / d \rfloor$ (round down).
2. Single sets: $\lvert A \rvert = 50$, $\lvert B \rvert = 33$, $\lvert C \rvert = 20$.
3. Pairs: divisible by both 2 and 3 means divisible by 6, and so on:
   $\lvert A \cap B \rvert = \lfloor 100/6 \rfloor = 16$, $\lvert A \cap C \rvert = \lfloor 100/10 \rfloor = 10$,
   $\lvert B \cap C \rvert = \lfloor 100/15 \rfloor = 6$.
4. Triple: divisible by 30: $\lvert A \cap B \cap C \rvert = \lfloor 100/30 \rfloor = 3$.
5. Inclusion-exclusion:

$$
\lvert A \cup B \cup C \rvert = 50 + 33 + 20 - 16 - 10 - 6 + 3 = 74
$$

**Answer.** $P(\text{divisible by 2, 3 or 5}) = \frac{74}{100} = 0.74$.

**Check.** The other 26 numbers have no factor 2, 3 or 5: they are 1, 7, 11, 13, 17,
19, 23, 29, 31, 37, ... The code below counts them by brute force.

### Example 2: Every Server Gets a Job

**Problem.** Six different jobs are each sent to one of 3 servers at random, all
$3^6$ assignments equally likely. What is the probability that **every** server gets at
least one job?

**Solution.**

1. All assignments: $3^6 = 729$ (each job picks one of 3 servers).
2. Let $A_i$ be the assignments where server $i$ gets **no** job. We want the
   assignments in none of $A_1, A_2, A_3$.
3. $\lvert A_i \rvert = 2^6 = 64$ (every job avoids server $i$). Pairs:
   $\lvert A_i \cap A_j \rvert = 1^6 = 1$ (all jobs on the third server). Triple:
   $\lvert A_1 \cap A_2 \cap A_3 \rvert = 0$ (jobs must go somewhere).
4. Inclusion-exclusion for the union:

$$
\lvert A_1 \cup A_2 \cup A_3 \rvert = 3 \cdot 64 - 3 \cdot 1 + 0 = 192 - 3 = 189
$$

5. Assignments with every server busy: $729 - 189 = 540$.

$$
P(\text{every server busy}) = \frac{540}{729} = \frac{20}{27} \approx 0.741
$$

**Answer.** About $0.741$.

**Check.** The same steps for $k$ jobs and $n$ servers give
$\sum_{j=0}^{n} (-1)^j \binom{n}{j} (n-j)^k$ **onto** assignments (every server used). With
$k = n = 3$ this is $27 - 24 + 3 - 0 = 6 = 3!$, which is right: each server gets exactly
one job.

### Example 3: Students and Sports

**Problem.** In the class of 30 from the Intuition, 18 play cricket, 15 football and 8
both. A student is chosen at random. What is the probability that they play
neither?

**Solution.**

1. Let $C$ = cricket and $F$ = football. By the two-set formula,
   $\lvert C \cup F \rvert = 18 + 15 - 8 = 25$.
2. Neither: $30 - 25 = 5$ students.

$$
P(\text{neither}) = \frac{5}{30} = \frac{1}{6} \approx 0.167
$$

**Answer.** $\frac{1}{6}$.

**Check.** Split into disjoint regions: only cricket $18 - 8 = 10$, only football
$15 - 8 = 7$, both 8, neither 5. Total $10 + 7 + 8 + 5 = 30$.

## Simulate It

The code counts Example 1 by brute force and simulates Example 2.

```python
import numpy as np

rng = np.random.default_rng(42)

# Example 1: count 1..100 divisible by 2, 3 or 5.
x = np.arange(1, 101)
count = np.sum((x % 2 == 0) | (x % 3 == 0) | (x % 5 == 0))
print(f"Divisible by 2, 3 or 5: {count} (formula {50 + 33 + 20 - 16 - 10 - 6 + 3})")

# Example 2: 6 jobs, each sent to server 0, 1 or 2 at random.
n_trials = 1_000_000
jobs = rng.integers(0, 3, size=(n_trials, 6))
all_busy = np.all([np.any(jobs == s, axis=1) for s in range(3)], axis=0)
print(f"P(every server busy): simulation {all_busy.mean():.4f}, exact {540 / 729:.4f}")
```

Output:

```text
Divisible by 2, 3 or 5: 74 (formula 74)
P(every server busy): simulation 0.7398, exact 0.7407
```

## Common Mistakes

- **Stopping after subtracting the pairs.** With three sets you must add the triple
  overlap back, or elements in all three sets are counted zero times.
- **Getting the signs wrong.** Odd-size intersections get $+$, even-size intersections
  get $-$. Check with an element that is in every set: it must be counted once.
- **Using the wrong overlap.** Divisible by 2 **and** 3 is divisible by 6, but divisible
  by 4 and 6 is divisible by 12, not 24. Use the least common multiple.
- **Forgetting the complement step.** Inclusion-exclusion counts "at least one"; for
  "none" subtract the result from the total.
- **Using it when a simpler route exists.** For "at least one six in 4 rolls", the
  complement $6^4 - 5^4$ is much quicker.

## Where It Is Used

- **Probability:** the probability of a union,
  $P(A \cup B) = P(A) + P(B) - P(A \cap B)$, is the same formula with sizes replaced by
  probabilities; see [3.4 Addition Rule](../03-AXIOMS-OF-PROBABILITY/3.4-Addition-Rule.md).
- **Computer science:** counting onto functions (every bucket or server used), the
  number of strings that avoid several patterns, and the analysis of the coupon
  collector problem.
- **AI and machine learning:** the probability that at least one of several model
  checks fails, and the exact correction to the union bound
  ([3.6 Union Bound](../03-AXIOMS-OF-PROBABILITY/3.6-Union-Bound.md)).
- **Number theory:** counting numbers with no small prime factor, as in Example 1.
- **Everyday life:** surveys ("how many like tea or coffee?") and scheduling.

## Practice

**1. (Easy)** Of 40 people, 25 drink tea, 20 drink coffee and 10 drink both. How many
drink neither?

<details>
<summary>Answer</summary>

$$40 - (25 + 20 - 10) = 40 - 35 = 5$$

**2. (Easy)** How many whole numbers from 1 to 1000 are divisible by 3 or 7?

<details>
<summary>Answer</summary>

Multiples of 3: 333. Multiples of 7: 142. Multiples of 21: 47.

$$333 + 142 - 47 = 428$$

</details>

**3. (Medium)** How many 8-bit strings start with 1 or end with 00?

<details>
<summary>Answer</summary>

Start with 1: $2^7 = 128$. End with 00: $2^6 = 64$. Both: $2^5 = 32$.

$$128 + 64 - 32 = 160$$

</details>

**4. (Medium)** You are dealt 5 cards from a 52-card deck. What is the probability that
at least one suit is missing from your hand?

<details>
<summary>Answer</summary>

Let $A_s$ be the hands with no card of suit $s$. One suit missing: choose 5 of the other 39 cards.
Two suits missing: 5 of 26. Three suits missing: 5 of 13. Four missing: impossible.

$$4\binom{39}{5} - 6\binom{26}{5} + 4\binom{13}{5} = 4 \cdot 575757 - 6 \cdot 65780 + 4 \cdot 1287 = 1913496$$

$$P(\text{a suit is missing}) = \frac{1913496}{2598960} \approx 0.736$$

The coefficients 4, 6, 4 are $\binom{4}{1}, \binom{4}{2}, \binom{4}{3}$, the number of ways to
pick which suits are missing.

</details>

**5. (Hard)** Prove the three-set formula using only the two-set formula.

<details>
<summary>Answer</summary>

Treat $A \cup B$ as one set and apply the two-set formula to it and $C$:

$$\lvert A \cup B \cup C \rvert = \lvert A \cup B \rvert + \lvert C \rvert - \lvert (A \cup B) \cap C \rvert$$

By the distributive law, $(A \cup B) \cap C = (A \cap C) \cup (B \cap C)$, and the two-set
formula for this union gives
$\lvert A \cap C \rvert + \lvert B \cap C \rvert - \lvert A \cap B \cap C \rvert$, because
$(A \cap C) \cap (B \cap C) = A \cap B \cap C$. Also
$\lvert A \cup B \rvert = \lvert A \rvert + \lvert B \rvert - \lvert A \cap B \rvert$. Substituting both:

$$\lvert A \cup B \cup C \rvert = \lvert A \rvert + \lvert B \rvert - \lvert A \cap B \rvert + \lvert C \rvert - \lvert A \cap C \rvert - \lvert B \cap C \rvert + \lvert A \cap B \cap C \rvert$$

which is the three-set formula.

</details>

**6. (Simulate)** Check Problem 4 by dealing many random hands.

<details>
<summary>Answer</summary>

```python
import numpy as np

rng = np.random.default_rng(42)
n_trials = 500_000
hands = rng.permuted(np.tile(np.arange(52), (n_trials, 1)), axis=1)[:, :5]
suits = hands // 13                              # suit 0, 1, 2 or 3
n_suits = np.stack([np.any(suits == s, axis=1) for s in range(4)]).sum(axis=0)
print(f"Simulation: {np.mean(n_suits < 4):.4f}")
print(f"Exact:      {1913496 / 2598960:.4f}")
```

Output:

```text
Simulation: 0.7346
Exact:      0.7363
```

</details>

## Summary

- Adding overlapping sets double counts; inclusion-exclusion corrects it exactly.
- Two sets: add both, subtract the overlap. Three sets: also add back the triple
  overlap.
- In general the signs alternate: $+$ for single sets, $-$ for pairs, $+$ for triples, and
  so on.
- The proof: an element in $m$ sets is counted $1 - (1 - 1)^m = 1$ time.
- For "none of the sets", subtract the union from the total.

The one formula to remember:

$$
\boxed{\lvert A \cup B \rvert = \lvert A \rvert + \lvert B \rvert - \lvert A \cap B \rvert}
$$
