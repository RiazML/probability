# 2.11 Classic Counting Problems

[Probability](../../README.md) / [Module 02: Counting](../README.md) / 2.11 Classic Counting Problems

> **Big idea:** Three famous problems (shared birthdays, nobody getting their own hat back, and poker hands) show how the counting tools of this module turn into real probabilities, often with surprising answers.

Each problem here uses several tools at once: permutations and the complement for the
birthday problem, inclusion-exclusion for derangements, and combinations with the
multiplication rule for poker hands. Each one also teaches a lesson about intuition:
collisions come much sooner than we expect, some probabilities barely depend on the
size of the problem, and careful case-splitting is needed to avoid double counting.
Read them in order, after [2.1](../2.1-Multiplication-and-Addition-Rules.md) to
[2.10](../2.10-Story-Proofs.md); each one stands alone if you only need one.
