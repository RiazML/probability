# 4.1 Conditional Probability

[Probability](../README.md) / [Module 04: Conditional Probability, Independence and Bayes](README.md) / 4.1 Conditional Probability

**Level:** 1 (Zero) · **Time:** about 45 minutes · **Before this:** [Module 03: Axioms of Probability](../03-AXIOMS-OF-PROBABILITY/README.md)

> **Big idea:** When you learn that $B$ happened, throw away every outcome outside $B$ and rescale what is left so it adds up to 1 again.

---

## Why It Matters

Probabilities are not fixed forever. They change when you learn something. A
doctor sees a test result, a spam filter sees the word "lottery", a card player
sees one card. **Conditional probability** is the rule for this change. Every other
idea in this module, including Bayes' theorem, independence and tree diagrams, is
built on the one formula in this file.

## Intuition

Roll a fair die. The chance of a 6 is $\frac{1}{6}$. Now a friend looks at the die,
hides it from you, and says: "It is even." Should you still say $\frac{1}{6}$?

No. The friend has removed the outcomes 1, 3 and 5. Only 2, 4 and 6 are left, and
they are still equally likely. So the chance of a 6 is now 1 out of 3. The
information did not change the die. It changed **what you know**, and so it changed
the set of outcomes you must consider.

The same idea works with counts. A mail server receives 1,000 emails. 300 are spam
and 700 are normal. The word "free" appears in 240 spam emails and in 70 normal
emails. You pick an email at random and see the word "free". Now only the
$240 + 70 = 310$ emails with "free" matter. Of those, 240 are spam, so the chance
of spam is $\frac{240}{310} \approx 0.774$. Before you saw the word, it was
$\frac{300}{1000} = 0.3$.

Notice the pattern in both stories:

1. Keep only the outcomes where the new information is true. This is the new,
   smaller world.
2. Inside that smaller world, ask what fraction also has the event you care about.

## Picture

```text
   Before: the whole space Ω              After learning "B happened"

  +-------------------------------+        +-------------------------------+
  |  Ω                            |        |  ...........................  |
  |      +---------+              |        |  .  (thrown away)          .  |
  |      |  A      |              |        |  .     +-------------+     .  |
  |      |    +----+--------+     |        |  .     |  A∩B        |     .  |
  |      |    |A∩B |        |     |  --->  |  .     +-------------+     .  |
  |      +----+----+   B    |     |        |  .     |  rest of B  |     .  |
  |           |             |     |        |  .     +-------------+     .  |
  |           +-------------+     |        |  .     new world = B       .  |
  +-------------------------------+        +-------------------------------+

       P(A) = area of A / area of Ω       P(A | B) = area of A∩B / area of B
```

Conditioning on $B$ makes $B$ the new sample space, and $A$ keeps only its part inside $B$.

## Definition

Let $A$ and $B$ be events, and suppose $P(B) \gt 0$. The **conditional
probability of $A$ given $B$**, written $P(A \mid B)$, is the probability that $A$
happens when we know that $B$ happens. It is defined as:

$$
P(A \mid B) = \frac{P(A \cap B)}{P(B)}
$$

where:

- $P(A \cap B)$ is the probability that $A$ **and** $B$ both happen,
- $P(B)$ is the probability of the information we learned, and it must be
  greater than $0$,
- the bar $\mid$ is read "given".

**In words:** the probability of $A$ given $B$ is the share of $B$ that is also
inside $A$.

When all outcomes are equally likely, the formula becomes a count:

$$
P(A \mid B) = \frac{\text{number of outcomes in } A \cap B}{\text{number of outcomes in } B}
$$

**In words:** count the outcomes of $B$, and find what fraction of them are also in $A$.

> **Warning:** $P(A \mid B)$ and $P(B \mid A)$ are different numbers. In the spam
> story, $P(\text{spam} \mid \text{"free"}) = \frac{240}{310} \approx 0.774$, but
> $P(\text{"free"} \mid \text{spam}) = \frac{240}{300} = 0.8$. Mixing them up is the
> most common mistake in all of probability. See
> [4.11.3 Prosecutor's Fallacy](4.11-Classic-Puzzles/4.11.3-Prosecutors-Fallacy.md).

## Why It Is True

A definition cannot be "proved", but we can show that it is the **only sensible
choice**. We want a new probability rule $Q(A) = P(A \mid B)$ that describes the
world after we learn $B$. It should satisfy three wishes:

1. $Q(B) = 1$, because we now know $B$ happened.
2. Outcomes outside $B$ get probability $0$, so $Q(A \cap B^c) = 0$.
3. Inside $B$, the information does not favor any outcome, so relative chances do
   not change. If $C \subseteq B$ was twice as likely as $D \subseteq B$ before, it is
   still twice as likely after. So $Q(C) = c \cdot P(C)$ for every $C \subseteq B$,
   with one constant $c$.

Now put the wishes together:

$$
\begin{aligned}
1 = Q(B) &= c \cdot P(B) && \text{(wish 1, and wish 3 with } C = B \text{)} \\
c &= \frac{1}{P(B)} && \text{(solve for } c \text{; needs } P(B) \gt 0 \text{)} \\
Q(A) &= Q(A \cap B) + Q(A \cap B^c) && \text{(A splits into two disjoint parts)} \\
&= \frac{P(A \cap B)}{P(B)} + 0 && \text{(wish 3 with } C = A \cap B \text{, and wish 2)}
\end{aligned}
$$

So the wishes force $Q(A) = \frac{P(A \cap B)}{P(B)}$, which is the definition.

**The frequency view agrees.** Repeat an experiment $n$ times. Say $B$ happens
$n_B$ times, and $A$ and $B$ happen together $n_{AB}$ times. Among the runs where
$B$ happened, the fraction with $A$ is:

$$
\frac{n_{AB}}{n_B} = \frac{n_{AB} / n}{n_B / n} \approx \frac{P(A \cap B)}{P(B)}
$$

**Conditional probability is a real probability.** For a fixed $B$ with
$P(B) \gt 0$, the rule $A \mapsto P(A \mid B)$ obeys all three
[Kolmogorov axioms](../03-AXIOMS-OF-PROBABILITY/3.2-Kolmogorov-Axioms.md):

- It is never negative, because it is a ratio of a non-negative number and a
  positive number.
- $P(\Omega \mid B) = \frac{P(\Omega \cap B)}{P(B)} = \frac{P(B)}{P(B)} = 1$.
- If $A_1, A_2, \dots$ are disjoint, then so are $A_1 \cap B, A_2 \cap B, \dots$,
  and additivity of $P$ carries over after dividing by $P(B)$.

So every rule you know still works when everything is conditioned on $B$. For example, the complement rule
becomes $P(A^c \mid B) = 1 - P(A \mid B)$.

## Worked Examples

### Example 1: Two Dice, Both Directions

**Problem.** Roll two fair dice. Let $A$ = "the sum is 8" and $B$ = "the first die
shows 3". Find $P(A \mid B)$ and $P(B \mid A)$.

**Solution.**

1. There are $6 \times 6 = 36$ equally likely ordered pairs.
2. $B$ has 6 outcomes: $(3,1), (3,2), (3,3), (3,4), (3,5), (3,6)$.
3. $A$ has 5 outcomes: $(2,6), (3,5), (4,4), (5,3), (6,2)$.
4. $A \cap B$ has 1 outcome: $(3,5)$.
5. Given $B$, the new world has 6 outcomes, and 1 of them is in $A$:

$$
P(A \mid B) = \frac{1}{6} \approx 0.167
$$

6. Given $A$, the new world has 5 outcomes, and 1 of them is in $B$:

$$
P(B \mid A) = \frac{1}{5} = 0.2
$$

**Answer.** $P(A \mid B) = \frac{1}{6}$ and $P(B \mid A) = \frac{1}{5}$. The same
overlap $(3,5)$ is divided by different totals, so the two answers differ.

**Check.** With the formula: $P(A \cap B) = \frac{1}{36}$ and $P(B) = \frac{6}{36}$,
so $P(A \mid B) = \frac{1/36}{6/36} = \frac{1}{6}$. The simulation below agrees.

### Example 2: A Spam Filter Reads One Word

**Problem.** Use the mail server from the Intuition section: 1,000 emails, 300 spam,
700 normal. "Free" appears in 240 spam and 70 normal emails. A random email
contains "free". What is the probability it is spam? What is the probability that
an email **without** "free" is spam?

**Solution.**

1. Put the counts in a table. Each row and column adds up.

| | contains "free" | no "free" | total |
|---|---|---|---|
| spam | 240 | 60 | 300 |
| normal | 70 | 630 | 700 |
| total | 310 | 690 | 1000 |

2. Given "free", look only at the first column, 310 emails:

$$
P(\text{spam} \mid \text{free}) = \frac{240}{310} \approx 0.774
$$

3. Given no "free", look only at the second column, 690 emails:

$$
P(\text{spam} \mid \text{no free}) = \frac{60}{690} \approx 0.087
$$

**Answer.** About 77% of emails with "free" are spam, but only about 9% of
emails without it are spam.

**Check.** The overall spam rate, $0.3$, lies between $0.087$ and $0.774$. It must,
because it is a mix of the two columns. This is the
[law of total probability](4.3-Law-of-Total-Probability.md), coming soon.

### Example 3: A Card Game

**Problem.** You draw 2 cards from a shuffled deck of 52, without putting the
first back. Given that **at least one** card is an ace, what is the probability
that **both** are aces?

**Solution.**

1. Count unordered pairs of cards: $\binom{52}{2} = 1326$, all equally likely.
2. Pairs with no ace: $\binom{48}{2} = 1128$. So pairs with at least one ace:
   $1326 - 1128 = 198$.
3. Pairs with two aces: $\binom{4}{2} = 6$.
4. "Both aces" is inside "at least one ace", so the intersection is just "both aces":

$$
P(\text{both aces} \mid \text{at least one ace}) = \frac{6}{198} = \frac{1}{33} \approx 0.030
$$

**Answer.** About 3%. Knowing that there is at least one ace does not make two aces
likely.

**Check.** Compare with $P(\text{both aces}) = \frac{6}{1326} \approx 0.0045$. The
information raised the chance by a factor of $\frac{1326}{198} \approx 6.7$, which
makes sense: we threw away 1,128 pairs that could not be "both aces".

## Simulate It

This code rolls two dice many times and checks both answers from Example 1.

```python
import numpy as np

rng = np.random.default_rng(42)
n_trials = 1_000_000

die1 = rng.integers(1, 7, size=n_trials)
die2 = rng.integers(1, 7, size=n_trials)
A = (die1 + die2 == 8)     # the sum is 8
B = (die1 == 3)            # the first die shows 3

# Conditioning = keep only the trials where the condition is true.
p_A_given_B = A[B].mean()
p_B_given_A = B[A].mean()

print(f"P(A | B): simulation {p_A_given_B:.4f}, exact {1 / 6:.4f}")
print(f"P(B | A): simulation {p_B_given_A:.4f}, exact {1 / 5:.4f}")
```

Output:

```text
P(A | B): simulation 0.1659, exact 0.1667
P(B | A): simulation 0.1985, exact 0.2000
```

The line `A[B].mean()` is conditioning in code: keep the rows where $B$ is true,
then take the fraction where $A$ is true.

## Common Mistakes

- **Swapping the condition.** $P(A \mid B)$ is not $P(B \mid A)$. Ask: "Which
  event do I already know?" That one goes after the bar.
- **Dividing by the wrong total.** After conditioning on $B$, divide by $P(B)$
  (or the count of $B$), not by 1 (or the size of $\Omega$).
- **Conditioning on an impossible event.** If $P(B) = 0$, the formula divides by
  zero and $P(A \mid B)$ is not defined here. (For continuous variables there is a
  fix, in [10.4 Conditional Distributions](../10-JOINT-DISTRIBUTIONS/10.4-Conditional-Distributions.md).)
- **Adding over the wrong side.** $P(A \mid B) + P(A^c \mid B) = 1$ is always
  true. But $P(A \mid B) + P(A \mid B^c)$ can be any number from 0 to 2. In Example
  2 it is $0.774 + 0.087 = 0.861$.
- **Thinking information changes the world.** The die did not change when your
  friend said "even". Only your knowledge changed. Conditional probability
  measures knowledge.

## Where It Is Used

- **AI and machine learning:** a classifier outputs $P(\text{class} \mid \text{input})$,
  such as $P(\text{cat} \mid \text{image})$. Language models output
  $P(\text{next word} \mid \text{words so far})$.
- **Computer science:** a cache designer asks for $P(\text{hit} \mid \text{key was used recently})$.
  A monitoring system asks for $P(\text{failure} \mid \text{high CPU})$.
- **Medicine:** a test result changes the chance of disease. This is
  $P(\text{disease} \mid \text{positive test})$, worked out in
  [4.11.2 Medical Testing](4.11-Classic-Puzzles/4.11.2-Medical-Testing.md).
- **Insurance:** prices depend on $P(\text{accident} \mid \text{age, city, car})$.
- **Everyday life:** "Given that the sky is dark grey, will it rain?" You condition
  on what you see all day long.

## Practice

**1. (Easy)** Draw one card from a standard deck. Given that it is a heart, what is
the probability that it is a face card (J, Q or K)?

<details>
<summary>Answer</summary>

The new world is the 13 hearts. Three of them are face cards:

$$P(\text{face} \mid \text{heart}) = \frac{3}{13} \approx 0.231$$

This is the same as $P(\text{face}) = \frac{12}{52} = \frac{3}{13}$, so here the
information did not change the chance. That is independence, the topic of
[4.7 Independence](4.7-Independence.md).

</details>

**2. (Easy)** $P(A) = 0.5$, $P(B) = 0.4$ and $P(A \cap B) = 0.1$. Find
$P(A \mid B)$ and $P(B \mid A)$.

<details>
<summary>Answer</summary>

$$P(A \mid B) = \frac{0.1}{0.4} = 0.25, \qquad P(B \mid A) = \frac{0.1}{0.5} = 0.2$$

</details>

**3. (Medium)** A family has two children. Each child is a boy or a girl with
probability $\frac{1}{2}$, independently. Given that **at least one** child is a
boy, what is the probability that both are boys?

<details>
<summary>Answer</summary>

The equally likely outcomes are BB, BG, GB, GG (older child first). "At least one
boy" keeps BB, BG, GB, which is 3 outcomes. Only BB has two boys:

$$P(\text{two boys} \mid \text{at least one boy}) = \frac{1}{3}$$

Many people say $\frac{1}{2}$. That is the answer to a different question: "the
**older** child is a boy", which keeps only BB and BG.

</details>

**4. (Medium)** Show that if $A \subseteq B$ and $P(B) \gt 0$, then
$P(A \mid B) = \frac{P(A)}{P(B)}$, and so $P(A \mid B) \ge P(A)$.

<details>
<summary>Answer</summary>

If $A \subseteq B$, then $A \cap B = A$. So:

$$P(A \mid B) = \frac{P(A \cap B)}{P(B)} = \frac{P(A)}{P(B)}$$

Since $0 \lt P(B) \le 1$, dividing by $P(B)$ cannot make a non-negative number
smaller. So $P(A \mid B) \ge P(A)$. Learning that a bigger event happened can only
make $A$ more likely (or keep it the same).

</details>

**5. (Hard)** Prove that $P(A \mid B) \ge 1 - \frac{P(A^c)}{P(B)}$ whenever
$P(B) \gt 0$. Then use it: if $P(A) = 0.99$ and $P(B) = 0.5$, how small can
$P(A \mid B)$ be?

<details>
<summary>Answer</summary>

Start from the complement rule given $B$, then use $A^c \cap B \subseteq A^c$:

$$P(A \mid B) = 1 - P(A^c \mid B) = 1 - \frac{P(A^c \cap B)}{P(B)} \ge 1 - \frac{P(A^c)}{P(B)}$$

With the numbers: $P(A \mid B) \ge 1 - \frac{0.01}{0.5} = 1 - 0.02 = 0.98$. A very
likely event stays very likely after conditioning on an event that is not rare.

</details>

**6. (Simulate)** Simulate two-child families and check the answer $\frac{1}{3}$ to
Problem 3.

<details>
<summary>Answer</summary>

```python
import numpy as np

rng = np.random.default_rng(42)
n_families = 1_000_000
older_boy = rng.random(n_families) < 0.5
younger_boy = rng.random(n_families) < 0.5
at_least_one = older_boy | younger_boy
both = older_boy & younger_boy
print(f"P(both | at least one): simulation {both[at_least_one].mean():.4f}, exact {1 / 3:.4f}")
```

Output:

```text
P(both | at least one): simulation 0.3337, exact 0.3333
```

</details>

## Summary

- Conditioning on $B$ means: keep only the outcomes in $B$, then rescale so they
  add up to 1.
- With equally likely outcomes, $P(A \mid B)$ is a count of $A \cap B$ divided by
  a count of $B$.
- $P(A \mid B)$ and $P(B \mid A)$ are usually different. Always check which event is
  known.
- For a fixed $B$, $P(\cdot \mid B)$ is a full probability rule. The complement
  rule and the addition rule still work given $B$.
- In code, conditioning is filtering: `A[B].mean()`.

The one formula to remember:

$$
\boxed{P(A \mid B) = \frac{P(A \cap B)}{P(B)}, \quad P(B) \gt 0}
$$
