# 4.11 Classic Puzzles

[Probability](../../README.md) / [Module 04: Conditional Probability, Independence and Bayes](../README.md) / 4.11 Classic Puzzles

> **Big idea:** Five famous puzzles where intuition fails and careful conditioning, with Bayes' theorem, trees and the law of total probability, gives the right answer.

Each puzzle uses the tools of this module on one memorable story, and each one teaches
a lesson you will meet again in real life: model how evidence is produced, never forget
the base rate, never swap the condition, compare like with like, and condition on the
first step. Read them in order: the first three are Bayes' theorem in three settings
(a game show, a clinic, a courtroom), the fourth is about the law of total probability,
and the fifth uses it on a process with no fixed length.
