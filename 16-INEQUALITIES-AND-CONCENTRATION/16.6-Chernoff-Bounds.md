# 16.6 Chernoff Bounds

[Probability](../README.md) / [Module 16: Inequalities and Concentration](README.md) / 16.6 Chernoff Bounds

**Level:** 4 (Big Theorems) · **Time:** about 65 minutes · **Before this:** [16.5 Union Bound Revisited](16.5-Union-Bound-Revisited.md)

> **Big idea:** Apply Markov's inequality to $e^{tX}$ instead of $X$, then choose the best $t$: the tail probability is bounded by $\min_{t \gt 0} e^{-ta} M_X(t)$, and for sums of independent variables this is exponentially small.

---

## Why It Matters

Markov uses one number (the mean). Chebyshev uses two (the mean and variance). But the tail of a sum of many independent variables is far smaller than Chebyshev can see: it falls **exponentially**, not like $\frac{1}{n}$. To capture this we need all the moments at once, and the moment generating function ([15.1](../15-GENERATING-FUNCTIONS/15.1-Moment-Generating-Function.md)) is exactly the object that holds them all. The **Chernoff bound** is Markov's inequality applied to $e^{tX}$. It is the main tool for showing that randomized algorithms, polls and learning algorithms fail with probability that shrinks exponentially fast.

## Intuition

You run a randomized algorithm that gives the correct answer with probability $\frac{2}{3}$ each time. To be safer you run it 101 times and take the majority vote. How likely is the majority to be wrong?

The vote is wrong if at most 50 of the 101 runs are correct, while the average number of correct runs is $101 \times \frac{2}{3} \approx 67$. Getting 17 fewer than average is very unlikely, but how unlikely? Chebyshev says only that it is at most about $0.07$, which is weak. The truth is about $0.00027$.

The reason is that all the runs would have to go wrong **together**. Each extra run makes a joint failure much less likely, by a constant factor. Chernoff's idea captures this by adding the "tilts" $e^{tX_i}$ of all the runs: the MGF of a sum is the product of the MGFs ([15.3](../15-GENERATING-FUNCTIONS/15.3-MGF-of-Sums.md)), so its logarithm grows in a straight line with the number of runs, and its exponential gives the exponential decay.

Each $t$ gives a different valid bound, and the curve is a bowl. The best bound is the bottom of the bowl, so we minimize over $t$.

## Definition

**Chernoff bound.** Let $X$ be a random variable with MGF $M_X(t) = E[e^{tX}]$. For every real number $a$:

$$
P(X \ge a) \le \min_{t \gt 0} \thinspace e^{-ta} M_X(t)
$$

and for the lower tail:

$$
P(X \le a) \le \min_{t \gt 0} \thinspace e^{ta} M_X(-t)
$$

where:

- $t$ is a free positive number that we may choose after we see $a$. Only values of $t$ for which $M_X(t)$ is finite can be used.
- "min" means the smallest value over all allowed $t$ (in general, the infimum; when $M$ is finite on an open interval it is a minimum).

**In words:** the chance that $X$ is at least $a$ is at most $e^{-ta} E[e^{tX}]$, and this is true for every $t \gt 0$, so we use the best $t$.

**Where is the best $t$?** Write $K(t) = \ln M_X(t)$ (the cumulant generating function, [15.7](../15-GENERATING-FUNCTIONS/15.7-Cumulants.md)). The bound is $e^{-ta + K(t)}$, so we minimize the exponent $-ta + K(t)$. Setting the derivative to zero gives

$$
K'(t^{\ast}) = a
$$

**In words:** choose $t$ so that the "tilted" mean $K'(t)$ equals the target $a$.

**For sums of independent variables.** If $S = X_1 + \cdots + X_n$ with independent $X_i$, then $M_S(t) = \prod_i M_{X_i}(t)$, and

$$
P(S \ge a) \le \min_{t \gt 0} \thinspace \exp\left( -ta + \sum_{i=1}^{n} \ln M_{X_i}(t) \right)
$$

The sum inside grows linearly with $n$, so the bound shrinks like $e^{-cn}$.

## Why It Is True

**The proof is two lines.** Fix $t \gt 0$. The function $x \mapsto e^{tx}$ is increasing, so the events $\lbrace X \ge a \rbrace$ and $\lbrace e^{tX} \ge e^{ta} \rbrace$ are the same event. The variable $e^{tX}$ is positive, so Markov's inequality applies to it ([16.1](16.1-Markov-Inequality.md)):

$$
\begin{aligned}
P(X \ge a) &= P\big(e^{tX} \ge e^{ta}\big) && \text{(} e^{tx} \text{ is increasing for } t \gt 0 \text{)} \\
&\le \frac{E[e^{tX}]}{e^{ta}} && \text{(Markov for the positive variable } e^{tX} \text{)} \\
&= e^{-ta} M_X(t) && \text{(definition of the MGF)}
\end{aligned}
$$

This holds for every $t \gt 0$ where $M_X(t)$ is finite. The left side does not depend on $t$, so it is below the smallest right side. For the lower tail, use $-X$: $P(X \le a) = P(-X \ge -a) \le e^{ta} M_{-X}(t) = e^{ta} M_X(-t)$.

**Why $e^{tX}$ is a good choice.** In [16.1](16.1-Markov-Inequality.md) we saw that Markov's inequality is tight when the variable is only 0 or $a$. The curve $e^{t(x-a)}$ is at least 1 for $x \ge a$ and falls towards 0 for $x \lt a$, so it is a good upper "fence" for the step function $I_{\lbrace x \ge a \rbrace}$. The parameter $t$ lets us bend the fence to fit the distribution. For a sum, the tilt $e^{tS}$ is a product $\prod e^{tX_i}$, which is why independence makes the problem easy.

**Case 1: the normal distribution.** For $X \sim \mathcal{N}(\mu, \sigma^2)$ the MGF is $\exp(\mu t + \frac{\sigma^2 t^2}{2})$ ([15.1](../15-GENERATING-FUNCTIONS/15.1-Moment-Generating-Function.md)). The exponent is $-t(a - \mu) + \frac{\sigma^2 t^2}{2}$. Its derivative is $-(a-\mu) + \sigma^2 t$, which is 0 at $t^{\ast} = \frac{a - \mu}{\sigma^2}$ (positive when $a \gt \mu$). Substituting gives

$$
P(X \ge a) \le \exp\left( -\frac{(a - \mu)^2}{2\sigma^2} \right) \qquad (a \gt \mu)
$$

For a standard normal this is $P(Z \ge a) \le e^{-a^2/2}$. This has the right exponential shape, and it is off only by a factor of about $a\sqrt{2\pi}$.

**Case 2: the binomial distribution.** Let $X \sim \text{Bin}(n, p)$ and $p \lt a \lt 1$. We bound $P(X \ge na)$. The MGF is $(1 - p + pe^t)^n$, so the bound is

$$
\left( e^{-ta} (1 - p + pe^t) \right)^n
$$

Set the derivative of the exponent to zero. The condition $K'(t) = na$ becomes $\frac{pe^t}{1 - p + pe^t} = a$, so $e^t = \frac{a(1-p)}{p(1-a)}$. Then $1 - p + pe^t = \frac{1-p}{1-a}$, and

$$
\ln\left( e^{-ta}(1 - p + pe^t) \right) = -a \ln\frac{a(1-p)}{p(1-a)} + \ln\frac{1-p}{1-a} = -\left[ a \ln\frac{a}{p} + (1-a)\ln\frac{1-a}{1-p} \right]
$$

The bracket is the **KL divergence** between a coin with success chance $a$ and a coin with success chance $p$, written $D(a \Vert p)$ (see [16.3](16.3-Jensen-Inequality.md), where we showed $D \ge 0$). So

$$
P(X \ge na) \le e^{-n D(a \Vert p)}, \qquad D(a \Vert p) = a \ln\frac{a}{p} + (1-a)\ln\frac{1-a}{1-p}
$$

The same bound holds for the lower tail $P(X \le na)$ when $0 \lt a \lt p$.

**In words:** the chance of seeing a success fraction $a$ when the true chance is $p$ falls like $e^{-n}$ times how different the two coins are.

**Case 3: handy forms for sums of independent 0-1 variables.** Let $X = X_1 + \cdots + X_n$ with independent $X_i \in \lbrace 0, 1 \rbrace$ and $P(X_i = 1) = p_i$ (the $p_i$ may differ), and $\mu = E[X] = \sum_i p_i$. We use $1 + x \le e^x$ for all real $x$ (the line $1 + x$ is the tangent of the convex curve $e^x$ at 0, [16.3](16.3-Jensen-Inequality.md)):

$$
M_{X_i}(t) = 1 + p_i(e^t - 1) \le \exp\big(p_i(e^t - 1)\big) \quad \implies \quad M_X(t) \le \exp\big(\mu(e^t - 1)\big)
$$

Choose $t = \ln(1 + \delta)$ for the upper tail, with $\delta \gt 0$:

$$
P\big(X \ge (1+\delta)\mu\big) \le \exp\big(\mu(e^t - 1) - t(1+\delta)\mu\big) = \exp\Big( \mu\big( \delta - (1+\delta)\ln(1+\delta) \big) \Big)
$$

For the lower tail, use $P(X \le (1-\delta)\mu) \le e^{t(1-\delta)\mu} M_X(-t)$ with $t = -\ln(1-\delta)$ and $0 \lt \delta \lt 1$:

$$
P\big(X \le (1-\delta)\mu\big) \le \exp\Big( \mu\big( -\delta - (1-\delta)\ln(1-\delta) \big) \Big)
$$

These simplify, for $0 \lt \delta \lt 1$ in the lower tail and $0 \lt \delta \le 1$ in the upper tail, to the easy-to-use forms:

$$
\boxed{P\big(X \ge (1+\delta)\mu\big) \le e^{-\delta^2 \mu / 3}} \qquad \boxed{P\big(X \le (1-\delta)\mu\big) \le e^{-\delta^2 \mu / 2}}
$$

<details>
<summary>Why the two exponents simplify (optional)</summary>

**Lower tail.** Use the series $\ln(1 - \delta) = -\sum_{k \ge 1} \frac{\delta^k}{k}$. Multiply by $1 - \delta$ and collect the powers of $\delta$:

$$(1-\delta)\ln(1-\delta) = -\delta + \sum_{k \ge 2} \frac{\delta^k}{k(k-1)}$$

So $-\delta - (1-\delta)\ln(1-\delta) = -\sum_{k \ge 2} \frac{\delta^k}{k(k-1)} \le -\frac{\delta^2}{2}$, because every term is not negative and the first term is $\frac{\delta^2}{2}$.

**Upper tail.** We need $g(\delta) = (1+\delta)\ln(1+\delta) - \delta - \frac{\delta^2}{3} \ge 0$ on $[0, 1]$. We have $g(0) = 0$, and $g'(\delta) = \ln(1+\delta) - \frac{2\delta}{3}$ with $g'(0) = 0$. Also $g''(\delta) = \frac{1}{1+\delta} - \frac{2}{3}$ is positive for $\delta \lt \frac{1}{2}$ and negative after. So $g'$ goes up and then down on $[0, 1]$, and its smallest value is at an end: $g'(0) = 0$ or $g'(1) = \ln 2 - \frac{2}{3} \approx 0.026 \gt 0$. Hence $g' \ge 0$ on $[0, 1]$, so $g$ increases from $g(0) = 0$ and $g \ge 0$.

</details>

> **Warning:** The exact exponent of the binomial, $nD(a \Vert p)$, is always at least as good as the handy forms. For a fair coin the handy forms are weak (see the table below). They are best when $p$ is small and $\mu$ is the number of rare events.

**How the bounds compare.** For $X \sim \text{Bin}(100, \frac{1}{2})$ (mean 50, variance 25):

| Event | Exact | Markov | Cantelli ([16.2](16.2-Chebyshev-Inequality.md)) | Chernoff $e^{-nD}$ |
|---|---|---|---|---|
| $X \ge 60$ | $0.0284$ | $0.833$ | $0.200$ | $0.1335$ |
| $X \ge 70$ | $0.0000393$ | $0.714$ | $0.0588$ | $0.000267$ |

For a moderate deviation ($X \ge 60$) the bounds are all rough. For a large deviation ($X \ge 70$) Chernoff is within a factor of 7 of the exact value, while Chebyshev-type bounds are 1,500 times too big.

## Worked Examples

### Example 1: The Normal Tail

**Problem.** For a standard normal $Z$, compare $P(Z \ge a)$ with the Chernoff bound $e^{-a^2/2}$ and with Chebyshev for $a = 2, 3, 4$.

**Solution.**

1. Exact values from the normal table: $P(Z \ge 2) = 0.02275$, $P(Z \ge 3) = 0.00135$, $P(Z \ge 4) = 0.0000317$.
2. Chernoff: $e^{-2} = 0.1353$, $e^{-4.5} = 0.0111$, $e^{-8} = 0.000335$.
3. Chebyshev ([16.2](16.2-Chebyshev-Inequality.md)) for the two tails together is $\frac{1}{a^2}$. Because the normal is symmetric, one tail is half of it, $\frac{1}{2a^2}$: $0.125$, $0.0556$, $0.03125$.

| $a$ | Exact $P(Z \ge a)$ | Chernoff $e^{-a^2/2}$ | Chebyshev (one tail) $\frac{1}{2a^2}$ |
|---|---|---|---|
| 2 | $0.02275$ | $0.1353$ | $0.125$ |
| 3 | $0.00135$ | $0.0111$ | $0.0556$ |
| 4 | $0.0000317$ | $0.000335$ | $0.03125$ |

**Answer.** Chernoff is about 6, 8 and 11 times above the exact value at $a = 2, 3, 4$ (the ratio grows slowly, like $a\sqrt{2\pi}$). Chebyshev is about 5 times too big at $a = 2$, 41 times at $a = 3$, and 990 times at $a = 4$.

**Check.** The Chernoff bound has the correct speed $e^{-a^2/2}$; Chebyshev's $\frac{1}{a^2}$ is much too slow. At $a = 2$ Chebyshev is as good as Chernoff, because for small $a$ the extra moments do not help yet.

### Example 2: A Server Overload

**Problem.** A server is used by 10,000 independent users. In a given second, each user sends a request with probability $0.01$. The server can handle 150 requests per second. Bound the probability that it is overloaded, $P(X \ge 150)$ where $X$ is the number of requests.

**Solution.**

1. $X \sim \text{Bin}(10000, 0.01)$. The mean is $\mu = 100$ and the variance is $10000 \times 0.01 \times 0.99 = 99$.
2. Markov: $\frac{100}{150} = 0.667$.
3. Chebyshev (one tail, Cantelli): the distance is $50$, so the bound is $\frac{99}{99 + 2500} = 0.0381$.
4. Handy Chernoff form: $150 = (1 + \delta)\mu$ with $\delta = 0.5$. The simple form gives $e^{-\delta^2\mu/3} = e^{-0.25 \times 100 / 3} = e^{-8.33} \approx 2.4 \times 10^{-4}$. The sharper form before simplification gives:

$$
\exp\Big( 100\big( 0.5 - 1.5\ln 1.5 \big) \Big) = \exp\big( 100(0.5 - 0.6082) \big) = e^{-10.82} \approx 2.0 \times 10^{-5}
$$

5. The best form, $e^{-nD(a \Vert p)}$ with $a = 0.015$ and $p = 0.01$: $D = 0.015\ln 1.5 + 0.985 \ln\frac{0.985}{0.99} \approx 0.006082 - 0.004987 = 0.001095$, so the bound is $e^{-10000 \times 0.001095} = e^{-10.95} \approx 1.76 \times 10^{-5}$.
6. The exact value (from the binomial) is $1.66 \times 10^{-6}$.

**Answer.** Chernoff gives about $2 \times 10^{-5}$, within a factor of 10 of the truth $1.7 \times 10^{-6}$. Chebyshev gives $0.038$, which is 23,000 times too large.

**Check.** The Chebyshev-style bound allows an overload as often as once in 26 seconds. The Chernoff bound shows that it happens no more often than once in about 14 hours, and the truth is once in about 7 days. Capacity planning needs the exponential bound.

### Example 3: Majority Vote Amplifies a Randomized Algorithm

**Problem.** A randomized algorithm is correct with probability $\frac{2}{3}$ on each run, and runs are independent. Run it $n$ times (take $n$ odd) and output the majority answer. Bound the probability that the majority is wrong, and find $n$ that makes it below $10^{-6}$.

**Solution.**

1. Let $X$ be the number of correct runs, $X \sim \text{Bin}(n, \frac{2}{3})$. The majority is wrong when $X \le \frac{n-1}{2}$, so wrong implies $X \le \frac{n}{2}$.
2. Use the lower-tail Chernoff bound with $a = \frac{1}{2}$ and $p = \frac{2}{3}$:

$$
D\left(\tfrac{1}{2} \Vert \tfrac{2}{3}\right) = \tfrac{1}{2}\ln\frac{1/2}{2/3} + \tfrac{1}{2}\ln\frac{1/2}{1/3} = \tfrac{1}{2}\ln\frac{3}{4} + \tfrac{1}{2}\ln\frac{3}{2} = \tfrac{1}{2}\ln\frac{9}{8} \approx 0.0589
$$

3. So $P(\text{majority wrong}) \le e^{-nD} = \left(\frac{8}{9}\right)^{n/2}$. For $n = 101$ this is $0.0026$. The exact value is $0.00027$.
4. We need $\left(\frac{8}{9}\right)^{n/2} \le 10^{-6}$. Take logs: $\frac{n}{2} \ln\frac{9}{8} \ge 6 \ln 10 = 13.816$, so $n \ge \frac{2 \times 13.816}{0.11778} = 234.6$. Take $n = 235$.

**Answer.** The error is at most $(8/9)^{n/2}$; 235 runs guarantee error below one in a million.

**Check.** The exact binomial says 193 runs would be enough, so the bound is a little careful (22% more runs than needed), but the key fact is the shape: **every 20 extra runs cut the bound to about 31%**, because $(8/9)^{10} \approx 0.31$. A Chebyshev-type bound is $\frac{8}{n}$ here, and would need about 8 million runs for the same guarantee.

## Simulate It

We compare the simulated tail, the exact tail and the bounds for three binomials, and show the majority vote error.

```python
import numpy as np
from scipy.stats import binom

rng = np.random.default_rng(42)
n_trials = 2_000_000

def kl(a, p):
    # D(a || p): the exponent of the Chernoff bound for a Binomial(n, p) tail
    return a * np.log(a / p) + (1 - a) * np.log((1 - a) / (1 - p))

print("   n      p     k   simulated      exact     Chernoff    Cantelli   Markov")
for n, p, k in [(100, 0.5, 60), (100, 0.5, 70), (10_000, 0.01, 150)]:
    x = rng.binomial(n, p, size=n_trials)
    mu, var = n * p, n * p * (1 - p)
    chernoff = np.exp(-n * kl(k / n, p))               # min over t of e^(-tk) M(t)
    cantelli = var / (var + (k - mu) ** 2)             # one-sided Chebyshev (see 16.2)
    print(f"{n:6d}  {p:5.2f}  {k:4d}  {np.mean(x >= k):.2e}  {binom.sf(k - 1, n, p):.2e}  "
          f"{chernoff:.2e}  {cantelli:.2e}  {mu / k:.3f}")

# Majority vote of n independent runs, each correct with probability 2/3.
for n in [11, 51, 101, 201]:
    exact = binom.cdf((n - 1) // 2, n, 2 / 3)          # majority is wrong
    print(f"majority of {n:3d} runs wrong: exact {exact:.2e}, Chernoff (8/9)^(n/2) = {(8 / 9) ** (n / 2):.2e}")
```

Output:

```text
   n      p     k   simulated      exact     Chernoff    Cantelli   Markov
   100   0.50    60  2.84e-02  2.84e-02  1.34e-01  2.00e-01  0.833
   100   0.50    70  4.00e-05  3.93e-05  2.67e-04  5.88e-02  0.714
 10000   0.01   150  2.00e-06  1.66e-06  1.76e-05  3.81e-02  0.667
majority of  11 runs wrong: exact 1.22e-01, Chernoff (8/9)^(n/2) = 5.23e-01
majority of  51 runs wrong: exact 6.89e-03, Chernoff (8/9)^(n/2) = 4.96e-02
majority of 101 runs wrong: exact 2.72e-04, Chernoff (8/9)^(n/2) = 2.61e-03
majority of 201 runs wrong: exact 5.53e-07, Chernoff (8/9)^(n/2) = 7.23e-06
```

The simulated and exact columns agree (the last simulated value is based on only 4 events out of 2,000,000, so it is noisy). The Chernoff column is always above the exact value and, for rare events, close to it. The Cantelli column is hundreds or thousands of times too big for rare events. The majority vote error drops by a factor of about 12 for every 40 extra runs.

## Common Mistakes

- **Forgetting to minimize over $t$.** Any single $t \gt 0$ gives a valid bound, but a bad $t$ gives a weak one. Always find the $t$ with $K'(t) = a$.
- **Using the wrong sign of $t$.** For the upper tail $P(X \ge a)$ use $t \gt 0$ and $e^{-ta}$. For the lower tail use $e^{ta} M_X(-t)$ with $t \gt 0$, or equivalently $t \lt 0$ in the first formula.
- **Using it when the MGF does not exist.** For the Cauchy, the log-normal or a Pareto variable, $M_X(t) = \infty$ for every $t \gt 0$, and the bound is empty. Chebyshev may still work (Practice 5).
- **Multiplying MGFs of dependent variables.** The step $M_S = \prod M_{X_i}$ needs independence ([15.3](../15-GENERATING-FUNCTIONS/15.3-MGF-of-Sums.md)).
- **Using the handy form $e^{-\delta^2\mu/3}$ for everything.** It needs $0 \lt \delta \le 1$ and is loose for a fair coin. If you can, use $e^{-nD(a \Vert p)}$.

## Where It Is Used

- **AI and machine learning:** the proof that a model's test error is close to its true error with probability $1 - \delta$, where the failure probability falls exponentially in the number of examples. It is also the basis of Hoeffding's inequality ([16.7](16.7-Hoeffding-Inequality.md)) and PAC learning bounds.
- **Computer science:** amplifying success of randomized algorithms by repeating and taking the majority (Example 3); load balancing (no server gets more than a little over its fair share); hashing and sketching.
- **Networks and engineering:** capacity planning (Example 2), buffer overflow, and the chance that a link carries too much traffic.
- **Information theory:** large deviations. The exponent $D(a \Vert p)$ is the true rate of decay of a binomial tail, and a theorem of Cramér says no better exponent exists.
- **Everyday life:** a poll of 1,000 people that shows 55% or more for a candidate who really has 50% has probability below 0.001 (Practice 4), so it is not a coincidence to expect.

**2. (Medium)** Let $X \sim \text{Exp}(1)$ (rate 1), with $M_X(t) = \frac{1}{1-t}$ for $t \lt 1$. Find the Chernoff bound for $P(X \ge a)$ with $a \gt 1$, and evaluate it for $a = 5$. Compare with Markov and the exact value.

<details>
<summary>Answer</summary>

The bound is $e^{-ta}/(1-t)$ for $0 \lt t \lt 1$. Minimize the exponent $-ta - \ln(1-t)$: its derivative is $-a + \frac{1}{1-t} = 0$, so $t^{\ast} = 1 - \frac{1}{a}$. Substituting:

$$P(X \ge a) \le e^{-(1 - 1/a)a} \cdot a = a e^{1-a}$$

For $a = 5$: $5e^{-4} \approx 0.0916$. Markov gives $\frac{1}{5} = 0.2$ and the exact value is $e^{-5} \approx 0.00674$. The Chernoff bound is better than Markov, and has the right speed $e^{-a}$ up to the factor $ae$.

</details>

**3. (Medium)** Let $X \sim \text{Pois}(\lambda)$ (rate $\lambda$), with $M_X(t) = \exp(\lambda(e^t - 1))$. Show that $P(X \ge a) \le e^{-\lambda}\left(\frac{e\lambda}{a}\right)^a$ for $a \gt \lambda$, and evaluate it for $\lambda = 4$, $a = 10$.

<details>
<summary>Answer</summary>

The exponent is $-ta + \lambda(e^t - 1)$. Its derivative $-a + \lambda e^t$ is 0 at $e^t = \frac{a}{\lambda}$, that is $t = \ln\frac{a}{\lambda} \gt 0$. Substituting:

$$P(X \ge a) \le \exp\left( -a\ln\frac{a}{\lambda} + a - \lambda \right) = e^{-\lambda}\left(\frac{e\lambda}{a}\right)^a$$

For $\lambda = 4$, $a = 10$: $e^{-4}(0.4e)^{10} = e^{-4} \times 2.3 \approx 0.0423$. The exact value is $0.00813$, about 5 times smaller.

</details>

**5. (Hard)** Let $X \ge 1$ have density $f(x) = 3x^{-4}$ for $x \ge 1$. Show that $M_X(t) = \infty$ for every $t \gt 0$, so the Chernoff bound is empty, but that Chebyshev still gives a useful bound for $P(X \ge 5)$.

<details>
<summary>Answer</summary>

For $t \gt 0$ we have $e^{tx} \ge \frac{(tx)^3}{6}$ (one term of the series), so

$$M_X(t) = \int_1^{\infty} e^{tx} \cdot 3x^{-4} \thinspace dx \ge \int_1^{\infty} \frac{t^3 x^3}{6} \cdot 3x^{-4} \thinspace dx = \frac{t^3}{2} \int_1^{\infty} \frac{dx}{x} = \infty$$

so the Chernoff bound is $\infty$. But $E[X] = \int_1^{\infty} 3x^{-3} dx = \frac{3}{2}$ and $E[X^2] = \int_1^{\infty} 3x^{-2} dx = 3$, so $\operatorname{Var}(X) = 3 - \frac{9}{4} = \frac{3}{4}$. Chebyshev with distance $5 - 1.5 = 3.5$:

$$P(X \ge 5) \le \frac{3/4}{3.5^2} = \frac{0.75}{12.25} \approx 0.0612$$

The exact value is $\int_5^{\infty} 3x^{-4}dx = 5^{-3} = 0.008$. Heavy tails need Chebyshev, light tails allow Chernoff.

</details>

**6. (Simulate)** Simulate $10^7$ standard normal values and compare $P(Z \ge a)$ with $e^{-a^2/2}$ for $a = 1, 2, 3, 4$.

<details>
<summary>Answer</summary>

```python
import numpy as np
from scipy.stats import norm

rng = np.random.default_rng(42)
z = rng.normal(size=10_000_000)                        # standard normal
for a in [1, 2, 3, 4]:
    print(f"a = {a}: simulated {np.mean(z >= a):.6f}, exact {norm.sf(a):.6f}, Chernoff exp(-a^2/2) = {np.exp(-a * a / 2):.6f}")
```

Output:

```text
a = 1: simulated 0.158510, exact 0.158655, Chernoff exp(-a^2/2) = 0.606531
a = 2: simulated 0.022759, exact 0.022750, Chernoff exp(-a^2/2) = 0.135335
a = 3: simulated 0.001364, exact 0.001350, Chernoff exp(-a^2/2) = 0.011109
a = 4: simulated 0.000034, exact 0.000032, Chernoff exp(-a^2/2) = 0.000335
```

The bound is true everywhere; the ratio to the exact value grows slowly (about $a\sqrt{2\pi}$).

</details>

## Summary

- Chernoff bound: $P(X \ge a) \le \min_{t \gt 0} e^{-ta} M_X(t)$. It is Markov's inequality applied to $e^{tX}$, with the best $t$ (where $K'(t) = a$).
- For independent sums the MGFs multiply, so the bound is exponentially small in $n$. For $\text{Bin}(n, p)$: $P(X \ge na) \le e^{-nD(a \Vert p)}$.
- Handy forms for sums of independent 0-1 variables with mean $\mu$: $e^{-\delta^2\mu/3}$ above and $e^{-\delta^2\mu/2}$ below.
- It needs the MGF to exist, so it works for light tails and fails for heavy tails.

The one formula to remember:

$$
\boxed{P(X \ge a) \le \min_{t \gt 0} \thinspace e^{-ta} M_X(t)}
$$
