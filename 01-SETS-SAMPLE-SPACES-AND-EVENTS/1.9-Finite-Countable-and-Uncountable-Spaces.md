# 1.9 Finite, Countable and Uncountable Spaces

[Probability](../README.md) / [Module 01: Sets, Sample Spaces and Events](README.md) / 1.9 Finite, Countable and Uncountable Spaces

**Level:** 1 (Zero) · **Time:** about 45 minutes · **Before this:** [1.8 De Morgan's Laws](1.8-De-Morgans-Laws.md)

> **Big idea:** A sample space is finite, countably infinite or uncountable, and its size decides how probabilities can be given to its events.

---

## Why It Matters

The counting rule of [1.1](1.1-What-is-Probability.md) needs a finite sample space. But many
real experiments have no largest outcome (the number of emails in an hour) or have so many
outcomes that you cannot even list them (an exact waiting time). Knowing which kind of
infinity you face tells you which tool to use: sums for the **discrete** random variables of
[Module 05](../05-DISCRETE-RANDOM-VARIABLES/README.md), and lengths and integrals for the
**continuous** ones of [Module 08](../08-CONTINUOUS-RANDOM-VARIABLES/README.md).

## Intuition

Look at three experiments.

- **Roll a die.** There are 6 outcomes. You can write them all down and stop.
- **Flip a coin until the first head.** The answer can be 1 flip, 2 flips, 3 flips, and so
  on. There is no largest answer, so the list never ends. But you can still **list** the
  outcomes one by one: first 1, then 2, then 3. Every possible answer appears at some finite
  place in the list.
- **Pick a random point on a ruler from 0 to 1.** Between any two points there are more
  points. Here something stranger is true: no list at all, even an endless one, can contain
  every point. You will see the proof below.

These three kinds of size behave differently. In the first, you can count. In the second,
you can add up probabilities one outcome at a time, but they must get smaller and smaller.
In the third, every single point has probability 0, and probability must come from
**length** instead.

## Picture

```text
   FINITE               COUNTABLY INFINITE       UNCOUNTABLE
   roll a die           flips until first head   a random point in [0, 1]

   1  2  3  4  5  6     1  2  3  4  5  6  ...    0 |================| 1

   list them all        list them one by one,    every point is an
   and stop             but the list never       outcome; no list can
                        ends                     hold them all

   size: 6              size: countable          size: uncountable
```

The three sizes a sample space can have, from the smallest to the largest.

## Definition

A set is **finite** if it has $n$ elements for some whole number $n$. For example,
$\lbrace 1, 2, 3, 4, 5, 6 \rbrace$ has $n = 6$.

A set is **countably infinite** if it is infinite and its elements can be written as one
endless list

$$
\omega_1, \omega_2, \omega_3, \dots
$$

in which every element appears exactly once. In other words, there is a **one-to-one
matching** (also called a **bijection**) between the set and the positive whole numbers
$\lbrace 1, 2, 3, \dots \rbrace$. Examples: $\lbrace 1, 2, 3, \dots \rbrace$ itself, and
$\lbrace 0, 1, 2, \dots \rbrace$ (match $k$ with $k + 1$).

A set is **countable** if it is finite or countably infinite. A set is **uncountable** if
it is not countable: no list can contain all its elements. Examples: the interval
$[0, 1]$, all real numbers $\mathbb{R}$, and the set of all infinite sequences of coin flips.

A sample space that is countable is called **discrete**. On a discrete sample space, give
each outcome a probability $P(\lbrace \omega \rbrace) \ge 0$, with all of them adding up to
1. Then every event gets its probability by adding:

$$
P(A) = \sum_{\omega \in A} P(\lbrace \omega \rbrace)
$$

**In words:** in a countable sample space, the probability of an event is the sum of the
probabilities of the outcomes in it.

This works because different outcomes are mutually exclusive
([1.6](1.6-Mutually-Exclusive-Events.md)). For an infinite list of outcomes, adding them
up is allowed by the third axiom in
[3.2 Kolmogorov Axioms](../03-AXIOMS-OF-PROBABILITY/3.2-Kolmogorov-Axioms.md).

On an uncountable sample space this sum does not work, because single points have
probability 0. Probability comes from length or area instead
([3.8 Geometric Probability](../03-AXIOMS-OF-PROBABILITY/3.8-Geometric-Probability.md)),
and later from densities ([8.1](../08-CONTINUOUS-RANDOM-VARIABLES/8.1-Probability-Density-Function.md)).

## Why It Is True

**1. The integers are countable.** Even though they go on in two directions, we can list
them: $0, 1, -1, 2, -2, 3, -3, \dots$. Every integer appears at some finite place: $0$ at
place 1, a positive $k$ at place $2k$, and $-k$ at place $2k + 1$. So "infinite in two directions" is
still countable.

**2. No fair choice among infinitely many outcomes.** Suppose a countably infinite sample
space $\omega_1, \omega_2, \dots$ had all outcomes equally likely, each with probability $c$.

- If $c \gt 0$, pick a whole number $n \gt \frac{1}{c}$. The first $n$ outcomes alone would
  have total probability $nc \gt 1$. That is impossible.
- If $c = 0$, all the outcomes together would have probability $0 + 0 + \dots = 0$, not 1.

So in a countably infinite space, the outcomes **cannot** all be equally likely. Their
probabilities must shrink, like $\frac{1}{2}, \frac{1}{4}, \frac{1}{8}, \dots$

**3. The infinite coin-flip sequences are uncountable (Cantor's diagonal argument).** Write
heads as 1 and tails as 0. Suppose, to get a contradiction, that some list
$s_1, s_2, s_3, \dots$ contains **every** infinite 0/1 sequence. Build a new sequence $d$
by walking down the diagonal and flipping each digit:

```text
               position:   1   2   3   4   5  ...
     s1          =         0   1   1   0   1  ...
     s2          =         1   1   0   0   0  ...
     s3          =         0   0   0   1   1  ...
     s4          =         1   0   1   1   0  ...
     s5          =         0   1   0   0   1  ...
     ...
     diagonal    =         0   1   0   1   1  ...   (digit k of s_k)
     d (flipped) =         1   0   1   0   0  ...   differs from every s_k
```

Digit $k$ of $d$ is different from digit $k$ of $s_k$. So $d$ is not $s_1$ (they differ at
place 1), not $s_2$ (they differ at place 2), and so on: $d$ is not anywhere in the list.
But $d$ is an infinite 0/1 sequence, and the list was supposed to contain all of them. This
contradiction shows that no such list exists.

**4. The interval $[0, 1]$ is uncountable.** Read a 0/1 sequence as a binary number:
$0.b_1 b_2 b_3 \dots$ in base 2. Every sequence gives a number in $[0, 1]$, and each number
comes from at most two sequences (for example $0.0111\dots = 0.1000\dots$ in base 2). If
we could list $[0, 1]$, we could list all sequences, two per number. Point 3 says that is
impossible.

## Worked Examples

### Example 1: Flips Until the First Head

**Problem.** Flip a fair coin until the first head. Let $\Omega = \lbrace 1, 2, 3, \dots \rbrace$
be the number of flips. Find the probability of each outcome, check that they add up to 1,
and find (a) $P(\text{at most 3 flips})$, (b) $P(\text{an even number of flips})$.

**Solution.**

1. The first head comes on flip $k$ exactly when the first $k$ flips are $T \dots TH$: $k - 1$ tails, then a
   head. That is 1 of the $2^k$ equally likely strings of $k$ flips
   ([1.2](1.2-Random-Experiments-and-Sample-Spaces.md)). So:

$$
P(\lbrace k \rbrace) = \frac{1}{2^k}, \qquad k = 1, 2, 3, \dots
$$

2. Check the total. Let $S_n$ be the sum of the first $n$ terms. Double it and subtract:

$$
\begin{aligned}
S_n &= \tfrac{1}{2} + \tfrac{1}{4} + \dots + \tfrac{1}{2^n} \\
2 S_n &= 1 + \tfrac{1}{2} + \dots + \tfrac{1}{2^{n-1}} \\
2 S_n - S_n &= 1 - \tfrac{1}{2^n} && \text{(all middle terms cancel)}
\end{aligned}
$$

So $S_n = 1 - \frac{1}{2^n}$, which gets as close to 1 as we like as $n$ grows. The full
infinite sum is 1.

3. (a) The event "at most 3 flips" is $\lbrace 1, 2, 3 \rbrace$:

$$
P(\lbrace 1, 2, 3 \rbrace) = \frac{1}{2} + \frac{1}{4} + \frac{1}{8} = \frac{4 + 2 + 1}{8} = \frac{7}{8}
$$

4. (b) The event "even" is $\lbrace 2, 4, 6, \dots \rbrace$, an infinite event. Call its
   probability $T$, multiply by 4, and compare:

$$
\begin{aligned}
T &= \tfrac{1}{4} + \tfrac{1}{16} + \tfrac{1}{64} + \dots \\
4T &= 1 + \tfrac{1}{4} + \tfrac{1}{16} + \dots = 1 + T
\end{aligned}
$$

So $4T = 1 + T$, which gives $3T = 1$ and $T = \frac{1}{3}$.

**Answer.** $P(\lbrace k \rbrace) = \frac{1}{2^k}$; (a) $\frac{7}{8}$; (b) $\frac{1}{3}$.

**Check.** An odd number of flips must then have probability $1 - \frac{1}{3} = \frac{2}{3}$:
odd numbers win, because the most likely outcome, 1 flip, is odd. The outcome "tails
forever" is not in $\Omega$. It is allowed to leave it out: its probability would be at most
$\frac{1}{2^n}$ for every $n$, so it is 0.

### Example 2: Which Size Is It

**Problem.** Classify each sample space as finite, countably infinite or uncountable.

**Solution.**

| Experiment | Sample space | Size |
|---|---|---|
| A password of exactly 8 lowercase letters | all strings of length 8 | finite: $26^8 = 208{,}827{,}064{,}576$ |
| Emails arriving in one hour | $\lbrace 0, 1, 2, \dots \rbrace$ | countably infinite |
| Retries until a packet gets through | $\lbrace 1, 2, 3, \dots \rbrace$ | countably infinite |
| Exact response time of a server, in seconds | $[0, \infty)$ | uncountable |
| Every future flip of a coin | all infinite H/T sequences | uncountable |

**Answer.** As in the table. Note that a huge finite space (the passwords) is still
finite: the counting rule works, even if the numbers are big.

**Check.** The email count has no fixed upper limit, so we allow every whole number. In
practice it will never be a billion, but such outcomes just get tiny probabilities.

### Example 3: A Random Point in an Interval

**Problem.** A random number $x$ is picked from $[0, 1]$ so that the probability of landing
in any interval equals the length of that interval. Find $P(0.2 \le x \le 0.5)$ and
$P(x = 0.5)$.

**Solution.**

1. The interval $[0.2, 0.5]$ has length $0.5 - 0.2 = 0.3$, so
   $P(0.2 \le x \le 0.5) = 0.3$.
2. The single point $0.5$ is the interval $[0.5, 0.5]$, of length $0.5 - 0.5 = 0$. So
   $P(x = 0.5) = 0$.

**Answer.** $P(0.2 \le x \le 0.5) = 0.3$ and $P(x = 0.5) = 0$.

**Check.** The value $0.5$ is a perfectly possible outcome, yet its probability is 0. In an
uncountable space, **probability 0 does not mean impossible**: some point must come up, and
every point has probability 0. See
[8.2 Why Point Probabilities are Zero](../08-CONTINUOUS-RANDOM-VARIABLES/8.2-Why-Point-Probabilities-are-Zero.md).

## Simulate It

The code checks Example 1 and Example 3. numpy's `rng.geometric(0.5)` directly gives the
number of flips until the first head (the geometric distribution of
[7.3](../07-DISCRETE-DISTRIBUTIONS/7.3-Geometric.md)).

```python
import numpy as np

rng = np.random.default_rng(42)
n_trials = 1_000_000

# Countably infinite: the number of flips until the first head (1, 2, 3, ...).
flips = rng.geometric(0.5, size=n_trials)
for k in range(1, 5):
    print(f"P(first head on flip {k}): simulation {np.mean(flips == k):.4f}, "
          f"exact {0.5 ** k:.4f}")
print(f"P(even number of flips):  simulation {np.mean(flips % 2 == 0):.4f}, "
      f"exact {1 / 3:.4f}")

# Uncountable: a random number in [0, 1]. Probability comes from length.
x = rng.random(n_trials)
print(f"P(0.2 <= x <= 0.5):       simulation {np.mean((x >= 0.2) & (x <= 0.5)):.4f}, "
      f"exact {0.3:.4f}")
print(f"Runs where x was exactly 0.5: {np.sum(x == 0.5)}")
```

Output:

```text
P(first head on flip 1): simulation 0.5002, exact 0.5000
P(first head on flip 2): simulation 0.2497, exact 0.2500
P(first head on flip 3): simulation 0.1249, exact 0.1250
P(first head on flip 4): simulation 0.0627, exact 0.0625
P(even number of flips):  simulation 0.3333, exact 0.3333
P(0.2 <= x <= 0.5):       simulation 0.3003, exact 0.3000
Runs where x was exactly 0.5: 0
```

In a million tries, $x$ never hit $0.5$ exactly. (A computer number is really one of finitely
many values, so the true chance is tiny rather than 0. The continuous model is a very good
approximation.)

## Common Mistakes

- **Thinking "infinite" means "uncountable".** $\lbrace 1, 2, 3, \dots \rbrace$ is infinite
  but countable. Uncountable is a strictly bigger kind of infinity.
- **Making infinitely many outcomes equally likely.** On a countably infinite space this is
  impossible (point 2 above). On $[0, 1]$, "uniform" means equal probability for equal
  **lengths**, not for points.
- **Reading probability 0 as impossible.** On an uncountable space every single outcome has
  probability 0, yet one of them happens.
- **Using the counting rule on an infinite space.** $\frac{\lvert A \rvert}{\lvert \Omega \rvert}$
  makes no sense when $\Omega$ is infinite. Use sums (countable) or lengths (uncountable).
- **Forgetting that big finite spaces are still finite.** $26^8$ passwords is huge, but
  every password still has probability $\frac{1}{26^8}$ under a random choice.

## Where It Is Used

- **AI and machine learning:** class labels form a finite space; counts of words in a
  document are countable; model weights and sensor readings are modelled as real numbers,
  an uncountable space with densities.
- **Computer science:** "retries until success" and "steps until a randomized algorithm
  stops" live in $\lbrace 1, 2, 3, \dots \rbrace$. Cantor's diagonal argument is also the
  reason some problems cannot be solved by any program.
- **Networks and queues:** the number of packets or customers that arrive is countable,
  modelled with the Poisson distribution ([7.5](../07-DISCRETE-DISTRIBUTIONS/7.5-Poisson.md)).
- **Physics and engineering:** times, distances and voltages are modelled as continuous,
  uncountable quantities.
- **Everyday life:** "how many tries until I pass the driving test" has no fixed upper
  limit, but large numbers of tries get small probabilities.

## Practice

**1. (Easy)** Classify each sample space as finite, countably infinite or uncountable:
(a) the suit of a card; (b) the number of goals in a football match; (c) the exact height of
a random person; (d) the number of visitors to a website tomorrow.

<details>
<summary>Answer</summary>

(a) Finite: 4 suits. (b) Countably infinite: $\lbrace 0, 1, 2, \dots \rbrace$ (we do not fix
a largest score). (c) Uncountable: any real number in some range. (d) Countably infinite:
$\lbrace 0, 1, 2, \dots \rbrace$ in the usual model.

</details>

**2. (Easy)** Show that the set of odd positive numbers $\lbrace 1, 3, 5, \dots \rbrace$ is
countable.

<details>
<summary>Answer</summary>

Match each $n = 1, 2, 3, \dots$ with the odd number $2n - 1$. This gives the list
$1, 3, 5, 7, \dots$, which contains every odd positive number exactly once: the odd number
$m$ is at place $\frac{m + 1}{2}$. So the set is countable, even though it seems to be "half"
of the positive numbers.

</details>

**3. (Medium)** Flip a fair coin until the first head. What is the probability that you need
more than 3 flips? Answer in two different ways.

<details>
<summary>Answer</summary>

First way: "more than 3" is the complement of "at most 3", which has probability $\frac{7}{8}$
(Example 1). So the answer is $1 - \frac{7}{8} = \frac{1}{8}$.

Second way: you need more than 3 flips exactly when the first 3 flips are all tails, which
is 1 of the 8 equally likely strings of 3 flips:

$$P(\text{more than 3 flips}) = \frac{1}{8}$$

</details>

**4. (Medium)** A friend says: "Pick a positive whole number completely at random, each one
equally likely." Explain why this is impossible.

<details>
<summary>Answer</summary>

If each number had the same probability $c \gt 0$, then the first $n$ numbers with
$n \gt \frac{1}{c}$ would have total probability $nc \gt 1$, which is impossible. If $c = 0$,
the total over all numbers would be 0, not 1. Either way, no such rule exists. A random
positive whole number must favor some numbers over others, for example
$P(\lbrace k \rbrace) = \frac{1}{2^k}$.

</details>

**5. (Hard)** Prove that the set of all pairs $(i, j)$ of positive whole numbers is
countable. What does this say about the positive fractions $\frac{i}{j}$?

<details>
<summary>Answer</summary>

List the pairs by their sum $s = i + j$. For $s = 2$: $(1,1)$. For $s = 3$: $(1,2), (2,1)$.
For $s = 4$: $(1,3), (2,2), (3,1)$. And so on. Each group is finite (it has $s - 1$ pairs),
so every pair $(i, j)$ appears at some finite place. In fact the pair $(i, j)$ with
$s = i + j$ is at place

$$\frac{(s - 2)(s - 1)}{2} + i$$

because the earlier groups hold $1 + 2 + \dots + (s - 2) = \frac{(s-2)(s-1)}{2}$ pairs.
For example $(1,1)$ is at place $0 + 1 = 1$ and $(1,3)$ is at place $3 + 1 = 4$.

Every positive fraction $\frac{i}{j}$ comes from a pair, so we can list all positive fractions
too (skip repeats like $\frac{2}{4} = \frac{1}{2}$). The positive fractions are countable,
while $[0, 1]$ is not.

</details>

**6. (Simulate)** Roll a fair die until the first six. Simulate 1,000,000 runs to estimate the
probability that you need more than 6 rolls. The exact answer is
$\left( \frac{5}{6} \right)^6$, because the first 6 rolls must all avoid the six: $5^6$ of the
$6^6$ equally likely strings.

<details>
<summary>Answer</summary>

```python
import numpy as np

rng = np.random.default_rng(42)
rolls = rng.integers(1, 7, size=(1_000_000, 6))     # the first 6 rolls are enough
more_than_6 = (rolls != 6).all(axis=1)            # no six in the first 6 rolls
print(f"Simulation: {more_than_6.mean():.4f}")
print(f"Exact:      {(5 / 6) ** 6:.4f}")
```

Output:

```text
Simulation: 0.3352
Exact:      0.3349
```

</details>

## Summary

- A sample space is finite, countably infinite (can be listed, but the list never ends), or
  uncountable (cannot be listed at all).
- Countable spaces are discrete: give each outcome a probability and add them up.
- On a countably infinite space the outcomes cannot all be equally likely.
- Cantor's diagonal argument shows that infinite coin-flip sequences, and the interval
  $[0, 1]$, are uncountable.
- On an uncountable space single points have probability 0, and probability comes from
  length, area or density.

The one formula to remember (for a countable sample space):

$$
\boxed{P(A) = \sum_{\omega \in A} P(\lbrace \omega \rbrace)}
$$
