# 1.5 Venn Diagrams

[Probability](../README.md) / [Module 01: Sets, Sample Spaces and Events](README.md) / 1.5 Venn Diagrams

**Level:** 1 (Zero) · **Time:** about 35 minutes · **Before this:** [1.4 Set Operations on Events](1.4-Set-Operations-on-Events.md)

> **Big idea:** A Venn diagram draws events as regions inside a box, so you can see unions, intersections and complements, and count by filling in one region at a time.

---

## Why It Matters

Set formulas from [1.4](1.4-Set-Operations-on-Events.md) are exact, but they are hard to
"see". A **Venn diagram** turns them into a picture you can check in seconds. It is the
fastest way to avoid the most common counting mistake, counting the overlap twice. You will
draw one for almost every problem with two or three events, including the conditional
probability problems of [Module 04](../04-CONDITIONAL-PROBABILITY-AND-BAYES/README.md).

## Intuition

A teacher asks 100 computer science students two questions: "Do you know Python?" and "Do
you know Java?". 60 say yes to Python, 45 say yes to Java, and 25 say yes to both. How many
know neither?

Adding $60 + 45 = 105$ gives more than 100 students, so something is counted twice: the 25
who know both. Draw two overlapping boxes. Put 25 in the overlap first. Then the "Python
only" part holds $60 - 25 = 35$, and the "Java only" part holds $45 - 25 = 20$. Together
the boxes hold $35 + 25 + 20 = 80$ students. The other $100 - 80 = 20$ students know
neither language.

The trick is to fill the picture **from the inside out**: first the overlap, then the parts
around it, and last the outside.

## Picture

```text
   Ω = 100 students
  +------------------------------------------------------------+
  |                                                            |
  |    +-------------------------+                             |
  |    | P = Python              |                             |
  |    |             +-----------+-------------+               |
  |    |             |           |             |               |
  |    |  only P     |  both     |             |               |
  |    |   35        |   25      |   only J    |               |
  |    |             |           |    20       |               |
  |    +-------------+-----------+             |               |
  |                  |              J = Java   |               |
  |                  +-------------------------+    neither    |
  |                                                  20        |
  +------------------------------------------------------------+
```

Two events cut the sample space into 4 regions; the numbers in the 4 regions add up to 100.

With three events there are 8 regions. We number them like this, and use the numbers in the
rest of this file:

```text
   Ω
  +------------------------------------------------------+
  |                                                      |
  |   +-------------------------+                        |
  |   | A     [1]               |                        |
  |   |             +-----------+-------------+          |
  |   |             |   [4]     |             |          |
  |   |     +-------+-----------+-----+       |          |
  |   |     | [5]   |   [7]     |     |       |          |
  |   |     |       |           |     |       |          |
  |   +-----+-------+-----------+     |   [2] |          |
  |         |       |            [6]  |    B  |          |
  |         |       +-----------------+-------+          |
  |         | C       [3]             |           [8]    |
  |         +-------------------------+                  |
  +------------------------------------------------------+
```

The three events A, B and C cut the sample space into 8 regions, one for each way to be in
or out of each event.

## Definition

A **Venn diagram** draws the sample space $\Omega$ as a rectangle and each event as a closed
shape (a circle or a box) inside it. Each outcome sits at exactly one point of the picture.
A **region** is a piece of the picture that lies inside some of the shapes and outside all
the others.

For three events, the 8 regions are these intersections:

| Region | Set | In words |
|---|---|---|
| [1] | $A \cap B^c \cap C^c$ | only A |
| [2] | $A^c \cap B \cap C^c$ | only B |
| [3] | $A^c \cap B^c \cap C$ | only C |
| [4] | $A \cap B \cap C^c$ | A and B, but not C |
| [5] | $A \cap B^c \cap C$ | A and C, but not B |
| [6] | $A^c \cap B \cap C$ | B and C, but not A |
| [7] | $A \cap B \cap C$ | all three |
| [8] | $A^c \cap B^c \cap C^c$ | none of them |

Every event built from $A$, $B$, $C$ is a union of some of these regions. For example,
$A$ is regions [1], [4], [5], [7], and $B \cup C$ is every region except [1] and [8].

With $n$ events, a full Venn diagram has

$$
\text{number of regions} = 2^n
$$

**In words:** each region is one pattern of "in" or "out" for each of the $n$ events, and
there are $2^n$ such patterns.

## Why It Is True

**Why $2^n$ regions.** For each event, an outcome is either inside or outside: 2 choices.
For $n$ events that is a string of $n$ choices, like $n$ coin flips, so there are $2^n$
patterns ([1.2](1.2-Random-Experiments-and-Sample-Spaces.md)). Each pattern is one region.
The regions never overlap, and together they cover all of $\Omega$, because every outcome
has exactly one pattern.

**Why counts add up.** Since the regions do not overlap, the size of any event is the sum of
its regions. For two events, $A \cup B$ is three regions: only A, both, only B. And $A$
itself is two regions: only A and both. So:

$$
\begin{aligned}
\lvert A \cup B \rvert &= \lvert A \cap B^c \rvert + \lvert A \cap B \rvert + \lvert A^c \cap B \rvert && \text{(three regions, no overlap)} \\
&= \big( \lvert A \rvert - \lvert A \cap B \rvert \big) + \lvert A \cap B \rvert + \big( \lvert B \rvert - \lvert A \cap B \rvert \big) && \text{(} A \text{ and } B \text{ are two regions each)} \\
&= \lvert A \rvert + \lvert B \rvert - \lvert A \cap B \rvert && \text{(collect terms)}
\end{aligned}
$$

**In words:** add the two events, then subtract the overlap once, because it was counted
twice. This is the simplest case of **inclusion-exclusion**, studied fully in
[2.8 Inclusion-Exclusion](../02-COUNTING/2.8-Inclusion-Exclusion.md). For probabilities it
becomes the addition rule of [3.4](../03-AXIOMS-OF-PROBABILITY/3.4-Addition-Rule.md).

**Why a region check is a real proof.** Whether an outcome belongs to an expression such as
$(A \cup B) \cap C^c$ depends only on its in/out pattern, that is, on its region. So two
expressions are equal exactly when they contain the same regions. Checking all $2^n$
regions is the truth table of [1.4](1.4-Set-Operations-on-Events.md) drawn as a picture.
Looking at one drawing and "seeing" that two areas match is **not** a proof, but checking
every region is.

## Worked Examples

### Example 1: Python and Java

**Problem.** Of 100 students, 60 know Python, 45 know Java and 25 know both. How many know
neither? How many know exactly one? If we pick a student at random, what is the
probability that the student knows exactly one of the two languages?

**Solution.**

1. Let $P$ = "knows Python" and $J$ = "knows Java". Start in the middle:
   $\lvert P \cap J \rvert = 25$.
2. Python only: $\lvert P \cap J^c \rvert = 60 - 25 = 35$.
3. Java only: $\lvert P^c \cap J \rvert = 45 - 25 = 20$.
4. Inside the boxes: $\lvert P \cup J \rvert = 35 + 25 + 20 = 80$.
5. Outside: $\lvert P^c \cap J^c \rvert = 100 - 80 = 20$.
6. Exactly one language: $35 + 20 = 55$ students. Each student is equally likely to be
   picked, so:

$$
P(\text{exactly one}) = \frac{55}{100} = 0.55
$$

**Answer.** 20 students know neither language, 55 know exactly one, and the probability is
$0.55$.

**Check.** The formula gives $\lvert P \cup J \rvert = 60 + 45 - 25 = 80$, the same as step 4.
And the 4 regions add up: $35 + 25 + 20 + 20 = 100$.

### Example 2: Three Spam Rules

**Problem.** A mail server checks 200 emails with three rules: $A$ = "contains a link",
$B$ = "sender is unknown", $C$ = "says the word free". The counts are:
$\lvert A \rvert = 70$, $\lvert B \rvert = 75$, $\lvert C \rvert = 60$,
$\lvert A \cap B \rvert = 25$, $\lvert A \cap C \rvert = 15$, $\lvert B \cap C \rvert = 30$,
$\lvert A \cap B \cap C \rvert = 10$. How many emails trigger no rule? Exactly one rule? If
an email is picked at random, what is the probability that it triggers at least two rules?

**Solution.** Fill the 8 regions from the center outward, using the region numbers from the
picture.

1. Center: region [7] $= \lvert A \cap B \cap C \rvert = 10$.
2. Two-event regions. Each pair overlap contains the center, so subtract it:
   region [4] $= 25 - 10 = 15$, region [5] $= 15 - 10 = 5$, region [6] $= 30 - 10 = 20$.
3. One-event regions. Subtract everything else inside that event:
   region [1] $= 70 - 15 - 5 - 10 = 40$, region [2] $= 75 - 15 - 20 - 10 = 30$,
   region [3] $= 60 - 5 - 20 - 10 = 25$.
4. Inside at least one shape: $10 + 15 + 5 + 20 + 40 + 30 + 25 = 145$.
5. Outside all shapes: region [8] $= 200 - 145 = 55$.
6. Exactly one rule: regions [1], [2], [3]: $40 + 30 + 25 = 95$.
7. At least two rules: regions [4], [5], [6], [7]: $15 + 5 + 20 + 10 = 50$. So:

$$
P(\text{at least two rules}) = \frac{50}{200} = 0.25
$$

**Answer.** 55 emails trigger no rule, 95 trigger exactly one, and the probability of at
least two is $0.25$.

**Check.** All 8 regions add up to the total: $40 + 30 + 25 + 15 + 5 + 20 + 10 + 55 = 200$.
The simulation below rebuilds the 200 emails from the regions and gets back every count we
started with.

### Example 3: Checking an Identity With Regions

**Problem.** Is $(A \cup B) \setminus C = A \cup (B \setminus C)$ true for all events?

**Solution.**

1. Write each event as its regions: $A = \lbrace 1, 4, 5, 7 \rbrace$,
   $B = \lbrace 2, 4, 6, 7 \rbrace$, $C = \lbrace 3, 5, 6, 7 \rbrace$ (sets of region
   numbers).
2. Left side: $A \cup B$ is regions $\lbrace 1, 2, 4, 5, 6, 7 \rbrace$. Remove the
   regions of $C$: left with $\lbrace 1, 2, 4 \rbrace$.
3. Right side: $B \setminus C$ is $\lbrace 2, 4 \rbrace$. Add $A$: right side is
   $\lbrace 1, 2, 4, 5, 7 \rbrace$.
4. The sides differ in regions [5] and [7], the outcomes in both $A$ and $C$.
5. A concrete counterexample, for one die: $A = \lbrace 1 \rbrace$, $B = \varnothing$,
   $C = \lbrace 1 \rbrace$. The left side is $\varnothing$, but the right side is
   $\lbrace 1 \rbrace$.

**Answer.** No. The correct identity is $(A \cup B) \setminus C = (A \setminus C) \cup (B \setminus C)$,
which is regions $\lbrace 1, 4 \rbrace \cup \lbrace 2, 4 \rbrace = \lbrace 1, 2, 4 \rbrace$.

**Check.** The region check found the exact place where the claim fails, and the die example
confirms it.

## Simulate It

The code rebuilds the 200 emails of Example 2 from the region counts, checks that the
totals come back, and then picks emails at random.

```python
import numpy as np

rng = np.random.default_rng(42)

# Region counts from Example 2: (in A, in B, in C) -> number of emails.
regions = {(1, 0, 0): 40, (0, 1, 0): 30, (0, 0, 1): 25, (1, 1, 0): 15,
           (1, 0, 1): 5, (0, 1, 1): 20, (1, 1, 1): 10, (0, 0, 0): 55}
emails = np.repeat(np.array(list(regions)), list(regions.values()), axis=0)
A, B, C = emails[:, 0] == 1, emails[:, 1] == 1, emails[:, 2] == 1

# The filled-in regions must give back the numbers we started from.
print("Total:", len(emails), "| A:", A.sum(), "| B:", B.sum(), "| C:", C.sum())
print("A and B:", (A & B).sum(), "| A and C:", (A & C).sum(),
      "| B and C:", (B & C).sum(), "| all three:", (A & B & C).sum())

# Pick emails at random. Estimate P(flagged by at least two rules).
n_trials = 100_000
picks = rng.integers(0, len(emails), size=n_trials)
n_flags = emails.sum(axis=1)
print(f"Simulation: {np.mean(n_flags[picks] >= 2):.4f}")
print(f"Exact:      {50 / 200:.4f}")
```

Output:

```text
Total: 200 | A: 70 | B: 75 | C: 60
A and B: 25 | A and C: 15 | B and C: 30 | all three: 10
Simulation: 0.2506
Exact:      0.2500
```

Every count from the problem comes back exactly, so the region values are right.

## Common Mistakes

- **Putting the total of $A$ in the "only A" region.** "60 know Python" includes the 25 who
  also know Java. Always fill from the inside out.
- **Forgetting the outside region.** The part of $\Omega$ outside every shape is a real
  region, often the one the question asks about.
- **Reading probability from area.** The size of a region in the drawing means nothing. Only
  the numbers you write in it count.
- **Proving by one drawing.** A drawing shows one arrangement. A proof must check every
  region, or chase elements as in [1.4](1.4-Set-Operations-on-Events.md).
- **Drawing four events with circles.** Four circles can make at most 14 regions, but four
  events need $2^4 = 16$. Use carefully placed ellipses, or a table of regions, for four or
  more events.

## Where It Is Used

- **AI and machine learning:** a **confusion matrix** is a two-event Venn diagram written as
  a table: "predicted positive" and "actually positive" make the 4 regions true positive,
  false positive, false negative and true negative.
- **Databases:** an SQL `INNER JOIN` keeps the overlap of two tables' keys, and a
  `FULL OUTER JOIN` keeps their union.
- **Biology:** researchers draw Venn diagrams of the genes found by two or three
  experiments, to see which genes all experiments agree on.
- **Surveys and marketing:** "who uses product A, B or both" is a Venn diagram of customers.
- **Everyday life:** finding a meeting time that suits two people is finding the overlap of
  their free times.

## Practice

**1. (Easy)** In a class of 40 students, 25 play cricket, 18 play football, and 10 play both.
How many play neither?

<details>
<summary>Answer</summary>

Cricket only: $25 - 10 = 15$. Football only: $18 - 10 = 8$. Inside the shapes:
$15 + 10 + 8 = 33$. Neither: $40 - 33 = 7$ students.

</details>

**2. (Easy)** In a two-event Venn diagram, which region is $A^c \cap B$? Which regions make
up $A \cup B^c$?

<details>
<summary>Answer</summary>

$A^c \cap B$ is the "only B" region: inside $B$, outside $A$. The event $A \cup B^c$ is the
other three regions: only A, both, and the outside. It is the complement of $A^c \cap B$.

</details>

**3. (Medium)** Use regions to decide whether $A \setminus (B \cup C) = (A \setminus B) \cap (A \setminus C)$
for all events $A$, $B$, $C$.

<details>
<summary>Answer</summary>

With the region numbers of this file: $A = \lbrace 1, 4, 5, 7 \rbrace$ and
$B \cup C = \lbrace 2, 3, 4, 5, 6, 7 \rbrace$, so the left side is $\lbrace 1 \rbrace$. On
the right, $A \setminus B = \lbrace 1, 5 \rbrace$ and $A \setminus C = \lbrace 1, 4 \rbrace$,
and their intersection is $\lbrace 1 \rbrace$. Both sides are region [1], "only A", so the
identity is true.

</details>

**4. (Medium)** 100 people say which of three apps they use. 50 use app A, 40 use B, 30 use
C. 20 use A and B, 15 use A and C, 10 use B and C, and 5 use all three. How many use none of
the apps? How many use exactly one? What is the probability that a random person uses
exactly one?

<details>
<summary>Answer</summary>

Fill from the center: all three: 5. A and B only: $20 - 5 = 15$. A and C only:
$15 - 5 = 10$. B and C only: $10 - 5 = 5$. Only A: $50 - 15 - 10 - 5 = 20$. Only B:
$40 - 15 - 5 - 5 = 15$. Only C: $30 - 10 - 5 - 5 = 10$. Inside:
$5 + 15 + 10 + 5 + 20 + 15 + 10 = 80$, so 20 people use none. Exactly one:
$20 + 15 + 10 = 45$ people:

$$P(\text{exactly one}) = \frac{45}{100} = 0.45$$

</details>

**5. (Hard)** A sample space has 100 equally likely outcomes. Event $A$ has 60 outcomes and
event $B$ has 50. What are the smallest and the largest possible values of
$\lvert A \cap B \rvert$? Give an example for each.

<details>
<summary>Answer</summary>

Largest: the overlap cannot be bigger than the smaller event, so it is at most 50. This
happens when $B \subseteq A$, for example $A = \lbrace 1, \dots, 60 \rbrace$ and
$B = \lbrace 1, \dots, 50 \rbrace$.

Smallest: the union fits inside $\Omega$, so $\lvert A \cup B \rvert \le 100$. Use the
formula from "Why It Is True":

$$\lvert A \cap B \rvert = \lvert A \rvert + \lvert B \rvert - \lvert A \cup B \rvert \ge 60 + 50 - 100 = 10$$

This happens when $A \cup B = \Omega$, for example $A = \lbrace 1, \dots, 60 \rbrace$ and
$B = \lbrace 51, \dots, 100 \rbrace$, whose overlap is $\lbrace 51, \dots, 60 \rbrace$. So
$10 \le \lvert A \cap B \rvert \le 50$.

</details>

**6. (Simulate)** Build the 100 people of Problem 4 from your region counts, pick people at
random 100,000 times, and estimate the probability of exactly one app.

<details>
<summary>Answer</summary>

```python
import numpy as np

rng = np.random.default_rng(42)
# Regions from Problem 4: only-one-app regions hold 20 + 15 + 10 people.
n_apps = np.repeat([1, 2, 3, 0], [20 + 15 + 10, 15 + 10 + 5, 5, 20])
picks = rng.integers(0, 100, size=100_000)
print(f"Simulation: {np.mean(n_apps[picks] == 1):.4f}")
print(f"Exact:      {45 / 100:.4f}")
```

Output:

```text
Simulation: 0.4502
Exact:      0.4500
```

</details>

## Summary

- A Venn diagram draws $\Omega$ as a box and each event as a shape inside it.
- Two events make 4 regions, three make 8, and $n$ events make $2^n$.
- Fill counts from the inside out: the overlap of all events first, the outside last.
- The regions never overlap, so their counts add up to the total. This gives the
  two-event counting formula below.
- A picture explains; a check of every region proves.

The one formula to remember:

$$
\boxed{\lvert A \cup B \rvert = \lvert A \rvert + \lvert B \rvert - \lvert A \cap B \rvert}
$$
