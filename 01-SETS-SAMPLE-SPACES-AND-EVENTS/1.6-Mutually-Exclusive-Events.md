# 1.6 Mutually Exclusive Events

[Probability](../README.md) / [Module 01: Sets, Sample Spaces and Events](README.md) / 1.6 Mutually Exclusive Events

**Level:** 1 (Zero) · **Time:** about 30 minutes · **Before this:** [1.5 Venn Diagrams](1.5-Venn-Diagrams.md)

> **Big idea:** Two events are mutually exclusive when they cannot happen at the same time, and then the chance of "one or the other" is just the sum of their chances.

---

## Why It Matters

Adding probabilities is the most natural thing to do, and the most common source of wrong
answers. It is correct **only** when the events cannot happen together. This topic gives
that condition a name and a test. It is the heart of the third axiom of probability in
[3.2 Kolmogorov Axioms](../03-AXIOMS-OF-PROBABILITY/3.2-Kolmogorov-Axioms.md), and it is
why the probabilities of a classifier's classes add up to 1.

## Intuition

Roll one die. "Roll a 1" and "roll a 6" cannot both happen: the die shows one face. To
count the ways to get "1 or 6", just add: $1 + 1 = 2$ ways out of 6.

Now take "roll an even number" (2, 4, 6) and "roll more than 3" (4, 5, 6). Adding gives
$3 + 3 = 6$ ways, which would make the event certain. But a roll of 1 is neither even nor
more than 3, so that is wrong. The faces 4 and 6 belong to **both** events and were counted
twice. The true count is 4 ways: 2, 4, 5, 6.

So the question "can these two events happen together?" decides whether simple adding works.
When the answer is no, the events are called **mutually exclusive**.

## Picture

```text
  +-------------------------------+    +-------------------------------+
  |                               |    |                               |
  |  +---------+                  |    |  +--------------+             |
  |  |         |    +----------+  |    |  | A            |             |
  |  |   A     |    |          |  |    |  |        +-----+---------+   |
  |  |         |    |    B     |  |    |  |        | A∩B |         |   |
  |  |         |    |          |  |    |  |        |     |         |   |
  |  +---------+    |          |  |    |  +--------+-----+         |   |
  |                 +----------+  |    |           |            B  |   |
  |                               |    |           +---------------+   |
  +-------------------------------+    +-------------------------------+
    mutually exclusive:                  NOT mutually exclusive:
    A ∩ B is empty                       A ∩ B has outcomes in it
```

On the left the two events share no outcome; on the right the shared part is counted twice
if you just add.

## Definition

Two events $A$ and $B$ are **mutually exclusive** (also called **disjoint**) when they have
no outcome in common:

$$
A \cap B = \varnothing
$$

**In words:** $A$ and $B$ can never happen in the same run of the experiment.

A list of events $A_1, A_2, \dots, A_n$ is **pairwise disjoint** when every two different
events in the list are mutually exclusive:

$$
A_i \cap A_j = \varnothing \quad \text{for all } i \ne j
$$

**In words:** no outcome belongs to two events of the list, so at most one of them can
happen.

The key property: for mutually exclusive events, sizes add. In a finite sample space with
equally likely outcomes this gives:

$$
A \cap B = \varnothing \implies P(A \cup B) = P(A) + P(B)
$$

**In words:** if two events cannot happen together, the probability that one of them happens
is the sum of their probabilities.

The same is true for any list of pairwise disjoint events. In
[Module 03](../03-AXIOMS-OF-PROBABILITY/README.md) this addition becomes an **axiom**, a rule
that every probability must obey, even when outcomes are not equally likely.

## Why It Is True

**Two events.** Suppose $A \cap B = \varnothing$. Every outcome of $A \cup B$ is in $A$ or in
$B$, and never in both. So if you list the outcomes of $A$ and then the outcomes of $B$, you
list every outcome of $A \cup B$ exactly once:

$$
\begin{aligned}
\lvert A \cup B \rvert &= \lvert A \rvert + \lvert B \rvert && \text{(no outcome is listed twice)} \\
\frac{\lvert A \cup B \rvert}{\lvert \Omega \rvert} &= \frac{\lvert A \rvert}{\lvert \Omega \rvert} + \frac{\lvert B \rvert}{\lvert \Omega \rvert} && \text{(divide by } \lvert \Omega \rvert \text{)} \\
P(A \cup B) &= P(A) + P(B) && \text{(counting rule)}
\end{aligned}
$$

This is also the formula of [1.5](1.5-Venn-Diagrams.md),
$\lvert A \cup B \rvert = \lvert A \rvert + \lvert B \rvert - \lvert A \cap B \rvert$,
with $\lvert A \cap B \rvert = 0$.

**Many events.** Let $A_1, \dots, A_n$ be pairwise disjoint. The union of the first $n - 1$
events shares no outcome with $A_n$: such an outcome would lie in some $A_i \cap A_n$ with
$i \lt n$, and that set is empty. So we can peel off one event at a time:

$$
\lvert A_1 \cup \dots \cup A_n \rvert = \lvert A_1 \cup \dots \cup A_{n-1} \rvert + \lvert A_n \rvert = \dots = \lvert A_1 \rvert + \lvert A_2 \rvert + \dots + \lvert A_n \rvert
$$

**Three useful pairs that are always disjoint.**

- $A$ and $A^c$: an outcome cannot be in $A$ and not in $A$.
- $A \cap B$ and $A \setminus B$: the first is inside $B$, the second outside. Their union
  is $A$, so $\lvert A \rvert = \lvert A \cap B \rvert + \lvert A \setminus B \rvert$.
- $\lbrace \omega_1 \rbrace$ and $\lbrace \omega_2 \rbrace$ for two different outcomes. This
  is why the probability of an event is the sum of the probabilities of its outcomes.

**Pairwise is stronger than "no common outcome to all".** For one die, take
$A = \lbrace 1, 2 \rbrace$, $B = \lbrace 2, 3 \rbrace$, $C = \lbrace 1, 3 \rbrace$. No
outcome is in all three, so $A \cap B \cap C = \varnothing$. But $A \cap B = \lbrace 2 \rbrace$,
so they are **not** pairwise disjoint, and adding gives
$\frac{2}{6} + \frac{2}{6} + \frac{2}{6} = 1$, while $P(A \cup B \cup C) = \frac{3}{6}$.

## Worked Examples

### Example 1: Adding Correctly on a Die

**Problem.** Roll a fair die. Let $A = \lbrace 1, 2 \rbrace$, $B = \lbrace 5, 6 \rbrace$ and
$C = \lbrace 2, 4, 6 \rbrace$. Find $P(A \cup B)$ and $P(A \cup C)$. Where does adding work?

**Solution.**

1. $A \cap B = \varnothing$, so $A$ and $B$ are mutually exclusive. Add:

$$
P(A \cup B) = P(A) + P(B) = \frac{2}{6} + \frac{2}{6} = \frac{4}{6} = \frac{2}{3}
$$

2. $A \cap C = \lbrace 2 \rbrace$, which is not empty. Adding would give
   $\frac{2}{6} + \frac{3}{6} = \frac{5}{6}$, which counts the outcome 2 twice.
3. Count directly instead: $A \cup C = \lbrace 1, 2, 4, 6 \rbrace$, so

$$
P(A \cup C) = \frac{4}{6} = \frac{2}{3}
$$

**Answer.** $P(A \cup B) = \frac{2}{3}$, found by adding. $P(A \cup C) = \frac{2}{3}$ too,
but adding would wrongly give $\frac{5}{6}$.

**Check.** The extra $\frac{5}{6} - \frac{4}{6} = \frac{1}{6}$ is exactly
$P(A \cap C) = P(\lbrace 2 \rbrace)$, the part counted twice.

### Example 2: Kings, Queens and Hearts

**Problem.** Draw one card from a well-shuffled deck of 52. Find
$P(\text{king or queen})$ and $P(\text{king or heart})$.

**Solution.**

1. One card cannot be a king and a queen at once. So these events are mutually exclusive.
   There are 4 kings and 4 queens:

$$
P(\text{king or queen}) = \frac{4}{52} + \frac{4}{52} = \frac{8}{52} = \frac{2}{13} \approx 0.154
$$

2. A card can be a king **and** a heart: the king of hearts. So these events are not
   mutually exclusive. Count the union: 13 hearts, plus the 3 kings that are not hearts,
   gives $13 + 3 = 16$ cards:

$$
P(\text{king or heart}) = \frac{16}{52} = \frac{4}{13} \approx 0.308
$$

**Answer.** $\frac{2}{13}$ for king or queen, and $\frac{4}{13}$ for king or heart.

**Check.** Plain adding for king or heart gives $\frac{4 + 13}{52} = \frac{17}{52}$, one card
too many: the king of hearts was counted twice.

### Example 3: HTTP Status Codes

**Problem.** A web server logged 10,000 responses. Each response has exactly one status
class: 9,200 were 2xx (success), 300 were 3xx (redirect), 400 were 4xx (client error) and
100 were 5xx (server error). What fraction of responses were errors (4xx or 5xx)?

**Solution.**

1. Each response has exactly one status class, so the four classes are pairwise disjoint.
2. The fractions are $0.92$, $0.03$, $0.04$ and $0.01$.
3. "Error" is the union of two disjoint classes, so add:

$$
P(\text{error}) = P(\text{4xx}) + P(\text{5xx}) = 0.04 + 0.01 = 0.05
$$

**Answer.** 5% of the responses were errors, that is 500 of the 10,000.

**Check.** The four classes are disjoint and together cover every response, so their
fractions must add to 1: $0.92 + 0.03 + 0.04 + 0.01 = 1$. They do. A list of events that is
disjoint **and** covers everything is called a partition, the topic of
[1.7](1.7-Partitions.md).

## Simulate It

The code checks that adding works for the disjoint pair of Example 1 and fails for the
overlapping pair.

```python
import numpy as np

rng = np.random.default_rng(42)
n_trials = 100_000
roll = rng.integers(1, 7, size=n_trials)

A = np.isin(roll, [1, 2])        # {1, 2}
B = np.isin(roll, [5, 6])        # {5, 6}: no outcome in common with A
C = np.isin(roll, [2, 4, 6])     # even: shares the outcome 2 with A

print("Disjoint A and B:")
print(f"  P(A or B) = {np.mean(A | B):.4f}   P(A) + P(B) = {A.mean() + B.mean():.4f}")
print("Overlapping A and C:")
print(f"  P(A or C) = {np.mean(A | C):.4f}   P(A) + P(C) = {A.mean() + C.mean():.4f}")
print(f"  P(A and C) = {np.mean(A & C):.4f}  <- the part counted twice")
print(f"Exact: P(A or B) = {4 / 6:.4f}, P(A or C) = {4 / 6:.4f}, "
      f"P(A and C) = {1 / 6:.4f}")
```

Output:

```text
Disjoint A and B:
  P(A or B) = 0.6679   P(A) + P(B) = 0.6679
Overlapping A and C:
  P(A or C) = 0.6666   P(A) + P(C) = 0.8335
  P(A and C) = 0.1669  <- the part counted twice
Exact: P(A or B) = 0.6667, P(A or C) = 0.6667, P(A and C) = 0.1667
```

For the disjoint pair, the two numbers agree **exactly**, even in the simulation: the
counts of a disjoint union always add. For the overlapping pair, the sum is too big by
$P(A \cap C)$.

## Common Mistakes

- **Adding probabilities of events that overlap.** Before you add, ask "can both happen at
  once?". If yes, subtract the overlap, as in [1.5](1.5-Venn-Diagrams.md).
- **Confusing mutually exclusive with independent.** They are almost opposites, as the
  warning below explains.
- **Checking only the intersection of all events.** $A \cap B \cap C = \varnothing$ does not
  make $A$, $B$, $C$ pairwise disjoint. Check every pair.
- **Thinking disjoint means complementary.** $\lbrace 1 \rbrace$ and $\lbrace 6 \rbrace$ are
  disjoint, but they are not complements: together they do not cover $\Omega$.
- **Deciding by the names of the events.** "Sunny" and "rainy" sound exclusive, but one day
  can have both. Decide from the outcomes in your sample space.

> **Warning:** Mutually exclusive does **not** mean independent. If $A$ and $B$ are
> disjoint and both can happen, then learning that $A$ happened tells you for sure that $B$
> did not. That is strong dependence. Independence is defined in
> [4.7 Independence](../04-CONDITIONAL-PROBABILITY-AND-BAYES/4.7-Independence.md).

## Where It Is Used

- **AI and machine learning:** in **multi-class** classification (a digit is 0, 1, ..., or
  9) the classes are mutually exclusive, so the model's probabilities must add to 1. In
  **multi-label** tagging (a photo can be "cat" and "outdoor") the tags overlap, so their
  probabilities need not add to 1.
- **Computer science:** a process is running, waiting or stopped, never two at once. A
  function returns exactly one error code. Disjoint states make analysis simple.
- **Networks:** a packet is delivered, dropped or corrupted. The three probabilities add to
  1 only because the cases are disjoint.
- **Insurance:** a policy that pays for "fire or flood" is priced by adding the two risks
  only if the two cannot happen in the same claim.
- **Everyday life:** "I will finish first, second or third in the race" can be added up,
  because one runner has one place.

## Practice

**1. (Easy)** For one die roll, which pairs are mutually exclusive? (a) even and odd;
(b) even and prime; (c) more than 4 and less than 3.

<details>
<summary>Answer</summary>

(a) Yes: $\lbrace 2, 4, 6 \rbrace \cap \lbrace 1, 3, 5 \rbrace = \varnothing$.
(b) No: 2 is even and prime. (c) Yes: $\lbrace 5, 6 \rbrace \cap \lbrace 1, 2 \rbrace = \varnothing$.

</details>

**2. (Easy)** A student gets exactly one final grade from A, B, C, D, F. The probability of an
A is $0.2$ and of a B is $0.35$. What is the probability of an A or a B?

<details>
<summary>Answer</summary>

One student cannot get two grades, so the events are mutually exclusive:

$$P(\text{A or B}) = 0.2 + 0.35 = 0.55$$

</details>

**3. (Medium)** For one die roll, let $A = \lbrace 1, 2 \rbrace$, $B = \lbrace 3, 4 \rbrace$
and $C = \lbrace 4, 5, 6 \rbrace$. Is the list $A$, $B$, $C$ pairwise disjoint? Is
$P(A \cup B \cup C) = P(A) + P(B) + P(C)$?

<details>
<summary>Answer</summary>

$A \cap B = \varnothing$ and $A \cap C = \varnothing$, but $B \cap C = \lbrace 4 \rbrace$.
So the list is not pairwise disjoint. Adding gives $\frac{2}{6} + \frac{2}{6} + \frac{3}{6} = \frac{7}{6}$,
which is more than 1 and so cannot be a probability. In fact
$A \cup B \cup C = \Omega$, so the true answer is 1.

</details>

**4. (Medium)** $A$ and $B$ are mutually exclusive, $P(A) = 0.3$ and $P(B) = 0.5$. Find
$P(A \cup B)$, $P(A \cap B)$ and the probability that neither happens.

<details>
<summary>Answer</summary>

$P(A \cup B) = 0.3 + 0.5 = 0.8$, and $P(A \cap B) = P(\varnothing) = 0$. "Neither" is
$(A \cup B)^c$. The events $A \cup B$ and $(A \cup B)^c$ are disjoint and together make
$\Omega$, whose probability is 1:

$$P((A \cup B)^c) = 1 - P(A \cup B) = 1 - 0.8 = 0.2$$

</details>

**5. (Hard)** In a finite sample space with equally likely outcomes, prove that if $A$ and
$B$ are mutually exclusive, then $P(A) + P(B) \le 1$. Can two mutually exclusive events have
$P(A) = 0.6$ and $P(B) = 0.5$?

<details>
<summary>Answer</summary>

Since $A \cap B = \varnothing$, the sizes add, and $A \cup B$ fits inside $\Omega$:

$$\lvert A \rvert + \lvert B \rvert = \lvert A \cup B \rvert \le \lvert \Omega \rvert$$

Divide by $\lvert \Omega \rvert$ to get $P(A) + P(B) \le 1$. So no: $0.6 + 0.5 = 1.1 \gt 1$.
Two events with these probabilities must overlap, in at least $0.1$ of the probability
(compare Practice 5 in [1.5](1.5-Venn-Diagrams.md)).

</details>

**6. (Simulate)** Simulate 100,000 responses of the server in Example 3, with class
probabilities $0.92$, $0.03$, $0.04$, $0.01$, and estimate $P(\text{error})$.

<details>
<summary>Answer</summary>

```python
import numpy as np

rng = np.random.default_rng(42)
classes = np.array(["2xx", "3xx", "4xx", "5xx"])
status = rng.choice(classes, size=100_000, p=[0.92, 0.03, 0.04, 0.01])
is_error = (status == "4xx") | (status == "5xx")
print(f"Simulation: {is_error.mean():.4f}")
print(f"Exact:      {0.04 + 0.01:.4f}")
```

Output:

```text
Simulation: 0.0504
Exact:      0.0500
```

</details>

## Summary

- $A$ and $B$ are mutually exclusive (disjoint) when $A \cap B = \varnothing$: they never
  happen together.
- A list of events is pairwise disjoint when every two of them are disjoint.
- For disjoint events, counts and probabilities add. For overlapping events, plain adding
  counts the overlap twice.
- $A$ and $A^c$ are always disjoint, and so are $A \cap B$ and $A \setminus B$.
- Mutually exclusive is not the same as independent.

The one formula to remember:

$$
\boxed{A \cap B = \varnothing \implies P(A \cup B) = P(A) + P(B)}
$$
