# 7.7 Discrete Uniform

[Probability](../README.md) / [Module 07: Discrete Distributions](README.md) / 7.7 Discrete Uniform

**Level:** 2 (Random Variables) · **Time:** about 30 minutes · **Before this:** [7.6 Hypergeometric](7.6-Hypergeometric.md)

> **Big idea:** The discrete uniform distribution gives the same probability to each of a finite list of whole numbers, like a fair die.

---

## Why It Matters

A fair die, a random index into an array, a random PIN, a card picked from a
shuffled deck: all of these choose one value from a list, with no value preferred.
The **discrete uniform distribution** is the model for "pick one at random". It is
also the raw material of simulation: a computer's random generator first makes
uniform numbers, and every other distribution is built from them
([19.2](../19-SIMULATION-AND-MONTE-CARLO/19.2-Pseudo-Random-Numbers-and-Seeds.md)).

## Intuition

Roll a fair die. Each face from 1 to 6 has probability $\frac{1}{6}$. Where is the
"center"? The faces are placed evenly, so the balance point is halfway between 1
and 6, at 3.5. You can never roll 3.5, but over many rolls the average gets close
to it.

Now pick a random whole number from 1 to 100. The center moves to 50.5, and the
values spread much wider. The spread grows with the number of values. A neat
formula, $\frac{n^2 - 1}{12}$, gives the variance for $n$ evenly spaced values.

## Picture

```text
  P(X = k)

          1     2     3     4     5     6       k
                         ^
                     mean 3.5
```

The PMF of a fair die: six bars of the same height, with the mean in the middle.

## Definition

Let $a \le b$ be whole numbers, and let $n = b - a + 1$ be the number of whole
numbers from $a$ to $b$. A random variable $X$ is **discrete uniform** on
$\lbrace a, a+1, \dots, b \rbrace$, written $X \sim \text{Unif}\lbrace a, \dots, b \rbrace$, if:

$$
P(X = k) = \frac{1}{n} = \frac{1}{b - a + 1}, \qquad k = a, a+1, \dots, b
$$

**In words:** each of the $n$ values has the same chance, one in $n$.

The support is $\lbrace a, a+1, \dots, b \rbrace$. The mean and variance are:

$$
E[X] = \frac{a + b}{2}, \qquad \operatorname{Var}(X) = \frac{n^2 - 1}{12} = \frac{(b - a + 1)^2 - 1}{12}
$$

**In words:** the mean is the midpoint of the two ends, and the variance depends
only on how many values there are, not on where they start.

The braces in the name remind you that the values are a finite list of whole
numbers. The continuous uniform $\text{Unif}(a, b)$ on an interval is a different
distribution ([9.1](../09-CONTINUOUS-DISTRIBUTIONS/9.1-Uniform.md)), with variance
$\frac{(b-a)^2}{12}$.

## Why It Is True

**Start with $\lbrace 1, \dots, n \rbrace$.** Let $Y \sim \text{Unif}\lbrace 1, \dots, n \rbrace$.
We need two sums.

1. $1 + 2 + \dots + n = \frac{n(n+1)}{2}$. Write the sum forwards and backwards and
   add: each of the $n$ columns adds to $n + 1$, so twice the sum is $n(n+1)$.
2. $1^2 + 2^2 + \dots + n^2 = \frac{n(n+1)(2n+1)}{6}$. (Proof below.)

Then:

$$
\begin{aligned}
E[Y] &= \sum_{k=1}^{n} k \cdot \frac{1}{n} = \frac{1}{n} \cdot \frac{n(n+1)}{2} = \frac{n+1}{2} && \text{(sum 1)} \\
E[Y^2] &= \sum_{k=1}^{n} k^2 \cdot \frac{1}{n} = \frac{(n+1)(2n+1)}{6} && \text{(sum 2)} \\
\operatorname{Var}(Y) &= \frac{(n+1)(2n+1)}{6} - \frac{(n+1)^2}{4} && \text{(shortcut formula)} \\
&= \frac{(n+1)\left[2(2n+1) - 3(n+1)\right]}{12} = \frac{(n+1)(n-1)}{12} = \frac{n^2 - 1}{12} && \text{(common denominator 12)}
\end{aligned}
$$

**Shift to $\lbrace a, \dots, b \rbrace$.** If $X \sim \text{Unif}\lbrace a, \dots, b \rbrace$, then
$X = Y + (a - 1)$ with $Y \sim \text{Unif}\lbrace 1, \dots, n \rbrace$. A shift moves the
mean but does not change the variance
([6.6](../06-EXPECTATION-VARIANCE-AND-MOMENTS/6.6-Properties-of-Variance.md)):

$$
E[X] = \frac{n + 1}{2} + a - 1 = \frac{(b - a + 2) + 2a - 2}{2} = \frac{a + b}{2}, \qquad \operatorname{Var}(X) = \frac{n^2 - 1}{12}
$$

<details>
<summary>Proof of the sum of squares (optional)</summary>

Expand a cube: $(k+1)^3 - k^3 = 3k^2 + 3k + 1$. Add this for $k = 1, \dots, n$. On the
left, almost everything cancels (a **telescoping** sum), leaving only the last and
first terms:

$$(n+1)^3 - 1 = 3 \sum_{k=1}^{n} k^2 + 3 \cdot \frac{n(n+1)}{2} + n$$

Solve for the sum of squares. The left side is $n^3 + 3n^2 + 3n$, so:

$$3 \sum_{k=1}^{n} k^2 = n^3 + 3n^2 + 3n - \frac{3n^2 + 3n}{2} - n = \frac{2n^3 + 3n^2 + n}{2} = \frac{n(n+1)(2n+1)}{2}$$

Divide by 3 to get $\frac{n(n+1)(2n+1)}{6}$.

</details>

**The CDF** is a staircase with $n$ equal steps: for $k$ in the support,
$F_X(k) = P(X \le k) = \frac{k - a + 1}{n}$.

## Worked Examples

### Example 1: A Fair Die

**Problem.** Find the mean, variance and standard deviation of one roll of a fair die.

**Solution.**

1. $X \sim \text{Unif}\lbrace 1, \dots, 6 \rbrace$, so $a = 1$, $b = 6$, $n = 6$.
2. Mean: $\frac{1 + 6}{2} = 3.5$.
3. Variance: $\frac{6^2 - 1}{12} = \frac{35}{12} \approx 2.917$.
4. Standard deviation: $\sqrt{35/12} \approx 1.708$.

**Answer.** $E[X] = 3.5$, $\operatorname{Var}(X) = \frac{35}{12} \approx 2.917$, $\sigma \approx 1.71$.

**Check.** Directly: $E[X^2] = \frac{1 + 4 + 9 + 16 + 25 + 36}{6} = \frac{91}{6} \approx 15.167$, and
$15.167 - 3.5^2 = 15.167 - 12.25 = 2.917$. It matches.

### Example 2: Cost of a Linear Search

**Problem.** An array holds 1,000 different items. You search for one item by
checking positions 1, 2, 3, ... until you find it. The item is equally likely to
be at any position. What are the mean and standard deviation of the number of
checks?

**Solution.**

1. If the item is at position $k$, you need $k$ checks. So the number of checks is
   $X \sim \text{Unif}\lbrace 1, \dots, 1000 \rbrace$.
2. Mean: $\frac{1 + 1000}{2} = 500.5$ checks.
3. Variance: $\frac{1000^2 - 1}{12} = \frac{999999}{12} \approx 83333.25$, so
   $\sigma \approx 288.7$ checks.

**Answer.** On average 500.5 checks, with standard deviation about 289.

**Check.** This is the classic "a successful linear search looks at about half the
array on average". The large standard deviation says single searches vary a lot.

### Example 3: The Modulo Bias Bug

**Problem.** A program needs a random digit from 0 to 9. It takes a random byte
$B \sim \text{Unif}\lbrace 0, \dots, 255 \rbrace$ and outputs $D = B \text{ mod } 10$ (the
remainder after dividing by 10). Is $D$ uniform on $\lbrace 0, \dots, 9 \rbrace$?

**Solution.**

1. Count the bytes that give each digit. The bytes 0 to 249 form 25 full rounds of
   0 to 9, so each digit gets 25 bytes from them.
2. The 6 bytes left, 250 to 255, give the digits 0, 1, 2, 3, 4, 5 one more time.
3. So digits 0 to 5 each come from 26 bytes, and digits 6 to 9 from 25 bytes:

$$
P(D = 0) = \frac{26}{256} \approx 0.1016, \qquad P(D = 9) = \frac{25}{256} \approx 0.0977
$$

4. A fix: if $B \ge 250$, throw it away and draw a new byte. Each try is accepted with
   probability $\frac{250}{256}$, so the number of tries is geometric
   ([7.3](7.3-Geometric.md)) with mean $\frac{256}{250} = 1.024$.

**Answer.** No. Small digits are about 4% more likely than large ones. Rejecting
bytes from 250 to 255 makes $D$ exactly uniform, at a cost of only 1.024 bytes per
digit on average.

**Check.** The probabilities add up: $6 \times \frac{26}{256} + 4 \times \frac{25}{256} = \frac{156 + 100}{256} = 1$.
The bias is small but real, and in cryptography even a small bias can leak secrets.

## Simulate It

We roll a die with `rng.integers` and show the modulo bias from Example 3.
Note that `rng.integers(low, high)` never returns `high`, so a die is
`rng.integers(1, 7)`.

```python
import numpy as np

rng = np.random.default_rng(42)
n_trials = 1_000_000

rolls = rng.integers(1, 7, size=n_trials)     # uniform on {1, ..., 6}
print(f"die: mean {rolls.mean():.4f} (exact 3.5), "
      f"var {rolls.var():.4f} (exact {35 / 12:.4f})")

# Modulo bias: random bytes 0..255 turned into digits with % 10.
digits = rng.integers(0, 256, size=n_trials) % 10
print(f"P(D=0): sim {np.mean(digits == 0):.4f}, exact {26 / 256:.4f}")
print(f"P(D=9): sim {np.mean(digits == 9):.4f}, exact {25 / 256:.4f}")
```

Output:

```text
die: mean 3.4981 (exact 3.5), var 2.9152 (exact 2.9167)
P(D=0): sim 0.1016, exact 0.1016
P(D=9): sim 0.0980, exact 0.0977
```

## Common Mistakes

- **Counting the values wrong.** From 3 to 10 there are $10 - 3 + 1 = 8$ values, not
  7. Always use $n = b - a + 1$.
- **Forgetting that `rng.integers` excludes the upper end.** `rng.integers(1, 6)`
  gives 1 to 5, not 1 to 6. Python's `random.randint(1, 6)` includes 6. Check
  the documentation of every tool.
- **Using the continuous formula.** For the die, $\frac{(6-1)^2}{12} \approx 2.08$ is
  wrong. The discrete formula $\frac{6^2 - 1}{12} \approx 2.92$ is right.
- **Thinking a function of a uniform is uniform.** The sum of two dice, the maximum
  of two dice, and $B \text{ mod } 10$ in Example 3 are all **not** uniform.

## Where It Is Used

- **Computer science:** choosing a random index, a random pivot in quicksort, and
  the Fisher-Yates shuffle, which makes all orderings of a list equally likely.
- **Hashing:** the ideal hash function sends each key to a uniformly random bucket
  ([21.3.2](../21-APPLICATIONS-OF-PROBABILITY/21.3-Computer-Science/21.3.2-Hashing-and-Bloom-Filters.md)).
- **AI and machine learning:** picking random minibatches, random train/test
  splits, and random exploration in reinforcement learning.
- **Security:** keys and passwords must be uniform over a huge set, so that no
  guess is better than any other ([21.4](../21-APPLICATIONS-OF-PROBABILITY/21.4-Cryptography-and-Security.md)).
- **Everyday life:** dice, lottery balls, drawing names from a hat.

## Practice

**1. (Easy)** $X \sim \text{Unif}\lbrace 10, \dots, 20 \rbrace$. Find $P(X \le 12)$, $E[X]$ and
$\operatorname{Var}(X)$.

<details>
<summary>Answer</summary>

There are $n = 20 - 10 + 1 = 11$ values. $P(X \le 12) = \frac{3}{11}$ (the values 10, 11, 12).

$$E[X] = \frac{10 + 20}{2} = 15, \qquad \operatorname{Var}(X) = \frac{11^2 - 1}{12} = \frac{120}{12} = 10$$

</details>

**2. (Easy)** A 4-digit PIN from 0000 to 9999 is chosen uniformly at random and read
as a number. What is its mean?

<details>
<summary>Answer</summary>

It is uniform on $\lbrace 0, \dots, 9999 \rbrace$, so the mean is $\frac{0 + 9999}{2} = 4999.5$.

</details>

**3. (Medium)** Roll two fair dice and let $M$ be the larger of the two numbers.
Show that $P(M = k) = \frac{2k - 1}{36}$ for $k = 1, \dots, 6$. Is $M$ uniform?

<details>
<summary>Answer</summary>

$M \le k$ means both dice are at most $k$, which has probability $\frac{k^2}{36}$. So

$$P(M = k) = P(M \le k) - P(M \le k - 1) = \frac{k^2 - (k-1)^2}{36} = \frac{2k - 1}{36}$$

This grows with $k$ (from $\frac{1}{36}$ up to $\frac{11}{36}$), so $M$ is not uniform.

</details>

**4. (Medium)** A 3-bit random number $B$ is uniform on $\lbrace 0, \dots, 7 \rbrace$. Find the
distribution of $B \text{ mod } 3$.

<details>
<summary>Answer</summary>

The remainders of $0, 1, \dots, 7$ are $0, 1, 2, 0, 1, 2, 0, 1$. So

$$P(0) = \frac{3}{8}, \qquad P(1) = \frac{3}{8}, \qquad P(2) = \frac{2}{8}$$

It is not uniform, because 8 is not a multiple of 3.

</details>

**5. (Hard)** Let $X \sim \text{Unif}\lbrace 1, \dots, n \rbrace$. Find $P(X \gt k)$ for
$k = 0, 1, \dots, n$, and use the tail-sum formula
([6.9](../06-EXPECTATION-VARIANCE-AND-MOMENTS/6.9-Tail-Sum-Formula.md)) to get $E[X]$
again.

<details>
<summary>Answer</summary>

$X \gt k$ for the $n - k$ values $k+1, \dots, n$, so $P(X \gt k) = \frac{n - k}{n}$. Then

$$E[X] = \sum_{k=0}^{n-1} P(X \gt k) = \frac{n + (n-1) + \dots + 1}{n} = \frac{1}{n} \cdot \frac{n(n+1)}{2} = \frac{n+1}{2}$$

</details>

**6. (Simulate)** Fix the modulo bias: draw random bytes, reject those that are 250
or more, and check that every digit now has probability close to $0.1$. Also check
the average number of bytes used per digit.

<details>
<summary>Answer</summary>

```python
import numpy as np

rng = np.random.default_rng(42)
bytes_ = rng.integers(0, 256, size=1_100_000)
kept = bytes_[bytes_ < 250]                 # reject 250..255
digits = kept % 10
freq = np.bincount(digits, minlength=10) / len(digits)
print(f"digit frequencies from {freq.min():.4f} to {freq.max():.4f} "
      f"(exact 0.1 each)")
print(f"bytes per digit: {len(bytes_) / len(kept):.4f} (exact 1.024)")
```

Output:

```text
digit frequencies from 0.0995 to 0.1008 (exact 0.1 each)
bytes per digit: 1.0239 (exact 1.024)
```

</details>

## Summary

- $\text{Unif}\lbrace a, \dots, b \rbrace$ gives each of the $n = b - a + 1$ values probability $\frac{1}{n}$.
- The mean is the midpoint $\frac{a+b}{2}$; the variance is $\frac{n^2 - 1}{12}$.
- The proofs use the sums $\sum k = \frac{n(n+1)}{2}$ and $\sum k^2 = \frac{n(n+1)(2n+1)}{6}$, plus a shift.
- Functions of a uniform (sums, maxima, remainders) are usually not uniform.
- In numpy, sample it with `rng.integers(a, b + 1, size)`; the upper end is excluded.

The one formula to remember:

$$
\boxed{P(X = k) = \frac{1}{n}, \quad E[X] = \frac{a + b}{2}, \quad \operatorname{Var}(X) = \frac{n^2 - 1}{12}}
$$
