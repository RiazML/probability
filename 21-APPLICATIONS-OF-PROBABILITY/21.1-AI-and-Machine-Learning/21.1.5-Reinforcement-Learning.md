> **Big idea:** A learning agent lives in a Markov chain that it can steer: the value of a state is a conditional expectation of future rewards, it obeys a one-step equation from the law of total expectation, and a bandit agent can balance trying and exploiting by sampling from its Beta posterior.

---

## Why It Matters

In **reinforcement learning** an agent acts, sees what happens, and collects rewards. It must learn which actions are good from its own experience. A game-playing program, a robot, and a system that chooses which advertisement to show are all of this type. The world is random, so the question "how good is this state?" has the answer "good on average", and an average is an expectation. This file shows the two probability ideas behind most of the field: **value functions** (conditional expectations that satisfy the Bellman equation) and the **exploration problem** (how much to try new things), solved nicely by Bayes' theorem.

## Intuition

You are a delivery rider choosing between two routes. Route A took 20 minutes on the one day you tried it. Route B took 25 minutes on two days out of two. Should you always take A? Not necessarily: one day is a small sample. Maybe A is usually slow and you were lucky. To learn, you must **explore** (try routes that look worse) and also **exploit** (use the route that looks best). Too much exploring wastes time. Too little may leave you stuck with a poor route forever.

Now think about a board game. The value of a position is not one number you are told. It is the average reward you would collect if you started from there and kept playing. Positions near a win are worth a lot. A position is worth about what the next position is worth, plus any reward you collect on the way. This "worth now equals reward plus worth next" idea is the Bellman equation.

## Picture

```text
  The learning loop:

     +-------+      action a_t              +-------------+
     | agent | ---------------------------> | environment |
     |       | <--------------------------- |             |
     +-------+     next state, reward        +-------------+

  A chain with rewards (the policy is fixed):

     +-------+  0.5   +--------+  0.8   +------+
     | Start | -----> | Middle | -----> | Done |
     | r= -1 | <----- | r= -1  |        | r= 0 |
     +-------+  0.2   +--------+        +------+

     Start stays in Start with probability 0.5; Done stays in Done.
```

Top: the agent picks an action, and the world answers with a new state and a reward. Bottom: once the agent's rule for acting is fixed, the world is just a Markov chain with a reward in each state.

## Definition

A **Markov decision process** (MDP) has: a set of **states** $s$; a set of **actions** $a$; transition probabilities $P(s' \mid s, a)$ for the next state; and a **reward** $R$ received at each step. A **policy** $\pi(a \mid s)$ is the agent's rule: in state $s$ it draws action $a$ from a categorical distribution ([7.8](../../07-DISCRETE-DISTRIBUTIONS/7.8-Categorical.md)). The **discount factor** $\gamma$ with $0 \le \gamma \lt 1$ says how much a reward one step later is worth, compared with a reward now.

The **return** is the discounted sum of future rewards, and the **value** of a state under a policy is its expected value, starting from that state:

$$
G = R_1 + \gamma R_2 + \gamma^2 R_3 + \cdots = \sum_{k=0}^{\infty} \gamma^k R_{k+1}, \qquad V(s) = E[G \mid S_0 = s]
$$

where $S_0$ is the starting state and $R_{k+1}$ is the reward at step $k$. The return $G$ is a random variable, and $V(s)$ is a conditional expectation ([14.1](../../14-CONDITIONAL-EXPECTATION/14.1-Conditional-Expectation-Given-a-Value.md)).

**In words:** the value of a state is the average total (discounted) reward that the agent collects from there on.

When the policy is fixed, the states form a Markov chain with transition matrix $P$ and a mean reward $r(s)$ for each state. Then the values obey the **Bellman equation**:

$$
V(s) = r(s) + \gamma \sum_{s'} P(s' \mid s) \thinspace V(s'), \qquad \text{that is,} \qquad \mathbf{V} = \mathbf{r} + \gamma P \mathbf{V}
$$

**In words:** the value of a state is the reward you get now, plus the discounted average of the values of the states you may go to next.

The simplest MDP has one state and $K$ actions, called **arms**. This is the **multi-armed bandit**. Arm $k$ pays 1 with unknown probability $\theta_k$ and 0 otherwise. **Thompson sampling** keeps a Beta posterior for each $\theta_k$, draws one number $\tilde{\theta}_k$ from each posterior, and plays the arm with the largest draw.

## Why It Is True

**A fixed policy gives a Markov chain.** Choose the action by the law of total probability ([4.3](../../04-CONDITIONAL-PROBABILITY-AND-BAYES/4.3-Law-of-Total-Probability.md)). The next state depends only on the current state and the freshly drawn action, so:

$$
P(S_{t+1} = s' \mid S_t = s) = \sum_{a} \pi(a \mid s) \thinspace P(s' \mid s, a)
$$

This is the Markov property ([18.3.1](../../18-STOCHASTIC-PROCESSES/18.3-Markov-Chains/18.3.1-Markov-Property.md)).

**The Bellman equation is first-step analysis.** Split the return after the first step, $G = R_1 + \gamma G'$, where $G'$ is the return from the next state onward. By linearity of expectation and the tower rule ([14.3](../../14-CONDITIONAL-EXPECTATION/14.3-Law-of-Total-Expectation.md)), conditioning on the next state $S_1$:

$$
\begin{aligned}
V(s) &= E[R_1 \mid S_0 = s] + \gamma E[G' \mid S_0 = s] && \text{(linearity)} \\
&= r(s) + \gamma \sum_{s'} P(s' \mid s) \thinspace E[G' \mid S_1 = s', S_0 = s] && \text{(total expectation over } S_1 \text{)} \\
&= r(s) + \gamma \sum_{s'} P(s' \mid s) \thinspace V(s') && \text{(Markov: the past before } S_1 \text{ does not matter)}
\end{aligned}
$$

**The equation can be solved.** The $n$-step transition matrix is $P^k$ ([18.3.2](../../18-STOCHASTIC-PROCESSES/18.3-Markov-Chains/18.3.2-Transition-Matrix-and-N-Step-Transitions.md)), so the mean reward after $k$ steps is the vector $P^k \mathbf{r}$. Adding the discounted means (linearity of expectation):

$$
\mathbf{V} = \sum_{k=0}^{\infty} \gamma^k P^k \mathbf{r} = (I - \gamma P)^{-1} \mathbf{r}
$$

The sum converges because the entries of $P^k \mathbf{r}$ are bounded by the largest $\lvert r(s) \rvert$ and $\gamma^k \to 0$. It equals $(I - \gamma P)^{-1}$ by the geometric series, and one checks that $(I - \gamma P) \sum_k \gamma^k P^k = I$.

**Discounting is a survival probability.** Suppose that after every step the process stops with probability $1 - \gamma$, independent of everything else. Then step $k$ happens with probability $\gamma^k$, so the expected **undiscounted** total reward is $\sum_k \gamma^k E[R_{k+1}]$. This is exactly the discounted value. The number of steps is geometric ([7.3](../../07-DISCRETE-DISTRIBUTIONS/7.3-Geometric.md)) with mean $\frac{1}{1 - \gamma}$.

**Thompson sampling plays the best-arm probability.** The Beta posterior is a conjugate update ([9.5](../../09-CONTINUOUS-DISTRIBUTIONS/9.5-Beta.md), [10.7](../../10-JOINT-DISTRIBUTIONS/10.7-Bayes-for-Random-Variables.md)). With a $\text{Beta}(\alpha, \beta)$ prior and $s$ successes and $f$ failures, the posterior is proportional to prior times likelihood:

$$
\theta^{\alpha - 1} (1 - \theta)^{\beta - 1} \cdot \theta^{s} (1 - \theta)^{f} = \theta^{\alpha + s - 1} (1 - \theta)^{\beta + f - 1}
$$

which is $\text{Beta}(\alpha + s, \beta + f)$. Now the draws $\tilde{\theta}_k$ are independent samples from the posteriors of the true $\theta_k$. So the event "arm $k$ has the largest draw" has exactly the probability that arm $k$ has the largest true rate, given the data:

$$
P(\text{play arm } k) = P\left( \theta_k = \max_j \theta_j \mid \text{data so far} \right)
$$

**In words:** each arm is played with the probability that it is the best one. An arm that is uncertain keeps a real chance of being played, so the agent explores. As data arrive, the posteriors narrow, and the best arm is played more and more.

## Worked Examples

### Example 1: The Value of a State by Hand

**Problem.** Use the chain in the picture, with $\gamma = 0.9$ and a reward of $-1$ for each step spent in Start or Middle (the "cost of one step"). From Start the chain stays with probability 0.5 and moves to Middle with 0.5. From Middle it returns to Start with 0.2 and reaches Done with 0.8. Done pays 0 forever. Find $V(\text{Start})$ and $V(\text{Middle})$.

**Solution.**

1. The value of Done is $V(\text{Done}) = 0$.
2. Write the Bellman equation for Middle:

$$
V_M = -1 + 0.9 \left( 0.2 V_S + 0.8 \times 0 \right) = -1 + 0.18 V_S
$$

3. Write it for Start:

$$
V_S = -1 + 0.9 \left( 0.5 V_S + 0.5 V_M \right) = -1 + 0.45 V_S + 0.45 V_M
$$

4. Substitute $V_M$ from step 2:

$$
V_S = -1 + 0.45 V_S + 0.45 (-1 + 0.18 V_S) = -1.45 + 0.45 V_S + 0.081 V_S
$$

5. Collect $V_S$: $V_S (1 - 0.531) = -1.45$, so $V_S = \frac{-1.45}{0.469} \approx -3.092$.
6. Then $V_M = -1 + 0.18 \times (-3.092) \approx -1.557$.

**Answer.** $V(\text{Start}) \approx -3.092$ and $V(\text{Middle}) \approx -1.557$.

**Check.** The values are negative because every step costs 1. Middle is closer to Done, so it costs less. The simulation below, which averages discounted returns, gives $-3.097$ and $-1.546$.

### Example 2: Which Arm Does Thompson Sampling Play?

**Problem.** Two arms start with a uniform prior $\text{Beta}(1, 1)$. Arm A has been tried once and won. Arm B has been tried once and lost. What is the chance that Thompson sampling plays arm A on the next step?

**Solution.**

1. Posterior of A: $\text{Beta}(1 + 1, 1 + 0) = \text{Beta}(2, 1)$, with density $2x$ on $(0, 1)$. Posterior of B: $\text{Beta}(1, 2)$, with density $2(1 - y)$.
2. The CDF of B is $P(\tilde{\theta}_B \le x) = \int_0^x 2(1 - y) \thinspace dy = 2x - x^2$.
3. Arm A is played when $\tilde{\theta}_A \gt \tilde{\theta}_B$. Condition on $\tilde{\theta}_A = x$ and integrate:

$$
P(\tilde{\theta}_A \gt \tilde{\theta}_B) = \int_0^1 2x \left( 2x - x^2 \right) dx = \int_0^1 \left( 4x^2 - 2x^3 \right) dx = \frac{4}{3} - \frac{1}{2} = \frac{5}{6}
$$

**Answer.** Arm A is played with probability $\frac{5}{6} \approx 0.833$, and arm B with probability $\frac{1}{6}$.

**Check.** Arm A is favoured, but arm B is not ruled out after a single failure. This is exploration. The simulation gives 0.8336.

### Example 3: Discounting as a Chance of Stopping

**Problem.** A reward of 1 arrives at every step, and $\gamma = 0.9$. Find the discounted value, and show that it equals the expected number of steps if the process stops after each step with probability 0.1.

**Solution.**

1. The discounted value is the geometric series $\sum_{k=0}^{\infty} 0.9^k = \frac{1}{1 - 0.9} = 10$.
2. The number of steps until the first stop, with stop chance $p = 0.1$ per step, is $\text{Geom}(0.1)$, with mean $\frac{1}{p} = 10$ ([7.3](../../07-DISCRETE-DISTRIBUTIONS/7.3-Geometric.md)).
3. Each step pays 1, so the expected total undiscounted reward is $10$.

**Answer.** Both are 10.

**Check.** This is the survival argument of "Why It Is True". It is why a discount factor of 0.9 can be read as "a 10% chance that the game ends after each step". The code below confirms it.

## Simulate It

Part 1 simulates discounted returns on the chain of Example 1 and compares them with the Bellman solution. Part 2 checks the 5/6 of Example 2 and compares Thompson sampling with a "greedy" agent that always plays the arm with the best posterior mean, on a 3-armed bandit with success rates 0.3, 0.5 and 0.6. Regret is the reward lost, per step, against always playing the best arm.

```python
import numpy as np

rng = np.random.default_rng(42)

# A small Markov reward process: states 0 (start), 1 (middle), 2 (done, absorbing).
P = np.array([[0.5, 0.5, 0.0],
              [0.2, 0.0, 0.8],
              [0.0, 0.0, 1.0]])
r = np.array([-1.0, -1.0, 0.0])        # reward of -1 for every step before "done"
gamma = 0.9

# Exact values from the Bellman equation V = r + gamma P V, so V = (I - gamma P)^(-1) r.
V_exact = np.linalg.solve(np.eye(3) - gamma * P, r)

# Simulation: average discounted return over many episodes from each start state.
def discounted_return(start, horizon=200):
    state, total, discount = start, 0.0, 1.0
    for _ in range(horizon):
        total += discount * r[state]
        discount *= gamma
        state = rng.choice(3, p=P[state])
    return total

n_episodes = 20_000
for s in [0, 1]:
    estimate = np.mean([discounted_return(s) for _ in range(n_episodes)])
    print(f"State {s}: simulated {estimate:.3f}, Bellman {V_exact[s]:.3f}")
```

Output:

```text
State 0: simulated -3.097, Bellman -3.092
State 1: simulated -1.546, Bellman -1.557
```

Part 2:

```python
import numpy as np

rng = np.random.default_rng(42)

# Thompson sampling plays an arm with the posterior probability that it is the best.
draws_a = rng.beta(2, 1, size=1_000_000)       # arm A: 1 success, 0 failures, uniform prior
draws_b = rng.beta(1, 2, size=1_000_000)       # arm B: 0 successes, 1 failure
print(f"P(A is played): simulated {np.mean(draws_a > draws_b):.4f}, exact {5 / 6:.4f}")

# A 3-armed bandit with true success rates 0.3, 0.5, 0.6. Compare average regret.
theta = np.array([0.3, 0.5, 0.6])
n_steps, n_runs = 1_000, 200
regret = {"thompson": 0.0, "greedy": 0.0}
for _ in range(n_runs):
    for method in regret:
        wins, losses = np.ones(3), np.ones(3)            # Beta(1, 1) priors
        for _ in range(n_steps):
            if method == "thompson":
                arm = np.argmax(rng.beta(wins, losses))    # one draw per arm
            else:
                arm = np.argmax(wins / (wins + losses))    # always the best posterior mean
            success = rng.random() < theta[arm]
            wins[arm] += success
            losses[arm] += 1 - success
            regret[method] += theta.max() - theta[arm]
for method, total in regret.items():
    print(f"{method:>8}: average regret over {n_steps} steps = {total / n_runs:.1f}")
```

Output:

```text
P(A is played): simulated 0.8336, exact 0.8333
thompson: average regret over 1000 steps = 17.8
  greedy: average regret over 1000 steps = 45.3
```

The values match the Bellman solution and the $\frac{5}{6}$ of Example 2. Over 1,000 steps Thompson sampling loses about 17.8 reward units to not knowing the best arm, and the greedy agent loses about 45.3, because it can lock onto a worse arm after an early lucky streak and never test the others.

## Common Mistakes

- **Mixing up the return and the value.** The return $G$ is random (one run). The value $V(s)$ is its average. A single episode can be far from $V(s)$.
- **Using a discount factor of 1 for an endless task.** The sum may not converge. With $\gamma \lt 1$ and bounded rewards it always does.
- **Treating the action as free.** The Bellman equation above is for a fixed policy. If the agent changes its policy, the values change too.
- **Always exploiting.** A greedy agent can be stuck with a bad arm, because it never gathers the data that would change its mind (see the regret numbers).
- **Reading one trial as proof.** After one win, an arm is not "known to be good". The posterior $\text{Beta}(2, 1)$ is still wide. Keep the uncertainty.

## Where It Is Used

- **AI and machine learning:** game-playing and control agents estimate value functions. Bandits choose which advertisement, article or recommendation to show. Both rest on the ideas above.
- **Adaptive experiments:** a bandit rule can steer more users to the better version of a web page while the test is still running, as an alternative to a fixed A/B test ([21.2](../21.2-Statistics-and-Data-Science.md)).
- **Markov chains and queues:** the equation $\mathbf{V} = \mathbf{r} + \gamma P \mathbf{V}$ is first-step analysis ([14.3](../../14-CONDITIONAL-EXPECTATION/14.3-Law-of-Total-Expectation.md)), the same tool that gives the expected length of Snakes and Ladders ([18.3.7](../../18-STOCHASTIC-PROCESSES/18.3-Markov-Chains/18.3.7-Absorbing-Chains.md)).
- **Finance and operations:** discounting, and optimal stopping, from the price of an option to when to sell a house ([21.5](../21.5-Finance-and-Insurance.md)).
- **Everyday life:** trying a new restaurant, or staying with a favourite one, is the exploration versus exploitation choice.

## Practice

**1. (Easy)** A reward of 2 arrives every step forever, and $\gamma = 0.8$. What is the discounted value?

<details>
<summary>Answer</summary>

$$V = \sum_{k=0}^{\infty} 2 \times 0.8^k = \frac{2}{1 - 0.8} = 10$$

</details>

**2. (Easy)** A bandit arm starts with a $\text{Beta}(1, 1)$ prior and then wins 7 times and loses 3 times. What is its posterior, and the posterior mean of its success rate?

<details>
<summary>Answer</summary>

The posterior is $\text{Beta}(1 + 7, 1 + 3) = \text{Beta}(8, 4)$. The mean is $\frac{8}{8 + 4} = \frac{2}{3} \approx 0.667$.

</details>

**3. (Medium)** A chain has two states, A and B. From A it always goes to B with reward 1. From B it always goes to A with reward 0. With $\gamma = 0.5$, find $V(\text{A})$ and $V(\text{B})$.

<details>
<summary>Answer</summary>

The Bellman equations are $V_A = 1 + 0.5 V_B$ and $V_B = 0 + 0.5 V_A$. Substitute the second into the first:

$$V_A = 1 + 0.25 V_A \implies 0.75 V_A = 1 \implies V_A = \tfrac{4}{3}$$

Then $V_B = 0.5 \times \frac{4}{3} = \frac{2}{3}$.

</details>

**4. (Medium)** Arm A has posterior $\text{Beta}(2, 1)$ and arm B has a known success rate of exactly 0.5. What is the probability that Thompson sampling plays A? (The CDF of $\text{Beta}(2, 1)$ is $x^2$.)

<details>
<summary>Answer</summary>

Arm A is played when its draw exceeds 0.5. Using the CDF $F(x) = x^2$:

$$P(\tilde{\theta}_A \gt 0.5) = 1 - F(0.5) = 1 - 0.25 = 0.75$$

</details>

**5. (Hard)** Show that if a process stops after each step with probability $1 - \gamma$ (independent of the rewards), the expected total undiscounted reward equals $\sum_{k=0}^{\infty} \gamma^k E[R_{k+1}]$.

<details>
<summary>Answer</summary>

Let $T$ be the number of steps taken, so $P(T \gt k) = \gamma^k$ (the process survived $k$ stops). The total reward is $\sum_{k=0}^{\infty} I_{\lbrace T \gt k \rbrace} R_{k+1}$, where the indicator says that step $k$ is taken. The stopping is independent of the rewards, so $E[I_{\lbrace T \gt k \rbrace} R_{k+1}] = P(T \gt k) E[R_{k+1}] = \gamma^k E[R_{k+1}]$. Add over $k$ by linearity:

$$E\left[ \sum_{k=0}^{\infty} I_{\lbrace T \gt k \rbrace} R_{k+1} \right] = \sum_{k=0}^{\infty} \gamma^k E[R_{k+1}]$$

</details>

**6. (Simulate)** Check Example 3 by simulation: reward 1 per step, stopping probability 0.1 after each step. Average the total reward over many runs.

<details>
<summary>Answer</summary>

```python
import numpy as np

rng = np.random.default_rng(42)
n_episodes = 500_000

# Reward 1 at every step; after each step the process stops with probability 0.1.
# The number of rewards collected is Geom(0.1): trials until the first stop.
total_reward = rng.geometric(0.1, size=n_episodes)

# Discounted value with gamma = 0.9 for a reward of 1 forever: 1 / (1 - gamma).
print(f"Average total reward: {total_reward.mean():.3f}")
print(f"Discounted value:     {1 / (1 - 0.9):.3f}")
```

Output:

```text
Average total reward: 9.983
Discounted value:     10.000
```

</details>

## Summary

- A policy turns a decision process into a Markov chain with rewards. The agent's randomness is a categorical draw in each state.
- The value of a state is the conditional expectation of the discounted return. It satisfies $V(s) = r(s) + \gamma \sum_{s'} P(s' \mid s) V(s')$, which is first-step analysis, and $\mathbf{V} = (I - \gamma P)^{-1} \mathbf{r}$.
- A discount factor $\gamma$ is the same as stopping with probability $1 - \gamma$ at each step.
- In a bandit, a Beta posterior updates by adding wins and losses. Thompson sampling plays each arm with the probability that it is the best, so it explores when it is unsure.

The one formula to remember:

$$
\boxed{V(s) = E[G \mid S_0 = s] = r(s) + \gamma \sum_{s'} P(s' \mid s) \thinspace V(s')}
$$
