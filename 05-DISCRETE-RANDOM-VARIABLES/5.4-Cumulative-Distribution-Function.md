# 5.4 Cumulative Distribution Function

[Probability](../README.md) / [Module 05: Discrete Random Variables](README.md) / 5.4 Cumulative Distribution Function

**Level:** 2 (Random Variables) · **Time:** about 50 minutes · **Before this:** [5.3 Probability Mass Function](5.3-Probability-Mass-Function.md)

> **Big idea:** The CDF answers "what is the chance that X is at most x?" for every x, and for a discrete variable it is a staircase that jumps by p(x) at each value.

---

## Why It Matters

The PMF works only for discrete variables. The **cumulative distribution
function** (CDF) works for **every** random variable: discrete, continuous or
mixed. It also makes some questions much easier, such as "what is the chance the
slowest of three servers answers within 4 seconds?". The CDF returns in
[Module 08](../08-CONTINUOUS-RANDOM-VARIABLES/README.md), where the density is its
slope, and in [Module 19](../19-SIMULATION-AND-MONTE-CARLO/README.md), where it is
used to generate random numbers.

## Intuition

Flip two fair coins and let $X$ be the number of heads. The PMF is
$p(0) = \frac{1}{4}$, $p(1) = \frac{1}{2}$, $p(2) = \frac{1}{4}$. Now walk along the
number line from left to right, and carry a bag. Every time you pass a value of
$X$, put its probability into the bag. The weight in the bag at position $x$ is
$P(X \le x)$.

Before 0 the bag is empty: weight 0. At 0 you pick up $\frac{1}{4}$. Between 0 and 1
nothing changes, so the weight stays $\frac{1}{4}$, even at $x = 0.5$ or $x = 0.99$. At
1 you pick up $\frac{1}{2}$ more, so the weight is $\frac{3}{4}$. At 2 you pick up the last
$\frac{1}{4}$, and the bag holds 1 from then on.

That running total is the CDF. It never goes down, it starts at 0 and ends at 1,
and for a discrete variable it moves in **jumps**. The size of each jump is the PMF
at that point.


The CDF of the number of heads in two coin flips: a staircase with jumps of 1/4, 1/2 and 1/4.

## Definition

The **cumulative distribution function** (CDF) of a random variable $X$ is

$$
F_X(x) = P(X \le x) \qquad \text{for every real number } x
$$

where $x$ can be any real number, not only a value that $X$ takes. For a discrete
$X$ with PMF $p_X$, this is a running sum:

$$
F_X(x) = \sum_{x_i \le x} p_X(x_i)
$$

**In words:** the CDF at $x$ adds up the probability of every value of $X$ that is
at most $x$.

Every CDF has these four properties:

1. **Bounded:** $0 \le F_X(x) \le 1$.
2. **Non-decreasing:** if $x \lt y$, then $F_X(x) \le F_X(y)$.
3. **Limits:** $F_X(x) \to 0$ as $x \to -\infty$, and $F_X(x) \to 1$ as $x \to +\infty$.
4. **Right-continuous:** $F_X(x + h) \to F_X(x)$ as $h$ shrinks to $0$ from above.
   This is why the filled dot in the picture is at the **top** of each jump.

Two formulas let you use the CDF for intervals and single points. Here $F_X(x^-)$
means the limit of $F_X$ just to the left of $x$, which equals $P(X \lt x)$:

$$
P(a \lt X \le b) = F_X(b) - F_X(a), \qquad P(X = x) = F_X(x) - F_X(x^-)
$$

**In words:** the probability of an interval is the rise of the CDF across it, and
the probability of a single point is the size of the jump at that point.

## Why It Is True

**The interval rule.** For $a \lt b$, the event $\lbrace X \le b \rbrace$ splits into
two disjoint pieces: $\lbrace X \le a \rbrace$ and $\lbrace a \lt X \le b \rbrace$.

$$
\begin{aligned}
P(X \le b) &= P(X \le a) + P(a \lt X \le b) && \text{(disjoint pieces: additivity)} \\
F_X(b) &= F_X(a) + P(a \lt X \le b) && \text{(definition of } F_X \text{)} \\
P(a \lt X \le b) &= F_X(b) - F_X(a) && \text{(subtract } F_X(a) \text{)}
\end{aligned}
$$

**Non-decreasing.** The middle line shows $F_X(b) = F_X(a) + (\text{a probability})$,
and a probability is at least 0. So $F_X(b) \ge F_X(a)$.

**Limits and right-continuity.** These use the continuity of probability from
[3.9 Continuity of Probability](../03-AXIOMS-OF-PROBABILITY/3.9-Continuity-of-Probability.md):
if events grow (or shrink) step by step to a limit event, their probabilities
approach its probability.

- The events $\lbrace X \le n \rbrace$ for $n = 1, 2, 3, \dots$ grow and their union is
  $\Omega$, so $F_X(n) \to P(\Omega) = 1$.
- The events $\lbrace X \le -n \rbrace$ shrink and their intersection is
  $\varnothing$, because every outcome has a finite value. So $F_X(-n) \to 0$.
- The events $\lbrace X \le x + \frac{1}{n} \rbrace$ shrink to $\lbrace X \le x \rbrace$, so
  $F_X(x + \frac{1}{n}) \to F_X(x)$. Since $F_X$ is non-decreasing, this is enough
  for every $h$ shrinking to 0, not only $h = \frac{1}{n}$.
- The events $\lbrace X \le x - \frac{1}{n} \rbrace$ grow to $\lbrace X \lt x \rbrace$ (not
  $\le$, because $x$ itself is never included). So $F_X(x^-) = P(X \lt x)$, and the
  jump at $x$ is $P(X \le x) - P(X \lt x) = P(X = x)$.

**Why a discrete CDF is a staircase.** If no value of $X$ lies in $(a, b]$, the
interval rule gives $F_X(b) - F_X(a) = 0$, so $F_X$ is flat there. At a value $x_i$
it jumps by $P(X = x_i) = p_X(x_i)$. Flat pieces and jumps: a staircase.

## Worked Examples

### Example 1: One Die, With Care at the Endpoints

**Problem.** Roll a fair die and let $X$ be the result. Find $F_X(3.7)$,
$P(2 \lt X \le 5)$ and $P(2 \le X \le 5)$ using the CDF.

**Solution.**

1. Each face has probability $\frac{1}{6}$. The faces at most $3.7$ are 1, 2 and 3,
   so $F_X(3.7) = \frac{3}{6} = \frac{1}{2}$.
2. In general, $F_X(x) = 0$ for $x \lt 1$, $F_X(x) = \frac{\lfloor x \rfloor}{6}$ for
   $1 \le x \lt 6$, and $F_X(x) = 1$ for $x \ge 6$.
3. Interval rule: $P(2 \lt X \le 5) = F_X(5) - F_X(2) = \frac{5}{6} - \frac{2}{6} = \frac{3}{6} = \frac{1}{2}$.
4. Now 2 is included. $P(2 \le X \le 5) = P(X \le 5) - P(X \lt 2) = F_X(5) - F_X(2^-)$,
   and $F_X(2^-) = P(X \lt 2) = P(X = 1) = \frac{1}{6}$. So the answer is
   $\frac{5}{6} - \frac{1}{6} = \frac{4}{6} = \frac{2}{3}$.

**Answer.** $F_X(3.7) = \frac{1}{2}$, $P(2 \lt X \le 5) = \frac{1}{2}$ and
$P(2 \le X \le 5) = \frac{2}{3}$.

**Check.** Count faces directly: $2 \lt X \le 5$ is $\lbrace 3, 4, 5 \rbrace$, 3
faces; $2 \le X \le 5$ is $\lbrace 2, 3, 4, 5 \rbrace$, 4 faces. For a discrete
variable, $\lt$ and $\le$ give different answers.

### Example 2: Reading a PMF From a CDF

**Problem.** The number of errors $X$ in a nightly log file has this CDF:

$$
F_X(x) =
\begin{cases}
0 & \text{if } x \lt 0 \\
0.5 & \text{if } 0 \le x \lt 1 \\
0.8 & \text{if } 1 \le x \lt 3 \\
1 & \text{if } x \ge 3
\end{cases}
$$

Find the PMF of $X$, $P(X \gt 1)$ and $P(X \ge 1)$.

**Solution.**

1. The CDF jumps at 0, 1 and 3. The jump sizes are the PMF:
   $p_X(0) = 0.5 - 0 = 0.5$, $p_X(1) = 0.8 - 0.5 = 0.3$, $p_X(3) = 1 - 0.8 = 0.2$.
2. There is no jump at 2, so $p_X(2) = 0$: a night with exactly 2 errors never
   happens in this model.
3. $P(X \gt 1) = 1 - P(X \le 1) = 1 - F_X(1) = 1 - 0.8 = 0.2$.
4. $P(X \ge 1) = 1 - P(X \lt 1) = 1 - F_X(1^-) = 1 - 0.5 = 0.5$.

**Answer.** $p_X(0) = 0.5$, $p_X(1) = 0.3$, $p_X(3) = 0.2$; $P(X \gt 1) = 0.2$
and $P(X \ge 1) = 0.5$.

**Check.** $0.5 + 0.3 + 0.2 = 1$. Also $P(X \gt 1)$ is just $p_X(3) = 0.2$, and
$P(X \ge 1) = p_X(1) + p_X(3) = 0.5$. The CDF and the PMF carry the same
information.

### Example 3: The Slowest of Three Servers

**Problem.** A job is split across 3 servers that run in parallel. Each server
needs 1, 2, 3, 4, 5 or 6 seconds, each equally likely, independently of the others.
The job is done when the slowest server is done. Let $M$ be the job time. Find
$P(M \le 4)$ and $P(M = 6)$.

**Solution.**

1. The slowest server finishes within $m$ seconds exactly when **all three** do. By
   independence, the CDF of $M$ is a product:

$$
F_M(m) = P(M \le m) = P(\text{all three} \le m) = \left(\frac{m}{6}\right)^3, \qquad m = 1, 2, \dots, 6
$$

2. $P(M \le 4) = \left(\frac{4}{6}\right)^3 = \frac{64}{216} = \frac{8}{27} \approx 0.296$.
3. The jump at 6 gives the PMF:
   $P(M = 6) = F_M(6) - F_M(5) = 1 - \frac{125}{216} = \frac{91}{216} \approx 0.421$.

**Answer.** $P(M \le 4) = \frac{8}{27} \approx 0.296$ and
$P(M = 6) = \frac{91}{216} \approx 0.421$.

**Check.** $P(M = 6)$ is also "not all three are at most 5", which is
$1 - \left(\frac{5}{6}\right)^3$, the same number. Finding the PMF of a maximum
directly is hard; the CDF makes it a one-line product. This trick returns in
[13.6 Max and Min](../13-FUNCTIONS-OF-RANDOM-VARIABLES/13.6-Max-and-Min.md).

## Simulate It

We estimate the CDF of the sum of two dice from data. The **empirical CDF** at $x$
is the fraction of samples that are at most $x$. We compare it with the exact
running sum of the PMF, including points between the values.

```python
import numpy as np

rng = np.random.default_rng(42)
n_trials = 1_000_000

# S is the sum of two fair dice; its PMF is (6 - |s - 7|) / 36.
S = rng.integers(1, 7, size=n_trials) + rng.integers(1, 7, size=n_trials)
values = np.arange(2, 13)
pmf = (6 - np.abs(values - 7)) / 36

for x in [1.5, 2, 4.5, 7, 7.9, 10, 12, 13]:
    empirical = np.mean(S <= x)             # fraction of samples at most x
    exact = pmf[values <= x].sum()          # F(x) = sum of p(s) for s <= x
    print(f"F({x:>4}): simulation {empirical:.4f}, exact {exact:.4f}")
```

Output:

```text
F( 1.5): simulation 0.0000, exact 0.0000
F(   2): simulation 0.0278, exact 0.0278
F( 4.5): simulation 0.1663, exact 0.1667
F(   7): simulation 0.5838, exact 0.5833
F( 7.9): simulation 0.5838, exact 0.5833
F(  10): simulation 0.9171, exact 0.9167
F(  12): simulation 1.0000, exact 1.0000
F(  13): simulation 1.0000, exact 1.0000
```

Notice that $F(7) = F(7.9)$: no value of $S$ lies in $(7, 7.9]$, so the staircase
is flat there.

## Common Mistakes

- **Using $\lt$ and $\le$ as if they were the same.** For a discrete variable they
  are not: $P(X \le 2) - P(X \lt 2) = P(X = 2)$, which can be large. Write down
  which endpoints are included before using $F(b) - F(a)$.
- **Thinking the CDF is defined only at the values of $X$.** $F_X(x)$ exists for
  every real $x$, such as $F_X(3.7)$ for a die. Between values it stays flat.
- **Drawing the dot at the bottom of a jump.** A CDF is right-continuous:
  $F_X(x)$ includes $P(X = x)$, so the filled dot sits at the top of each step.
- **Mixing up the CDF and the PMF.** The PMF is the height of one bar; the CDF is
  the sum of all bars up to $x$. The CDF never decreases; a PMF can go up and down.
- **Using $P(X \gt x) = 1 - F_X(x)$ for "at least".** For $P(X \ge x)$ you need
  $1 - F_X(x^-)$, which also counts the point $x$ itself.

## Where It Is Used

- **AI and machine learning:** ROC curves and calibration plots are built from
  CDFs of a model's scores; quantiles of a CDF set decision thresholds.
- **Computer science:** latency targets such as "99% of requests within 200 ms"
  are statements about the CDF of response time.
- **Simulation:** inverse transform sampling turns uniform random numbers into any
  distribution by inverting its CDF
  ([19.4 Inverse Transform Sampling](../19-SIMULATION-AND-MONTE-CARLO/19.4-Inverse-Transform-Sampling.md)).
- **Engineering:** the CDF of a part's lifetime is the probability it has failed
  by time $t$.
- **Everyday life:** "you are in the top 10% of your class" is a statement about
  where your score sits on the CDF of all scores.

**1. (Easy)** Let $X$ be the number of heads in two fair coin flips. Find
$F_X(-3)$, $F_X(0.5)$, $F_X(1)$, $F_X(1.99)$ and $F_X(5)$.

<details>
<summary>Answer</summary>

Use $p(0) = \frac{1}{4}$, $p(1) = \frac{1}{2}$, $p(2) = \frac{1}{4}$ and add the
values at most $x$:

$$F_X(-3) = 0, \quad F_X(0.5) = \tfrac{1}{4}, \quad F_X(1) = F_X(1.99) = \tfrac{3}{4}, \quad F_X(5) = 1$$

</details>

**2. (Easy)** A random variable has $F_X(3) = 0.6$ and $F_X(7) = 0.9$. Find
$P(3 \lt X \le 7)$ and $P(X \gt 7)$.

<details>
<summary>Answer</summary>

$$P(3 \lt X \le 7) = F_X(7) - F_X(3) = 0.9 - 0.6 = 0.3$$

$$P(X \gt 7) = 1 - F_X(7) = 1 - 0.9 = 0.1$$

</details>

**3. (Medium)** Let $S$ be the sum of two fair dice. Use the CDF to find
$P(4 \lt S \le 9)$, and check by adding PMF values.

<details>
<summary>Answer</summary>

From the PMF counts $1, 2, 3, 4, 5, 6, 5, 4, 3, 2, 1$: $F_S(9) = \frac{1+2+3+4+5+6+5+4}{36} = \frac{30}{36}$
and $F_S(4) = \frac{1+2+3}{36} = \frac{6}{36}$.

$$P(4 \lt S \le 9) = \frac{30}{36} - \frac{6}{36} = \frac{24}{36} = \frac{2}{3}$$

Check: the sums 5, 6, 7, 8, 9 have $4 + 5 + 6 + 5 + 4 = 24$ pairs, so $\frac{24}{36}$.

</details>

**4. (Medium)** Which of these can be a CDF? Explain each.
(a) $G(x) = 0$ for $x \lt 0$, $0.5$ for $0 \le x \lt 1$, $0.4$ for $1 \le x \lt 2$, $1$ for $x \ge 2$.
(b) $H(x) = 0$ for $x \lt 5$ and $0.9$ for $x \ge 5$.
(c) $K(x) = 0$ for $x \lt 1$, $0.2$ for $1 \le x \lt 4$, $1$ for $x \ge 4$.

<details>
<summary>Answer</summary>

(a) No: it goes down from $0.5$ to $0.4$, but a CDF is non-decreasing.
(b) No: it never reaches 1, but a CDF must tend to 1 as $x \to \infty$.
(c) Yes: it is non-decreasing, goes from 0 to 1, and is right-continuous. It is the
CDF of a variable with $p(1) = 0.2$ and $p(4) = 0.8$.

</details>

**5. (Hard)** Prove that $P(X = x) = F_X(x) - F_X(x^-)$ for any random variable $X$.
Conclude that $F_X$ is continuous at $x$ exactly when $P(X = x) = 0$.

<details>
<summary>Answer</summary>

Let $A_n = \lbrace X \le x - \frac{1}{n} \rbrace$. These events grow with $n$, and
their union is $\lbrace X \lt x \rbrace$: if $X(\omega) \lt x$, then
$X(\omega) \le x - \frac{1}{n}$ for all large $n$; and no outcome with
$X(\omega) = x$ is ever included. By continuity of probability,

$$F_X(x^-) = \lim_{n \to \infty} F_X(x - \tfrac{1}{n}) = \lim_{n \to \infty} P(A_n) = P(X \lt x)$$

(the limit along $\frac{1}{n}$ is the full left limit because $F_X$ is
non-decreasing). Then, since $\lbrace X \le x \rbrace$ is the disjoint union of
$\lbrace X \lt x \rbrace$ and $\lbrace X = x \rbrace$:

$$P(X = x) = P(X \le x) - P(X \lt x) = F_X(x) - F_X(x^-)$$

$F_X$ is always right-continuous, so it is continuous at $x$ exactly when the left
limit equals $F_X(x)$, which happens exactly when $P(X = x) = 0$.

</details>

**6. (Simulate)** Simulate Example 3 (the slowest of three servers) one million

</details>

## Summary

- The CDF $F_X(x) = P(X \le x)$ is defined for every real $x$ and for every kind of
  random variable.
- It is non-decreasing, goes from 0 to 1, and is right-continuous.
- For a discrete variable it is a staircase: flat between values, with a jump of
  $p_X(x)$ at each value $x$.
- Intervals: $P(a \lt X \le b) = F_X(b) - F_X(a)$. Watch which endpoints are
  included.
- The CDF is often the easy route to the distribution of a maximum.

The one formula to remember:

$$
\boxed{P(a \lt X \le b) = F_X(b) - F_X(a)}
$$
