# 5.2 Discrete vs Continuous

[Probability](../README.md) / [Module 05: Discrete Random Variables](README.md) / 5.2 Discrete vs Continuous

**Level:** 2 (Random Variables) · **Time:** about 30 minutes · **Before this:** [5.1 What is a Random Variable](5.1-What-is-a-Random-Variable.md)

> **Big idea:** A discrete random variable puts its probability on values you can list one by one, while a continuous one spreads its probability so thinly that every single value gets probability zero.

---

## Why It Matters

Discrete and continuous random variables need different tools. For a discrete
variable you **add** probabilities of single values, using a probability mass
function ([5.3](5.3-Probability-Mass-Function.md)). For a continuous variable you
**integrate** a density, which starts in
[Module 08](../08-CONTINUOUS-RANDOM-VARIABLES/README.md). So the first question in
any problem is: which kind is this?

## Intuition

Count the emails you get in one hour. The answer is 0, 1, 2, 3, and so on. You
can list the possible values one by one, even if the list never ends. It makes
sense to ask "what is the chance of exactly 3 emails?", and the answer is a
positive number, maybe $0.18$.

Now measure the **time until the next email**. It could be 3.2 minutes, or 3.21,
or 3.2117... Any number in an interval is possible, and you cannot list them. Ask
"what is the chance the wait is exactly 3 minutes, to infinitely many decimal
places?" The answer is $0$. Only questions about **ranges** make sense, such as
"between 3 and 4 minutes".

Think of probability as 1 kilogram of material placed on the number line. A
discrete variable uses **pebbles**: each possible value gets a pebble with a real
weight. A continuous variable uses **fine sand**, spread smoothly. Any stretch of
the line holds some sand, but a single point holds none.

## Picture

```text
   |       #                            |          .-''''-.
   |   #   #   #                        |       .-'        '-.

   |   #   #   #   #   #                |__-'      ######        '-.__
```

On the left probability sits on single points; on the right it is spread so a point holds none.

## Definition

A random variable $X$ is **discrete** if it can take only a finite or
**countably infinite** list of values $x_1, x_2, x_3, \dots$ (a list you can
number, see
[1.9 Finite, Countable and Uncountable Spaces](../01-SETS-SAMPLE-SPACES-AND-EVENTS/1.9-Finite-Countable-and-Uncountable-Spaces.md)),
and these values carry all the probability:

$$
\sum_{i} P(X = x_i) = 1
$$

where the sum runs over the whole list of possible values.

**In words:** a discrete variable lives on a list of points, and the probabilities
of those points add up to 1.

A random variable $X$ is **continuous** if every single value has probability
zero, and probabilities of intervals come from a density $f_X$:

$$
P(X = x) = 0 \ \text{ for every } x, \qquad P(a \le X \le b) = \int_{a}^{b} f_X(t) \thinspace \mathrm{d}t
$$

**In words:** a continuous variable has no weight on any point; only intervals
have probability, and that probability is an area under a curve.

You do not need integrals in this module. The density is the subject of
[8.1 Probability Density Function](../08-CONTINUOUS-RANDOM-VARIABLES/8.1-Probability-Density-Function.md).
Some variables are **mixed**: part of the probability sits on points and part is
spread out (see [8.9 Mixed Distributions](../08-CONTINUOUS-RANDOM-VARIABLES/8.9-Mixed-Distributions.md)).

> **Note:** "Discrete" is about the **values** of $X$, not about $\Omega$. Pick a
> point $\omega$ uniformly in $[0, 1]$ and let $X = 1$ if $\omega \lt 0.3$, else
> $X = 0$. The sample space is continuous, but $X$ takes only two values, so $X$ is
> discrete.

## Why It Is True

Why must a continuous variable give probability zero to single points? Take the
simplest one: a **uniform spinner** $U$ on $[0, 1)$, where the probability of an
interval is its length, so $P(a \le U \lt b) = b - a$. Fix any point $x$ and any
small number $\varepsilon \gt 0$.

$$
\begin{aligned}
0 \le P(U = x) &\le P(x \le U \lt x + \varepsilon) && \text{(the point lies inside the interval)} \\
&= (x + \varepsilon) - x && \text{(probability = length)} \\
&= \varepsilon && \text{(for every } \varepsilon \gt 0 \text{)}
\end{aligned}
$$

A number that is at least $0$ and at most every positive $\varepsilon$ must be
$0$. So $P(U = x) = 0$.

Now see why we cannot build $P(0 \le U \lt 1) = 1$ by adding point
probabilities. Every point gives $0$, so any **countable** sum of them is $0$, not
$1$. The axioms let us add only countably many disjoint pieces
([3.2 Kolmogorov Axioms](../03-AXIOMS-OF-PROBABILITY/3.2-Kolmogorov-Axioms.md)),
and $[0, 1)$ has uncountably many points. This is exactly why continuous variables
need areas instead of sums, and why discrete variables, whose values can be listed,
can use sums.

## Worked Examples

### Example 1: Sort the Variables

**Problem.** Is each variable discrete, continuous or mixed?

**Solution.** Ask: can I list the possible values, and do single values carry
positive probability?

| Variable | Possible values | Type |
|---|---|---|
| Heads in 10 coin flips | $0, 1, \dots, 10$ | Discrete (finite list) |
| Emails in one hour | $0, 1, 2, \dots$ | Discrete (countably infinite) |
| Flips until the first head | $1, 2, 3, \dots$ | Discrete (countably infinite) |
| Time until the next email | any number $t \ge 0$ | Continuous |
| A student's height | any number in an interval | Continuous |
| Height rounded to the nearest cm | $150, 151, 152, \dots$ | Discrete |
| Rain tomorrow in mm | $0$ with positive probability, or any $r \gt 0$ | Mixed |

**Answer.** See the last column. Rounding turns a continuous variable into a
discrete one. Rainfall is mixed, because "no rain at all" has positive
probability but every exact positive amount has probability zero.

**Check.** "Discrete" does not mean "finite": the number of emails has no largest
value, yet it is discrete because its values can be numbered.

### Example 2: A Spinner and Its Sectors

**Problem.** A game wheel has a pointer that stops at a uniform position $U$ in
$[0, 100)$ cm along the rim. The rim is painted with 10 sectors of 10 cm each,
numbered 0 to 9. Let $X$ be the sector number. Find $P(U = 25)$,
$P(20 \le U \lt 30)$ and $P(X = 2)$.

**Solution.**

1. For the uniform position, probability is length divided by 100:
   $P(a \le U \lt b) = \frac{b - a}{100}$.
2. By the argument in "Why It Is True", a single point has probability zero:
   $P(U = 25) \le P(25 \le U \lt 25 + \varepsilon) = \frac{\varepsilon}{100}$ for every
   $\varepsilon \gt 0$, so $P(U = 25) = 0$.
3. $P(20 \le U \lt 30) = \frac{30 - 20}{100} = \frac{10}{100} = 0.1$.
4. Sector 2 covers positions $20 \le U \lt 30$, so the event $X = 2$ is the same
   event: $P(X = 2) = 0.1$.

**Answer.** $P(U = 25) = 0$, $P(20 \le U \lt 30) = 0.1$, and $P(X = 2) = 0.1$.

**Check.** $X$ is discrete with values $0, 1, \dots, 9$, each with probability
$0.1$, and $10 \times 0.1 = 1$. $U$ is continuous. The sector number is a function
of the position, $X = \lfloor U / 10 \rfloor$, so one experiment gives both a
continuous and a discrete random variable.

### Example 3: Are Computer Random Numbers Continuous?

**Problem.** NumPy's `rng.random()` returns numbers of the form $\frac{k}{2^{53}}$
for $k = 0, 1, \dots, 2^{53} - 1$, each equally likely. Is this discrete or
continuous? What is the probability of any one value?

**Solution.**

1. The values form a finite list of $2^{53} \approx 9.007 \times 10^{15}$ numbers,
   so strictly speaking the variable is **discrete**.
2. Each value has probability $\frac{1}{2^{53}} \approx 1.11 \times 10^{-16}$.
3. For any interval wider than about $10^{-15}$, the probability is almost
   exactly its length, just as for the continuous uniform.

**Answer.** Discrete in theory, with point probabilities of about $10^{-16}$. In
practice we treat it as continuous, because no simulation is long enough to tell
the difference.

**Check.** Real data is like this too: every measurement is rounded somewhere.
"Continuous" is a model that is accurate when the grid is very fine.

## Simulate It

We compare a die (discrete) with a uniform number (continuous). Single values of
the die appear often; single values of the uniform almost never repeat.

```python
import numpy as np

rng = np.random.default_rng(42)
n_trials = 10_000_000

# Discrete: a fair die. A single value carries probability 1/6.
rolls = rng.integers(1, 7, size=n_trials)
print(f"Die:     P(X = 3) simulation {np.mean(rolls == 3):.4f}, exact {1 / 6:.4f}")

# Continuous: uniform on [0, 1). A single value carries probability 0,
# but an interval of length 0.1 carries probability 0.1.
u = rng.random(n_trials)
print(f"Uniform: P(U = 0.3) simulation {np.mean(u == 0.3):.4f}, exact 0.0000")
inside = (u >= 0.3) & (u <= 0.4)
print(f"Uniform: P(0.3 <= U <= 0.4) simulation {np.mean(inside):.4f}, exact 0.1000")
print(f"Distinct values among {n_trials:,} uniforms: {np.unique(u).size:,}")
```

Output:

```text
Die:     P(X = 3) simulation 0.1667, exact 0.1667
Uniform: P(U = 0.3) simulation 0.0000, exact 0.0000
Uniform: P(0.3 <= U <= 0.4) simulation 0.1000, exact 0.1000
Distinct values among 10,000,000 uniforms: 10,000,000
```

Ten million uniform draws, and no value appeared twice. That is what "every single
value has probability zero" looks like in practice.

## Common Mistakes

- **"Discrete means finite."** The number of emails, $0, 1, 2, \dots$, has no
  largest value but is still discrete. What matters is that you can list the
  values.
- **"Discrete means whole numbers."** A variable with values $0.5, 1.5, 2.5$ or
  $\frac{1}{2}, \frac{1}{3}, \frac{1}{4}, \dots$ is also discrete.
- **"Probability zero means impossible."** For a continuous variable, every value
  has probability $0$, yet some value always happens. See
  [8.2 Why Point Probabilities are Zero](../08-CONTINUOUS-RANDOM-VARIABLES/8.2-Why-Point-Probabilities-are-Zero.md).
- **"Every variable is either discrete or continuous."** Rainfall, insurance
  claims (often exactly 0) and waiting times with a chance of "no wait" are mixed.
- **Judging by the sample space.** A discrete variable can live on a continuous
  $\Omega$, like the sector number in Example 2. Look at the values of $X$.

## Where It Is Used

- **AI and machine learning:** a classifier's label is discrete (a softmax gives a
  PMF over classes), while a regression target such as a house price is modelled
  as continuous.
- **Language models:** the next token is a discrete random variable over a finite
  vocabulary of tens of thousands of tokens.
- **Computer science:** counts of requests, cache misses and collisions are
  discrete; response times and network delays are modelled as continuous.
- **Engineering:** the number of failures in a year is discrete; the time until
  the first failure is continuous.
- **Everyday life:** goals in a football match are discrete; the distance you run
  is continuous; your exam grade (A, B, C) is a rounded, discrete version of a
  score.

## Practice

**1. (Easy)** Classify each as discrete or continuous: (a) the number of cars in a
parking lot, (b) the weight of a mango, (c) the number of rolls until a die shows
6, (d) the temperature at noon, (e) the temperature rounded to the nearest degree.

<details>
<summary>Answer</summary>

(a) Discrete. (b) Continuous. (c) Discrete: the values $1, 2, 3, \dots$ can be
listed, even though there is no largest one. (d) Continuous. (e) Discrete, because
rounding leaves a list of whole-degree values.

</details>

**2. (Easy)** A friend says: "The number of rolls until the first 6 can be any
positive integer, which is infinitely many values, so it must be continuous." Is
this right?

<details>
<summary>Answer</summary>

No. Infinitely many values are fine for a discrete variable, as long as they can be
listed: $1, 2, 3, \dots$. Each value has positive probability, for example
$P(X = 1) = \frac{1}{6}$. A continuous variable has $P(X = x) = 0$ for every $x$.

</details>

**3. (Medium)** Let $U$ be uniform on $[0, 1)$ and let $Y = \lfloor 10 U \rfloor$, the
first decimal digit of $U$. Is $Y$ discrete or continuous? Find $P(Y = 7)$ and
$P(U = 0.7)$.

<details>
<summary>Answer</summary>

$Y$ takes the values $0, 1, \dots, 9$, so it is discrete. $Y = 7$ exactly when
$0.7 \le U \lt 0.8$, an interval of length $0.1$:

$$P(Y = 7) = P(0.7 \le U \lt 0.8) = 0.8 - 0.7 = 0.1$$

$U$ is continuous, so $P(U = 0.7) = 0$.

</details>

**4. (Medium)** Tomorrow's rainfall $R$ (in mm) is $0$ with probability $0.7$.
With probability $0.3$ it rains, and then the amount is uniform on $(0, 20]$. Find
$P(R = 0)$, $P(R = 5)$ and $P(R \le 10)$. Is $R$ discrete or continuous?

<details>
<summary>Answer</summary>

$P(R = 0) = 0.7$. Given rain, the amount is continuous, so $P(R = 5) = 0$. For
$R \le 10$: either no rain, or rain with amount in $(0, 10]$, which is half of
$(0, 20]$:

$$P(R \le 10) = 0.7 + 0.3 \times \frac{10}{20} = 0.7 + 0.15 = 0.85$$

$R$ is neither: it has a point with positive probability (so it is not continuous)
and a spread-out part (so it is not discrete). It is **mixed**.

</details>

**5. (Hard)** Prove that for **any** random variable $X$, at most $n$ values $x$
can have $P(X = x) \ge \frac{1}{n}$. Then explain why the set of values with
$P(X = x) \gt 0$ is always finite or countably infinite.

<details>
<summary>Answer</summary>

Suppose $n + 1$ different values each had probability at least $\frac{1}{n}$. The
events $\lbrace X = x \rbrace$ for different $x$ are disjoint, so by additivity

$$P(X \in \lbrace x_1, \dots, x_{n+1} \rbrace) \ge (n + 1) \cdot \frac{1}{n} = 1 + \frac{1}{n} \gt 1$$

which is impossible. So at most $n$ values have $P(X = x) \ge \frac{1}{n}$.

Every value with $P(X = x) \gt 0$ has $P(X = x) \ge \frac{1}{n}$ for some whole
number $n$. So this set is the union, over $n = 1, 2, 3, \dots$, of sets with at
most $n$ elements. A countable union of finite sets can be listed (list the first
set, then the second, and so on), so it is finite or countably infinite. In words:
point masses can sit on at most a countable list of points.

</details>

**6. (Simulate)** Simulate 1,000,000 values of $Y = \lfloor 10 U \rfloor$ from

<details>
<summary>Answer</summary>

```python
Y = np.floor(10 * u).astype(int)          # first decimal digit of U

    print(f"P(Y = {k}): simulation {np.mean(Y == k):.4f}, exact 0.1000")
```

```text
P(Y = 1): simulation 0.1002, exact 0.1000
P(Y = 2): simulation 0.0999, exact 0.1000
P(Y = 3): simulation 0.1000, exact 0.1000
P(Y = 4): simulation 0.1003, exact 0.1000
P(Y = 5): simulation 0.1000, exact 0.1000
P(Y = 6): simulation 0.0998, exact 0.1000
```

</details>

## Summary

- A **discrete** variable takes a finite or countable list of values, and their
  probabilities add up to 1.
- A **continuous** variable gives probability $0$ to every single value; only
  intervals have probability, given by areas under a density.
- Some variables are **mixed**, with both point masses and a spread-out part.
- Discrete means "listable values", not "finite" and not "whole numbers".
- Discrete variables use sums; continuous ones use integrals (from Module 08).

The one formula to remember (for a discrete $X$ with values $x_1, x_2, \dots$):

$$
\boxed{\sum_{i} P(X = x_i) = 1}
$$
