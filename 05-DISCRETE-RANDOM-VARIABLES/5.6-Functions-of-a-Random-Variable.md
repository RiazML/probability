# 5.6 Functions of a Random Variable

[Probability](../README.md) / [Module 05: Discrete Random Variables](README.md) / 5.6 Functions of a Random Variable

**Level:** 2 (Random Variables) · **Time:** about 40 minutes · **Before this:** [5.5 Indicator Random Variables](5.5-Indicator-Random-Variables.md)

> **Big idea:** If Y = g(X), then Y is a new random variable, and its PMF is found by adding the probabilities of all values of X that g sends to the same y.

---

## Why It Matters

We rarely care about a random variable only as it is. We care about the profit it
brings, its square, its value capped at a limit, or which hash bucket it lands
in. Each of these is a **function of a random variable**. Knowing how to get the
PMF of $Y = g(X)$ from the PMF of $X$ is the first step toward expectation of
functions ([6.3 LOTUS](../06-EXPECTATION-VARIANCE-AND-MOMENTS/6.3-LOTUS.md)) and
toward [Module 13: Functions of Random Variables](../13-FUNCTIONS-OF-RANDOM-VARIABLES/README.md).

## Intuition

A game: you roll a die and win $20 \times (\text{roll}) - 50$ taka. A roll of 1 loses
30 taka, a roll of 6 wins 70 taka. Your winnings are a new random variable. Each
roll gives a different amount, so each amount simply inherits the probability
$\frac{1}{6}$ of its roll. Nothing merges.

Now a different rule. A robot takes a random step $X$ of $-2, -1, 0, 1$ or $2$
metres, and you care about the **squared distance** $Y = X^2$. The steps $-1$ and
$1$ both give $Y = 1$. So the event $Y = 1$ happens when $X = -1$ **or** when
$X = 1$, and its probability is the sum of both. When a function sends several
values to the same place, their probabilities pile up.

That is the whole idea: follow each value of $X$ to where $g$ sends it, and add the
probabilities that arrive at the same place.

## Picture

```text
   value of X   p_X(x)                        value of Y   p_Y(y)

       -2        0.1   ---------------+
                                      +----->     4        0.1 + 0.1 = 0.2
        2        0.1   ---------------+

       -1        0.2   ---------------+
                                      +----->     1        0.2 + 0.2 = 0.4
        1        0.2   ---------------+

        0        0.4   --------------------->     0        0.4
```

The function $g(x) = x^2$ merges $-2$ with $2$ and $-1$ with $1$, so their probabilities add.

## Definition

Let $X$ be a discrete random variable and $g$ a function from numbers to numbers.
The random variable $Y = g(X)$ is defined outcome by outcome:

$$
Y(\omega) = g\big(X(\omega)\big) \qquad \text{for every outcome } \omega
$$

where $X(\omega)$ is the value of $X$ on outcome $\omega$, and $g$ is then applied
to that number.

**In words:** first find the value of $X$, then apply $g$ to it; the result is the
value of $Y$.

The PMF of $Y$ is

$$
p_Y(y) = \sum_{x \thinspace : \thinspace g(x) = y} p_X(x)
$$

where the sum runs over all values $x$ of $X$ with $g(x) = y$.

**In words:** the probability that $Y$ equals $y$ is the total probability of all
values of $X$ that $g$ sends to $y$.

If $g$ is **one-to-one** (different inputs always give different outputs), each
sum has only one term, so $p_Y(g(x)) = p_X(x)$: the values are relabelled and the
probabilities stay the same.

## Why It Is True

Fix a number $y$. The event $\lbrace Y = y \rbrace$ contains the outcomes $\omega$ with
$g(X(\omega)) = y$. That happens exactly when $X(\omega)$ is one of the values $x$
with $g(x) = y$.

$$
\begin{aligned}
P(Y = y) &= P\big( g(X) = y \big) && \text{(definition of } Y \text{)} \\
&= P\Big( \bigcup_{x \thinspace : \thinspace g(x) = y} \lbrace X = x \rbrace \Big) && \text{(} g(X) = y \text{ means } X \text{ is one of these values)} \\
&= \sum_{x \thinspace : \thinspace g(x) = y} P(X = x) && \text{(the events } \lbrace X = x \rbrace \text{ are disjoint)} \\
&= \sum_{x \thinspace : \thinspace g(x) = y} p_X(x) && \text{(definition of the PMF)}
\end{aligned}
$$

The third step is additivity, and it works because the events $\lbrace X = x \rbrace$
for different $x$ never overlap ([5.1](5.1-What-is-a-Random-Variable.md)). Since
$X$ takes a countable list of values, $Y$ does too, so $Y$ is again discrete.

## Worked Examples

### Example 1: The Square of a Random Step

**Problem.** A robot's step $X$ has PMF $p_X(-2) = 0.1$, $p_X(-1) = 0.2$,
$p_X(0) = 0.4$, $p_X(1) = 0.2$, $p_X(2) = 0.1$. Find the PMF of $Y = X^2$.

**Solution.**

1. List where each value goes: $(-2)^2 = 4$, $(-1)^2 = 1$, $0^2 = 0$, $1^2 = 1$,
   $2^2 = 4$. So $Y$ takes the values 0, 1 and 4.
2. $p_Y(0)$: only $x = 0$ gives 0, so $p_Y(0) = 0.4$.
3. $p_Y(1)$: $x = -1$ and $x = 1$ give 1, so $p_Y(1) = 0.2 + 0.2 = 0.4$.
4. $p_Y(4)$: $x = -2$ and $x = 2$ give 4, so $p_Y(4) = 0.1 + 0.1 = 0.2$.

**Answer.** $p_Y(0) = 0.4$, $p_Y(1) = 0.4$, $p_Y(4) = 0.2$.

**Check.** $0.4 + 0.4 + 0.2 = 1$. $X$ had 5 values but $Y$ has only 3, because
$x^2$ is not one-to-one on these values.

### Example 2: Winnings From a Die

**Problem.** Roll a fair die. You win $Y = 20X - 50$ taka, where $X$ is the roll (a
negative amount is a loss). Find the PMF of $Y$ and $P(Y \gt 0)$.

**Solution.**

1. The rule $g(x) = 20x - 50$ is one-to-one, so each value of $Y$ has one source.
2. The values are $g(1) = -30$, $g(2) = -10$, $g(3) = 10$, $g(4) = 30$,
   $g(5) = 50$, $g(6) = 70$, each with probability $\frac{1}{6}$.
3. $Y \gt 0$ means $20X - 50 \gt 0$, that is $X \gt 2.5$, so $X \in \lbrace 3, 4, 5, 6 \rbrace$:
   $P(Y \gt 0) = \frac{4}{6} = \frac{2}{3}$.

**Answer.** $Y$ takes the values $-30, -10, 10, 30, 50, 70$ taka, each with
probability $\frac{1}{6}$, and $P(Y \gt 0) = \frac{2}{3}$.

**Check.** Any event about $Y$ can be turned into an event about $X$ by solving
for $X$. That is what step 3 did.

### Example 3: Hashing With the Wrong Table Size

**Problem.** A system puts each user into one of 4 servers using the last digit of
the user ID: server $Y = X \operatorname{mod} 4$, where $X$ is the last digit. Assume $X$ is
uniform on $\lbrace 0, 1, \dots, 9 \rbrace$. Find the PMF of $Y$. Is the load
balanced?

**Solution.**

1. Each digit has $p_X(x) = \frac{1}{10}$.
2. Group the digits by their remainder when divided by 4:
   - $Y = 0$ from $x \in \lbrace 0, 4, 8 \rbrace$, so $p_Y(0) = \frac{3}{10}$;
   - $Y = 1$ from $x \in \lbrace 1, 5, 9 \rbrace$, so $p_Y(1) = \frac{3}{10}$;
   - $Y = 2$ from $x \in \lbrace 2, 6 \rbrace$, so $p_Y(2) = \frac{2}{10}$;
   - $Y = 3$ from $x \in \lbrace 3, 7 \rbrace$, so $p_Y(3) = \frac{2}{10}$.

**Answer.** $p_Y = (0.3, 0.3, 0.2, 0.2)$ for servers 0 to 3. The load is **not**
balanced: servers 0 and 1 get 50% more users than servers 2 and 3.

**Check.** The probabilities sum to $0.3 + 0.3 + 0.2 + 0.2 = 1$. The problem is
that 10 is not a multiple of 4. With 5 servers, each would get exactly 2 digits,
and the load would be even. The simulation below confirms the imbalance.

## Simulate It

We simulate the server assignment of Example 3 for a million users and compare
each server's share with the exact PMF.

```python
import numpy as np

rng = np.random.default_rng(42)
n_users = 1_000_000

# X = last digit of the user ID, uniform on 0..9.
X = rng.integers(0, 10, size=n_users)

# Y = g(X) = X mod 4: several digits are sent to the same server.
Y = X % 4

exact = [0.3, 0.3, 0.2, 0.2]
for y in range(4):
    print(f"P(Y = {y}): simulation {np.mean(Y == y):.4f}, exact {exact[y]:.4f}")
```

Output:

```text
P(Y = 0): simulation 0.2995, exact 0.3000
P(Y = 1): simulation 0.3006, exact 0.3000
P(Y = 2): simulation 0.2000, exact 0.2000
P(Y = 3): simulation 0.1999, exact 0.2000
```

## Common Mistakes

- **Forgetting to merge.** Writing $p_Y(1) = 0.2$ in Example 1 forgets that $x = -1$
  also gives $Y = 1$. Always list **every** $x$ that maps to each $y$.
- **Applying $g$ to the probabilities.** The values change; the probabilities are
  only moved and added. $p_Y(y)$ is never $g(p_X(x))$.
- **Assuming the average passes through $g$.** In general the average of $g(X)$ is
  not $g$ of the average of $X$. In Example 1, $X$ averages 0 but $Y = X^2$ does
  not. See [6.3 LOTUS](../06-EXPECTATION-VARIANCE-AND-MOMENTS/6.3-LOTUS.md) and
  [16.3 Jensen Inequality](../16-INEQUALITIES-AND-CONCENTRATION/16.3-Jensen-Inequality.md).
- **Using this formula for continuous variables.** For a density, "add the
  probabilities" becomes a change of variables with an extra stretch factor. See
  [8.8 Change of Variables](../08-CONTINUOUS-RANDOM-VARIABLES/8.8-Change-of-Variables.md).
- **Thinking $Y$ has as many values as $X$.** A function can only merge values,
  never split them. $Y$ has at most as many values as $X$.

## Where It Is Used

- **AI and machine learning:** a classifier turns a score into a label with a
  threshold, $Y = I_{\lbrace X \gt 0.5 \rbrace}$; a loss function turns a prediction
  error into a cost.
- **Computer science:** hashing ($X \operatorname{mod} m$), rounding, and capping a retry count
  are functions of random variables, and their PMFs reveal imbalance or overflow.
- **Finance and insurance:** profit is a function of sales; an insurance payout
  $\min(\text{loss}, \text{limit})$ is a capped function of the loss.
- **Physics and engineering:** energy is a function of speed ($\frac{1}{2} m v^2$),
  and a sensor reading is a rounded function of the true value.
- **Everyday life:** the grade (A, B, C) is a function of the score; a phone plan's
  bill is a function of the minutes used.

## Practice

**1. (Easy)** $X$ is uniform on $\lbrace 1, 2, 3, 4 \rbrace$. Find the PMF of
$Y = 2X + 1$.

<details>
<summary>Answer</summary>

$g(x) = 2x + 1$ is one-to-one, so the values are relabelled:

$$p_Y(3) = p_Y(5) = p_Y(7) = p_Y(9) = \frac{1}{4}$$

</details>

**2. (Easy)** Roll a fair die and let $Y = X \operatorname{mod} 2$, the remainder when the roll
$X$ is divided by 2. Find the PMF of $Y$. Which earlier idea is $Y$?

<details>
<summary>Answer</summary>

$Y = 1$ for the odd rolls $1, 3, 5$ and $Y = 0$ for the even rolls $2, 4, 6$:

$$p_Y(1) = \frac{3}{6} = \frac{1}{2}, \qquad p_Y(0) = \frac{1}{2}$$

$Y$ is the indicator of the event "the roll is odd" from
[5.5](5.5-Indicator-Random-Variables.md).

</details>

**3. (Medium)** $X$ is uniform on $\lbrace -3, -2, -1, 0, 1, 2, 3 \rbrace$. Find the PMF
of $Y = \lvert X \rvert$.

<details>
<summary>Answer</summary>

Each $x$ has probability $\frac{1}{7}$. Only $x = 0$ gives $Y = 0$. For $k = 1, 2, 3$,
both $x = k$ and $x = -k$ give $Y = k$:

$$p_Y(0) = \frac{1}{7}, \qquad p_Y(1) = p_Y(2) = p_Y(3) = \frac{2}{7}$$

Check: $\frac{1 + 2 + 2 + 2}{7} = 1$.

</details>

**4. (Medium)** In the retry example of [5.3](5.3-Probability-Mass-Function.md),
the number of tries $X$ has $p_X(k) = 0.2^{k-1} \times 0.8$ for $k = 1, 2, \dots$. A
log only records $Y = \min(X, 3)$, so "3" means "3 or more tries". Find the PMF of
$Y$.

<details>
<summary>Answer</summary>

$Y = 1$ and $Y = 2$ come from one value of $X$ each. $Y = 3$ collects all
$X \ge 3$, which happens when the first two tries fail:

$$p_Y(1) = 0.8, \quad p_Y(2) = 0.2 \times 0.8 = 0.16, \quad p_Y(3) = P(X \ge 3) = 0.2^2 = 0.04$$

Check: $0.8 + 0.16 + 0.04 = 1$. Here $g$ merges infinitely many values into one.

</details>

**5. (Hard)** For a set of numbers $C$, define the **preimage**
$g^{-1}(C) = \lbrace x : g(x) \in C \rbrace$, the set of inputs that $g$ sends into
$C$. Prove that $P(g(X) \in C) = P(X \in g^{-1}(C))$. Use it to find $P(X^2 \le 1)$
for the robot step of Example 1.

<details>
<summary>Answer</summary>

For any outcome $\omega$: $g(X(\omega)) \in C$ holds exactly when $X(\omega)$ is an
input that $g$ sends into $C$, that is, when $X(\omega) \in g^{-1}(C)$. So the
events $\lbrace g(X) \in C \rbrace$ and $\lbrace X \in g^{-1}(C) \rbrace$ contain the
same outcomes, and they have the same probability.

For $g(x) = x^2$ and $C = \lbrace y : y \le 1 \rbrace$, the preimage is
$\lbrace x : x^2 \le 1 \rbrace = [-1, 1]$. The values of $X$ in it are $-1, 0, 1$:

$$P(X^2 \le 1) = p_X(-1) + p_X(0) + p_X(1) = 0.2 + 0.4 + 0.2 = 0.8$$

This matches $p_Y(0) + p_Y(1) = 0.4 + 0.4 = 0.8$ from Example 1.

</details>

**6. (Simulate)** Simulate the robot step of Example 1 one million times and check
the PMF of $Y = X^2$.

<details>
<summary>Answer</summary>

```python
import numpy as np

rng = np.random.default_rng(42)
X = rng.choice([-2, -1, 0, 1, 2], p=[0.1, 0.2, 0.4, 0.2, 0.1], size=1_000_000)
Y = X ** 2
for y, exact in [(0, 0.4), (1, 0.4), (4, 0.2)]:
    print(f"P(Y = {y}): simulation {np.mean(Y == y):.4f}, exact {exact:.4f}")
```

Output:

```text
P(Y = 0): simulation 0.4001, exact 0.4000
P(Y = 1): simulation 0.4000, exact 0.4000
P(Y = 4): simulation 0.1999, exact 0.2000
```

</details>

## Summary

- A function of a random variable, $Y = g(X)$, is again a random variable:
  $Y(\omega) = g(X(\omega))$.
- Its PMF is found by sending each value of $X$ through $g$ and adding the
  probabilities that land on the same $y$.
- If $g$ is one-to-one, the values are just relabelled and the probabilities do
  not change.
- Any event about $Y$ is an event about $X$: $P(g(X) \in C) = P(X \in g^{-1}(C))$.
- The average of $g(X)$ is usually not $g$ of the average of $X$.

The one formula to remember:

$$
\boxed{p_Y(y) = \sum_{x \thinspace : \thinspace g(x) = y} p_X(x)}
$$
