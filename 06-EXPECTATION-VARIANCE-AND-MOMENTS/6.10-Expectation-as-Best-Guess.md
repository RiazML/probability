# 6.10 Expectation as Best Guess

[Probability](../README.md) / [Module 06: Expectation, Variance and Moments](README.md) / 6.10 Expectation as Best Guess

**Level:** 2 (Random Variables) · **Time:** about 40 minutes · **Before this:** [6.9 Tail-Sum Formula](6.9-Tail-Sum-Formula.md)

> **Big idea:** If you must guess a random value with one number and you pay the squared error, the best guess is the mean; if you pay the absolute error, it is the median; if you only care about being exactly right, it is the mode.

---

## Why It Matters

Every prediction is a guess about a random quantity: tomorrow's temperature, a delivery
time, the price of a house. To choose the "best" guess, you must first say how you will be
punished for mistakes. This choice is called a **loss function**. This topic shows that the
three summaries of this module, the mean, the median and the mode, are exactly the best
guesses for the three most common losses. It is the reason why regression models trained
with squared error predict averages, and it is the first step toward
[14.5 Best Predictor Under Squared Error](../14-CONDITIONAL-EXPECTATION/14.5-Best-Predictor-Under-Squared-Error.md).

## Intuition

A friend will roll a die, and you must write down one number $c$ before the roll. If the die
shows $x$, you pay $(x - c)^2$ taka. Which $c$ is cheapest on average?

If you guess $c = 1$, a roll of 6 costs you $5^2 = 25$ taka. Guessing in the middle protects
you against both ends. Squares punish big misses very hard, so you want to stay close to
**all** values, weighted by how likely they are. That is the balance point: the mean,
$3.5$. Notice that you will never be exactly right, since the die never shows 3.5, and that
is fine: you are minimizing the **average** cost, not trying to hit the value.

Change the rule: now you pay $\lvert x - c \rvert$ taka. Big misses are no longer extra
expensive. Now the best guess is any point with half of the probability on each side: the
median. And if you pay 1 taka for any wrong guess and nothing for an exact hit, you
should guess the most likely value: the mode.

## Picture

```text
  E[(X - c)^2]
      |   *                                                 *
      |
      |
      |        *                                       *
      |             *                             *
      |
      |                  *    *         *    *
      |                            *   <- lowest point at c = 3.5
      +---+---------+---------+---------+---------+---------+--- c
          1         2         3         4         5         6
```

For a die, the expected squared error of a guess $c$ is a parabola. Its lowest point is at
the mean, $c = 3.5$, and its height there is the variance, $\frac{35}{12} \approx 2.92$.

## Definition

Let $X$ be a random variable with mean $\mu$ and finite variance, and let $c$ be a constant
guess. The **mean squared error** (MSE) of the guess is $E[(X - c)^2]$. The key identity is

$$
E\big[(X - c)^2\big] = \operatorname{Var}(X) + (\mu - c)^2
$$

**In words:** the average squared error of a guess is the unavoidable spread of $X$, plus
the squared distance between the guess and the mean.

Three best guesses follow:

| Loss when $X = x$ and you guess $c$ | Name | Best guess | Smallest expected loss |
|---|---|---|---|
| $(x - c)^2$ | squared error | the mean $\mu$ | $\operatorname{Var}(X)$ |
| $\lvert x - c \rvert$ | absolute error | any median $m$ | $E[\lvert X - m \rvert]$ |
| 0 if $x = c$, else 1 | 0-1 loss | any mode | $1 - \max_x p(x)$ |

In symbols, for the first one:

$$
\min_c E\big[(X - c)^2\big] = \operatorname{Var}(X), \quad \text{reached only at } c = E[X]
$$

**In words:** the mean is the single best constant guess under squared error, and the
variance is the error that even the best guess cannot remove.

## Why It Is True

**Squared error.** Write $X - c = (X - \mu) + (\mu - c)$ and expand. The second part, $\mu - c$, is
a constant:

$$
\begin{aligned}
E\big[(X - c)^2\big] &= E\big[(X - \mu)^2 + 2(\mu - c)(X - \mu) + (\mu - c)^2\big] && \text{(expand the square)} \\
&= E\big[(X - \mu)^2\big] + 2(\mu - c) E[X - \mu] + (\mu - c)^2 && \text{(linearity)} \\
&= \operatorname{Var}(X) + 2(\mu - c) \cdot 0 + (\mu - c)^2 && \text{(} E[X - \mu] = 0 \text{)} \\
&= \operatorname{Var}(X) + (\mu - c)^2 && \text{(simplify)}
\end{aligned}
$$

The first term does not depend on $c$. The second is a square, so it is at least 0, and it is
0 only when $c = \mu$. So $c = \mu$ is the unique best guess, and the smallest MSE is
$\operatorname{Var}(X)$.

**0-1 loss.** The expected loss of guessing $c$ is $P(X \ne c) = 1 - p(c)$. This is smallest
when $p(c)$ is largest, that is, when $c$ is a mode.

**Absolute error.** The median result needs a little more care.

<details>
<summary>Full proof (optional)</summary>

Let $m$ be a median, so $P(X \le m) \ge \frac{1}{2}$ and $P(X \ge m) \ge \frac{1}{2}$. Take any $c \gt m$ and
compare $\lvert x - c \rvert$ with $\lvert x - m \rvert$ for each value $x$.

If $x \le m$, then both $x - c$ and $x - m$ are at most 0, and

$$\lvert x - c \rvert - \lvert x - m \rvert = (c - x) - (m - x) = c - m$$

If $x \gt m$, moving the guess from $m$ to $c$ cannot shrink the distance by more than $c - m$
(the triangle inequality), so

$$\lvert x - c \rvert - \lvert x - m \rvert \ge -(c - m)$$

Average these with the PMF of $X$. The first case has probability $P(X \le m)$, the second
$P(X \gt m) = 1 - P(X \le m)$:

$$E\lvert X - c \rvert - E\lvert X - m \rvert \ge (c - m) P(X \le m) - (c - m) P(X \gt m) = (c - m)\big(2P(X \le m) - 1\big) \ge 0$$

The last step uses $c - m \gt 0$ and $P(X \le m) \ge \frac{1}{2}$. So no $c \gt m$ beats $m$. The case
$c \lt m$ is the mirror image, and uses $P(X \ge m) \ge \frac{1}{2}$ instead. Therefore $m$ minimizes
$E\lvert X - c \rvert$.

</details>

## Worked Examples

### Example 1: Guessing a Die Roll

**Problem.** For a fair die, find the MSE of the guesses $c = 3.5$ and $c = 3$. Then find the
expected absolute error of the guesses $c = 3$, $c = 3.5$ and $c = 1$.

**Solution.**

1. From [6.5](6.5-Variance-and-Standard-Deviation.md), $\operatorname{Var}(X) = \frac{35}{12} \approx 2.917$ and $\mu = 3.5$.
2. MSE at $c = 3.5$: $\frac{35}{12} + 0^2 \approx 2.917$.
3. MSE at $c = 3$: $\frac{35}{12} + (3.5 - 3)^2 = 2.917 + 0.25 \approx 3.167$.
4. Absolute error at $c = 3$: the distances for faces 1 to 6 are $2, 1, 0, 1, 2, 3$:

$$
E\lvert X - 3 \rvert = \frac{2 + 1 + 0 + 1 + 2 + 3}{6} = \frac{9}{6} = 1.5
$$

5. At $c = 3.5$ the distances are $2.5, 1.5, 0.5, 0.5, 1.5, 2.5$, which also add to 9, so the
   answer is again $1.5$.
6. At $c = 1$ the distances are $0, 1, 2, 3, 4, 5$, which add to 15, so the answer is $2.5$.

**Answer.** MSE: $2.917$ at $3.5$ and $3.167$ at $3$. Absolute error: $1.5$ at both $3$ and $3.5$,
but $2.5$ at $1$.

**Check.** The medians of a die are all of $[3, 4]$ ([6.8](6.8-Median-Mode-and-Quantiles.md)), so
every guess in that interval has the same, smallest, absolute error. Under squared error
only the mean $3.5$ is best.

### Example 2: Promising a Delivery Time

**Problem.** An online shop's delivery time $X$, in days, is 1 with probability $0.6$, 2 with
probability $0.2$, and 10 with probability $0.2$ (some parcels get stuck at customs). The
shop wants to show one number $c$ on its website. Find the best $c$ under squared error and
under absolute error, and the expected loss of each.

**Solution.**

1. Mean: $\mu = 1(0.6) + 2(0.2) + 10(0.2) = 0.6 + 0.4 + 2 = 3$.
2. Variance: $E[X^2] = 1(0.6) + 4(0.2) + 100(0.2) = 0.6 + 0.8 + 20 = 21.4$, so
   $\operatorname{Var}(X) = 21.4 - 9 = 12.4$.
3. Median: $P(X \le 1) = 0.6 \ge 0.5$ and $P(X \ge 1) = 1 \ge 0.5$, so 1 is a median. (For any
   $c \gt 1$, $P(X \ge c) \le 0.4$, so 1 is the only median.) The mode is also 1.
4. Squared error: the best guess is $c = 3$, with MSE $12.4$. Guessing $c = 1$ gives
   $12.4 + (3 - 1)^2 = 16.4$.
5. Absolute error at $c = 1$:

$$
E\lvert X - 1 \rvert = 0(0.6) + 1(0.2) + 9(0.2) = 0 + 0.2 + 1.8 = 2.0
$$

6. Absolute error at $c = 3$:

$$
E\lvert X - 3 \rvert = 2(0.6) + 1(0.2) + 7(0.2) = 1.2 + 0.2 + 1.4 = 2.8
$$

**Answer.** Under squared error, promise 3 days (MSE $12.4$). Under absolute error, promise
1 day (expected error 2 days). Under 0-1 loss ("be exactly right"), also promise 1 day,
which is right 60% of the time.

**Check.** The answers differ because the distribution is skewed. Squared error fears the
rare 10-day parcels and moves the guess toward them; absolute error does not. Which
number the shop should show depends on what a wrong promise costs it. The simulation
finds the same best guesses by trying many values of $c$.

### Example 3: The Simplest Machine Learning Model

**Problem.** A regression model with **no input features** must predict the same number
$\hat{y}$ for every house. The training prices, in lakh taka (1 lakh = 100,000), are 40, 50,
50, 60 and 300.
What does the model learn if it is trained with squared error? With absolute error?

**Solution.**

1. Training picks the $\hat{y}$ with the smallest **average** loss over the data. That is the
   expected loss when $Y$ is a random training example, each with probability $\frac{1}{5}$.
2. Squared error: the best $\hat{y}$ is the mean,

$$
\hat{y} = \frac{40 + 50 + 50 + 60 + 300}{5} = \frac{500}{5} = 100
$$

3. Absolute error: the best $\hat{y}$ is the median of 40, 50, 50, 60, 300, which is 50.

**Answer.** Squared error learns 100 lakh taka; absolute error learns 50 lakh taka.

**Check.** One expensive house pulls the squared-error model far from the typical price. This
is why absolute error (or other "robust" losses) is used when the data has outliers. A real
model with features learns a guess for each input; with squared error it learns the
**conditional mean** $E[Y \mid \text{features}]$ (see
[21.1.2 Loss Functions as Probability](../21-APPLICATIONS-OF-PROBABILITY/21.1-AI-and-Machine-Learning/21.1.2-Loss-Functions-as-Probability.md)).

## Simulate It

The code checks Example 2. It tries many guesses $c$ from 0 to 10 and keeps the one with
the smallest average loss.

```python
import numpy as np

rng = np.random.default_rng(42)
n_trials = 1_000_000

# Delivery time in days: 1 (prob 0.6), 2 (prob 0.2), 10 (prob 0.2).
days = rng.choice([1, 2, 10], size=n_trials, p=[0.6, 0.2, 0.2])

# Try many constant guesses c and measure the average loss of each.
guesses = np.arange(0, 10.01, 0.25)
mse = np.array([np.mean((days - c) ** 2) for c in guesses])
mae = np.array([np.mean(np.abs(days - c)) for c in guesses])

print(f"Best c for squared error:  {guesses[mse.argmin()]:.2f}  (mean = 3)")
print(f"  smallest average loss:   {mse.min():.4f}  (Var = 12.4)")
print(f"Best c for absolute error: {guesses[mae.argmin()]:.2f}  (median = 1)")
print(f"  smallest average loss:   {mae.min():.4f}  (exact 2.0)")
```

Output:

```text
Best c for squared error:  3.00  (mean = 3)
  smallest average loss:   12.4074  (Var = 12.4)
Best c for absolute error: 1.00  (median = 1)
  smallest average loss:   2.0010  (exact 2.0)
```

## Common Mistakes

- **Thinking "best guess" has one meaning.** The best guess depends on the loss. Always ask
  first: how are mistakes punished?
- **Using the mean when big errors are not extra costly.** For skewed data with outliers, the
  mean can be a poor "typical" guess. The median is often better.
- **Expecting the best guess to be a possible value.** The mean $3.5$ is the best squared-error
  guess for a die, even though it never comes up.
- **Thinking a good guess can have zero error.** Even the best constant guess has MSE equal to
  $\operatorname{Var}(X)$. Only extra information about $X$ (features, conditioning) can
  reduce it ([Module 14](../14-CONDITIONAL-EXPECTATION/README.md)).
- **Forgetting the cross term.** When expanding $E[(X - c)^2]$, the middle term vanishes only
  because $E[X - \mu] = 0$. This works around the mean, not around other points.

## Where It Is Used

- **AI and machine learning:** training with squared error (MSE) makes a model predict the
  mean; with absolute error (MAE) the median; with cross-entropy for classes, the
  predicted label is the mode of the predicted distribution.
- **Statistics:** the sample mean is the least-squares estimate of a center. The identity
  above is the simplest **bias-variance decomposition**: error = variance + bias squared.
- **Computer science:** a cache or a load balancer that must plan for one "typical" load
  picks the mean or a quantile, depending on the cost of being wrong.
- **Business:** inventory and staffing decisions choose a number that minimizes expected
  cost; with unequal costs for too much and too little, the best choice is a quantile.
- **Everyday life:** "When should I leave to catch the train?" depends on whether being late
  is a little bad or very bad.

## Practice

**1. (Easy)** $X$ has mean 10 and variance 4. What is the mean squared error of the guess
$c = 12$? Of $c = 10$?

<details>
<summary>Answer</summary>

$$E[(X - 12)^2] = 4 + (10 - 12)^2 = 4 + 4 = 8$$

At $c = 10$ the MSE is $4 + 0 = 4$, the smallest possible.

</details>

**2. (Easy)** You must guess the sum of two dice and win only if you are exactly right. What
should you guess, and what is your chance of winning?

<details>
<summary>Answer</summary>

Guess the mode, 7. Its probability is $\frac{6}{36} = \frac{1}{6}$, the largest of all sums, so the
chance of winning is $\frac{1}{6} \approx 0.167$.

</details>

**3. (Medium)** $X$ is 0 with probability $0.7$ and 100 with probability $0.3$. Find the best guess
and its expected loss under (a) squared error and (b) absolute error.

<details>
<summary>Answer</summary>

(a) The mean is $30$. The variance is $E[X^2] - 30^2 = 0.3 \times 10000 - 900 = 3000 - 900 = 2100$, so the
best MSE is $2100$.

(b) The median is 0, since $P(X \le 0) = 0.7 \ge 0.5$ and $P(X \ge 0) = 1$. The expected absolute
error is

$$E\lvert X - 0 \rvert = 0.3 \times 100 = 30$$

</details>

**4. (Medium)** $X$ is uniform on $\lbrace 1, 2, 3, 4 \rbrace$. Find every $c$ that minimizes $E\lvert X - c \rvert$, and
the smallest value.

<details>
<summary>Answer</summary>

The medians are all $c$ in $[2, 3]$, since $P(X \le c) \ge \frac{1}{2}$ and $P(X \ge c) \ge \frac{1}{2}$ there. For such
$c$:

$$E\lvert X - c \rvert = \frac{(c - 1) + (c - 2) + (3 - c) + (4 - c)}{4} = \frac{4}{4} = 1$$

Outside $[2, 3]$ the value is larger, for example $1.25$ at $c = 1.5$.

</details>

**5. (Hard)** Prove that the minimum of $E[(X - c)^2]$ over all $c$ is $\operatorname{Var}(X)$, and use
this to give a second proof that $E[X^2] \ge (E[X])^2$.

<details>
<summary>Answer</summary>

From the identity, $E[(X - c)^2] = \operatorname{Var}(X) + (\mu - c)^2 \ge \operatorname{Var}(X)$, with equality at
$c = \mu$, so the minimum is $\operatorname{Var}(X)$. Now take the guess $c = 0$:

$$E[X^2] = E[(X - 0)^2] = \operatorname{Var}(X) + \mu^2 \ge \mu^2 = (E[X])^2$$

since $\operatorname{Var}(X) \ge 0$.

</details>

**6. (Simulate)** Check Practice 4 by simulation: estimate $E\lvert X - c \rvert$ for
$c = 1.5, 2, 2.5, 3, 3.5$.

<details>
<summary>Answer</summary>

```python
import numpy as np

rng = np.random.default_rng(42)
x = rng.integers(1, 5, size=1_000_000)       # uniform on 1, 2, 3, 4
for c in [1.5, 2.0, 2.5, 3.0, 3.5]:
    print(f"c = {c}: average |X - c| = {np.mean(np.abs(x - c)):.4f}")
```

Output:

```text
c = 1.5: average |X - c| = 1.2492
c = 2.0: average |X - c| = 0.9995
c = 2.5: average |X - c| = 0.9997
c = 3.0: average |X - c| = 0.9999
c = 3.5: average |X - c| = 1.2505
```

The flat bottom from 2 to 3 is the interval of medians.

</details>

## Summary

- The best constant guess depends on the loss function.
- Squared error: guess the mean; the leftover error is the variance.
- Absolute error: guess a median. 0-1 loss: guess a mode.
- $E[(X - c)^2] = \operatorname{Var}(X) + (\mu - c)^2$ explains why the mean wins under squared error.
- Machine learning models inherit this: MSE learns means, MAE learns medians.

The one formula to remember:

$$
\boxed{E\big[(X - c)^2\big] = \operatorname{Var}(X) + (E[X] - c)^2}
$$
