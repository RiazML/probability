## Warm-Up

**W1. (Easy)** *Uses [20.2 Sigma-Algebras and Measurable Spaces](20.2-Sigma-Algebras-and-Measurable-Spaces.md).*
Show that the collection of all subsets of a finite set $\Omega$ is a $\sigma$-algebra. How many events are there if $\Omega$ has 5 outcomes?

<details>
<summary>Answer</summary>

Let $\mathcal{F}$ be the collection of all subsets of $\Omega$. Then $\Omega \in \mathcal{F}$. If $A \subseteq \Omega$ then $A^c \subseteq \Omega$, so $A^c \in \mathcal{F}$. Any union of subsets of $\Omega$ (finite or countable) is a subset of $\Omega$, so it is in $\mathcal{F}$. All three rules hold.

Each of the 5 outcomes is in a subset or not, so the number of events is:

$$2^5 = 32$$

</details>

**W2. (Easy)** *Uses [20.2](20.2-Sigma-Algebras-and-Measurable-Spaces.md).*
Roll a die. Let $A = \lbrace 1, 2, 3 \rbrace$ and $B = \lbrace 3, 4 \rbrace$. Find the atoms of $\sigma(\lbrace A, B \rbrace)$ and the number of events. Is $\lbrace 1 \rbrace$ an event? Is $\lbrace 1, 2, 3, 4 \rbrace$?

<details>
<summary>Answer</summary>

Look at the membership of each face in $A$ and $B$. Face 3 is in both. Faces 1 and 2 are in $A$ only. Face 4 is in $B$ only. Faces 5 and 6 are in neither. The atoms are:

$$\lbrace 3 \rbrace, \quad \lbrace 1, 2 \rbrace, \quad \lbrace 4 \rbrace, \quad \lbrace 5, 6 \rbrace$$

With 4 atoms there are $2^4 = 16$ events. The set $\lbrace 1 \rbrace$ is not an event (it splits the atom $\lbrace 1, 2 \rbrace$). The set $\lbrace 1, 2, 3, 4 \rbrace = A \cup B$ is an event.

</details>

**W3. (Easy)** *Uses [20.3 Probability Measures](20.3-Probability-Measures.md).*
Let $\Omega = \lbrace 1, 2, 3, \dots \rbrace$ and $P(\lbrace n \rbrace) = \frac{1}{3} \left( \frac{2}{3} \right)^{n-1}$. Find $P(n \ge 4)$ and $P(n \text{ even})$, and explain why $P(n \ge M) \to 0$ as $M \to \infty$ by continuity.

<details>
<summary>Answer</summary>

The tail is a geometric sum with ratio $\frac{2}{3}$:

$$P(n \ge 4) = \sum_{n=4}^{\infty} \tfrac{1}{3} \left( \tfrac{2}{3} \right)^{n-1} = \tfrac{1}{3} \cdot \frac{(2/3)^3}{1 - 2/3} = \left( \tfrac{2}{3} \right)^3 = \tfrac{8}{27} \approx 0.296$$

The even numbers $2, 4, 6, \dots$ have masses $\frac{1}{3} \cdot \frac{2}{3}, \frac{1}{3} \cdot \left( \frac{2}{3} \right)^3, \dots$:

$$P(n \text{ even}) = \tfrac{2}{9} \cdot \frac{1}{1 - 4/9} = \tfrac{2}{9} \cdot \tfrac{9}{5} = \tfrac{2}{5}$$

The events $\lbrace n \ge M \rbrace$ decrease with $M$ and their intersection is empty. By continuity from above, $P(n \ge M) \to P(\varnothing) = 0$. Indeed $P(n \ge M) = \left( \frac{2}{3} \right)^{M-1} \to 0$.

</details>

**W4. (Easy)** *Uses [20.4 Random Variables as Measurable Functions](20.4-Random-Variables-as-Measurable-Functions.md).*
Flip two fair coins, so $\Omega = \lbrace HH, HT, TH, TT \rbrace$, and let $X$ be the number of heads. List the atoms of $\sigma(X)$. Is the event "the first coin is heads" in $\sigma(X)$?

<details>
<summary>Answer</summary>

$X = 2$ on $\lbrace HH \rbrace$, $X = 1$ on $\lbrace HT, TH \rbrace$, and $X = 0$ on $\lbrace TT \rbrace$. The atoms of $\sigma(X)$ are these three level sets, so $\sigma(X)$ has $2^3 = 8$ events.

The event that the first coin is heads is $\lbrace HH, HT \rbrace$. It splits the atom $\lbrace HT, TH \rbrace$, so it is not in $\sigma(X)$: knowing only the number of heads does not tell you whether the first coin was heads.

</details>

**W5. (Easy)** *Uses [20.6 Borel-Cantelli Lemmas](20.6-Borel-Cantelli-Lemmas.md).*
The events $A_n$ are independent. For each case, decide whether infinitely many $A_n$ happen with probability 0 or 1: (a) $P(A_n) = \frac{1}{(n+1)^2}$, (b) $P(A_n) = \frac{1}{3n}$, (c) $P(A_n) = \frac{1}{n^{1.01}}$, (d) $P(A_n) = \frac{1}{\sqrt{n}}$.

<details>
<summary>Answer</summary>

(a) $\sum \frac{1}{(n+1)^2}$ converges, so the probability is 0 (first lemma).

(b) $\sum \frac{1}{3n} = \frac{1}{3} \sum \frac{1}{n} = \infty$, so the probability is 1 (second lemma, using independence).

(c) $\sum n^{-1.01}$ converges (a $p$-series with $p \gt 1$), so the probability is 0.

(d) $\sum n^{-1/2} = \infty$, so the probability is 1.

</details>

## Core

**C1. (Medium)** *Uses [20.5 Lebesgue Integral and Expectation](20.5-Lebesgue-Integral-and-Expectation.md).*
Let $X \sim \text{Exp}(1)$ and $X \wedge n = \min(X, n)$. Compute $E[X \wedge n]$, and use the monotone convergence theorem to find $E[X]$.

<details>
<summary>Answer</summary>

Split at $n$. On $\lbrace X \lt n \rbrace$ the value is $X$, and on $\lbrace X \ge n \rbrace$ it is $n$. Integrate by parts for the first part:

$$E[X \wedge n] = \int_0^n x e^{-x} \thinspace dx + n P(X \ge n) = \big[ 1 - e^{-n}(1 + n) \big] + n e^{-n} = 1 - e^{-n}$$

The variables $X \wedge n$ are non-negative and increase to $X$ as $n$ grows. By the monotone convergence theorem:

$$E[X] = \lim_{n \to \infty} E[X \wedge n] = \lim_{n \to \infty} (1 - e^{-n}) = 1$$

This agrees with the mean $\frac{1}{\lambda} = 1$ of $\text{Exp}(1)$.

</details>

**C2. (Medium)** *Uses [20.6](20.6-Borel-Cantelli-Lemmas.md) and [20.3](20.3-Probability-Measures.md).*
A fair coin is flipped forever. Show that with probability 1, for every $k = 1, 2, 3, \dots$, a run of $k$ heads in a row occurs infinitely often. Then show that the probability that the sequence is eventually all tails is 0.

<details>
<summary>Answer</summary>

Fix $k$. Cut the sequence into disjoint blocks of $k$ flips. Let $B_j$ be the event that block $j$ is all heads. The blocks use different flips, so the $B_j$ are independent, and $P(B_j) = \frac{1}{2^k}$. Then $\sum_j P(B_j) = \infty$, so by the second lemma infinitely many blocks are all heads, almost surely. So a run of $k$ heads occurs infinitely often, with probability 1.

Let $G_k$ be this probability-1 event. The intersection $\bigcap_{k \ge 1} G_k$ is a countable intersection of events of probability 1, so it has probability 1. On this event, runs of every length occur infinitely often.

The event that the sequence is eventually all tails is inside the complement of $G_1$ (heads infinitely often), because an all-tails ending contains no further heads. So its probability is at most $1 - P(G_1) = 0$.

</details>

**C3. (Medium)** *Uses [20.8 Martingales](20.8-Martingales.md).*
**Polya's urn.** An urn starts with 1 red and 1 blue ball. At each step, draw a ball at random, and return it with one more ball of the same colour. Let $R_n$ be the fraction of red balls after $n$ draws. Show that $(R_n)$ is a martingale. Why does it converge almost surely?

<details>
<summary>Answer</summary>

After $n$ draws the urn has $n + 2$ balls. Suppose it has $r$ red balls, so $R_n = \frac{r}{n+2}$. The next draw is red with probability $\frac{r}{n+2}$. Then $R_{n+1}$ is $\frac{r+1}{n+3}$ if red, and $\frac{r}{n+3}$ if blue:

$$E[R_{n+1} \mid \mathcal{F}_n] = \frac{r}{n+2} \cdot \frac{r+1}{n+3} + \frac{n+2-r}{n+2} \cdot \frac{r}{n+3} = \frac{r(r + 1 + n + 2 - r)}{(n+2)(n+3)} = \frac{r(n+3)}{(n+2)(n+3)} = \frac{r}{n+2}$$

So $E[R_{n+1} \mid \mathcal{F}_n] = R_n$. Each $R_n$ lies in $[0, 1]$, so it is integrable and $\sup_n E\lvert R_n \rvert \le 1$. By Doob's convergence theorem, $R_n$ converges almost surely to a random limit $R_{\infty}$. (Simulation Project S1 shows that for this urn the limit is uniform on $[0, 1]$.)

</details>

**C4. (Medium)** *Uses [20.9 Stopping Times and Optional Stopping](20.9-Stopping-Times-and-Optional-Stopping.md).*
Re-derive the gambler's ruin probability with optional stopping. A player starts with $k = 4$ taka and plays a fair game until she has $N = 12$ taka or nothing. Find the probability that she reaches 12 and the expected number of rounds. Then repeat for a game with win probability $p = 0.4$.

<details>
<summary>Answer</summary>

**Fair game.** The fortune $S_n$ is a martingale, and it stays in $[0, 12]$ until the stop, so optional stopping gives $E[S_T] = 4$. With $w = P(S_T = 12)$:

$$12 w = 4 \implies w = \tfrac{1}{3}$$

The process $S_n^2 - n$ is a martingale, so $E[S_T^2] - E[T] = 16$. Since $E[S_T^2] = 144 w = 48$:

$$E[T] = 48 - 16 = 32 = k(N - k) = 4 \times 8$$

**Biased game, $p = 0.4$, $q = 0.6$.** Let $r = \frac{q}{p} = 1.5$. The process $r^{S_n}$ is a martingale:

$$w = \frac{1 - r^4}{1 - r^{12}} = \frac{1 - 5.0625}{1 - 129.746} = \frac{-4.0625}{-128.746} \approx 0.0316$$

The process $S_n - n(p - q)$ is a martingale, so $E[S_T] - (p - q) E[T] = 4$:

$$E[T] = \frac{k - N w}{q - p} = \frac{4 - 12(0.0316)}{0.2} = \frac{4 - 0.3787}{0.2} \approx 18.11$$

The slightly unfair coin cuts the winning chance from about 33% to about 3%.

</details>

**C5. (Medium)** *Uses [20.9](20.9-Stopping-Times-and-Optional-Stopping.md) (Wald's identity).*
Each round, you roll a fair die and add its face to your score. Then you flip a fair coin: on tails the game ends, on heads you play another round. Find the expected final score. Why is Wald's identity allowed here?

<details>
<summary>Answer</summary>

Let $T$ be the number of rounds. The decision to stop after round $n$ uses only the coin flips so far, so $\lbrace T = n \rbrace$ is decided by the information up to round $n$: $T$ is a stopping time for the filtration generated by the rolls and the flips. (Each die roll is independent of the past coin flips.) $T$ is geometric with success probability $\frac{1}{2}$, so $E[T] = 2$, which is finite. The die rolls are i.i.d. with mean 3.5. Wald's identity gives:

$$E[S_T] = 3.5 \times 2 = 7$$

</details>

**C6. (Medium)** *Uses [20.10 Radon-Nikodym and Densities](20.10-Radon-Nikodym-and-Densities.md).*
A server's waiting time $X$ is 0 with probability $0.5$ (no queue) and otherwise $\text{Exp}(1)$. Find a density of $P_X$ with respect to $\mu = \lambda + \delta_0$, then compute $E[X]$ and $P(X \gt 1)$ from it.

<details>
<summary>Answer</summary>

Since $\mu(\lbrace 0 \rbrace) = 1$ and $P_X(\lbrace 0 \rbrace) = 0.5$, we have $f(0) = 0.5$. On $x \gt 0$ the law has Lebesgue density $0.5 e^{-x}$, so $f(x) = 0.5 e^{-x}$. Check the total mass:

$$\int f \thinspace d\mu = 0.5 + \int_0^{\infty} 0.5 e^{-x} \thinspace dx = 0.5 + 0.5 = 1$$

The mean: the atom contributes $0 \times 0.5$, so:

$$E[X] = \int x f(x) \thinspace d\mu = \int_0^{\infty} x \cdot 0.5 e^{-x} \thinspace dx = 0.5 \times 1 = 0.5$$

The tail: $P(X \gt 1) = \int_1^{\infty} 0.5 e^{-x} \thinspace dx = 0.5 e^{-1} \approx 0.184$.

</details>

## Challenge

**H1. (Hard)** *Uses [20.2](20.2-Sigma-Algebras-and-Measurable-Spaces.md) (proof).*
Let $\Omega = \lbrace 1, 2, 3, \dots \rbrace$ and let $\mathcal{F}_n$ be the $\sigma$-algebra generated by the singletons $\lbrace 1 \rbrace, \dots, \lbrace n \rbrace$. Then $\mathcal{F}_1 \subseteq \mathcal{F}_2 \subseteq \cdots$ is a filtration. Show that $\bigcup_n \mathcal{F}_n$ is **not** a $\sigma$-algebra, and find $\sigma\left( \bigcup_n \mathcal{F}_n \right)$.

<details>
<summary>Answer</summary>

The atoms of $\mathcal{F}_n$ are $\lbrace 1 \rbrace, \dots, \lbrace n \rbrace$ and $\lbrace n+1, n+2, \dots \rbrace$. So a set is in $\mathcal{F}_n$ exactly when it contains all of $\lbrace n+1, n+2, \dots \rbrace$ or none of it. A set is in $\bigcup_n \mathcal{F}_n$ if and only if it is finite or has a finite complement.

This collection is closed under complements and finite unions, but not countable unions. The sets $\lbrace 2 \rbrace, \lbrace 4 \rbrace, \lbrace 6 \rbrace, \dots$ are all in it, but their union, the set of even numbers, is infinite and has an infinite complement. So it is not a $\sigma$-algebra.

The generated $\sigma$-algebra contains all singletons, and so every countable union of singletons, which is every subset of $\Omega$. So $\sigma\left( \bigcup_n \mathcal{F}_n \right)$ is the power set of $\Omega$. This is why the information at time infinity is defined as the $\sigma$-algebra generated by the union, not the union itself.

</details>

**H2. (Hard)** *Uses [20.5](20.5-Lebesgue-Integral-and-Expectation.md) and [20.6](20.6-Borel-Cantelli-Lemmas.md) (proof).*
Let $X_1, X_2, \dots$ be i.i.d. with $E\lvert X_1 \rvert \lt \infty$. Prove that $\frac{X_n}{n} \to 0$ almost surely. (Together with [20.6](20.6-Borel-Cantelli-Lemmas.md), Example 4, this shows that $\frac{X_n}{n} \to 0$ almost surely if and only if $E\lvert X_1 \rvert \lt \infty$.)

<details>
<summary>Answer</summary>

Fix $\varepsilon \gt 0$ and let $Y = \frac{\lvert X_1 \rvert}{\varepsilon}$, so $E[Y] \lt \infty$. Because the $X_n$ are identically distributed:

$$\sum_{n=1}^{\infty} P\big( \lvert X_n \rvert \gt \varepsilon n \big) = \sum_{n=1}^{\infty} P(Y \gt n) \le \sum_{n=1}^{\infty} P(Y \ge n) = E\lfloor Y \rfloor \le E[Y] \lt \infty$$

(the equality is the tail-sum formula of [20.5](20.5-Lebesgue-Integral-and-Expectation.md) for the whole-number variable $\lfloor Y \rfloor$). By the first Borel-Cantelli lemma, with probability 1 only finitely many events $\lbrace \lvert X_n \rvert \gt \varepsilon n \rbrace$ happen. So, almost surely, $\frac{\lvert X_n \rvert}{n} \le \varepsilon$ for all large $n$.

Take $\varepsilon = \frac{1}{j}$ for $j = 1, 2, \dots$. Each of these countably many statements holds almost surely, so they hold simultaneously almost surely. On that event $\limsup \frac{\lvert X_n \rvert}{n} \le \frac{1}{j}$ for every $j$, so $\frac{X_n}{n} \to 0$.

</details>

**H3. (Hard)** *Uses [20.9](20.9-Stopping-Times-and-Optional-Stopping.md) (proof).*
Let $S_n$ be a fair $\pm 1$ walk from 0 and $T$ the first time $S_n = +1$. Prove that $P(T \lt \infty) = 1$ but $E[T] = \infty$, using only gambler's ruin and Wald's identity.

<details>
<summary>Answer</summary>

**$T$ is finite.** Fix $m \ge 1$. Shift the walk up by $m$: it starts at $k = m$, and it reaches $+1$ before $-m$ exactly when the shifted walk reaches $N = m + 1$ before 0. By the gambler's ruin result ([20.9](20.9-Stopping-Times-and-Optional-Stopping.md)) the probability is $\frac{k}{N} = \frac{m}{m+1}$. The event $\lbrace T \lt \infty \rbrace$ contains this event, so:

$$P(T \lt \infty) \ge \frac{m}{m + 1} \quad \text{for every } m \implies P(T \lt \infty) = 1$$

**$E[T]$ is infinite.** The steps are i.i.d. with mean $\mu = 0$, and $T$ is a stopping time. Suppose $E[T] \lt \infty$. Wald's identity would give $E[S_T] = \mu E[T] = 0 \times E[T] = 0$. But $S_T = 1$ with probability 1 (since $T \lt \infty$), so $E[S_T] = 1$. This is a contradiction. So $E[T] = \infty$.

</details>

**H4. (Hard)** *Uses [20.10](20.10-Radon-Nikodym-and-Densities.md) (proof).*
Let $P \ll Q$ be probability measures with $L = \frac{dP}{dQ}$. The **KL divergence** is $D(P \Vert Q) = E_P[\ln L]$. Prove that $D(P \Vert Q) \ge 0$, with equality only if $P = Q$. Check it for $P = (0.5, 0.5)$ and $Q = (0.9, 0.1)$ on two points.

<details>
<summary>Answer</summary>

By the change-of-measure formula, $E_P[\ln L] = E_Q[L \ln L]$. The function $\phi(x) = x \ln x$ is convex. By Jensen's inequality ([16.3](../16-INEQUALITIES-AND-CONCENTRATION/16.3-Jensen-Inequality.md)) and $E_Q[L] = P(\Omega) = 1$:

$$D(P \Vert Q) = E_Q[\phi(L)] \ge \phi(E_Q[L]) = \phi(1) = 1 \cdot \ln 1 = 0$$

Since $\phi$ is strictly convex, equality needs $L$ to be constant $Q$-almost surely, and then $L = E_Q[L] = 1$, so $P = Q$.

Numeric check: on two points,

$$D(P \Vert Q) = 0.5 \ln \tfrac{0.5}{0.9} + 0.5 \ln \tfrac{0.5}{0.1} = 0.5(-0.5878) + 0.5(1.6094) = 0.5108 \gt 0$$

</details>

## Simulation Projects

**S1. (Project)** *Uses [20.8 Martingales](20.8-Martingales.md) and [20.10](20.10-Radon-Nikodym-and-Densities.md).*
Simulate Polya's urn from C3 with 100,000 urns and 200 draws each. Check that the mean of the red fraction stays at $\frac{1}{2}$, that $E[R_{200} \mid R_{199}]$ matches $R_{199}$, and that the limit looks uniform on $[0, 1]$. Does the fraction settle down along a single path?

<details>
<summary>Answer</summary>

```python
import numpy as np

rng = np.random.default_rng(42)
n_urns, n_draws = 100_000, 200

# Polya urn: start with 1 red and 1 blue ball. Draw one at random, put it back with one more ball of the same colour.
red = np.ones(n_urns)
fraction = np.empty((n_urns, n_draws + 1))
fraction[:, 0] = 0.5
for n in range(1, n_draws + 1):
    total = n + 1                                    # balls in the urn before draw n
    red += rng.random(n_urns) < red / total          # a red ball is drawn with probability red / total
    fraction[:, n] = red / (total + 1)

for n in [0, 1, 10, 50, 200]:
    print(f"n = {n:>3}: mean of red fraction = {fraction[:, n].mean():.4f}")
final = fraction[:, -1]
in_bin = (fraction[:, -2] >= 0.30) & (fraction[:, -2] <= 0.32)
print(f"given fraction_199 in [0.30, 0.32]: mean fraction_199 = {fraction[in_bin, -2].mean():.4f}")
print(f"                                     mean fraction_200 = {fraction[in_bin, -1].mean():.4f}")
for q in [0.1, 0.25, 0.5, 0.75, 0.9]:
    print(f"P(final fraction <= {q}) = {np.mean(final <= q):.4f}   (uniform law: {q})")
print(f"typical change after n = 50: sd of (fraction_200 - fraction_50) = {np.std(fraction[:, -1] - fraction[:, 50]):.4f}")
```

Output:

```text
n =   0: mean of red fraction = 0.5000
n =   1: mean of red fraction = 0.4991
n =  10: mean of red fraction = 0.4993
n =  50: mean of red fraction = 0.4992
n = 200: mean of red fraction = 0.4990
given fraction_199 in [0.30, 0.32]: mean fraction_199 = 0.3108
                                     mean fraction_200 = 0.3108
P(final fraction <= 0.1) = 0.1004   (uniform law: 0.1)
P(final fraction <= 0.25) = 0.2501   (uniform law: 0.25)
P(final fraction <= 0.5) = 0.5040   (uniform law: 0.5)
P(final fraction <= 0.75) = 0.7513   (uniform law: 0.75)
P(final fraction <= 0.9) = 0.9009   (uniform law: 0.9)
typical change after n = 50: sd of (fraction_200 - fraction_50) = 0.0489
```

The mean stays at $\frac{1}{2}$ for every $n$ (martingale), and given $R_{199}$ in a narrow band, $R_{200}$ has the same mean as $R_{199}$ (the martingale property itself). The final fraction has the CDF of a uniform variable, so the limit $R_{\infty}$ is uniform on $[0, 1]$: the urn does not remember its start but keeps a random, lasting preference. Along one path, the fraction moves little after step 50: the typical change to step 200 is only about $0.05$, which is the almost sure convergence.

</details>

**S2. (Project)** *Uses [20.8](20.8-Martingales.md) and [20.9](20.9-Stopping-Times-and-Optional-Stopping.md).*
Test four betting systems in a fair coin game with 100 rounds and 200,000 games each: (1) bet 1 every round, (2) double the bet after a loss and reset to 1 after a win (or when the bet would pass 64), (3) bet 2 after a win and 1 after a loss, (4) bet 1 until you are 10 taka ahead, then stop. Report the mean profit, the standard deviation, and the chance of a gain and of a loss. Which system beats the game?

<details>
<summary>Answer</summary>

```python
import numpy as np

rng = np.random.default_rng(42)
n_games, n_rounds = 200_000, 100
win = rng.random((n_games, n_rounds)) < 0.5                    # fair coin: True = win the round

def play(rule):
    """Run one betting system; rule(profit, last_result, last_bet) returns the next bet (0 = stop)."""
    profit = np.zeros(n_games)
    last_win = np.ones(n_games, bool)
    bet = np.ones(n_games)
    for t in range(n_rounds):
        bet = rule(profit, last_win, bet)                      # chosen BEFORE the round: uses the past only
        profit += np.where(win[:, t], bet, -bet)
        last_win = win[:, t]
    return profit

systems = {
    "flat bet 1": lambda p, w, b: np.ones(n_games),
    "double after loss": lambda p, w, b: np.where(w | (b >= 64), 1.0, 2 * b),
    "press after win": lambda p, w, b: np.where(w, 2.0, 1.0),
    "stop at +10": lambda p, w, b: np.where(p >= 10, 0.0, 1.0),
}
print(f"{'system':<18} {'mean':>7} {'sd':>6} {'P(gain)':>8} {'P(loss)':>8}")
for name, rule in systems.items():
    result = play(rule)
    print(f"{name:<18} {result.mean():>+7.3f} {result.std():>6.2f} {np.mean(result > 0):>8.3f} {np.mean(result < 0):>8.3f}")
```

Output:

```text
system                mean     sd  P(gain)  P(loss)
flat bet 1          +0.004  10.00    0.460    0.460
double after loss   +0.084  78.18    0.677    0.323
press after win     +0.018  15.87    0.477    0.498
stop at +10         +0.003   9.22    0.488    0.442
```

Every mean is 0 within simulation noise (the standard error of the mean is $\frac{\text{sd}}{\sqrt{200000}}$, which is $0.02$ for the flat bet and $0.17$ for the doubling system, so $+0.084$ is well within it). No system beats the fair game: each stake is chosen from the past, so each profit is a martingale transform with mean 0 (20.8), and the rule that stops at +10 is a bounded stopping rule (20.9). The systems only change the **shape** of the result. Doubling gains often (68%) but risks big losses, with a standard deviation almost 8 times larger. Stopping at $+10$ turns many small losses into gains and a few big losses into a long tail. The sum is always zero.

</details>
