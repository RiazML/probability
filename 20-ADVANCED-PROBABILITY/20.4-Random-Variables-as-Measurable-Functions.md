# 20.4 Random Variables as Measurable Functions

[Probability](../README.md) / [Module 20: Advanced Probability](README.md) / 20.4 Random Variables as Measurable Functions

**Level:** 5 (Hero) · **Time:** about 55 minutes · **Before this:** [20.3 Probability Measures](20.3-Probability-Measures.md)

> **Big idea:** A random variable is a function $X$ from $\Omega$ to the real numbers such that every question of the form: is $X$ in this Borel set, is an event, and the events that $X$ can answer form a $\sigma$-algebra $\sigma(X)$ that measures how much information $X$ carries.

---

## Why It Matters

In [5.1](../05-DISCRETE-RANDOM-VARIABLES/5.1-What-is-a-Random-Variable.md) a random variable was a rule that turns each outcome into a number, with a small technical condition called **measurability** that we promised to explain. Here it is. The condition makes sure that $P(X \le x)$, $P(a \lt X \lt b)$ and $P(X \in B)$ for any reasonable set $B$ all exist. It also gives us the tools to say precisely what it means that $Y$ is a function of $X$, that two variables are independent, and that a sequence of variables converges almost surely. All of these are statements about $\sigma$-algebras.

## Intuition

Roll a fair die, so $\Omega = \lbrace 1, 2, 3, 4, 5, 6 \rbrace$ and every subset is an event. Define three random variables, each a function of the outcome:

- $Y(\omega) = \omega$, the face itself;
- $X(\omega) = 1$ if $\omega$ is odd and $0$ if even, the parity;
- $Z(\omega) = (\omega - 3)^2$, the squared distance from 3.

The event $X = 1$ is the set of outcomes that $X$ sends to 1: $\lbrace 1, 3, 5 \rbrace$. This set of outcomes is called the **preimage** of $\lbrace 1 \rbrace$. A random variable is good if the preimage of every reasonable set of numbers is an event.

Each variable reveals some information. $Y$ tells you everything. $X$ tells you only odd or even. $Z$ takes the values $4, 1, 0, 1, 4, 9$, so it cannot separate 2 from 4 or 1 from 5, but it does tell you the parity: $Z \in \lbrace 0, 4 \rbrace$ happens only for odd faces, and $Z \in \lbrace 1, 9 \rbrace$ only for even faces. The events that a variable can answer are exactly the preimages of sets of numbers. That is the $\sigma$-algebra $\sigma(X)$.

## Picture

The parity variable $X$ as a function. The arrows show where each outcome goes, and the boxes on the left are the preimages. They form a partition of $\Omega$:

```text
        Omega (die faces)                       R (the real line)

      +-------------------+
      |   1     3     5   | ------------------>  1       X = 1
      |    {X = 1}        |
      +-------------------+
      +-------------------+
      |   2     4     6   | ------------------>  0       X = 0
      |    {X = 0}        |
      +-------------------+

      P(X = 1) = P({1,3,5}) = 1/2
      sigma(X) = { {}, {1,3,5}, {2,4,6}, Omega }
```

A random variable pulls sets of numbers back to sets of outcomes. The collection of all pulled-back sets is $\sigma(X)$.

## Definition

Let $(\Omega, \mathcal{F}, P)$ be a probability space. A function $X : \Omega \to \mathbb{R}$ is a **random variable** (also called a **measurable function**) if

$$
X^{-1}(B) = \lbrace \omega \in \Omega : X(\omega) \in B \rbrace \in \mathcal{F} \quad \text{for every Borel set } B \in \mathcal{B}(\mathbb{R})
$$

**In words:** for every reasonable set of numbers $B$, the event that $X$ lands in $B$ is an allowed event, so it has a probability.

Three objects follow:

- The **law** (or distribution) of $X$ is the measure $P_X(B) = P(X \in B)$ on $(\mathbb{R}, \mathcal{B}(\mathbb{R}))$. It is a probability measure.
- The **$\sigma$-algebra generated by $X$** is $\sigma(X) = \lbrace X^{-1}(B) : B \in \mathcal{B}(\mathbb{R}) \rbrace$. It is the collection of all events that can be decided by looking at $X$.
- A variable $Z$ is **$\sigma(X)$-measurable** if $Z^{-1}(B) \in \sigma(X)$ for all Borel $B$. This means that $Z$ is determined by $X$.

**Doob-Dynkin lemma.** $Z$ is $\sigma(X)$-measurable if and only if $Z = g(X)$ for some Borel function $g$.

**In words:** $Z$ can be computed from $X$ exactly when the information in $Z$ is inside the information in $X$.

Why, in the finite case: if $Z$ is $\sigma(X)$-measurable, then $Z$ is constant on every atom of $\sigma(X)$, and the atoms of $\sigma(X)$ are the level sets of $X$. So $Z(\omega)$ depends on $\omega$ only through $X(\omega)$, which is the statement $Z = g(X)$. The general case is proved by approximating $Z$ with such functions, and we skip it.

**Random vectors.** A function $\mathbf{X} = (X_1, \dots, X_n) : \Omega \to \mathbb{R}^n$ is a random vector if each $X_i$ is a random variable. The same ideas hold with $\mathcal{B}(\mathbb{R}^n)$.

## Why It Is True

**Check on half-lines only.** To prove that $X$ is a random variable it is enough to check $\lbrace X \le x \rbrace \in \mathcal{F}$ for every real $x$. Why: let $\mathcal{G} = \lbrace B \subseteq \mathbb{R} : X^{-1}(B) \in \mathcal{F} \rbrace$. Preimages respect complements and unions, $X^{-1}(B^c) = (X^{-1}(B))^c$ and $X^{-1}(\bigcup B_n) = \bigcup X^{-1}(B_n)$, so $\mathcal{G}$ is a $\sigma$-algebra. If it contains all half-lines $(-\infty, x]$, it contains $\sigma(\text{half-lines}) = \mathcal{B}(\mathbb{R})$ ([20.2](20.2-Sigma-Algebras-and-Measurable-Spaces.md), Fact 4).

**The law is a probability measure.** $P_X(\mathbb{R}) = P(\Omega) = 1$. If $B_1, B_2, \dots$ are disjoint, so are the preimages $X^{-1}(B_n)$, and $X^{-1}(\bigcup B_n) = \bigcup X^{-1}(B_n)$. So $P_X(\bigcup B_n) = \sum P_X(B_n)$.

**$\sigma(X)$ is a $\sigma$-algebra.** It is the image of the $\sigma$-algebra $\mathcal{B}(\mathbb{R})$ under preimages, and preimages respect complements and unions, as just shown. It is the smallest $\sigma$-algebra for which $X$ is measurable.

**New variables from old.** Let $X, Y$ be random variables and $g$ a Borel function (for example any continuous function).

- $g(X)$ is a random variable: $\lbrace g(X) \in B \rbrace = \lbrace X \in g^{-1}(B) \rbrace$, and $g^{-1}(B)$ is Borel. Continuous functions are Borel because the preimage of an open set is open.
- $X + Y$ is a random variable. For any $c$, the event $\lbrace X + Y \lt c \rbrace$ is a countable union:

$$
\lbrace X + Y \lt c \rbrace = \bigcup_{q \in \mathbb{Q}} \big( \lbrace X \lt q \rbrace \cap \lbrace Y \lt c - q \rbrace \big)
$$

Why: if $X + Y \lt c$, there is a rational $q$ with $X \lt q \lt c - Y$. Each piece is an event, and a countable union of events is an event. The half-lines $(-\infty, c)$ generate $\mathcal{B}(\mathbb{R})$ as well. The same kind of argument works for $XY$, $\max(X, Y)$ and other combinations.

- **Limits.** If $X_1, X_2, \dots$ are random variables, so are $\sup_n X_n$, $\inf_n X_n$, $\limsup_n X_n$ and $\liminf_n X_n$. Indeed $\lbrace \sup_n X_n \le x \rbrace = \bigcap_n \lbrace X_n \le x \rbrace$, and $\limsup_n X_n = \inf_N \sup_{n \ge N} X_n$. Therefore the set where the sequence converges, $\lbrace \limsup X_n = \liminf X_n \rbrace$, is an event, and so is $\lbrace X_n \to X \rbrace$. This is what makes "almost sure convergence" ([17.1](../17-LIMIT-THEOREMS/17.1-Modes-of-Convergence.md)) meaningful.

**Indicators.** The indicator $I_A$ is a random variable if and only if $A \in \mathcal{F}$. (The preimages of Borel sets are $\varnothing$, $A$, $A^c$, $\Omega$.) So the indicator of a Vitali set is not a random variable.

**Independence.** Random variables $X$ and $Y$ are **independent** if $P(X \in A, Y \in B) = P(X \in A) P(Y \in B)$ for all Borel $A, B$, that is, if the $\sigma$-algebras $\sigma(X)$ and $\sigma(Y)$ are independent. It is enough to check half-lines:

$$
P(X \le x, Y \le y) = P(X \le x) P(Y \le y) \quad \text{for all } x, y \quad \implies \quad X \perp Y
$$

Proof. Fix $y$. The two set functions $A \mapsto P(X \in A, Y \le y)$ and $A \mapsto P(X \in A) P(Y \le y)$ are finite measures with the same total mass $P(Y \le y)$. They agree on half-lines $A = (-\infty, x]$. If the total mass is 0 both are zero. Otherwise divide by it: two probability measures that agree on a $\pi$-system, hence equal on all Borel sets $A$ by the uniqueness theorem of [20.3](20.3-Probability-Measures.md). Now fix a Borel $A$ and repeat the argument for $B \mapsto P(X \in A, Y \in B)$ and $B \mapsto P(X \in A) P(Y \in B)$. They agree on half-lines, so they agree on all Borel $B$.

**In words:** to test independence it is enough to compare the joint CDF with the product of the marginal CDFs, as in [10.2](../10-JOINT-DISTRIBUTIONS/10.2-Joint-CDF.md) and [10.5](../10-JOINT-DISTRIBUTIONS/10.5-Independence-of-Random-Variables.md).

## Worked Examples

### Example 1: Three Variables on a Die

**Problem.** With $X$ (parity), $Y$ (face) and $Z = (Y - 3)^2$ as above, find the law of $X$, the atoms of $\sigma(Z)$, and decide which variable is a function of which.

**Solution.**

1. Law of $X$: $P(X = 1) = P(\lbrace 1, 3, 5 \rbrace) = \frac{3}{6} = \frac{1}{2}$ and $P(X = 0) = \frac{1}{2}$, so $X \sim \text{Bern}(\frac{1}{2})$.
2. Values of $Z$: faces $1, 2, 3, 4, 5, 6$ give $4, 1, 0, 1, 4, 9$.
3. The atoms of $\sigma(Z)$ are the sets where $Z$ is constant: $\lbrace 3 \rbrace$ (value 0), $\lbrace 2, 4 \rbrace$ (value 1), $\lbrace 1, 5 \rbrace$ (value 4), $\lbrace 6 \rbrace$ (value 9). So $\sigma(Z)$ has $2^4 = 16$ events.
4. $Z = (Y - 3)^2$ is a function of $Y$, so $\sigma(Z) \subseteq \sigma(Y)$, which is all 64 subsets.
5. Parity is constant on each atom of $\sigma(Z)$: $\lbrace 3 \rbrace$ odd, $\lbrace 2, 4 \rbrace$ even, $\lbrace 1, 5 \rbrace$ odd, $\lbrace 6 \rbrace$ even. So $X = h(Z)$ with $h(0) = h(4) = 1$ and $h(1) = h(9) = 0$, and $\sigma(X) \subseteq \sigma(Z)$.
6. $Y$ is not a function of $Z$: $Z = 1$ is produced by both $Y = 2$ and $Y = 4$.

**Answer.** $X \sim \text{Bern}(\frac{1}{2})$, $\sigma(Z)$ has 16 events, and $\sigma(X) \subseteq \sigma(Z) \subseteq \sigma(Y)$.

**Check.** More information means a bigger $\sigma$-algebra: parity (4 events), squared distance (16 events), the face (64 events). The program below checks the "function of" claims by brute force.

### Example 2: "The Coin Averages to One Half" Is an Event

**Problem.** Let $S_n$ be the number of heads in the first $n$ flips of the infinite fair coin of [20.3](20.3-Probability-Measures.md). Show that $\lbrace S_n / n \to \frac{1}{2} \rbrace$ is an event, and say what the Strong Law of Large Numbers says about it.

**Solution.**

1. Each $S_n$ is a function of the first $n$ digits, a finite sum of indicators of events, so it is a random variable.
2. A sequence of numbers $a_n$ converges to $\frac{1}{2}$ exactly when: for every $k = 1, 2, \dots$ there is an $N$ such that for all $n \ge N$ we have $\lvert a_n - \frac{1}{2} \rvert \le \frac{1}{k}$.
3. Translate "for every", "there is" and "for all" into countable intersections and unions:

$$
\left\lbrace \frac{S_n}{n} \to \frac{1}{2} \right\rbrace = \bigcap_{k=1}^{\infty} \bigcup_{N=1}^{\infty} \bigcap_{n \ge N} \left\lbrace \left\lvert \frac{S_n}{n} - \frac{1}{2} \right\rvert \le \frac{1}{k} \right\rbrace
$$

4. Each set on the right is an event, and countable unions and intersections of events are events. So the left side is an event.
5. The Strong Law ([17.4](../17-LIMIT-THEOREMS/17.4-Strong-Law-of-Large-Numbers.md)) says that this event has probability 1.

**Answer.** It is an event, and its probability is 1.

**Check.** The event contains uncountably many sequences (all sequences with limit frequency $\frac{1}{2}$), and its complement contains uncountably many too, for example every sequence with frequency $\frac{1}{3}$. Yet the complement has probability 0. Uncountable does not mean likely.

### Example 3: One Uniform Number Makes Any Random Variable

**Problem.** Let $U$ be uniform on $[0, 1)$ (the probability space of [20.3](20.3-Probability-Measures.md)) and $X = -\frac{\ln(1 - U)}{\lambda}$. Find the law of $X$, and decide whether $\sigma(X) = \sigma(U)$.

**Solution.**

1. $X$ is a continuous function of $U$ on $[0, 1)$, hence measurable.
2. For $x \ge 0$: $P(X \le x) = P\big(-\ln(1 - U) \le \lambda x\big) = P\big(1 - U \ge e^{-\lambda x}\big) = P\big(U \le 1 - e^{-\lambda x}\big) = 1 - e^{-\lambda x}$.
3. This is the CDF of $\text{Exp}(\lambda)$, the rate being $\lambda$. By uniqueness ([20.3](20.3-Probability-Measures.md)), $X \sim \text{Exp}(\lambda)$.
4. The map $u \mapsto x$ has an inverse $x \mapsto 1 - e^{-\lambda x}$, which is continuous. So $U = 1 - e^{-\lambda X}$ is a function of $X$, and $X$ is a function of $U$: $\sigma(X) = \sigma(U)$.

**Answer.** $X \sim \text{Exp}(\lambda)$ and $\sigma(X) = \sigma(U)$.

**Check.** This is inverse transform sampling ([19.4](../19-SIMULATION-AND-MONTE-CARLO/19.4-Inverse-Transform-Sampling.md)): every law on $\mathbb{R}$ can be realized as a function $Q(U)$ of one uniform number $U$ on $([0, 1), \mathcal{B}, \lambda)$, where $Q$ is the quantile function.

## Simulate It

Part 1 checks the claims of Example 1 by brute force: $g$ is a function of $h$ exactly when $g$ is constant on each level set of $h$. Part 2 checks Example 3.

```python
import numpy as np

# Part 1: random variables on the die space are functions of the outcome.
# g is "known from h" if g(w) is constant on every level set of h.
faces = [1, 2, 3, 4, 5, 6]
value = {w: w for w in faces}                 # Y: the face
parity = {w: w % 2 for w in faces}            # X: 1 if odd, 0 if even
dist = {w: (w - 3) ** 2 for w in faces}       # Z: squared distance from 3

def is_function_of(g, h):
    seen = {}
    return all(seen.setdefault(h[w], g[w]) == g[w] for w in faces)

print("is it a function of ->    Y      Z      X")
for name, g in [("X (parity)", parity), ("Y (face)", value), ("Z (distance)", dist)]:
    flags = [is_function_of(g, h) for h in (value, dist, parity)]
    print(f"{name:<22}  " + "  ".join(f"{str(f):<5}" for f in flags))

# Part 2: one uniform point U drives a whole random variable: X = -ln(1 - U) / 2 is Exp(rate 2).
rng = np.random.default_rng(42)
u = rng.random(1_000_000)
x = -np.log(1 - u) / 2
for t in [0.25, 1.0, 2.0]:
    print(f"P(X <= {t}) = {np.mean(x <= t):.4f}   exact {1 - np.exp(-2 * t):.4f}")
print(f"mean of X = {x.mean():.4f}   exact 0.5000")
```

Output:

```text
is it a function of ->    Y      Z      X
X (parity)              True   True   True 
Y (face)                True   False  False
Z (distance)            True   True   False
P(X <= 0.25) = 0.3933   exact 0.3935
P(X <= 1.0) = 0.8647   exact 0.8647
P(X <= 2.0) = 0.9816   exact 0.9817
mean of X = 0.5001   exact 0.5000
```

The table says: parity is a function of all three variables, the face $Y$ is a function of nothing coarser, and $Z$ is a function of $Y$ but not of the parity. The second part shows that the simple function $-\frac{\ln(1-U)}{2}$ of a uniform number has the exponential CDF.

## Common Mistakes

- **Mixing up a variable and its law.** $X$ is a function on $\Omega$. $P_X$ is a measure on $\mathbb{R}$. Two different variables can have the same law ([20.3](20.3-Probability-Measures.md), Example 3).
- **Thinking that every function is a random variable.** Only measurable ones are. All functions you build from continuous functions, sums, products and limits are fine. The indicator of a Vitali set is not.
- **Reading $\sigma(X)$ as the set of values of $X$.** It is a collection of **events** (subsets of $\Omega$), not numbers.
- **Confusing "independent" with "uncorrelated".** Independence says every event about $X$ is independent of every event about $Y$. Uncorrelated only says $E[XY] = E[X]E[Y]$ ([11.4](../11-COVARIANCE-AND-CORRELATION/11.4-Uncorrelated-vs-Independent.md)).
- **Forgetting the order of quantifiers in convergence.** The event $X_n \to X$ is $\bigcap_k \bigcup_N \bigcap_{n \ge N}$: for **every** tolerance, **eventually**, always within it.

## Where It Is Used

- **Conditional expectation:** $E[Y \mid X]$ means $E[Y \mid \sigma(X)]$, and it is a $\sigma(X)$-measurable variable, hence a function $g(X)$ by the Doob-Dynkin lemma ([14.2](../14-CONDITIONAL-EXPECTATION/14.2-Conditional-Expectation-as-a-Random-Variable.md), [20.8](20.8-Martingales.md)).
- **Machine learning:** an estimator or a trained model is a measurable function of the data. A predictor that uses only the features $X$ is a $\sigma(X)$-measurable function.
- **Statistics:** a statistic $T(X_1, \dots, X_n)$ is **sufficient** when it keeps all the information about the parameter that $\sigma(X_1, \dots, X_n)$ has.
- **Stochastic processes and reinforcement learning:** an action at time $t$ must be $\sigma(\text{history up to } t)$-measurable. This is the idea behind **stopping times** and **predictable** betting systems ([20.9](20.9-Stopping-Times-and-Optional-Stopping.md)).
- **Simulation:** every sampling method builds a measurable function of uniform random numbers ([19.4](../19-SIMULATION-AND-MONTE-CARLO/19.4-Inverse-Transform-Sampling.md)).

## Practice

**1. (Easy)** Let $\Omega = \lbrace 1, 2, 3, 4 \rbrace$ with all subsets as events, and $X(\omega)$ equal to the remainder of $\omega$ divided by 2. List $\sigma(X)$.

<details>
<summary>Answer</summary>

$X = 1$ on $\lbrace 1, 3 \rbrace$ and $X = 0$ on $\lbrace 2, 4 \rbrace$. The preimages of Borel sets are $\varnothing$, $\lbrace 1, 3 \rbrace$, $\lbrace 2, 4 \rbrace$ and $\Omega$:

$$\sigma(X) = \lbrace \varnothing, \lbrace 1, 3 \rbrace, \lbrace 2, 4 \rbrace, \Omega \rbrace$$

</details>

**2. (Easy)** For $A \subseteq \Omega$, show that the indicator $I_A$ is a random variable if and only if $A \in \mathcal{F}$.

<details>
<summary>Answer</summary>

For a Borel set $B$ the preimage $I_A^{-1}(B)$ is $\varnothing$ if $B$ contains neither 0 nor 1, $A$ if $B$ contains 1 but not 0, $A^c$ if $B$ contains 0 but not 1, and $\Omega$ if $B$ contains both. All four are events if and only if $A$ is an event (then $A^c$ is too). Taking $B = \lbrace 1 \rbrace$ shows that $A$ must be in $\mathcal{F}$.

</details>

**3. (Medium)** Let $X$ be a random variable. Show that $X^2$ is a random variable using half-lines.

<details>
<summary>Answer</summary>

For $x \lt 0$: $\lbrace X^2 \le x \rbrace = \varnothing \in \mathcal{F}$. For $x \ge 0$:

$$\lbrace X^2 \le x \rbrace = \lbrace -\sqrt{x} \le X \le \sqrt{x} \rbrace = \lbrace X \le \sqrt{x} \rbrace \setminus \lbrace X \lt -\sqrt{x} \rbrace$$

Both sets on the right are events. For the second one, $\lbrace X \lt c \rbrace = \bigcup_n \lbrace X \le c - \frac{1}{n} \rbrace$ with $c = -\sqrt{x}$. A difference of events is an event. So every half-line has an event as preimage, and $X^2$ is a random variable.

</details>

**4. (Medium)** Let $X$ be a random variable. Show that $\lbrace X \in \mathbb{Q} \rbrace$ is an event. If $X \sim \text{Unif}(0, 1)$, what is its probability?

<details>
<summary>Answer</summary>

The rationals are a countable set, so $\mathbb{Q} \in \mathcal{B}(\mathbb{R})$ (a countable union of points). Therefore $\lbrace X \in \mathbb{Q} \rbrace = X^{-1}(\mathbb{Q}) \in \mathcal{F}$.

For $X \sim \text{Unif}(0, 1)$, each point has probability 0, and by countable additivity:

$$P(X \in \mathbb{Q}) = \sum_{q \in \mathbb{Q}} P(X = q) = 0$$

</details>

**5. (Hard)** Let $X_1, X_2, \dots$ be random variables. Prove that $\lbrace X_n \text{ converges to a finite limit} \rbrace$ is an event.

<details>
<summary>Answer</summary>

A real sequence converges if and only if it is a Cauchy sequence: for every $k$ there is $N$ such that for all $m, n \ge N$ we have $\lvert X_m - X_n \rvert \le \frac{1}{k}$. So:

$$\lbrace X_n \text{ converges} \rbrace = \bigcap_{k=1}^{\infty} \bigcup_{N=1}^{\infty} \bigcap_{m, n \ge N} \lbrace \lvert X_m - X_n \rvert \le \tfrac{1}{k} \rbrace$$

Each $X_m - X_n$ is a random variable (a sum of two), and so is its absolute value, so $\lbrace \lvert X_m - X_n \rvert \le \frac{1}{k} \rbrace \in \mathcal{F}$. The intersection over the countable set of pairs $(m, n)$, then the union over $N$, then the intersection over $k$ are all countable operations. So the result is in $\mathcal{F}$.

</details>

**6. (Simulate)** Let $X = -\frac{\ln(1 - U)}{\lambda}$ with $\lambda = 2$ and $U$ uniform. Estimate $P(X \gt 1)$ and $E[X]$ and compare with the exact values.

<details>
<summary>Answer</summary>

```python
import numpy as np

rng = np.random.default_rng(42)
lam = 2.0
u = rng.random(1_000_000)

print(f"P(X > 1) = {np.mean(x > 1):.4f}   exact {np.exp(-lam):.4f}")

```

```text
P(X > 1) = 0.1353   exact 0.1353
E[X]     = 0.5001   exact 0.5000
```

</details>

## Summary

- A **random variable** is a function $X : \Omega \to \mathbb{R}$ with $X^{-1}(B) \in \mathcal{F}$ for every Borel set $B$. It is enough to check the half-lines $\lbrace X \le x \rbrace$.
- The **law** $P_X(B) = P(X \in B)$ is a probability measure on $\mathbb{R}$. It is determined by the CDF.
- $\sigma(X)$ is the collection of events that $X$ can decide. $Z$ is determined by $X$ exactly when $Z = g(X)$.
- Sums, products, continuous functions, suprema and limits of random variables are random variables, and $\lbrace X_n \to X \rbrace$ is an event.
- Independence of random variables means independence of their $\sigma$-algebras. It can be checked on joint and marginal CDFs.

The one formula to remember:

$$
\boxed{X^{-1}(B) = \lbrace \omega : X(\omega) \in B \rbrace \in \mathcal{F} \ \text{ for all Borel } B, \qquad P_X(B) = P(X^{-1}(B))}
$$
