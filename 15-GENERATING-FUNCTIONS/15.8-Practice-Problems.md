# 15.8 Practice Problems

[Probability](../README.md) / [Module 15: Generating Functions](README.md) / 15.8 Practice Problems

**Level:** 4 (Big Theorems) · **Time:** about 3 hours · **Before this:** [15.7 Cumulants](15.7-Cumulants.md)

> **Big idea:** A generating function turns sums into products and moments into derivatives, and you only learn to see which one to use by solving many problems.

---

## How to Use This Set

- Each problem says which topic it uses. If you get stuck, reread that topic first.
- Try every problem on paper before opening the answer. Write each step, as in the
  worked examples.
- **Warm-Up** problems check the basic formulas. **Core** problems mix two or three
  ideas. **Challenge** problems include proofs. **Simulation Projects** ask you to write code.
- A good habit: for each problem, ask "do I need the whole distribution, or only some
  moments?" The MGF or CGF is best for moments and for recognizing a sum; the PGF is best for
  counts; the characteristic function is the safe choice when moments may not exist.
- After solving a problem by hand, check the number with a short simulation.

## Warm-Up

**W1. (Easy)** *Uses [15.1 Moment Generating Function](15.1-Moment-Generating-Function.md) and [15.2 Moments from the MGF](15.2-Moments-from-the-MGF.md).*
A variable $X$ takes the values $-1, 0, 2$ with probabilities $0.2, 0.5, 0.3$. Write $M_X(t)$,
check that $M_X(0) = 1$, and use derivatives to find $E[X]$ and $\operatorname{Var}(X)$.

<details>
<summary>Answer</summary>

$$M_X(t) = 0.2e^{-t} + 0.5 + 0.3e^{2t}, \qquad M_X(0) = 0.2 + 0.5 + 0.3 = 1$$

Differentiate: $M'(t) = -0.2e^{-t} + 0.6e^{2t}$ and $M''(t) = 0.2e^{-t} + 1.2e^{2t}$. At $t = 0$:

$$E[X] = -0.2 + 0.6 = 0.4, \qquad E[X^2] = 0.2 + 1.2 = 1.4$$

$$\operatorname{Var}(X) = 1.4 - 0.4^2 = 1.4 - 0.16 = 1.24$$

</details>

**W2. (Easy)** *Uses [15.2 Moments from the MGF](15.2-Moments-from-the-MGF.md).*
Let $X \sim \text{Exp}(4)$ (rate 4). Use $M_X(t) = \frac{4}{4 - t}$ to find $E[X]$, $\operatorname{Var}(X)$ and $E[X^3]$.

<details>
<summary>Answer</summary>

Write $M(t) = 4(4 - t)^{-1}$. Then $M' = 4(4-t)^{-2}$, $M'' = 8(4-t)^{-3}$ and $M''' = 24(4-t)^{-4}$. At $t = 0$:

$$E[X] = \frac{4}{16} = \frac{1}{4}, \qquad E[X^2] = \frac{8}{64} = \frac{1}{8}, \qquad E[X^3] = \frac{24}{256} = \frac{3}{32} = 0.09375$$

$$\operatorname{Var}(X) = \frac{1}{8} - \frac{1}{16} = \frac{1}{16}$$

These agree with $E[X^n] = n!/4^n$ and $\operatorname{Var}(X) = 1/\lambda^2$.

</details>

**W3. (Easy)** *Uses [15.3 MGF of Sums](15.3-MGF-of-Sums.md) and [15.4 Uniqueness Theorem](15.4-Uniqueness-Theorem.md).*
$X \sim \text{Bin}(3, 0.5)$ and $Y \sim \text{Bin}(5, 0.5)$ are independent. Use MGFs to find the distribution of $X + Y$, and $P(X + Y = 4)$.

<details>
<summary>Answer</summary>

$$M_{X+Y}(t) = (0.5 + 0.5e^t)^3 (0.5 + 0.5e^t)^5 = (0.5 + 0.5e^t)^8$$

This is the MGF of $\text{Bin}(8, 0.5)$, so by uniqueness $X + Y \sim \text{Bin}(8, 0.5)$:

$$P(X + Y = 4) = \binom{8}{4} \left( \tfrac{1}{2} \right)^8 = \frac{70}{256} \approx 0.2734$$

</details>

**W4. (Easy)** *Uses [15.5 Probability Generating Function](15.5-Probability-Generating-Function.md).*
A count $X$ is uniform on $\lbrace 0, 1, 2 \rbrace$. Write $G_X(s)$, find $E[X]$ from $G'(1)$, and use $G_X(s)^2$ to find $P(X_1 + X_2 = 2)$ for two independent copies.

<details>
<summary>Answer</summary>

$$G_X(s) = \frac{1 + s + s^2}{3}, \qquad G'(s) = \frac{1 + 2s}{3}, \qquad E[X] = G'(1) = 1$$

Square the polynomial: $(1 + s + s^2)^2 = 1 + 2s + 3s^2 + 2s^3 + s^4$. So

$$G_X(s)^2 = \frac{1 + 2s + 3s^2 + 2s^3 + s^4}{9}, \qquad P(X_1 + X_2 = 2) = \frac{3}{9} = \frac{1}{3}$$

Check by listing: $(0,2), (1,1), (2,0)$ are 3 of the 9 equally likely pairs.

</details>

**W5. (Easy)** *Uses [15.6 Characteristic Function](15.6-Characteristic-Function.md).*
For $X \sim \text{Bern}(0.5)$ compute $\varphi_X(\frac{\pi}{2})$ and its length. (Use $e^{i\pi/2} = i$.)

<details>
<summary>Answer</summary>

$$\varphi_X(t) = 0.5 + 0.5e^{it}, \qquad \varphi_X\left( \tfrac{\pi}{2} \right) = 0.5 + 0.5i$$

The length is $\sqrt{0.5^2 + 0.5^2} = \sqrt{0.5} \approx 0.7071$, which is at most $1$, as it must be.

</details>

## Core

**C1. (Medium)** *Uses [15.3 MGF of Sums](15.3-MGF-of-Sums.md).*
Two servers receive independent requests per second: $A \sim \text{Pois}(1.2)$ and $B \sim \text{Pois}(2.3)$ (means 1.2 and 2.3). Use MGFs to prove that the total $A + B$ is Poisson, and find $P(A + B = 0)$ and $P(A + B \ge 2)$.

<details>
<summary>Answer</summary>

$$M_{A+B}(t) = e^{1.2(e^t - 1)} e^{2.3(e^t - 1)} = e^{3.5(e^t - 1)}$$

This is the MGF of $\text{Pois}(3.5)$, so by uniqueness $A + B \sim \text{Pois}(3.5)$. Then

$$P(A + B = 0) = e^{-3.5} \approx 0.0302$$

$$P(A + B \ge 2) = 1 - e^{-3.5}(1 + 3.5) = 1 - 4.5 \times 0.030197 \approx 0.8641$$

</details>

**C2. (Medium)** *Uses [15.5 Probability Generating Function](15.5-Probability-Generating-Function.md).*
Roll a fair die and flip a fair coin. Add the die value to 6 if the coin shows heads, and to 0 if it shows tails. Use PGFs to find the distribution of the total.

<details>
<summary>Answer</summary>

The die has $G_D(s) = \frac{s + s^2 + \cdots + s^6}{6}$ and the coin adds $0$ or $6$ with $G_C(s) = \frac{1 + s^6}{2}$. They are independent, so multiply:

$$G(s) = \frac{(s + s^2 + \cdots + s^6)(1 + s^6)}{12} = \frac{s + s^2 + \cdots + s^6 + s^7 + \cdots + s^{12}}{12}$$

Every power from $s^1$ to $s^{12}$ has the coefficient $\frac{1}{12}$. So the total is uniform on $\lbrace 1, 2, \dots, 12 \rbrace$, each value with probability $\frac{1}{12}$. A fair die and a fair coin can imitate a fair 12-sided die.

</details>

**C3. (Medium)** *Uses [15.1](15.1-Moment-Generating-Function.md) and [15.2 Moments from the MGF](15.2-Moments-from-the-MGF.md).*
For $U \sim \text{Unif}(0, 1)$ the MGF is $M(t) = \frac{e^t - 1}{t}$. Expand it as a power series to find $E[U^n]$ for all $n$, and check the variance.

<details>
<summary>Answer</summary>

Use $e^t - 1 = t + \frac{t^2}{2!} + \frac{t^3}{3!} + \cdots$ and divide by $t$:

$$M(t) = \sum_{k=0}^{\infty} \frac{t^k}{(k+1)!}$$

The coefficient of $\frac{t^n}{n!}$ is the moment:

$$E[U^n] = n! \cdot \frac{1}{(n+1)!} = \frac{1}{n+1}$$

So $E[U] = \frac{1}{2}$ and $E[U^2] = \frac{1}{3}$, which gives $\operatorname{Var}(U) = \frac{1}{3} - \frac{1}{4} = \frac{1}{12}$, the known value.

</details>

**C4. (Medium)** *Uses [15.3 MGF of Sums](15.3-MGF-of-Sums.md) and [9.2 Normal](../09-CONTINUOUS-DISTRIBUTIONS/9.2-Normal-Gaussian.md).*
Two independent sensors read $X \sim \mathcal{N}(10, 4)$ and $Y \sim \mathcal{N}(12, 9)$ (second parameter is the variance). Use MGFs to find the distribution of $X - Y$, and $P(X \gt Y)$.

<details>
<summary>Answer</summary>

$$M_{X-Y}(t) = M_X(t) M_Y(-t) = e^{10t + 2t^2} \cdot e^{-12t + 4.5t^2} = e^{-2t + 6.5t^2}$$

Compare with $e^{\mu t + \sigma^2 t^2 / 2}$: $\mu = -2$ and $\frac{\sigma^2}{2} = 6.5$, so $\sigma^2 = 13$. Hence $X - Y \sim \mathcal{N}(-2, 13)$. Standardize:

$$P(X \gt Y) = P(X - Y \gt 0) = P\left( Z \gt \frac{2}{\sqrt{13}} \right) = P(Z \gt 0.5547) \approx 0.2895$$

</details>

**C5. (Medium)** *Uses [15.5 Probability Generating Function](15.5-Probability-Generating-Function.md).*
A user opens $N \sim \text{Bin}(10, 0.5)$ emails per day. Each opened email is spam with probability $0.2$, independently. Find the PGF and the distribution of the number $S$ of spam emails opened, and $P(S = 0)$.

<details>
<summary>Answer</summary>

Here $G_N(u) = (0.5 + 0.5u)^{10}$ and $G_X(s) = 0.8 + 0.2s$. By the random-sum rule:

$$G_S(s) = G_N\big( G_X(s) \big) = \big( 0.5 + 0.5(0.8 + 0.2s) \big)^{10} = (0.9 + 0.1s)^{10}$$

This is the PGF of $\text{Bin}(10, 0.1)$, so $S \sim \text{Bin}(10, 0.1)$ (binomial thinning), and

$$P(S = 0) = G_S(0) = 0.9^{10} \approx 0.3487$$

The mean is $10 \times 0.1 = 1 = E[N] \times 0.2 = 5 \times 0.2$, as in [14.7](../14-CONDITIONAL-EXPECTATION/14.7-Random-Sums.md).

</details>

**C6. (Medium)** *Uses [15.7 Cumulants](15.7-Cumulants.md).*
An insurer's yearly claims are $S = X_1 + \cdots + X_{25}$, with $X_i$ independent claims, each with mean 100, standard deviation 60 and skewness 1.5 (all in thousand taka). Find the mean, variance and skewness of $S$.

<details>
<summary>Answer</summary>

For one claim: $\kappa_1 = 100$, $\kappa_2 = 60^2 = 3600$ and $\kappa_3 = 1.5 \times 60^3 = 324000$. Cumulants add, so for 25 claims:

$$\kappa_1(S) = 2500, \qquad \kappa_2(S) = 90000, \qquad \kappa_3(S) = 8100000$$

The mean is $2500$ and the standard deviation is $\sqrt{90000} = 300$. The skewness is

$$\frac{\kappa_3(S)}{\kappa_2(S)^{3/2}} = \frac{8100000}{27000000} = 0.3 = \frac{1.5}{\sqrt{25}}$$

Adding 25 claims cuts the skewness by a factor of $\sqrt{25} = 5$.

</details>

## Challenge

**H1. (Hard)** *Uses [15.3](15.3-MGF-of-Sums.md), [15.5](15.5-Probability-Generating-Function.md) and [14.7 Random Sums](../14-CONDITIONAL-EXPECTATION/14.7-Random-Sums.md).*
Let $N \sim \text{Geom}(p)$ (trials until the first success, $q = 1 - p$) and $X_1, X_2, \dots \overset{\text{iid}}{\sim} \text{Exp}(\lambda)$, independent of $N$. Prove that $S = X_1 + \cdots + X_N$ is $\text{Exp}(p\lambda)$. (Module 14 promised this proof.)

<details>
<summary>Answer</summary>

Given $N = n$ the sum has $n$ independent terms, so $E[e^{tS} \mid N = n] = m^n$ where $m = M_X(t) = \frac{\lambda}{\lambda - t}$. Average over $N$, using $P(N = n) = q^{n-1}p$:

$$M_S(t) = \sum_{n=1}^{\infty} q^{n-1} p \thinspace m^n = \frac{pm}{1 - qm} \qquad \text{(valid when } qm \lt 1 \text{)}$$

Now put $m = \frac{\lambda}{\lambda - t}$ and multiply the top and bottom by $\lambda - t$:

$$M_S(t) = \frac{p\lambda}{(\lambda - t) - q\lambda} = \frac{p\lambda}{p\lambda - t}$$

because $\lambda - q\lambda = p\lambda$. The condition $qm \lt 1$ is the same as $t \lt p\lambda$. This is the MGF of $\text{Exp}(p\lambda)$ on $t \lt p\lambda$, so by uniqueness $S \sim \text{Exp}(p\lambda)$. The mean $\frac{1}{p\lambda}$ matches $E[N] \cdot \frac{1}{\lambda}$ from 14.7.

</details>

**H2. (Hard)** *Uses [15.5 Probability Generating Function](15.5-Probability-Generating-Function.md) and [3.9 Continuity of Probability](../03-AXIOMS-OF-PROBABILITY/3.9-Continuity-of-Probability.md).*
Each individual in a population has a number of children with PGF $G$. Starting from one individual, let $q$ be the probability that the family line dies out. **(a)** Prove that $q$ is the smallest root of $s = G(s)$ in $[0, 1]$. **(b)** Find $q$ when each individual has $\text{Bin}(2, 0.6)$ children.

<details>
<summary>Answer</summary>

**(a)** Let $q_n$ be the probability that the line is extinct by generation $n$, with $q_0 = 0$. Condition on the number $k$ of children (probability $p_k$). The line is extinct by generation $n + 1$ exactly when the lines of all $k$ children are extinct by generation $n$; these are independent copies, so

$$q_{n+1} = \sum_k p_k q_n^k = G(q_n)$$

The events of being extinct by generation $n$ grow with $n$ and their union is the event of dying out eventually, so $q_n$ rises to $q$ by continuity of probability, and since $G$ is continuous, $q = G(q)$. Now let $r$ be any root of $s = G(s)$ in $[0, 1]$. $G$ is increasing on $[0, 1]$ (its coefficients are not negative). From $q_0 = 0 \le r$ we get $q_1 = G(q_0) \le G(r) = r$, and by repeating, $q_n \le r$ for all $n$. So $q \le r$: $q$ is the smallest root.

**(b)** $G(s) = (0.4 + 0.6s)^2 = 0.16 + 0.48s + 0.36s^2$. Solve $s = G(s)$, that is $0.36s^2 - 0.52s + 0.16 = 0$. Multiply by 25: $9s^2 - 13s + 4 = 0$, with roots

$$s = \frac{13 \pm \sqrt{169 - 144}}{18} = \frac{13 \pm 5}{18} \in \left\lbrace \tfrac{4}{9}, 1 \right\rbrace$$

The smallest root is $q = \frac{4}{9} \approx 0.4444$. (The mean number of children is $1.2 \gt 1$, so survival is possible.)

</details>

**H3. (Hard)** *Uses [15.1](15.1-Moment-Generating-Function.md), [15.3](15.3-MGF-of-Sums.md) and [15.4 Uniqueness Theorem](15.4-Uniqueness-Theorem.md).*
Let $X_n \sim \text{Pois}(n)$ (mean $n$) and $Z_n = \frac{X_n - n}{\sqrt{n}}$. Prove that $Z_n \xrightarrow{d} \mathcal{N}(0, 1)$ as $n \to \infty$.

<details>
<summary>Answer</summary>

Shift and scale (15.1) give $M_{Z_n}(t) = e^{-t\sqrt{n}} M_{X_n}\left( \frac{t}{\sqrt{n}} \right)$, so

$$M_{Z_n}(t) = \exp\left( -t\sqrt{n} + n\left( e^{t/\sqrt{n}} - 1 \right) \right)$$

Put $s = \frac{t}{\sqrt{n}}$ and expand $e^s = 1 + s + \frac{s^2}{2} + r(s)$, where $\lvert r(s) \rvert \le \lvert s \rvert^3$ for $\lvert s \rvert \le 1$. Then $n(e^s - 1) = ns + \frac{ns^2}{2} + nr(s) = t\sqrt{n} + \frac{t^2}{2} + nr(s)$, and the exponent becomes

$$-t\sqrt{n} + t\sqrt{n} + \frac{t^2}{2} + nr(s) = \frac{t^2}{2} + nr(s)$$

The remainder satisfies $n\lvert r(s) \rvert \le n \frac{\lvert t \rvert^3}{n^{3/2}} = \frac{\lvert t \rvert^3}{\sqrt{n}} \to 0$. So $M_{Z_n}(t) \to e^{t^2/2}$ for every $t$, which is the MGF of $\mathcal{N}(0, 1)$. By the continuity theorem (15.4), $Z_n \xrightarrow{d} \mathcal{N}(0, 1)$. This is the CLT for Poisson counts, and it is also the normal approximation to the Poisson with a large mean.

</details>

## Simulation Projects

**S1. (Project)** *Uses [15.3](15.3-MGF-of-Sums.md) and [15.4 Uniqueness Theorem](15.4-Uniqueness-Theorem.md).*
Watch the CLT happen in the MGF. Let $U_i \sim \text{Unif}(0, 1)$ and $Z_n = \sqrt{12} \cdot \frac{U_1 + \cdots + U_n - n/2}{\sqrt{n}}$ (a standardized sum). Each term $\sqrt{12}(U_i - \frac{1}{2})$ is uniform on $(-\sqrt{3}, \sqrt{3})$, with MGF $\frac{\operatorname{sinh}(\sqrt{3}s)}{\sqrt{3}s}$. So $M_{Z_n}(t) = \left( \frac{\operatorname{sinh}(\sqrt{3}t/\sqrt{n})}{\sqrt{3}t/\sqrt{n}} \right)^n$. For $t = 1$ and $n = 1, 2, 5, 30$, compare the simulated average of $e^{tZ_n}$ with this formula and with the limit $e^{1/2}$.

<details>
<summary>Answer</summary>

```python
import numpy as np

rng = np.random.default_rng(42)
n_trials = 400_000
t = 1.0

# Standardized sum of n Unif(0,1). Each term is uniform on (-sqrt(3), sqrt(3)),
# with MGF sinh(sqrt(3) s) / (sqrt(3) s). So M_Zn(t) is that function at s = t / sqrt(n), to the power n.
for n in [1, 2, 5, 30]:
    u = rng.random((n_trials, n))
    z = np.sqrt(12) * (u - 0.5).sum(axis=1) / np.sqrt(n)
    s = np.sqrt(3) * t / np.sqrt(n)
    exact = (np.sinh(s) / s) ** n
    print(f"n = {n:>2}: simulation {np.mean(np.exp(t * z)):.4f}, exact {exact:.4f}")
print(f"limit exp(t^2/2) = {np.exp(t**2 / 2):.4f}")
```

Output:

```text
n =  1: simulation 1.5795, exact 1.5806
n =  2: simulation 1.6122, exact 1.6115
n =  5: simulation 1.6312, exact 1.6329
n = 30: simulation 1.6458, exact 1.6460
limit exp(t^2/2) = 1.6487
```

Already at $n = 5$ the MGF is within 1% of the normal limit $1.6487$; for $n = 30$ it is within 0.2%. Compare with the exponential case in [15.4](15.4-Uniqueness-Theorem.md), where the skewness makes the convergence slower ([15.7](15.7-Cumulants.md)): a symmetric starting distribution converges faster.

</details>

**S2. (Project)** *Uses [15.5 Probability Generating Function](15.5-Probability-Generating-Function.md).*
Simulate the branching process of H2, where each individual has $\text{Bin}(2, 0.6)$ children. A generation of $z$ individuals has $\text{Bin}(2z, 0.6)$ children in total. Start 200,000 families from one individual, run 80 generations, and compare the fraction that died out with $q = \frac{4}{9}$.

<details>
<summary>Answer</summary>

```python
import numpy as np

rng = np.random.default_rng(42)
n_families = 200_000

# Offspring: Bin(2, 0.6) children each. A generation of z individuals has Bin(2z, 0.6) children.
size = np.ones(n_families, dtype=np.int64)
for generation in range(80):
    size = rng.binomial(2 * np.minimum(size, 1000), 0.6)
print(f"smallest root of q = (0.4 + 0.6 q)^2: {4 / 9:.4f}")
print(f"simulated extinction probability:     {np.mean(size == 0):.4f}")
```

Output:

```text
smallest root of q = (0.4 + 0.6 q)^2: 0.4444
simulated extinction probability:     0.4442
```

The simulation agrees with the smallest root. The families that did not die out grow without bound (about $1.2$ times larger each generation on average), which is why a size cap of 1,000 is harmless.

</details>
