# 19.4 Inverse Transform Sampling

[Probability](../README.md) / [Module 19: Simulation and Monte Carlo](README.md) / 19.4 Inverse Transform Sampling

**Level:** 5 (Hero) · **Time:** about 45 minutes · **Before this:** [19.3 Monte Carlo Estimation](19.3-Monte-Carlo-Estimation.md)

> **Big idea:** To sample from any distribution with CDF $F$, draw $U \sim \text{Unif}(0, 1)$ and return the value $Q(U)$, where $Q$ is the quantile function (the inverse of $F$); this works for continuous and discrete distributions alike.

---

## Why It Matters

Computers give us uniform numbers ([19.2](19.2-Pseudo-Random-Numbers-and-Seeds.md)). Real problems need exponential waiting times, loaded dice, heavy-tailed prices and many other laws. Inverse transform sampling is the first and simplest bridge from one to the other. It is also exact: there is no approximation and no wasted draw. Its limits (the inverse must be easy to compute) lead directly to rejection sampling ([19.5](19.5-Rejection-Sampling.md)) and MCMC ([19.7](19.7-MCMC/README.md)). The idea was introduced with the quantile function in [8.7](../08-CONTINUOUS-RANDOM-VARIABLES/8.7-Quantile-Function.md); here we use it as a tool, extend it to discrete laws, and prove it in full generality.

## Intuition

Look at the graph of a CDF. The vertical axis is a probability from 0 to 1. Pick a random height $U$ on this axis, with every height equally likely. Walk right until you hit the curve, then go down to the horizontal axis. The value where you land is your sample.

Why does this give the right distribution? Where the CDF is steep, many heights lead to a small range of $x$ values, so those $x$ values are chosen often. That is exactly where the density is high. Where the CDF is flat, few heights land there, so those $x$ values are rare.

For a discrete variable, the CDF is a staircase. A random height falls on one of the steps, and the step tells you the value. A step that is tall (a large probability) is hit more often. This is the lookup in a table of cumulative sums that you would do by hand for a loaded die.

## Picture

```text
  F(x)
  1.0 |                          ______________
      |                    _.---'
  U ->|- - - - - - - - -.'   <- random height U
      |              .-'  :
      |           .-'     :
      |        .-'        :   steep part of F: many U land here,
      |     _.'           :   so this range of x is chosen often
      |__.-'              :
  0.0 +-------------------+------------------- x
                        X = Q(U)
```

Draw a random height $U$, go across to the CDF, then down to read the sample $X = Q(U)$.

## Definition

Let $F$ be a CDF. Its **quantile function** (or generalized inverse) is

$$
Q(u) = \min \lbrace x : F(x) \ge u \rbrace, \qquad 0 \lt u \lt 1
$$

**In words:** $Q(u)$ is the smallest value $x$ at which the CDF has reached the height $u$. When $F$ is continuous and strictly increasing this is just $F^{-1}(u)$.

**Inverse transform sampling.** If $U \sim \text{Unif}(0, 1)$, then $X = Q(U)$ has CDF $F$.

**In words:** feed uniform random numbers into the quantile function, and what comes out follows the target distribution.

The recipe has three steps:

1. Write the CDF $F(x)$.
2. Solve $F(x) = u$ for $x$ to get $Q(u)$. (For a discrete law, make a table of cumulative sums.)
3. Draw $U$ and return $Q(U)$.

## Why It Is True

[8.7](../08-CONTINUOUS-RANDOM-VARIABLES/8.7-Quantile-Function.md) proved the claim when $F$ is strictly increasing. Here is the proof for every CDF, including staircases. The key fact is the equivalence

$$
Q(u) \le x \iff u \le F(x)
$$

**Proof of the key fact.** Suppose $u \le F(x)$. Then $x$ belongs to the set $\lbrace y : F(y) \ge u \rbrace$, so the smallest element of that set is at most $x$: $Q(u) \le x$. Now suppose $Q(u) \le x$. A CDF is right-continuous, so the minimum is attained and $F(Q(u)) \ge u$. A CDF is also non-decreasing, so $F(x) \ge F(Q(u)) \ge u$. This proves the key fact.

Now the theorem. For $U \sim \text{Unif}(0, 1)$:

$$
\begin{aligned}
P(Q(U) \le x) &= P(U \le F(x)) && \text{(key fact)} \\
&= F(x) && \text{(}P(U \le t) = t \text{ for } 0 \le t \le 1 \text{)}
\end{aligned}
$$

So $Q(U)$ has CDF $F$.

**The reverse direction (probability integral transform).** If $X$ is continuous with CDF $F$, then $F(X) \sim \text{Unif}(0, 1)$. Here is why. Fix $0 \lt u \lt 1$. A continuous CDF reaches every height, so there is a largest $x_u$ with $F(x_u) = u$. Then $F(X) \le u$ exactly when $X \le x_u$ (if $X \gt x_u$, then $F(X) \ge u$, and $F(X) = u$ is impossible because $x_u$ is the largest such point). So $P(F(X) \le u) = F(x_u) = u$. This is the basis of checking a fitted distribution: transform the data by the fitted CDF and see whether the result looks uniform.

**Discrete case.** Let $X$ take values $x_1 \lt x_2 \lt \dots$ with probabilities $p_1, p_2, \dots$ and cumulative sums $c_k = p_1 + \dots + p_k$ (with $c_0 = 0$). Then $Q(u) = x_k$ exactly when $c_{k-1} \lt u \le c_k$. The probability of this event for a uniform $U$ is the length of the interval, $c_k - c_{k-1} = p_k$. So the value $x_k$ is returned with probability $p_k$.

## Worked Examples

### Example 1: The Exponential Distribution

**Problem.** Let $X \sim \text{Exp}(\lambda)$ with rate $\lambda = 2$ (mean $\frac{1}{2}$). Find the sampler. Use it with $U = 0.3$.

**Solution.**

1. The CDF is $F(x) = 1 - e^{-\lambda x}$ for $x \ge 0$ ([9.3](../09-CONTINUOUS-DISTRIBUTIONS/9.3-Exponential.md)).
2. Solve $1 - e^{-\lambda x} = u$:

$$
e^{-\lambda x} = 1 - u \quad \Rightarrow \quad x = Q(u) = -\frac{\ln(1 - u)}{\lambda}
$$

3. For $U = 0.3$ and $\lambda = 2$: $X = -\frac{\ln 0.7}{2} = \frac{0.3567}{2} = 0.1783$.
4. Since $1 - U$ is also uniform, many programs use $X = -\frac{\ln U}{\lambda}$ instead. It has the same distribution (Practice 4).

**Answer.** $X = -\frac{\ln(1 - U)}{\lambda}$, and $U = 0.3$ gives $X \approx 0.178$.

**Check.** The value $0.178$ is below the mean $0.5$, which fits $U = 0.3$ below $0.5$: the median of the law is $\frac{\ln 2}{2} = 0.3466$, and $F(0.1783) = 1 - e^{-0.3567} = 0.3$. The first code block checks the mean, the variance and three CDF values.

### Example 2: A Loaded Die and a Geometric Count

**Problem.** (a) A loaded die shows faces 1 to 6 with probabilities $0.1, 0.2, 0.3, 0.1, 0.2, 0.1$. Which face does $U = 0.65$ give? (b) For $X \sim \text{Geom}(p)$ with $p = 0.2$ (trials until the first success, [7.3](../07-DISCRETE-DISTRIBUTIONS/7.3-Geometric.md)), find a formula for the sampler and use it with $U = 0.7$.

**Solution.**

(a)

1. Cumulative sums: $c_1 = 0.1$, $c_2 = 0.3$, $c_3 = 0.6$, $c_4 = 0.7$, $c_5 = 0.9$, $c_6 = 1.0$.
2. Find the first $k$ with $U \le c_k$. Here $0.6 \lt 0.65 \le 0.7$, so $k = 4$.

(b)

3. The CDF is $F(k) = P(X \le k) = 1 - (1 - p)^k$ for $k = 1, 2, \dots$.
4. $Q(u)$ is the smallest integer $k$ with $1 - (1-p)^k \ge u$, that is, $(1-p)^k \le 1 - u$. Take logarithms. Since $\ln(1 - p) \lt 0$, the inequality flips:

$$
k \ge \frac{\ln(1 - u)}{\ln(1 - p)} \quad \Rightarrow \quad Q(u) = \left\lceil \frac{\ln(1 - u)}{\ln(1 - p)} \right\rceil
$$

5. For $p = 0.2$ and $U = 0.7$: $\frac{\ln 0.3}{\ln 0.8} = \frac{-1.2040}{-0.2231} = 5.396$. The ceiling is $6$.

**Answer.** (a) Face 4. (b) $X = \lceil \frac{\ln(1 - U)}{\ln(1 - p)} \rceil$, and $U = 0.7$ gives $X = 6$.

**Check.** For (b): $F(5) = 1 - 0.8^5 = 0.6723 \lt 0.7$ and $F(6) = 1 - 0.8^6 = 0.7379 \ge 0.7$, so 6 is the first count at which the CDF reaches $0.7$. For (a), the face 4 has the interval $(0.6, 0.7]$ of length $0.1$, which is its probability.

### Example 3: When There Is No Formula

**Problem.** The standard normal CDF $\Phi$ has no closed-form inverse. Can we still use inverse transform sampling?

**Solution.**

1. The theory still holds: $X = \Phi^{-1}(U)$ is exactly $\mathcal{N}(0, 1)$.
2. We compute $\Phi^{-1}$ numerically. Libraries do this with fast, accurate approximations: `scipy.stats.norm.ppf`.
3. The cheaper alternative used by most code is the Box-Muller transform ([13.8](../13-FUNCTIONS-OF-RANDOM-VARIABLES/13.8-Box-Muller-Transform.md)), which makes two normals from two uniforms using only $\ln$, $\sin$ and $\cos$.

**Answer.** Yes. A numerical inverse is as good as a formula, only slower.

**Check.** The third code block below samples with `norm.ppf` and finds $P(Z \le 1.96) = 0.9752$, against the exact $0.9750$. When no inverse is available even numerically, we need other methods: rejection sampling ([19.5](19.5-Rejection-Sampling.md)) and MCMC ([19.7](19.7-MCMC/README.md)).

## Simulate It

First the exponential sampler of Example 1 with $\lambda = 2$:

```python
import numpy as np

rng = np.random.default_rng(42)
n_samples = 200_000
rate = 2.0                                   # Exp(rate): mean 1/rate = 0.5

# Inverse transform: Q(u) = -ln(1 - u) / rate, applied to uniform numbers.
u = rng.random(n_samples)
x = -np.log(1 - u) / rate

print(f"mean      {x.mean():.4f}  (exact {1 / rate:.4f}, SE {x.std(ddof=1) / np.sqrt(n_samples):.4f})")
print(f"variance  {x.var(ddof=1):.4f}  (exact {1 / rate**2:.4f})")
for t in [0.25, 0.5, 1.0]:
    print(f"P(X <= {t:<4}) = {np.mean(x <= t):.4f}  (exact {1 - np.exp(-rate * t):.4f})")
```

Output:

```text
mean      0.5002  (exact 0.5000, SE 0.0011)
variance  0.2506  (exact 0.2500)
P(X <= 0.25) = 0.3928  (exact 0.3935)
P(X <= 0.5 ) = 0.6327  (exact 0.6321)
P(X <= 1.0 ) = 0.8645  (exact 0.8647)
```

Now the discrete cases of Example 2. For the die, `np.searchsorted(cum, u)` finds the first index where the cumulative sum reaches $u$.

```python
import numpy as np

rng = np.random.default_rng(42)
n_samples = 200_000
probs = np.array([0.1, 0.2, 0.3, 0.1, 0.2, 0.1])     # a loaded die, faces 1..6
cum = np.cumsum(probs)                                # F at each face: 0.1, 0.3, 0.6, ...

u = rng.random(n_samples)
faces = np.searchsorted(cum, u) + 1                   # smallest face with F >= u

freq = np.bincount(faces, minlength=7)[1:] / n_samples
for face, (f, p) in enumerate(zip(freq, probs), start=1):
    print(f"face {face}: simulation {f:.4f}  exact {p:.4f}")

# Geometric(p): number of trials to the first success.
p = 0.2
k = np.ceil(np.log(1 - rng.random(n_samples)) / np.log(1 - p))
print(f"Geom(0.2): mean {k.mean():.4f} (exact {1 / p:.4f}),  P(X=1) {np.mean(k == 1):.4f} (exact {p:.4f})")
```

Output:

```text
face 1: simulation 0.0992  exact 0.1000
face 2: simulation 0.2014  exact 0.2000
face 3: simulation 0.2996  exact 0.3000
face 4: simulation 0.1000  exact 0.1000
face 5: simulation 0.1993  exact 0.2000
face 6: simulation 0.1006  exact 0.1000
Geom(0.2): mean 4.9908 (exact 5.0000),  P(X=1) 0.2004 (exact 0.2000)
```

Every frequency is within about 0.001 of the exact value; for a probability of $0.2$ with $n = 200{,}000$ the standard error is $0.0009$. Last, the normal case of Example 3, and the probability integral transform in the other direction:

```python
import numpy as np
from scipy.stats import norm

rng = np.random.default_rng(42)
n_samples = 200_000

# Probability integral transform: if X ~ N(0, 1), then F(X) ~ Unif(0, 1).
x = rng.standard_normal(n_samples)
v = norm.cdf(x)
print(f"F(X): mean {v.mean():.4f} (exact 0.5000), var {v.var():.4f} (exact {1 / 12:.4f})")
print(f"P(F(X) <= 0.1) = {np.mean(v <= 0.1):.4f}, P(F(X) <= 0.9) = {np.mean(v <= 0.9):.4f}")

# The other direction: the numerical quantile function turns uniforms into normals.
z = norm.ppf(rng.random(n_samples))
print(f"norm.ppf(U): mean {z.mean():.4f}, sd {z.std():.4f}, "
      f"P(Z <= 1.96) = {np.mean(z <= 1.96):.4f} (exact {norm.cdf(1.96):.4f})")
```

Output:

```text
F(X): mean 0.4995 (exact 0.5000), var 0.0835 (exact 0.0833)
P(F(X) <= 0.1) = 0.1006, P(F(X) <= 0.9) = 0.8994
norm.ppf(U): mean -0.0018, sd 0.9977, P(Z <= 1.96) = 0.9752 (exact 0.9750)
```

## Common Mistakes

- **Using the CDF instead of its inverse.** The sampler is $Q(U)$, not $F(U)$. Applying $F$ to a uniform number gives a number between 0 and 1 that is not distributed like $X$.
- **Forgetting the ceiling in the discrete case.** For the geometric law, $\frac{\ln(1-U)}{\ln(1-p)}$ is a real number. Without the ceiling it is not a whole number of trials.
- **Using a wrong direction of the inequality in the discrete lookup.** Take the first $k$ with $U \le c_k$. The boundary case has probability zero, so it rarely matters, but off-by-one errors in the face numbers (starting at 0 or at 1) are common. Check the table by hand once.
- **Using one uniform number for two different variables.** Each sample needs its own fresh $U$. Re-using $U$ makes the two variables perfectly dependent.
- **Applying it to a joint distribution one coordinate at a time.** For two dependent variables, first sample $X$ from its marginal, then $Y$ from the conditional given $X$. Sampling both from their marginals makes them independent.

## Where It Is Used

- **AI and machine learning:** sampling from a categorical distribution (the next word of a language model) is exactly the loaded-die lookup with the cumulative sum of the model's probabilities. Reparameterization tricks write a sample as a function of a uniform or normal noise.
- **Computer science:** event simulations draw exponential gaps with $-\frac{\ln U}{\lambda}$ ([18.5](../18-STOCHASTIC-PROCESSES/18.5-Poisson-Process.md)). Random testing and games draw from custom laws the same way.
- **Statistics:** the probability integral transform checks whether data follow a fitted model (a PIT histogram) and is the basis of copulas.
- **Finance and engineering:** sampling a failure time from a Weibull lifetime ([9.11](../09-CONTINUOUS-DISTRIBUTIONS/9.11-Weibull.md)) or a loss from a heavy-tailed Pareto law.
- **Everyday life:** a lottery draw from a table of prizes with unequal probabilities uses the cumulative-sum lookup.

**1. (Easy)** For $X \sim \text{Exp}(1)$ (rate 1), what sample does $U = 0.5$ give?

<details>
<summary>Answer</summary>

$$X = -\ln(1 - 0.5) = \ln 2 \approx 0.6931$$

This is the median of the law, as expected for $U = 0.5$.

</details>

**2. (Easy)** For the loaded die of Example 2, which faces do $U = 0.05$, $U = 0.30$ and $U = 0.95$ give?

<details>
<summary>Answer</summary>

The cumulative sums are $0.1, 0.3, 0.6, 0.7, 0.9, 1.0$. We take the first $k$ with $U \le c_k$. $U = 0.05 \le 0.1$ gives face 1. $U = 0.30 \le 0.3$ gives face 2 (the boundary belongs to the lower face). $U = 0.95$: it is above $0.9$ and at most $1.0$, so face 6.

</details>

**3. (Medium)** A Pareto variable with minimum value $1$ and shape $3$ has CDF $F(x) = 1 - x^{-3}$ for $x \ge 1$. Find its sampler. What does $U = 0.875$ give?

<details>
<summary>Answer</summary>

Solve $1 - x^{-3} = u$: $x^{-3} = 1 - u$, so $x = (1 - u)^{-1/3}$. For $U = 0.875$:

$$X = (1 - 0.875)^{-1/3} = 0.125^{-1/3} = 8^{1/3} = 2$$

</details>

**4. (Medium)** Show that if $X = -\frac{\ln(1 - U)}{\lambda}$ then $X' = -\frac{\ln U}{\lambda}$ also has the $\text{Exp}(\lambda)$ distribution.

<details>
<summary>Answer</summary>

Let $V = 1 - U$. For $0 \le t \le 1$, $P(V \le t) = P(U \ge 1 - t) = 1 - (1 - t) = t$, so $V \sim \text{Unif}(0, 1)$. Then $X' = -\frac{\ln U}{\lambda}$ has the same distribution as $-\frac{\ln V}{\lambda} = X$, because $U$ and $V$ have the same distribution. Both are $\text{Exp}(\lambda)$.

</details>

**5. (Hard)** Prove that if $X$ is continuous with CDF $F$, then $F(X) \sim \text{Unif}(0, 1)$. Then explain why the claim fails for a discrete $X$.

<details>
<summary>Answer</summary>

Fix $0 \lt u \lt 1$. Because $F$ is continuous, it reaches the height $u$, and there is a largest point $x_u$ with $F(x_u) = u$. If $X \le x_u$, then $F(X) \le F(x_u) = u$ because $F$ is non-decreasing. If $X \gt x_u$, then $F(X) \ge u$, and $F(X) = u$ is impossible because $x_u$ is the largest point with this value, so $F(X) \gt u$. Therefore $\lbrace F(X) \le u \rbrace = \lbrace X \le x_u \rbrace$, and

$$P(F(X) \le u) = P(X \le x_u) = F(x_u) = u$$

so $F(X)$ has the uniform CDF. For a discrete $X$ the CDF jumps, so $F(X)$ only takes the finitely many values $c_1, c_2, \dots$ (the cumulative sums). A variable that takes only a few values is not uniform on $[0, 1]$.

</details>

**6. (Simulate)** The standard Cauchy distribution has CDF $F(x) = \frac{1}{2} + \frac{\operatorname{arctan} x}{\pi}$. Find the sampler and check that $P(\lvert C \rvert \lt 1) = \frac{1}{2}$.

<details>
<summary>Answer</summary>

Solve $\frac{1}{2} + \frac{\operatorname{arctan} x}{\pi} = u$: $x = \tan\big( \pi (u - \frac{1}{2}) \big)$. The exact value is $P(\lvert C \rvert \lt 1) = F(1) - F(-1) = \frac{2 \operatorname{arctan} 1}{\pi} = \frac{1}{2}$.

```python
import numpy as np

rng = np.random.default_rng(42)
n_samples = 200_000
u = rng.random(n_samples)
c = np.tan(np.pi * (u - 0.5))                      # Q(u) for the standard Cauchy
print(f"median {np.median(c):.4f} (exact 0)")
print(f"P(|C| < 1) = {np.mean(np.abs(c) < 1):.4f} (exact 0.5000)")
```

Output:

```text
median 0.0004 (exact 0)
P(|C| < 1) = 0.4995 (exact 0.5000)
```

The Cauchy mean does not exist ([9.9](../09-CONTINUOUS-DISTRIBUTIONS/9.9-Cauchy.md)), so we check the median and a probability instead.

</details>

## Summary

- Inverse transform sampling turns a uniform number $U$ into $X = Q(U)$, where $Q(u) = \min \lbrace x : F(x) \ge u \rbrace$.
- It works because $Q(u) \le x \iff u \le F(x)$, so $P(Q(U) \le x) = F(x)$.
- For continuous laws, solve $F(x) = u$. For discrete laws, look up $U$ in the table of cumulative sums.
- If the inverse has no formula, use a numerical inverse, or another method (Box-Muller, rejection, MCMC).
- Each sample needs its own fresh uniform number.

The one formula to remember:

$$
\boxed{X = F^{-1}(U) \sim F, \qquad \text{for example } X = -\frac{\ln(1 - U)}{\lambda} \sim \text{Exp}(\lambda)}
$$
