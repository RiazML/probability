# 19.7.2 Gibbs Sampling

[Probability](../../README.md) / [Module 19: Simulation and Monte Carlo](../README.md) / [19.7 MCMC](README.md) / 19.7.2 Gibbs Sampling

**Level:** 5 (Hero) · **Time:** about 55 minutes · **Before this:** [19.7.1 Metropolis-Hastings](19.7.1-Metropolis-Hastings.md)

> **Big idea:** To sample a vector with several coordinates, update one coordinate at a time by drawing it from its exact conditional distribution given all the others; every such move is accepted, and the chain has the joint distribution as its stationary law.

---

## Why It Matters

Many models have many unknowns: the mean and the variance of a data set, the topic of every word in a document, the hidden state at every time step. The joint law of all unknowns is hard to sample, but each unknown given the others is often a simple, named distribution. **Gibbs sampling** uses this. It needs no proposal and no step size, and it never rejects. It powers many Bayesian tools (BUGS, JAGS), topic models and image models. It is a special case of Metropolis-Hastings ([19.7.1](19.7.1-Metropolis-Hastings.md)), and it also shows clearly how correlation between coordinates slows MCMC down.

## Intuition

Imagine you are tuning two dials, $x$ and $y$, and you want to explore all the settings that make a machine work well, in proportion to how well they work. You cannot see the whole picture, but you can do the following. Freeze $y$, and find the best-matching random value of $x$ for that $y$. Then freeze the new $x$, and pick a random $y$ that fits it. Repeat. Each move changes only one dial, and each move is a fair draw given the other dial.

If the dials are independent, one sweep gives a completely fresh sample. If the dials are strongly tied together (say the good settings lie along a thin diagonal strip), each move can only go a small distance along the strip, because one dial can move only within the thin width allowed by the other. Then the walker moves along the diagonal in small steps, and the samples are highly correlated.

## Picture

```text
  y
  |
  |
  |
  |                            P4 -------->P5
  |                             ^
  |                             |
  |                P2 -------->P3
  |                 ^
  |                 |
  |      P0 ------>P1
  |
  +-------------------------------------------------------- x
```

A Gibbs path moves along the axes: P0 to P1 changes only $x$ (a draw from $p(x \mid y)$), P1 to P2 changes only $y$ (a draw from $p(y \mid x)$), and so on.

## Definition

Let the target be the joint law of $X = (X_1, \dots, X_d)$ with density or PMF $p(x_1, \dots, x_d)$. Write $x_{-j}$ for all coordinates except the $j$-th. The **full conditional** of coordinate $j$ is

$$
p(x_j \mid x_{-j}) = \frac{p(x_1, \dots, x_d)}{p(x_{-j})}
$$

**Gibbs sampling** starts at some $x^{(0)}$ and, in each **sweep**, updates the coordinates in turn:

1. Draw $x_1^{(t+1)} \sim p(x_1 \mid x_2^{(t)}, \dots, x_d^{(t)})$.
2. Draw $x_2^{(t+1)} \sim p(x_2 \mid x_1^{(t+1)}, x_3^{(t)}, \dots, x_d^{(t)})$.
3. Continue to $x_d^{(t+1)} \sim p(x_d \mid x_1^{(t+1)}, \dots, x_{d-1}^{(t+1)})$.

Always use the newest value of every other coordinate.

**In words:** resample each coordinate from its conditional distribution given the current values of all the others, one after the other, and repeat.

We need to be able to sample each full conditional (by [19.4](../19.4-Inverse-Transform-Sampling.md), [19.5](../19.5-Rejection-Sampling.md) or a named distribution). We do not need to know the normalizing constant of $p$: the conditional is proportional to the joint, viewed as a function of $x_j$ only.

## Why It Is True

**Each update has acceptance probability 1.** Consider the update of coordinate $j$. It is a Metropolis-Hastings step ([19.7.1](19.7.1-Metropolis-Hastings.md)) with the proposal $q(x' \mid x) = p(x'_j \mid x_{-j})$ (the other coordinates are unchanged: $x'_{-j} = x_{-j}$). The Hastings ratio is

$$
\frac{p(x') \thinspace q(x \mid x')}{p(x) \thinspace q(x' \mid x)} = \frac{p(x'_j \mid x_{-j}) \thinspace p(x_{-j}) \cdot p(x_j \mid x_{-j})}{p(x_j \mid x_{-j}) \thinspace p(x_{-j}) \cdot p(x'_j \mid x_{-j})} = 1
$$

using $p(x) = p(x_j \mid x_{-j}) p(x_{-j})$ and the same for $x'$. Everything cancels, so the acceptance probability is $\min(1, 1) = 1$.

**Each update keeps $p$ stationary.** Suppose $X \sim p$. Replace $X_j$ by a fresh draw $X'_j \sim p(\cdot \mid X_{-j})$. Then the pair $(X'_j, X_{-j})$ has probability

$$
p(x_{-j}) \thinspace p(x'_j \mid x_{-j}) = p(x'_j, x_{-j})
$$

which is again the joint law $p$. So one coordinate update leaves $p$ unchanged. A sweep is a composition of such updates, and a composition of maps that each keep $p$ stationary keeps $p$ stationary.

**Convergence.** If the conditional laws let the chain reach every region (for example $p \gt 0$ on a product set), the chain is irreducible and aperiodic ([18.3.4](../../18-STOCHASTIC-PROCESSES/18.3-Markov-Chains/18.3.4-Irreducible-and-Aperiodic-Chains.md)), and the law of $X^{(t)}$ tends to $p$ ([18.3.8](../../18-STOCHASTIC-PROCESSES/18.3-Markov-Chains/18.3.8-Convergence-to-Equilibrium.md)). Careful: if the set of possible points is split into islands that single-coordinate moves cannot connect, the chain is not irreducible and never crosses between the islands.

**Correlation slows it down.** For the standard bivariate normal with correlation $\rho$ ([12.10](../../12-MULTIVARIATE-GAUSSIAN/12.10-Bivariate-Normal.md)), the conditionals are $X \mid Y = y \sim \mathcal{N}(\rho y, 1 - \rho^2)$ and $Y \mid X = x \sim \mathcal{N}(\rho x, 1 - \rho^2)$ ([12.7](../../12-MULTIVARIATE-GAUSSIAN/12.7-Conditionals.md)). Substitute $Y_t = \rho X_t + \sqrt{1 - \rho^2} \thinspace \varepsilon_t$ into the next $X$-draw:

$$
X_{t+1} = \rho \thinspace Y_t + \sqrt{1 - \rho^2} \thinspace \varepsilon'_t = \rho^2 X_t + \sqrt{1 - \rho^2 + \rho^2 (1 - \rho^2)} \thinspace \varepsilon''_t
$$

The sequence $X_t$ is an autoregressive chain with coefficient $\rho^2$: its lag-1 autocorrelation is $\rho^2$. For $\rho = 0.8$ that is $0.64$, for $\rho = 0.99$ it is $0.98$: the chain barely moves from one sweep to the next.

## Worked Examples

### Example 1: Two Correlated Normals

**Problem.** Sample $(X, Y)$ from the standard bivariate normal with $\rho = 0.8$ by Gibbs sampling. Do one sweep by hand from $(0, 0)$, then use a long run to estimate $P(X \gt 1, Y \gt 1)$.

**Solution.**

1. The conditional standard deviation is $\sqrt{1 - \rho^2} = \sqrt{1 - 0.64} = 0.6$.
2. Draw $X \sim \mathcal{N}(\rho \cdot 0, 0.6^2)$ with the standard normal number $z_1 = 1.0$: $x = 0 + 0.6 \times 1.0 = 0.6$.
3. Draw $Y \sim \mathcal{N}(\rho x, 0.6^2)$ with $z_2 = -0.5$: $y = 0.8 \times 0.6 + 0.6 \times (-0.5) = 0.48 - 0.30 = 0.18$.
4. After one sweep the walker is at $(0.6, 0.18)$. Repeat 100,000 times, discard the first 1,000 sweeps, and record $(x, y)$ after each sweep.
5. The exact value is $P(X \gt 1, Y \gt 1) = 0.0976$ (by the symmetry of the law, equal to $P(X \lt -1, Y \lt -1)$, which a numerical bivariate normal CDF gives).

**Answer.** The simulation gives $P(X \gt 1, Y \gt 1) \approx 0.0980$ (exact $0.0976$), correlation $0.7979$ (exact $0.8$), and the mean of $X$ equal to $-0.0011 \pm 0.0068$.

**Check.** The error bar is larger than the $\frac{1}{\sqrt{99{,}000}} = 0.0032$ of independent samples, because the lag-1 autocorrelation of the $X$ chain is $0.6392$, matching $\rho^2 = 0.64$. The effective sample size is $n \frac{1 - r}{1 + r} = 21{,}792$, only 22% of the 99,000 steps.

### Example 2: A Table With Two Binary Variables

**Problem.** The joint law of two bits $(X, Y)$ is $P(0,0) = 0.4$, $P(0,1) = 0.1$, $P(1,0) = 0.1$, $P(1,1) = 0.4$. Find the conditionals, and show by hand that one Gibbs update leaves the law unchanged.

**Solution.**

1. Marginals: $P(X = 0) = P(X = 1) = P(Y = 0) = P(Y = 1) = 0.5$.
2. Conditionals: $P(X = 0 \mid Y = 0) = \frac{0.4}{0.5} = 0.8$ and $P(X = 1 \mid Y = 0) = 0.2$. By symmetry $P(X = 1 \mid Y = 1) = 0.8$, $P(X = 0 \mid Y = 1) = 0.2$. The same numbers hold for $Y$ given $X$.
3. Suppose $(X, Y) \sim p$ and we redraw $X' \sim p(\cdot \mid Y)$. Then for example

$$P(X' = 0, Y = 1) = P(Y = 1) \cdot P(X = 0 \mid Y = 1) = 0.5 \times 0.2 = 0.1$$

which is exactly $p(0, 1)$. The other three entries work the same way.
4. To draw $X$ given $Y = 1$ with the inverse transform ([19.4](../19.4-Inverse-Transform-Sampling.md)): return $X = 0$ if $U \le 0.2$, and $X = 1$ otherwise.

**Answer.** The conditionals are $0.8$ for "same value" and $0.2$ for "different value". One update preserves $p$.

**Check.** Running the chain for 200,000 sweeps gives $P(X = Y) = 0.8006$ (exact $0.8$, because $0.4 + 0.4 = 0.8$) and $P(X = 1) = 0.5029$ (exact $0.5$). Repeating the run with 40 other seeds shows that the standard errors are about $0.0009$ and $0.0015$ (the steps are correlated, with lag-1 autocorrelation $0.36$). So the first estimate is within one standard error, and the second is two standard errors high, which happens about once in 20 runs.

### Example 3: Mean and Variance of Exam Scores

**Problem.** Ten exam scores are $72, 85, 78, 90, 66, 81, 77, 88, 70, 83$. Assume they are i.i.d. $\mathcal{N}(\mu, \sigma^2)$ with unknown $\mu$ and $\sigma^2$, flat prior for $\mu$, and the prior $\propto \frac{1}{\sigma^2}$ for the variance. Find the posterior mean of $\mu$, the posterior mean of $\sigma^2$, and a 95% interval for $\mu$, using Gibbs sampling.

**Solution.**

1. Work with the precision $\tau = \frac{1}{\sigma^2}$. The data have $n = 10$, $\bar{x} = 79.0$ and $S = \sum (x_i - \bar{x})^2 = 562.0$.
2. The full conditionals are (standard results for this model, from multiplying the likelihood by the prior and recognizing the shape):

$$\mu \mid \tau, \text{data} \sim \mathcal{N}\left( \bar{x}, \frac{1}{n \tau} \right), \qquad \tau \mid \mu, \text{data} \sim \text{Gamma}\left( \frac{n}{2}, \thinspace \frac{1}{2} \sum_i (x_i - \mu)^2 \right)$$

where the Gamma is in the shape and **rate** form of the notation table.
3. Exact answers for this model (they come from integrating out one variable): $E[\mu \mid \text{data}] = \bar{x} = 79.0$, $\operatorname{Var}(\mu \mid \text{data}) = \frac{S}{n(n-3)} = \frac{562}{70} = 8.029$, $E[\sigma^2 \mid \text{data}] = \frac{S}{n - 3} = \frac{562}{7} = 80.29$, and the 95% interval for $\mu$ is the $t$ interval $\bar{x} \pm t_{9, 0.975} \sqrt{\frac{S}{n(n-1)}} = 79 \pm 2.262 \times 2.50 = (73.35, 84.65)$.
4. The code alternates the two draws for 100,000 sweeps, starting at the arbitrary values $\mu = 70$, $\tau = 1$.

**Answer.** The posterior mean of $\mu$ is $78.994 \pm 0.011$, the posterior mean of $\sigma^2$ is $80.19 \pm 0.16$, and the 95% interval for $\mu$ is $(73.35, 84.64)$.

**Check.** All three match the exact values $79.000$, $80.29$ and $(73.35, 84.65)$ within the error bars (batch means over 20 batches). The sample variance of $\mu$ is $7.991$ against the exact $8.029$. The wide interval reflects only 10 scores: the standard deviation of the scores is about $7.9$, so each score is a noisy guide to the mean.

## Simulate It

First, the bivariate normal of Example 1, with the check of the autocorrelation:

```python
import numpy as np
from scipy.stats import multivariate_normal

rng = np.random.default_rng(42)
rho = 0.8
sd = np.sqrt(1 - rho**2)                        # sd of X given Y (and of Y given X) = 0.6
n_steps, burn_in = 100_000, 1_000

x, y = 0.0, 0.0
xs, ys = np.empty(n_steps), np.empty(n_steps)
for t in range(n_steps):
    x = rho * y + sd * rng.standard_normal()    # draw X from p(x | y)
    y = rho * x + sd * rng.standard_normal()    # draw Y from p(y | x), using the new x
    xs[t], ys[t] = x, y
xs, ys = xs[burn_in:], ys[burn_in:]

r1 = np.corrcoef(xs[:-1], xs[1:])[0, 1]         # lag-1 autocorrelation of the X chain
n_eff = len(xs) * (1 - r1) / (1 + r1)           # effective sample size (AR(1) rule)
exact = multivariate_normal(mean=[0, 0], cov=[[1, rho], [rho, 1]]).cdf([-1, -1])
print(f"mean of X {xs.mean():.4f} +- {1 / np.sqrt(n_eff):.4f} (exact 0), sd of X {xs.std():.4f} (exact 1)")
print(f"correlation of X and Y {np.corrcoef(xs, ys)[0, 1]:.4f} (exact {rho})")
print(f"P(X > 1, Y > 1) {np.mean((xs > 1) & (ys > 1)):.4f} (exact {exact:.4f})")
print(f"lag-1 autocorrelation of X {r1:.4f} (theory rho^2 = {rho**2:.2f}), n_eff = {n_eff:,.0f}")
```

Output:

```text
mean of X -0.0011 +- 0.0068 (exact 0), sd of X 1.0011 (exact 1)
correlation of X and Y 0.7979 (exact 0.8)
P(X > 1, Y > 1) 0.0980 (exact 0.0976)
lag-1 autocorrelation of X 0.6392 (theory rho^2 = 0.64), n_eff = 21,792
```

The effective sample size formula $n \frac{1 - r}{1 + r}$ is the exact rule for an autoregressive chain and a good guide here ([19.7.3](19.7.3-Burn-in-Mixing-and-Diagnostics.md) explains it). Next the two bits of Example 2:

```python
import numpy as np

rng = np.random.default_rng(42)
joint = np.array([[0.4, 0.1],
                  [0.1, 0.4]])                   # joint[x, y] = P(X = x, Y = y)
n_steps = 200_000

x, y = 0, 0
count_equal, count_x1 = 0, 0
for _ in range(n_steps):
    x = int(rng.random() < joint[1, y] / joint[:, y].sum())    # X ~ p(x | y)
    y = int(rng.random() < joint[x, 1] / joint[x, :].sum())    # Y ~ p(y | x)
    count_equal += (x == y)
    count_x1 += x
print(f"P(X = Y)  {count_equal / n_steps:.4f} (exact 0.8000)")
print(f"P(X = 1)  {count_x1 / n_steps:.4f} (exact 0.5000)")
```

Output:

```text
P(X = Y)  0.8006 (exact 0.8000)
P(X = 1)  0.5029 (exact 0.5000)
```

Finally the exam scores of Example 3:

```python
import numpy as np

rng = np.random.default_rng(42)
scores = np.array([72, 85, 78, 90, 66, 81, 77, 88, 70, 83], dtype=float)
n, xbar = scores.size, scores.mean()

mu, tau = 70.0, 1.0                              # arbitrary start; tau = 1 / sigma^2
n_steps, burn_in = 100_000, 1_000
mus, sig2 = np.empty(n_steps), np.empty(n_steps)
for t in range(n_steps):
    # mu | tau, data ~ N(xbar, 1 / (n tau))
    mu = rng.normal(xbar, 1 / np.sqrt(n * tau))
    # tau | mu, data ~ Gamma(shape n/2, rate sum((x - mu)^2) / 2); numpy uses scale = 1/rate
    tau = rng.gamma(n / 2, 2 / np.sum((scores - mu) ** 2))
    mus[t], sig2[t] = mu, 1 / tau
mus, sig2 = mus[burn_in:], sig2[burn_in:]

def batch_se(v, k=20):                           # error bar for correlated samples
    return v[: len(v) // k * k].reshape(k, -1).mean(axis=1).std(ddof=1) / np.sqrt(k)

S = np.sum((scores - xbar) ** 2)
print(f"E[mu]     {mus.mean():.3f} +- {batch_se(mus):.3f} (exact {xbar:.3f})")
print(f"Var(mu)   {mus.var():.3f}          (exact {S / (n * (n - 3)):.3f})")
print(f"E[sigma2] {sig2.mean():.2f} +- {batch_se(sig2):.2f} (exact {S / (n - 3):.2f})")
lo, hi = np.percentile(mus, [2.5, 97.5])
print(f"95% interval for mu: ({lo:.2f}, {hi:.2f})  (exact t interval: (73.35, 84.65))")
```

Output:

```text
E[mu]     78.994 +- 0.011 (exact 79.000)
Var(mu)   7.991          (exact 8.029)
E[sigma2] 80.19 +- 0.16 (exact 80.29)
95% interval for mu: (73.35, 84.64)  (exact t interval: (73.35, 84.65))
```

## Common Mistakes

- **Using old values within a sweep.** When you update $x_2$, you must use the new $x_1$, not the one from the previous sweep. Updating all coordinates from the old values at the same time is a different (and wrong) algorithm.
- **Not knowing the conditional exactly.** Gibbs needs a draw from the exact full conditional. A rough approximation breaks the stationary law. If a conditional is not easy, use a Metropolis step for that coordinate ("Metropolis within Gibbs").
- **Ignoring strong correlation between coordinates.** For $\rho = 0.99$ the autocorrelation of the chain is $0.98$ and the effective sample size is about 1% of the number of sweeps (Practice 4). Update strongly linked coordinates together as a block, or reparametrize.
- **Constrained spaces that single-coordinate moves cannot cross.** If the allowed region has two separate islands, such as the points where $x = y$ and nothing else, one-coordinate updates cannot move at all: given $y$, the conditional of $x$ is a single point.
- **Treating sweeps as independent samples.** Consecutive sweeps are correlated. Report an error bar based on batches, several chains or the effective sample size.

## Where It Is Used

- **AI and machine learning:** latent Dirichlet allocation (topic models) is trained by Gibbs sampling: each word's topic is resampled given all other topics. Restricted Boltzmann machines and deep belief networks use Gibbs steps to sample hidden and visible units. Bayesian linear regression and mixture models often have simple full conditionals.
- **Computer science:** image denoising and segmentation with Markov random fields, where each pixel is resampled given its neighbours (the original use of Gibbs, from 1984), and sampling from the Ising model.
- **Statistics:** hierarchical Bayesian models in tools such as BUGS and JAGS, missing-data problems, and genetics.
- **Physics:** the heat-bath algorithm for lattices of spins is exactly Gibbs sampling.
- **Everyday life:** fixing one thing at a time while holding the others at their current best guess, and repeating, as when you adjust a recipe one ingredient at a time.

## Practice

**1. (Easy)** For the bivariate normal with $\rho = 0.6$ and mean 0, variance 1, give the conditional law of $X$ given $Y = 1$. If the standard normal draw is $z = 1$, what is the new $x$?

<details>
<summary>Answer</summary>

$X \mid Y = 1 \sim \mathcal{N}(\rho \cdot 1, 1 - \rho^2) = \mathcal{N}(0.6, 0.64)$, which has standard deviation $0.8$. With $z = 1$:

$$x = 0.6 + 0.8 \times 1 = 1.4$$

</details>

**2. (Easy)** Why does Gibbs sampling not need an accept-or-reject step?

<details>
<summary>Answer</summary>

Each update draws the coordinate from its exact full conditional, which is a Metropolis-Hastings proposal whose Hastings ratio equals 1. So the acceptance probability is 1 and every move is accepted.

</details>

**3. (Medium)** The joint PMF of two bits is $P(0,0) = 0.3$, $P(0,1) = 0.2$, $P(1,0) = 0.1$, $P(1,1) = 0.4$. Find $P(X = 1 \mid Y = 1)$ and $P(X = 1 \mid Y = 0)$. If the walker has $Y = 1$ and $U = 0.5$, what is the new $X$ (use the inverse transform)?

<details>
<summary>Answer</summary>

$P(Y = 1) = 0.2 + 0.4 = 0.6$ and $P(Y = 0) = 0.3 + 0.1 = 0.4$. Then

$$P(X = 1 \mid Y = 1) = \frac{0.4}{0.6} = \frac{2}{3}, \qquad P(X = 1 \mid Y = 0) = \frac{0.1}{0.4} = 0.25$$

Given $Y = 1$, $P(X = 0 \mid Y = 1) = \frac{1}{3}$. The inverse transform returns $X = 0$ if $U \le \frac{1}{3}$ and $X = 1$ otherwise. With $U = 0.5 \gt \frac{1}{3}$, the new value is $X = 1$.

</details>

**4. (Medium)** For the bivariate normal Gibbs sampler with $\rho = 0.99$, find the lag-1 autocorrelation of the $X$ chain and the fraction of effective samples $\frac{1 - r}{1 + r}$.

<details>
<summary>Answer</summary>

The lag-1 autocorrelation is $r = \rho^2 = 0.9801$. The fraction of effective samples is

$$\frac{1 - 0.9801}{1 + 0.9801} = \frac{0.0199}{1.9801} \approx 0.0100$$

So only about 1% of the sweeps count as independent samples. To get 10,000 effective samples you need about a million sweeps.

</details>

**5. (Hard)** Prove that if $X \sim p$ and $X'_j \sim p(\cdot \mid X_{-j})$ is drawn using only $X_{-j}$, then $(X'_j, X_{-j}) \sim p$. Conclude that a full sweep keeps $p$ stationary.

<details>
<summary>Answer</summary>

By the chain rule, the joint law of $(X_{-j}, X'_j)$ is $p(x_{-j}) \thinspace p(x'_j \mid x_{-j})$, because $X_{-j}$ has its marginal law $p(x_{-j})$ and $X'_j$ is drawn from the conditional given $X_{-j}$ (and nothing else). By the definition of conditional probability, $p(x_{-j}) \thinspace p(x'_j \mid x_{-j}) = p(x'_j, x_{-j})$. So $(X'_j, X_{-j}) \sim p$. A sweep applies this fact for $j = 1$, then for $j = 2$ to the output, and so on. After each step the vector still has law $p$, so after the whole sweep it does too.

</details>

**6. (Simulate)** Run the bivariate normal Gibbs sampler for $\rho = 0.5$ and $\rho = 0.95$ (100,000 sweeps each). Report the lag-1 autocorrelation of $X$ and the effective sample size.

<details>
<summary>Answer</summary>

```python
import numpy as np

rng = np.random.default_rng(42)
n_steps = 100_000
for rho in [0.5, 0.95]:
    sd = np.sqrt(1 - rho**2)
    x = y = 0.0
    xs = np.empty(n_steps)
    for t in range(n_steps):
        x = rho * y + sd * rng.standard_normal()
        y = rho * x + sd * rng.standard_normal()
        xs[t] = x
    r1 = np.corrcoef(xs[:-1], xs[1:])[0, 1]
    print(f"rho = {rho}: lag-1 autocorrelation {r1:.4f} (theory {rho**2:.4f}), n_eff = {n_steps * (1 - r1) / (1 + r1):,.0f}")
```

Output:

```text
rho = 0.5: lag-1 autocorrelation 0.2503 (theory 0.2500), n_eff = 59,959
rho = 0.95: lag-1 autocorrelation 0.9008 (theory 0.9025), n_eff = 5,221
```

A stronger correlation between the coordinates leaves only about 5% of the sweeps as independent information.

</details>

## Summary

- Gibbs sampling updates one coordinate at a time by drawing it from its full conditional $p(x_j \mid x_{-j})$, always using the newest values.
- It is Metropolis-Hastings with proposal equal to the conditional, so the acceptance probability is 1. Each update keeps $p$ stationary.
- It needs easy full conditionals but no tuning, no step size and no normalizing constant.
- Strong correlation between coordinates makes the chain crawl: for the bivariate normal the lag-1 autocorrelation is $\rho^2$.
- The samples are correlated, so error bars use batches, several chains or the effective sample size.

The one formula to remember:

$$
\boxed{x_j^{(t+1)} \sim p\big(x_j \mid x_{-j}\big), \quad j = 1, \dots, d \qquad \text{(accept with probability 1)}}
$$
