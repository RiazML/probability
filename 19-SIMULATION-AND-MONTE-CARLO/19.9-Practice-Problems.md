> **Big idea:** Every simulation answer is an estimate with an error bar, and you learn the craft by doing it for many problems: always find the exact value when you can, always report the standard error, and always ask whether the samples are independent.

---

## How to Use This Set

- Each problem says which topic it uses. If you get stuck, reread that topic first.
- Try every problem on paper (or in code) before opening the answer. In the simulation problems, **write the code before you read it**.
- **Warm-Up** problems check the basic formulas. **Core** problems mix two or three ideas. **Challenge** problems include proofs. **Simulation Projects** are programs that combine the whole module.
- In every simulation, use `rng = np.random.default_rng(42)`, print the standard error next to the estimate, and compare with the exact value when there is one.
- The three questions to ask of any simulation: Is the model the real experiment? How large is the error bar? Are the samples independent (and if not, what is the effective sample size)?

## Warm-Up

**W1. (Easy)** *Uses [19.1 Why Simulate](19.1-Why-Simulate.md) and [19.3 Monte Carlo Estimation](19.3-Monte-Carlo-Estimation.md).*
A simulation runs 2,500 trials, and the event happens 1,550 times. Give the estimate, its standard error and a 95% interval. How many trials give a standard error of $0.002$?

<details>
<summary>Answer</summary>

$$\hat{p} = \frac{1550}{2500} = 0.62, \qquad \operatorname{SE} = \sqrt{\frac{0.62 \times 0.38}{2500}} = \sqrt{0.0000942} = 0.0097$$

$$0.62 \pm 1.96 \times 0.0097 = 0.62 \pm 0.019, \text{ that is, } (0.601, \thinspace 0.639)$$

For $\operatorname{SE} = 0.002$ we need $\frac{0.62 \times 0.38}{n} = 0.002^2$, so $n = \frac{0.2356}{0.000004} = 58{,}900$ trials.

</details>

**W2. (Easy)** *Uses [19.2 Pseudo-Random Numbers and Seeds](19.2-Pseudo-Random-Numbers-and-Seeds.md).*
An LCG has $m = 9$, $a = 4$, $c = 1$ and seed $x_0 = 2$. Write the sequence until it repeats. Is it a full-period generator, and do the Hull-Dobell conditions agree?

<details>
<summary>Answer</summary>

$x_1 = (4 \cdot 2 + 1) \operatorname{mod} 9 = 0$, then $x_2 = 1$, $x_3 = 5$, $x_4 = 21 \operatorname{mod} 9 = 3$, $x_5 = 13 \operatorname{mod} 9 = 4$, $x_6 = 17 \operatorname{mod} 9 = 8$, $x_7 = 33 \operatorname{mod} 9 = 6$, $x_8 = 25 \operatorname{mod} 9 = 7$, $x_9 = 29 \operatorname{mod} 9 = 2$. The sequence is $2, 0, 1, 5, 3, 4, 8, 6, 7, 2, \dots$ and it returns to the seed after 9 steps, visiting every value $0, \dots, 8$ once: full period. The conditions hold: $c = 1$ shares no factor with $9$, and $a - 1 = 3$ is divisible by the only prime factor of $9$, which is $3$. (The condition about $4$ does not apply, because $4$ does not divide $9$.)

</details>

**W4. (Easy)** *Uses [19.5 Rejection Sampling](19.5-Rejection-Sampling.md).*
The target is $p(x) = 3x^2$ on $[0, 1]$ with the proposal $\text{Unif}(0, 1)$. Find $M$ and the acceptance rate. Decide the candidates $(x, u) = (0.8, 0.5)$ and $(0.4, 0.5)$.

## Core

**C1. (Medium)** *Uses [19.3 Monte Carlo Estimation](19.3-Monte-Carlo-Estimation.md).*
Since $\int_0^1 \frac{4}{1 + x^2} dx = \pi$, we can estimate $\pi$ by averaging $f(U) = \frac{4}{1 + U^2}$. Find the standard deviation of $f(U)$ and the number of samples for an error of at most $0.001$ with 95% confidence. Compare with the quarter-circle method of [19.3](19.3-Monte-Carlo-Estimation.md) (which needs about $10{,}360{,}000$).

<details>
<summary>Answer</summary>

$$E[f^2] = \int_0^1 \frac{16}{(1 + x^2)^2} dx = 16 \left( \frac{1}{4} + \frac{\pi}{8} \right) = 4 + 2\pi = 10.2832$$

$$\sigma^2 = 10.2832 - \pi^2 = 10.2832 - 9.8696 = 0.4136, \qquad \sigma = 0.6431$$

$$n \ge \left( \frac{1.96 \times 0.6431}{0.001} \right)^2 = 1260.5^2 \approx 1{,}589{,}000$$

This is 6.5 times fewer samples than the quarter-circle method ($\sigma = 1.642$). Smooth functions are better to average than a 0/1 indicator.

</details>

**C2. (Medium)** *Uses [19.4 Inverse Transform Sampling](19.4-Inverse-Transform-Sampling.md).*
The standard logistic distribution has CDF $F(x) = \frac{1}{1 + e^{-x}}$ ([9.10](../09-CONTINUOUS-DISTRIBUTIONS/9.10-Logistic-and-Gumbel.md)). Find its sampler, the median and the quartiles.

<details>
<summary>Answer</summary>

Solve $\frac{1}{1 + e^{-x}} = u$: $1 + e^{-x} = \frac{1}{u}$, so $e^{-x} = \frac{1 - u}{u}$ and

$$x = Q(u) = \ln \frac{u}{1 - u}$$

The sampler is $X = \ln \frac{U}{1 - U}$. The median is $Q(0.5) = \ln 1 = 0$. The quartiles are $Q(0.25) = \ln \frac{1}{3} = -1.0986$ and $Q(0.75) = \ln 3 = 1.0986$, so the interquartile range is $2.197$.

</details>

**C3. (Medium)** *Uses [19.5 Rejection Sampling](19.5-Rejection-Sampling.md).*
The target is $\text{Gamma}(2, 1)$ (shape 2, rate 1), $p(x) = x e^{-x}$ for $x \gt 0$. The proposal is $\text{Exp}$ with rate $\frac{1}{2}$, $q(x) = \frac{1}{2} e^{-x/2}$. Find the smallest $M$, the acceptance probability of a candidate $x$, and the overall acceptance rate.

<details>
<summary>Answer</summary>

The ratio is $\frac{p(x)}{q(x)} = 2x e^{-x/2}$. Its derivative is $2 e^{-x/2} (1 - \frac{x}{2})$, which is zero at $x = 2$. So

$$M = 2 \cdot 2 \cdot e^{-1} = \frac{4}{e} \approx 1.4715$$

The acceptance probability of a candidate $x$ is

$$\frac{p(x)}{M q(x)} = \frac{2x e^{-x/2}}{4/e} = \frac{x}{2} e^{1 - x/2}$$

which is exactly 1 at $x = 2$. The overall acceptance rate is $\frac{1}{M} = \frac{e}{4} \approx 0.6796$.

</details>

**C4. (Medium)** *Uses [19.6 Importance Sampling](19.6-Importance-Sampling.md).*
Estimate $\theta = P(X \gt 5) = e^{-5}$ for $X \sim \text{Exp}(1)$. Use the proposal $q = \text{Exp}$ with rate $0.2$ (mean 5). (a) Find the weight $w(x)$. (b) Find the variance of one importance sampling value $I(X \gt 5) w(X)$ and compare it with the plain Monte Carlo variance $\theta(1 - \theta)$. (c) How many samples does each method need for a standard error of $0.0001$?

<details>
<summary>Answer</summary>

(a) $w(x) = \frac{e^{-x}}{0.2 e^{-0.2x}} = 5 e^{-0.8x}$.

(b) The second moment of the value is

$$E_q[(I w)^2] = \int_5^{\infty} 25 e^{-1.6x} \cdot 0.2 e^{-0.2x} dx = 5 \int_5^{\infty} e^{-1.8x} dx = \frac{5 e^{-9}}{1.8} = 0.000343$$

With $\theta = e^{-5} = 0.006738$ and $\theta^2 = 0.0000454$, the variance is $0.000343 - 0.0000454 = 0.000298$ (standard deviation $0.01725$). Plain Monte Carlo has variance $0.006738 \times 0.993262 = 0.006693$ (standard deviation $0.0818$). The ratio is $\frac{0.006693}{0.000298} = 22.5$.

(c) We need $\frac{\text{variance}}{n} = 10^{-8}$. Plain: $n = \frac{0.006693}{10^{-8}} = 669{,}300$. Importance sampling: $n = \frac{0.000298}{10^{-8}} = 29{,}800$.

</details>

**C5. (Medium)** *Uses [19.7.1 Metropolis-Hastings](19.7-MCMC/19.7.1-Metropolis-Hastings.md) and [18.3.5 Stationary Distribution](../18-STOCHASTIC-PROCESSES/18.3-Markov-Chains/18.3.5-Stationary-Distribution.md).*
The target on the states $A, B, C$ is $p = (0.5, 0.25, 0.25)$. The proposal picks one of the other two states with probability $\frac{1}{2}$ each. Write the transition matrix of the Metropolis chain, check that $p$ is stationary, and find $P(X_2 = A \mid X_0 = B)$.

<details>
<summary>Answer</summary>

The proposal is symmetric. From $A$: to $B$ with probability $\frac{1}{2} \min(1, \frac{0.25}{0.5}) = 0.25$, to $C$ with probability $0.25$, and stay with probability $0.5$. From $B$: to $A$ with probability $\frac{1}{2} \min(1, \frac{0.5}{0.25}) = 0.5$, to $C$ with probability $\frac{1}{2} \min(1, 1) = 0.5$, stay with probability $0$. From $C$ the same: $0.5, 0.5, 0$.

The rows of $P$ (in the order $A, B, C$) are $(0.5, 0.25, 0.25)$, $(0.5, 0, 0.5)$ and $(0.5, 0.5, 0)$.

Stationarity: $(pP)_A = 0.5 \cdot 0.5 + 0.25 \cdot 0.5 + 0.25 \cdot 0.5 = 0.5$ and $(pP)_B = 0.5 \cdot 0.25 + 0.25 \cdot 0 + 0.25 \cdot 0.5 = 0.25$. By symmetry $(pP)_C = 0.25$. Two steps from $B$ to $A$: go via $A$ or via $C$:

$$P(X_2 = A \mid X_0 = B) = P_{BA} P_{AA} + P_{BC} P_{CA} = 0.5 \times 0.5 + 0.5 \times 0.5 = 0.5$$

</details>

**C6. (Medium)** *Uses [19.7.2 Gibbs Sampling](19.7-MCMC/19.7.2-Gibbs-Sampling.md) and [19.7.3 Burn-in, Mixing and Diagnostics](19.7-MCMC/19.7.3-Burn-in-Mixing-and-Diagnostics.md).*
A Gibbs sampler for the standard bivariate normal with $\rho = 0.9$ runs for $n = 100{,}000$ sweeps. Find the lag-1 autocorrelation of the $X$ chain, $\tau$, the ESS, and the standard error of the mean of $X$. How many sweeps give a standard error of $0.001$?

<details>
<summary>Answer</summary>

The autocorrelation is $r = \rho^2 = 0.81$, and $\rho_k = r^k$. So

$$\tau = \frac{1 + r}{1 - r} = \frac{1.81}{0.19} = 9.526, \qquad \text{ESS} = \frac{100{,}000}{9.526} \approx 10{,}497$$

$$\operatorname{SE} = \frac{1}{\sqrt{10{,}497}} = 0.00976$$

(the naive value $\frac{1}{\sqrt{100{,}000}} = 0.00316$ is about $3$ times too small). For $\operatorname{SE} = 0.001$ we need $\text{ESS} = 10^6$, that is $n = 9.526 \times 10^6$ sweeps.

</details>

## Challenge

**H1. (Hard)** *Uses [19.5 Rejection Sampling](19.5-Rejection-Sampling.md).*
**Proof.** Let $\tilde{p} = Zp$ be an unnormalized density, $q$ a proposal density, and $\tilde{M}$ a constant with $\tilde{p} \le \tilde{M} q$. Show that rejection sampling with the test $U \le \frac{\tilde{p}(X)}{\tilde{M} q(X)}$ accepts with probability $\frac{Z}{\tilde{M}}$, that the accepted value has density $p$, and that the mean number of candidates per accepted value is $\frac{\tilde{M}}{Z}$.

<details>
<summary>Answer</summary>

A candidate lands near $x$ with probability $q(x) \thinspace dx$ and is then accepted with probability $\frac{\tilde{p}(x)}{\tilde{M} q(x)}$ (a number in $[0, 1]$ because $\tilde{p} \le \tilde{M} q$). So

$$P(X \in dx, \text{ accepted}) = q(x) \frac{\tilde{p}(x)}{\tilde{M} q(x)} dx = \frac{\tilde{p}(x)}{\tilde{M}} dx$$

Integrating over $x$ and using $\int \tilde{p} = Z \int p = Z$:

$$P(\text{accept}) = \frac{Z}{\tilde{M}}$$

By the definition of conditional probability,

$$P(X \in dx \mid \text{accepted}) = \frac{\tilde{p}(x) \thinspace dx / \tilde{M}}{Z / \tilde{M}} = \frac{\tilde{p}(x)}{Z} dx = p(x) \thinspace dx$$

The rounds are independent, each succeeding with probability $\frac{Z}{\tilde{M}}$. The number of rounds is geometric, with mean $\frac{\tilde{M}}{Z}$. Note that $Z$ was never needed to run the algorithm.

</details>

**H2. (Hard)** *Uses [19.6 Importance Sampling](19.6-Importance-Sampling.md).*
Let $X \sim \text{Exp}(1)$ and estimate $P(X \gt a)$ with the proposal $q = \text{Exp}(\mu)$ (rate $\mu$). (a) Show that the estimator has finite variance if and only if $\mu \lt 2$, and find the variance. (b) For $a = 5$, find the $\mu$ with the smallest variance.

<details>
<summary>Answer</summary>

(a) The weight is $w(x) = \frac{e^{-x}}{\mu e^{-\mu x}}$, and $\theta = e^{-a}$. The second moment of one value $I(X \gt a) w(X)$ under $q$ is

$$E_q[(I w)^2] = \int_a^{\infty} \frac{p(x)^2}{q(x)} dx = \frac{1}{\mu} \int_a^{\infty} e^{-(2 - \mu)x} dx$$

The integral converges if and only if $2 - \mu \gt 0$. Then it equals $\frac{e^{-(2 - \mu)a}}{\mu (2 - \mu)}$, so

$$\operatorname{Var} = \frac{e^{-(2 - \mu)a}}{\mu (2 - \mu)} - e^{-2a} \qquad (\mu \lt 2)$$

and the variance is infinite for $\mu \ge 2$ (a proposal with a thin tail). For $\mu = 1$ (the plain method) this gives $e^{-a} - e^{-2a} = \theta(1 - \theta)$, as it should.

(b) Minimize $g(\mu) = \frac{e^{-(2 - \mu)a}}{\mu (2 - \mu)}$. Setting the derivative of $\ln g$ to zero: $a - \frac{1}{\mu} + \frac{1}{2 - \mu} = 0$. Multiply by $\mu (2 - \mu)$: $a \mu (2 - \mu) - (2 - \mu) + \mu = 0$, that is $a \mu^2 - (2a + 2) \mu + 2 = 0$. For $a = 5$: $5 \mu^2 - 12 \mu + 2 = 0$, so

$$\mu = \frac{12 - \sqrt{144 - 40}}{10} = \frac{12 - 10.198}{10} = 0.180$$

(the other root, $2.22$, is not below 2). The variance at $\mu = 0.18$ is $0.0002955$, only slightly smaller than $0.000298$ at $\mu = 0.2$ (the choice of C4). The choice of a proposal with mean about $a$ is already near-optimal.

</details>

**H3. (Hard)** *Uses [19.7.3 Burn-in, Mixing and Diagnostics](19.7-MCMC/19.7.3-Burn-in-Mixing-and-Diagnostics.md) and [18.3.5 Stationary Distribution](../18-STOCHASTIC-PROCESSES/18.3-Markov-Chains/18.3.5-Stationary-Distribution.md).*
**Proof.** Let $0 \le r \lt 1$ and $X_{t+1} = r X_t + \sqrt{1 - r^2} \thinspace \varepsilon_{t+1}$ with $\varepsilon_t$ i.i.d. $\mathcal{N}(0, 1)$, independent of $X_t$. (a) Show that $\mathcal{N}(0, 1)$ is a stationary law. (b) Show that in the stationary chain, $\operatorname{Cov}(X_t, X_{t+k}) = r^k$. (c) Find the effective sample size for $n$ steps.

<details>
<summary>Answer</summary>

(a) If $X_t \sim \mathcal{N}(0, 1)$, then $X_{t+1}$ is a sum of independent normals ([12.9](../12-MULTIVARIATE-GAUSSIAN/12.9-Sums-of-Gaussians.md)), so it is normal with mean $0$ and variance $r^2 \cdot 1 + (1 - r^2) \cdot 1 = 1$. So $X_{t+1} \sim \mathcal{N}(0, 1)$ and the law is stationary.

(b) The noise $\varepsilon_{t+1}$ is independent of $X_t$ and has mean 0, so $\operatorname{Cov}(X_t, X_{t+1}) = r \operatorname{Var}(X_t) = r$. By repeating, $X_{t+k} = r^k X_t + (\text{noise independent of } X_t)$, so $\operatorname{Cov}(X_t, X_{t+k}) = r^k$ and the autocorrelation is $\rho_k = r^k$.

(c) $\tau = 1 + 2 \sum_{k \ge 1} r^k = 1 + \frac{2r}{1 - r} = \frac{1 + r}{1 - r}$, so $\text{ESS} = n \frac{1 - r}{1 + r}$. For $r = 0.9$ it is $\frac{n}{19}$. This chain is a valid sampler for $\mathcal{N}(0, 1)$, and its speed is controlled by $r$ alone.

</details>

**H4. (Hard)** *Uses [19.3 Monte Carlo Estimation](19.3-Monte-Carlo-Estimation.md).*
**Proof.** Show that the sample variance $s^2 = \frac{1}{n - 1} \sum_{i=1}^{n} (Y_i - \bar{Y})^2$ of i.i.d. values $Y_i$ with mean $\mu$ and variance $\sigma^2$ satisfies $E[s^2] = \sigma^2$. This is why the code uses `ddof=1`.

<details>
<summary>Answer</summary>

Expand around $\bar{Y}$: $\sum (Y_i - \bar{Y})^2 = \sum Y_i^2 - n \bar{Y}^2$. Now $E[Y_i^2] = \sigma^2 + \mu^2$ and $E[\bar{Y}^2] = \operatorname{Var}(\bar{Y}) + \mu^2 = \frac{\sigma^2}{n} + \mu^2$. So

$$E\left[ \sum (Y_i - \bar{Y})^2 \right] = n (\sigma^2 + \mu^2) - n \left( \frac{\sigma^2}{n} + \mu^2 \right) = (n - 1) \sigma^2$$

Dividing by $n - 1$ gives $E[s^2] = \sigma^2$. Dividing by $n$ would give $\frac{n-1}{n} \sigma^2$, which is too small (though for large $n$ the difference is tiny).

</details>

## Simulation Projects

**P1. Verify three earlier results.** *Uses [19.8 Verifying Theory by Simulation](19.8-Verifying-Theory-by-Simulation.md), [4.11.1 Monty Hall](../04-CONDITIONAL-PROBABILITY-AND-BAYES/4.11-Classic-Puzzles/4.11.1-Monty-Hall.md) and [18.2.2 Gambler's Ruin](../18-STOCHASTIC-PROCESSES/18.2-Random-Walks/18.2.2-Gamblers-Ruin.md).*
Write a program that checks, with standard errors and $z$-scores: (1) the probability that a player who always switches wins at Monty Hall is $\frac{2}{3}$; (2) the mean number of rolls of a fair die needed to see all six faces is $6 \left( 1 + \frac{1}{2} + \dots + \frac{1}{6} \right) = 14.7$; (3) the mean number of rounds of the gambler's ruin that starts at 3 taka and stops at 0 or 10 taka is $3 \times 7 = 21$.

<details>
<summary>Answer</summary>

```python
import numpy as np

rng = np.random.default_rng(42)
n = 100_000

def report(name, values, exact):
    est = values.mean()
    se = values.std(ddof=1) / np.sqrt(len(values))
    print(f"{name:<22} {est:.4f} +- {se:.4f} | exact {exact:.4f} | z {(est - exact) / se:+.1f}")

# 1. Monty Hall: the player always switches. Exact P(win) = 2/3.
car = rng.integers(0, 3, n)
pick = rng.integers(0, 3, n)
switch_wins = pick != car          # the host removes a goat, so switching wins iff the first pick was wrong
report("Monty Hall, switch", switch_wins.astype(float), 2 / 3)

# 2. Coupon collector: rolls of a fair die until all six faces have appeared. Exact mean = 6 H_6 = 14.7.
def rolls_to_collect():
    seen, count = set(), 0
    while len(seen) < 6:
        seen.add(int(rng.integers(1, 7)))
        count += 1
    return count
rolls = np.array([rolls_to_collect() for _ in range(20_000)], dtype=float)
report("coupon collector", rolls, 14.7)

# 3. Gambler's ruin, start 3, stop at 0 or 10: expected number of rounds = 3 * 7 = 21.
money = np.full(n, 3)
rounds = np.zeros(n)
while True:
    playing = (money > 0) & (money < 10)
    if not playing.any():
        break
    money[playing] += rng.choice([-1, 1], size=playing.sum())
    rounds[playing] += 1
report("ruin, mean rounds", rounds, 21.0)
```

Output:

```text
Monty Hall, switch     0.6688 +- 0.0015 | exact 0.6667 | z +1.4
coupon collector       14.6945 +- 0.0438 | exact 14.7000 | z -0.1
ruin, mean rounds      21.0237 +- 0.0628 | exact 21.0000 | z +0.4
```

All three have $\lvert z \rvert \lt 2$, so all three theories pass. Note that the coupon collector used only 20,000 trials because each trial is a Python loop, which still gives a standard error of $0.044$.

</details>

**P2. A two-peak target with MCMC and full diagnostics.** *Uses [19.7.1 Metropolis-Hastings](19.7-MCMC/19.7.1-Metropolis-Hastings.md) and [19.7.3 Burn-in, Mixing and Diagnostics](19.7-MCMC/19.7.3-Burn-in-Mixing-and-Diagnostics.md).*
Sample from $p = 0.3 \thinspace \mathcal{N}(-2, 0.8^2) + 0.7 \thinspace \mathcal{N}(3, 1.2^2)$ with random-walk Metropolis. Run 8 chains from spread-out starts, discard a burn-in of 2,000 steps, and report $\hat{R}$, the mean (exact $0.3(-2) + 0.7(3) = 1.5$) and $P(X \lt 0)$ (exact $0.3 \thinspace \Phi(2.5) + 0.7 \thinspace \Phi(-2.5) = 0.3025$) with error bars from the spread of the chains. Then change the step size to $0.3$ and compare the error bars.

<details>
<summary>Answer</summary>

```python
import numpy as np
from scipy.stats import norm

rng = np.random.default_rng(42)

def target(x):
    # 0.3 N(-2, 0.8^2) + 0.7 N(3, 1.2^2)
    return 0.3 * norm.pdf(x, -2, 0.8) + 0.7 * norm.pdf(x, 3, 1.2)

n_chains, n_steps, burn_in, step = 8, 50_000, 2_000, 3.0
x = rng.uniform(-6, 7, n_chains)                               # spread-out starts
chains = np.empty((n_chains, n_steps))
for t in range(n_steps):
    proposal = x + step * rng.standard_normal(n_chains)
    accept = rng.random(n_chains) < target(proposal) / target(x)
    x = np.where(accept, proposal, x)
    chains[:, t] = x
chains = chains[:, burn_in:]
n = chains.shape[1]

W = chains.var(axis=1, ddof=1).mean()
B = n * chains.mean(axis=1).var(ddof=1)
r_hat = np.sqrt(((n - 1) / n * W + B / n) / W)

est = chains.mean(axis=1)                                      # one mean per chain
print(f"R-hat = {r_hat:.3f}")
print(f"mean  {est.mean():.3f} +- {est.std(ddof=1) / np.sqrt(n_chains):.3f}  (exact 1.500)")
below = (chains < 0).mean(axis=1)
print(f"P(X < 0) {below.mean():.4f} +- {below.std(ddof=1) / np.sqrt(n_chains):.4f}  (exact {0.3 * norm.cdf(2.5) + 0.7 * norm.cdf(-2.5):.4f})")
```

Output:

```text
R-hat = 1.000
mean  1.501 +- 0.013  (exact 1.500)
P(X < 0) 0.3019 +- 0.0025  (exact 0.3025)
```

With the step $3.0$ the chains cross the valley between the peaks (at $x = -2$ and $x = 3$) often, so $\hat{R} = 1.000$ and both estimates are within one standard error of the exact values. Now change `step` to $0.3$. Running the same program gives

```text
R-hat = 1.007
mean  1.623 +- 0.103  (exact 1.500)
P(X < 0) 0.2790 +- 0.0194  (exact 0.3025)
```

Here $\hat{R} = 1.007$ is still below $1.01$, but the error bars are about $8$ times larger ($0.103$ against $0.013$, and $0.0194$ against $0.0025$): each chain crawls in tiny steps, so its samples are strongly correlated and the effective sample size is small. This shows that a small $\hat{R}$ alone does not mean that a run is good. Always look at the ESS and the error bars as well. Try the steps $1$ and $2$ and find which one gives the smallest error bar.

</details>
