# 8.1 Probability Density Function

[Probability](../README.md) / [Module 08: Continuous Random Variables](README.md) / 8.1 Probability Density Function

**Level:** 2 (Random Variables) · **Time:** about 45 minutes · **Before this:** [Module 07: Discrete Distributions](../07-DISCRETE-DISTRIBUTIONS/README.md)

> **Big idea:** For a continuous random variable, probability is the area under a curve called the density.

---

## Why It Matters

Time, height, temperature, distance and price can take any value in a range, not
just whole numbers. A list of probabilities, one per value, cannot describe them.
The **probability density function** is the tool that replaces the PMF for these
variables. Every continuous distribution in
[Module 09](../09-CONTINUOUS-DISTRIBUTIONS/README.md), including the normal
distribution, is described by one.

## Intuition

Measure the height of 10,000 students and draw a histogram with bars 10 cm wide.
Each bar shows the fraction of students in that range. Now use bars 5 cm wide,
then 1 cm wide. The bars get thinner, and their tops start to trace a smooth curve.

There is a catch. With thinner bars, each bar holds fewer students, so the bars get
shorter and shorter. To keep a stable picture, we divide each fraction by the bar
width. Then the height of a bar means "fraction of students **per centimeter**".
With this scaling, the bars settle down to one smooth curve, and the **area** of a
bar (height times width) is the fraction of students in it.

That smooth curve is the density. To find the probability that a random student is
between 160 cm and 170 cm, you do not read one height off the curve. You find the
**area under the curve** between 160 and 170.

```text
  f(x)                                    f(x)
   |      ___                              |        .-'''-.
   |     |   |___                          |      .'  ###  '.

   | |   |   |   |___                      |  .'      ###      '.
   | |   |   |   |   |___                  |.'        ###        '.

   wide histogram bars        -->          thin bars become a curve;

```

As the bars of a histogram get thinner, their tops become a smooth curve, and the
probability of an interval becomes the area under the curve.

## Definition

### A One-Minute Reminder About Integrals

This is where calculus enters the book. You need only one idea from it. The
**integral** $\int_a^b f(x) \thinspace dx$ is the **area under the curve**
$y = f(x)$ between $x = a$ and $x = b$. Think of it as many thin rectangles: each
has height $f(x)$ and a tiny width $dx$, and the integral adds up all their areas.

To compute an area, find a function $G$ whose derivative is $f$ (called an
**antiderivative**). Then the area is $G(b) - G(a)$. We write this as
$\big[ G(x) \big]_a^b$. These four antiderivatives cover most of this module:

| Function $f(x)$ | Antiderivative $G(x)$ | Example |
|---|---|---|
| $x^n$ (for $n \ne -1$) | $\frac{x^{n+1}}{n+1}$ | $\int_0^1 x^2 \thinspace dx = \frac{1}{3} - 0 = \frac{1}{3}$ |
| $e^{-\lambda x}$ | $-\frac{1}{\lambda} e^{-\lambda x}$ | $\int_0^1 e^{-x} \thinspace dx = 1 - e^{-1}$ |
| $\frac{1}{x}$ (for $x \gt 0$) | $\ln x$ | $\int_1^2 \frac{1}{x} \thinspace dx = \ln 2$ |
| a constant $c$ | $cx$ | $\int_2^5 c \thinspace dx = 3c$ |

Constants can move outside an integral, and the integral of a sum is the sum of the
integrals. When a limit is $\infty$, we let $b$ grow without bound and see what the
area approaches.

### The Density

A random variable $X$ is **continuous** if there is a function $f_X$, called its
**probability density function** (**PDF**, or simply **density**), such that for
every interval:

$$
P(a \le X \le b) = \int_a^b f_X(x) \thinspace dx
$$

where:

- $a \le b$ are any two numbers (they can also be $-\infty$ or $\infty$),
- $f_X(x)$ is the height of the density curve at the point $x$.

**In words:** the probability that $X$ lands between $a$ and $b$ is the area under
the density curve between $a$ and $b$.

Every density must follow two rules:

$$
f_X(x) \ge 0 \text{ for all } x \qquad \text{and} \qquad \int_{-\infty}^{\infty} f_X(x) \thinspace dx = 1
$$

**In words:** the curve never goes below the $x$-axis, and the total area under it is
exactly 1.

The set of values where $f_X(x) \gt 0$ is the **support** of $X$: the values $X$ can
actually take (see [5.8 Support](../05-DISCRETE-RANDOM-VARIABLES/5.8-Support.md)).
Outside the support the density is 0, so integrals only need to cover the support.

| Discrete ([5.3 PMF](../05-DISCRETE-RANDOM-VARIABLES/5.3-Probability-Mass-Function.md)) | Continuous (this topic) |
|---|---|
| PMF $p_X(x) = P(X = x)$ | density $f_X(x)$, **not** a probability |
| $p_X(x) \ge 0$ | $f_X(x) \ge 0$ |
| $\sum_x p_X(x) = 1$ | $\int f_X(x) \thinspace dx = 1$ |
| $P(a \le X \le b) = \sum_{a \le x \le b} p_X(x)$ | $P(a \le X \le b) = \int_a^b f_X(x) \thinspace dx$ |

## Why It Is True

Why must a density follow the two rules? Both come from the
[axioms of probability](../03-AXIOMS-OF-PROBABILITY/3.2-Kolmogorov-Axioms.md).

**Rule 1: no negative values.** Suppose $f_X(x) \lt 0$ on some small interval
$[c, d]$. The area over that interval would be negative, so
$P(c \le X \le d) \lt 0$. That breaks the first axiom, $P(A) \ge 0$. So the density can
never be negative.

**Rule 2: total area 1.** The event $-\infty \lt X \lt \infty$ always happens, because
$X$ is always some real number. So:

$$
\begin{aligned}
\int_{-\infty}^{\infty} f_X(x) \thinspace dx &= P(-\infty \lt X \lt \infty) && \text{(definition of the density)} \\
&= P(\Omega) && \text{(the event always happens)} \\
&= 1 && \text{(second axiom)}
\end{aligned}
$$

**Why the histogram picture works.** For a tiny width $h$, the area of a thin strip
is about height times width:

$$
P(x \le X \le x + h) = \int_x^{x+h} f_X(t) \thinspace dt \approx f_X(x) \cdot h
$$

**In words:** the chance of landing in a tiny interval is about the density times
the width of the interval. Dividing both sides by $h$ shows that the density is
"probability per unit length", exactly the scaled height of a histogram bar.

## Worked Examples

### Example 1: Find the Constant

**Problem.** A random variable has density $f(x) = c x^2$ for $0 \le x \le 1$, and
$f(x) = 0$ elsewhere. Find $c$. Then find $P(X \le 0.5)$.

**Solution.**

1. The total area must be 1. The support is $[0, 1]$, so integrate from 0 to 1:

$$
\int_0^1 c x^2 \thinspace dx = c \left[ \frac{x^3}{3} \right]_0^1 = c \left( \frac{1}{3} - 0 \right) = \frac{c}{3}
$$

2. Set it equal to 1: $\frac{c}{3} = 1$, so $c = 3$. Also $3x^2 \ge 0$, so both rules hold.
3. Now find the area from 0 to 0.5:

$$
P(X \le 0.5) = \int_0^{0.5} 3x^2 \thinspace dx = \big[ x^3 \big]_0^{0.5} = 0.5^3 - 0 = 0.125
$$

**Answer.** $c = 3$ and $P(X \le 0.5) = 0.125$.

**Check.** The density $3x^2$ is small near 0 and large near 1, so most of the area
is on the right. Only one eighth of the probability is in the left half. That fits.

### Example 2: Server Response Time

**Problem.** The response time $X$ of a web server, in seconds, has density
$f(x) = 2 e^{-2x}$ for $x \ge 0$, and 0 for $x \lt 0$. Check that this is a valid
density. Find the probability that a request takes more than 1 second, and the
probability that it takes between 0.5 and 1 second.

**Solution.**

1. The density is never negative, because $e^{-2x} \gt 0$.
2. Total area, using the antiderivative $-e^{-2x}$ of $2e^{-2x}$:

$$
\int_0^{\infty} 2 e^{-2x} \thinspace dx = \big[ -e^{-2x} \big]_0^{\infty} = 0 - (-e^{0}) = 0 + 1 = 1
$$

3. More than 1 second:

$$
P(X \gt 1) = \int_1^{\infty} 2 e^{-2x} \thinspace dx = \big[ -e^{-2x} \big]_1^{\infty} = 0 + e^{-2} \approx 0.1353
$$

4. Between 0.5 and 1 second:

$$
P(0.5 \le X \le 1) = \big[ -e^{-2x} \big]_{0.5}^{1} = -e^{-2} + e^{-1} \approx 0.3679 - 0.1353 = 0.2325
$$

**Answer.** It is a valid density. About 13.5% of requests take more than 1 second,
and about 23.3% take between 0.5 and 1 second.

**Check.** At $x = 1$ the density is $2e^{-2} \approx 0.271$. By the strip rule, a
window of width $0.02$ centered at 1 second should hold about $0.271 \times 0.02 = 0.0054$
of the probability. The simulation below agrees. (This density is the exponential
distribution with rate 2, studied in [9.3 Exponential](../09-CONTINUOUS-DISTRIBUTIONS/9.3-Exponential.md).)

## Simulate It

We draw many response times from Example 2 and compare the fractions with the areas.

```python
import numpy as np

rng = np.random.default_rng(42)
n_trials = 4_000_000

# Response times with density 2 e^(-2x): numpy uses the mean, 1/2.
x = rng.exponential(scale=0.5, size=n_trials)

over_1 = np.mean(x > 1)
print(f"P(X > 1):         sim {over_1:.4f}, exact {np.exp(-2):.4f}")
middle = np.mean((x >= 0.5) & (x <= 1))
exact = np.exp(-1) - np.exp(-2)
print(f"P(0.5 <= X <= 1): sim {middle:.4f}, exact {exact:.4f}")

# Fraction in a thin strip, divided by its width, estimates the density.
h = 0.02
strip = np.mean((x >= 1 - h / 2) & (x <= 1 + h / 2))
print(f"density at 1:     sim {strip / h:.4f}, exact {2 * np.exp(-2):.4f}")
```

Output:

```text
P(X > 1):         sim 0.1352, exact 0.1353
P(0.5 <= X <= 1): sim 0.2324, exact 0.2325
density at 1:     sim 0.2706, exact 0.2707
```

The fractions match the areas. The last line shows the histogram idea: probability
in a thin strip, divided by the strip width, gives the height of the density.

## Common Mistakes

- **Reading $f(x)$ as a probability.** The height $f(x)$ is probability per unit
  length. Only areas are probabilities. A density can even be larger than 1; see
  [8.3 Densities Can Exceed One](8.3-Densities-Can-Exceed-One.md).
- **Forgetting to check the total area.** A function like $x^2$ on $[0, 1]$ looks like a
  density but has area $\frac{1}{3}$. Always find the constant that makes the area 1.
- **Integrating over the wrong range.** If the density is 0 outside $[0, 1]$, an
  integral from $-\infty$ to $0.5$ is really an integral from 0 to 0.5. Write the
  support down first.
- **Adding densities like a PMF.** For a continuous variable, $\sum_x f(x)$ means
  nothing. Probabilities come from integrals, not sums.

## Where It Is Used

- **AI and machine learning:** models of continuous data, such as image pixels,
  sensor readings or prices, output a density. Training often means making the
  density high where the data is.
- **Computer science:** response times, packet delays and job lengths are modeled
  with densities to size servers and set timeouts.
- **Science and engineering:** measurement errors and the lifetimes of machines are
  described by densities.
- **Everyday life:** a weather forecast for "between 10 and 20 mm of rain" is an area
  under a rainfall density.

## Practice

**1. (Easy)** Is $f(x) = 0.25$ for $0 \le x \le 4$ (and 0 elsewhere) a valid density?
Find $P(1 \le X \le 2)$.

<details>
<summary>Answer</summary>

It is never negative, and the area is a rectangle of width 4 and height 0.25, so the
total area is $4 \times 0.25 = 1$. It is valid. The area from 1 to 2 is a rectangle
of width 1:

$$P(1 \le X \le 2) = 1 \times 0.25 = 0.25$$

</details>

**2. (Easy)** A density is $f(x) = c x$ for $0 \le x \le 2$, and 0 elsewhere. Find $c$.

<details>
<summary>Answer</summary>

The total area must be 1:

$$\int_0^2 c x \thinspace dx = c \left[ \frac{x^2}{2} \right]_0^2 = c \cdot \frac{4}{2} = 2c = 1$$

So $c = \frac{1}{2}$.

</details>

**3. (Medium)** For the density in Problem 2, find $P(X \gt 1)$.

<details>
<summary>Answer</summary>

$$P(X \gt 1) = \int_1^2 \tfrac{1}{2} x \thinspace dx = \left[ \tfrac{x^2}{4} \right]_1^2 = 1 - \tfrac{1}{4} = \tfrac{3}{4}$$

The density grows with $x$, so the right half holds more than half of the probability.

</details>

**4. (Medium)** Can $f(x) = 2x - 1$ for $0 \le x \le 1$ (and 0 elsewhere) be a density?
Explain.

<details>
<summary>Answer</summary>

No. Its total area is $\big[ x^2 - x \big]_0^1 = 0$, not 1. Also, for $x \lt 0.5$ the value
$2x - 1$ is negative, which breaks the rule $f(x) \ge 0$. Either reason is enough.

</details>

**5. (Hard)** A density is $f(x) = \frac{c}{x^2}$ for $x \ge 1$, and 0 elsewhere. Find $c$
and $P(X \gt 10)$.

<details>
<summary>Answer</summary>

An antiderivative of $\frac{1}{x^2} = x^{-2}$ is $\frac{x^{-1}}{-1} = -\frac{1}{x}$. So:

$$\int_1^{\infty} \frac{c}{x^2} \thinspace dx = c \left[ -\frac{1}{x} \right]_1^{\infty} = c (0 + 1) = c$$

So $c = 1$. Then:

$$P(X \gt 10) = \left[ -\frac{1}{x} \right]_{10}^{\infty} = 0 + \frac{1}{10} = 0.1$$

</details>

**6. (Simulate)** In Example 1, one way to draw $X$ with density $3x^2$ is to take a
uniform random number $U$ in $[0, 1]$ and compute $X = U^{1/3}$. (Topic
[8.7 Quantile Function](8.7-Quantile-Function.md) explains why.) Use this to check
$P(X \le 0.5) = 0.125$.

<details>
<summary>Answer</summary>

```python
import numpy as np

rng = np.random.default_rng(42)
x = rng.random(1_000_000) ** (1 / 3)   # density 3x^2 on [0, 1]
print(f"P(X <= 0.5): simulation {np.mean(x <= 0.5):.4f}, exact {0.125:.4f}")
```

Output:

```text
P(X <= 0.5): simulation 0.1249, exact 0.1250
```

</details>

## Summary

- A continuous random variable is described by a density $f_X(x)$, not by a list of
  probabilities.
- Probability is area: the chance of an interval is the integral of the density over it.
- A density is never negative and has total area 1.
- The height $f_X(x)$ is probability per unit length. For a tiny width $h$, the
  chance of $[x, x + h]$ is about $f_X(x) \cdot h$.
- An integral is the area under a curve. Compute it with an antiderivative $G$ as $G(b) - G(a)$.

The one formula to remember:

$$
\boxed{P(a \le X \le b) = \int_a^b f_X(x) \thinspace dx}
$$
