# 8.10 Practice Problems

[Probability](../README.md) / [Module 08: Continuous Random Variables](README.md) / 8.10 Practice Problems

**Level:** 2 (Random Variables) · **Time:** about 3 hours · **Before this:** [8.9 Mixed Distributions](8.9-Mixed-Distributions.md)

> **Big idea:** For a continuous variable, probability is area under a density, and every tool in this module is a way to compute that area or to reshape it.

---

## How to Use This Set

- Try each problem on paper before you open the answer. Write the support of every
  variable first; most mistakes come from wrong limits of integration.
- Each problem says which topic it uses. If you are stuck, reread that topic, then try
  again.
- **Warm-Up** problems check one idea each. **Core** problems combine two or three.
  **Challenge** problems ask for proofs or careful thinking.
- Do the **Simulation Projects** last. They check several answers at once, and they
  show you how a programmer tests probability.

## Warm-Up

**W1. (Easy, topic 8.1)** A density is $f(x) = c(4 - x)$ for $0 \le x \le 4$, and 0
elsewhere. Find $c$ and $P(X \le 2)$.

<details>
<summary>Answer</summary>

The total area must be 1:

$$\int_0^4 c(4 - x) \thinspace dx = c \left[ 4x - \tfrac{x^2}{2} \right]_0^4 = c(16 - 8) = 8c = 1$$

So $c = \frac{1}{8}$. Then:

$$P(X \le 2) = \tfrac{1}{8} \left[ 4x - \tfrac{x^2}{2} \right]_0^2 = \tfrac{1}{8}(8 - 2) = \tfrac{6}{8} = 0.75$$

The density is tallest at 0 and falls to 0 at 4, so the left half holds most of the area.

</details>

**W2. (Easy, topic 8.2)** $X$ is spread evenly on $[0, 5]$. Find $P(X = 2)$,
$P(1 \lt X \le 3)$ and $P(1 \le X \lt 3)$.

<details>
<summary>Answer</summary>

The density is $\frac{1}{5}$ on $[0, 5]$. A single point has probability 0, so $P(X = 2) = 0$.
For a continuous variable the endpoints do not matter, so both intervals give the same
area:

$$P(1 \lt X \le 3) = P(1 \le X \lt 3) = (3 - 1) \times \tfrac{1}{5} = 0.4$$

</details>

**W3. (Easy, topic 8.3)** A sensor's error is spread evenly on $[-0.01, 0.01]$ volts. What
is its density? A friend says "a density of 50 is impossible". Answer the friend.

<details>
<summary>Answer</summary>

The range has width $0.02$ volts, so the height must be $\frac{1}{0.02} = 50$ per volt. This
is fine. A density is probability per volt, not a probability. The area is
$50 \times 0.02 = 1$, as it must be, and every probability (every area) is still at most 1.

</details>

**W4. (Easy, topic 8.4)** $X$ has CDF $F(x) = x^4$ on $[0, 1]$ (0 to the left, 1 to the
right). Find the density and $P(X \gt 0.5)$.

<details>
<summary>Answer</summary>

The density is the slope: $f(x) = 4x^3$ on $[0, 1]$. Then:

$$P(X \gt 0.5) = 1 - F(0.5) = 1 - 0.5^4 = 1 - 0.0625 = 0.9375$$

</details>

**W5. (Easy, topic 8.7)** $X$ is spread evenly on $[2, 8]$. Find its median and its 90th
percentile.

<details>
<summary>Answer</summary>

$F(x) = \frac{x - 2}{6}$ on $[2, 8]$. Solve $\frac{x - 2}{6} = u$: $Q(u) = 2 + 6u$. So:

$$Q(0.5) = 2 + 3 = 5, \qquad Q(0.9) = 2 + 5.4 = 7.4$$

</details>

## Core

**C1. (Medium, topics 8.1 and 8.5)** A density is $f(x) = c(1 - x^2)$ for $-1 \le x \le 1$.
(It is used in machine learning as the **Epanechnikov kernel** for smoothing data.) Find
$c$, $E[X]$ and $\operatorname{Var}(X)$.

<details>
<summary>Answer</summary>

Total area:

$$\int_{-1}^{1} c(1 - x^2) \thinspace dx = c \left[ x - \tfrac{x^3}{3} \right]_{-1}^{1} = c \left( \tfrac{2}{3} + \tfrac{2}{3} \right) = \tfrac{4c}{3} = 1$$

So $c = \frac{3}{4}$. The density is symmetric around 0, so $E[X] = 0$ (Challenge H4 proves
this in general). Then:

$$E[X^2] = \tfrac{3}{4} \int_{-1}^{1} (x^2 - x^4) \thinspace dx = \tfrac{3}{4} \left( \tfrac{2}{3} - \tfrac{2}{5} \right) = \tfrac{3}{4} \cdot \tfrac{4}{15} = \tfrac{1}{5}$$

$$\operatorname{Var}(X) = E[X^2] - 0^2 = \tfrac{1}{5} = 0.2$$

</details>

**C2. (Medium, topics 8.4 and 8.7)** A file size $X$ (in MB) has CDF $F(x) = 1 - \frac{1}{x^2}$
for $x \ge 1$. Find the density, $P(2 \lt X \le 4)$ and the median.

<details>
<summary>Answer</summary>

The slope of $-x^{-2}$ is $2x^{-3}$, so $f(x) = \frac{2}{x^3}$ for $x \ge 1$ (the density from
Example 3 of [8.5](8.5-Expectation-and-Variance-with-Integrals.md)). Then:

$$P(2 \lt X \le 4) = F(4) - F(2) = \left(1 - \tfrac{1}{16}\right) - \left(1 - \tfrac{1}{4}\right) = \tfrac{1}{4} - \tfrac{1}{16} = \tfrac{3}{16} = 0.1875$$

For the median, solve $1 - \frac{1}{x^2} = 0.5$: $x^2 = 2$, so the median is
$\sqrt{2} \approx 1.414$ MB. It is below the mean of 2 MB, because a few huge files pull the
mean up.

</details>

**C3. (Medium, topic 8.6)** $X$ is uniform on $[0, 1]$. Find $E[e^X]$ and compare it with
$e^{E[X]}$.

<details>
<summary>Answer</summary>

By LOTUS, using the antiderivative $e^x$ of $e^x$:

$$E[e^X] = \int_0^1 e^x \cdot 1 \thinspace dx = e^1 - e^0 = e - 1 \approx 1.718$$

But $e^{E[X]} = e^{0.5} \approx 1.649$. The mean of $e^X$ is larger, because $e^x$ curves upward
(big values of $X$ gain more than small values lose).

</details>

**C4. (Medium, topics 8.6 and 8.8)** $X$ is uniform on $(0, 1)$. Find the density of
$Y = \frac{1}{X}$. Then show in **two** ways that $E[Y]$ is infinite.

<details>
<summary>Answer</summary>

$g(x) = \frac{1}{x}$ is decreasing and maps $(0, 1)$ to $(1, \infty)$. Its inverse is
$h(y) = \frac{1}{y}$, with $h'(y) = -\frac{1}{y^2}$. So, for $y \gt 1$:

$$f_Y(y) = 1 \cdot \left\lvert -\tfrac{1}{y^2} \right\rvert = \tfrac{1}{y^2}$$

Way 1, with the density of $Y$:

$$E[Y] = \int_1^{\infty} y \cdot \tfrac{1}{y^2} \thinspace dy = \int_1^{\infty} \tfrac{1}{y} \thinspace dy = \big[ \ln y \big]_1^{\infty} = \infty$$

Way 2, with LOTUS and the density of $X$:

$$E\left[ \tfrac{1}{X} \right] = \int_0^1 \tfrac{1}{x} \thinspace dx = \big[ \ln x \big]_0^1 = 0 - (-\infty) = \infty$$

Both ways agree, as they must.

</details>

**C5. (Medium, topic 8.9)** An insurance claim is 0 with probability 0.9. Otherwise it is
spread evenly on $[1000, 5000]$ taka. Find the expected claim and $P(\text{claim} \le 2000)$.

<details>
<summary>Answer</summary>

The density part is $\frac{0.1}{4000} = 0.000025$ on $[1000, 5000]$. The mean is the atom
plus the integral:

$$E[X] = 0 \times 0.9 + \int_{1000}^{5000} x \cdot 0.000025 \thinspace dx = 0.000025 \cdot \tfrac{5000^2 - 1000^2}{2} = 0.000025 \times 12000000 = 300 \text{ taka}$$

(Or: 10% of customers claim 3000 taka on average, and $0.1 \times 3000 = 300$.) Then:

$$P(X \le 2000) = 0.9 + 0.000025 \times (2000 - 1000) = 0.9 + 0.025 = 0.925$$

</details>

**C6. (Medium, topic 8.7)** A server's latency has CDF $F(x) = 1 - e^{-x/100}$ (in ms) for
$x \ge 0$. Find the interquartile range.

<details>
<summary>Answer</summary>

The quantile function is $Q(u) = -100 \ln(1 - u)$ (from
[8.7](8.7-Quantile-Function.md), Example 2). So:

$$Q(0.25) = -100 \ln 0.75 = 100 \ln \tfrac{4}{3} \approx 28.77, \qquad Q(0.75) = -100 \ln 0.25 = 100 \ln 4 \approx 138.63$$

$$\text{IQR} = 100 \ln 4 - 100 \ln \tfrac{4}{3} = 100 \ln 3 \approx 109.86 \text{ ms}$$

</details>

## Challenge

**H1. (Hard, topics 8.4 and 8.5, proof)** Let $X \ge 0$ be continuous with density $f$ and
CDF $F$. Prove the **tail formula**

$$E[X] = \int_0^{\infty} \big( 1 - F(t) \big) \thinspace dt$$

Then use it to find $E[\min(T, 1)]$ when $T$ has density $2e^{-2t}$ for $t \ge 0$, and compare
with Example 3 of [8.9](8.9-Mixed-Distributions.md).

<details>
<summary>Answer</summary>

Write $1 - F(t) = P(X \gt t) = \int_t^{\infty} f(x) \thinspace dx$. Then we add up $f(x)$ over the
region $0 \le t \le x$ of the $(t, x)$ plane. All values are non-negative, so we may add
in the other order: for each $x$, let $t$ run from 0 to $x$:

$$\int_0^{\infty} P(X \gt t) \thinspace dt = \int_0^{\infty} \int_t^{\infty} f(x) \thinspace dx \thinspace dt = \int_0^{\infty} \int_0^{x} f(x) \thinspace dt \thinspace dx = \int_0^{\infty} x \thinspace f(x) \thinspace dx = E[X]$$

The inner integral $\int_0^x dt$ equals $x$. This is the continuous version of
[6.9 Tail-Sum Formula](../06-EXPECTATION-VARIANCE-AND-MOMENTS/6.9-Tail-Sum-Formula.md),
and the same proof works for mixed variables like $Y = \min(T, 1)$.

For $Y = \min(T, 1)$: when $t \lt 1$, $P(Y \gt t) = P(T \gt t) = e^{-2t}$, and when $t \ge 1$,
$P(Y \gt t) = 0$. So:

$$E[Y] = \int_0^1 e^{-2t} \thinspace dt = \left[ -\tfrac{1}{2} e^{-2t} \right]_0^1 = \tfrac{1 - e^{-2}}{2} \approx 0.4323$$

This matches Example 3 of 8.9, with much less work.

</details>

**H2. (Hard, topics 8.7 and 8.8, proof)** Let $X$ be continuous with a CDF $F$ that is
strictly increasing on the support. Prove that $U = F(X)$ is uniform on $[0, 1]$. (This is
called the **probability integral transform**.)

<details>
<summary>Answer</summary>

$U$ is a probability, so it lies in $[0, 1]$. Take $0 \lt u \lt 1$ and let $Q = F^{-1}$ be the
quantile function. Because $F$ is strictly increasing, $F(X) \le u$ happens exactly when
$X \le Q(u)$:

$$P(U \le u) = P(F(X) \le u) = P(X \le Q(u)) = F(Q(u)) = u$$

A CDF equal to $u$ on $[0, 1]$ is the CDF of the uniform distribution. This is the reverse
of inverse transform sampling: $Q$ turns uniform numbers into $X$, and $F$ turns $X$ back
into uniform numbers.

</details>

**H3. (Hard, topic 8.8)** $X$ has the density $\frac{3}{4}(1 - x^2)$ on $[-1, 1]$ from C1. Find
the density of $Y = \lvert X \rvert$ and $E[Y]$.

<details>
<summary>Answer</summary>

$g(x) = \lvert x \rvert$ is not monotone on $[-1, 1]$, so use the CDF. For $0 \le y \le 1$, by
symmetry of the density:

$$F_Y(y) = P(-y \le X \le y) = 2 \int_0^y \tfrac{3}{4}(1 - t^2) \thinspace dt = \tfrac{3}{2} \left( y - \tfrac{y^3}{3} \right)$$

Take the slope: $f_Y(y) = \frac{3}{2}(1 - y^2)$ on $[0, 1]$. (Check: $F_Y(1) = \frac{3}{2} \cdot \frac{2}{3} = 1$.)
Then:

$$E[Y] = \int_0^1 y \cdot \tfrac{3}{2}(1 - y^2) \thinspace dy = \tfrac{3}{2} \left( \tfrac{1}{2} - \tfrac{1}{4} \right) = \tfrac{3}{8} = 0.375$$

</details>

**H4. (Hard, topics 8.5 and 8.7, proof)** A density is **symmetric** around $m$ if
$f(m + t) = f(m - t)$ for every $t$. Prove that $m$ is a median, and that $E[X] = m$ when
the mean exists.

<details>
<summary>Answer</summary>

**Median.** The substitution $x = m + t$ and $x = m - t$ shows that the area to the right
of $m$ equals the area to the left of $m$, so $P(X \ge m) = P(X \le m)$. The two add to 1
(the point $m$ itself has probability 0), so each is $\frac{1}{2}$, and $m$ is a median.

**Mean.** Write $x = m + t$:

$$E[X - m] = \int_{-\infty}^{\infty} t \thinspace f(m + t) \thinspace dt$$

The function $t \thinspace f(m + t)$ takes opposite values at $t$ and $-t$, because
$f(m + t) = f(m - t)$. So the area for $t \gt 0$ cancels the area for $t \lt 0$, and
$E[X - m] = 0$. By linearity, $E[X] = m$. (When the mean does not exist, as for the
Cauchy distribution in [9.9](../09-CONTINUOUS-DISTRIBUTIONS/9.9-Cauchy.md), the two
areas are both infinite and cannot cancel.)

</details>

## Simulation Projects

**S1. (Simulate, topics 8.4, 8.5 and 8.7)** Use inverse transform sampling to draw a
million file sizes from C2. Check $P(2 \lt X \le 4)$, the median and the mean. Which one
is the slowest to settle, and why?

<details>
<summary>Answer</summary>

Solve $1 - \frac{1}{x^2} = u$ to get $Q(u) = \frac{1}{\sqrt{1 - u}}$.

```python
import numpy as np

rng = np.random.default_rng(42)
n_trials = 1_000_000

# Inverse transform: Q(u) = 1 / sqrt(1 - u) gives density 2 / x^3.
x = 1 / np.sqrt(1 - rng.random(n_trials))

print(f"P(2 < X <= 4): sim {np.mean((x > 2) & (x <= 4)):.4f}, exact 0.1875")
print(f"median:        sim {np.median(x):.4f}, exact {np.sqrt(2):.4f}")
print(f"mean:          sim {x.mean():.4f}, exact 2.0000")
```

Output:

```text
P(2 < X <= 4): sim 0.1876, exact 0.1875
median:        sim 1.4139, exact 1.4142
mean:          sim 2.0007, exact 2.0000
```

All three agree with a million samples. Of the three, the mean is the slowest to
settle: the variance of $X$ is infinite
([8.5](8.5-Expectation-and-Variance-with-Integrals.md), Example 3), so one rare huge file
can move the average a lot. The probability and the median do not care how huge the
largest files are, so they settle quickly.

</details>

**S2. (Simulate, topics 8.5, 8.6 and 8.8)** The middle value (median) of three numbers
drawn uniformly from $[-1, 1]$ has the density $\frac{3}{4}(1 - x^2)$ from C1. Use this to
check $\operatorname{Var}(X) = 0.2$ (C1), $E[\lvert X \rvert] = 0.375$ (H3) and
$P(\lvert X \rvert \le 0.5)$, which by H3 is $F_Y(0.5) = \frac{3}{2}(0.5 - \frac{0.125}{3}) = 0.6875$.

<details>
<summary>Answer</summary>

```python
import numpy as np

rng = np.random.default_rng(42)
n_trials = 1_000_000

# Median of three uniforms on [-1, 1] has density (3/4)(1 - x^2).
x = np.median(rng.uniform(-1, 1, size=(n_trials, 3)), axis=1)

print(f"Var(X):          sim {x.var():.4f}, exact 0.2000")
print(f"E|X|:            sim {np.mean(np.abs(x)):.4f}, exact 0.3750")
print(f"P(|X| <= 0.5):   sim {np.mean(np.abs(x) <= 0.5):.4f}, exact 0.6875")
```

Output:

```text
Var(X):          sim 0.2002, exact 0.2000
E|X|:            sim 0.3752, exact 0.3750
P(|X| <= 0.5):   sim 0.6868, exact 0.6875
```

All three agree with the exact answers. Why the median of three uniforms has this
density is shown in [13.7 Order Statistics](../13-FUNCTIONS-OF-RANDOM-VARIABLES/13.7-Order-Statistics.md).

</details>
