# 8.2 Why Point Probabilities are Zero

[Probability](../README.md) / [Module 08: Continuous Random Variables](README.md) / 8.2 Why Point Probabilities are Zero

**Level:** 2 (Random Variables) · **Time:** about 30 minutes · **Before this:** [8.1 Probability Density Function](8.1-Probability-Density-Function.md)

> **Big idea:** A continuous random variable hits any one exact value with probability 0, so probability lives on intervals, never on single points.

---

## Why It Matters

This one fact makes continuous variables feel strange at first: every single value
has probability 0, and yet some value always happens. Once you understand why, two
practical rules follow. First, for a continuous variable, $\le$ and $\lt$ give the
same answer, so you can stop worrying about endpoints. Second, "probability 0" does
**not** mean "impossible". Both rules are used in every later module.

## Intuition

A program picks a random number between 0 and 1, and every part of the range is
equally likely. What is the chance that it picks **exactly** 0.5?

Look at windows around 0.5 that get smaller and smaller:

- The number lands in $[0.4, 0.6]$ with probability 0.2 (the window is 0.2 wide).
- It lands in $[0.49, 0.51]$ with probability 0.02.
- It lands in $[0.499, 0.501]$ with probability 0.002.

The point 0.5 sits inside **every** one of these windows. So the chance of hitting
exactly 0.5 is smaller than 0.2, smaller than 0.02, smaller than 0.002, and smaller
than any positive number you can name. The only such number is 0.

Real life agrees once you look closely. Nobody is **exactly** 170 cm tall, to a
million decimal places. When a doctor writes "170 cm", it means "somewhere between
169.5 and 170.5 cm". That is an interval, and an interval has a positive probability.

## Picture

```text
  window around 0.5                        width      P(X in window)

  0 +---------[#########]---------+ 1      0.2        0.2
  0 +-------------[#]-------------+ 1      0.02       0.02
  0 +--------------#--------------+ 1      0.002      0.002
  0 +--------------|--------------+ 1      0          0
                  0.5                      (one point)
```

As the window around 0.5 shrinks, its probability shrinks with it, all the way to 0.

## Definition

If $X$ is a continuous random variable with density $f_X$, then for every number $c$:

$$
P(X = c) = 0
$$

**In words:** a continuous random variable never puts any probability on one single
value.

Two rules follow at once:

$$
P(a \le X \le b) = P(a \lt X \le b) = P(a \le X \lt b) = P(a \lt X \lt b)
$$

**In words:** for a continuous variable, including or leaving out the endpoints does
not change the probability.

The second rule is about words. An event with probability 0 is called a
**null event**. A null event is **not** always impossible. "The random number is
exactly 0.5" has probability 0, but it is a perfectly possible outcome.

> **Warning:** These rules are for continuous variables only. For a discrete variable
> such as a die, $P(X \le 3) = \frac{1}{2}$ but $P(X \lt 3) = \frac{1}{3}$. There the
> endpoints matter a lot.

## Why It Is True

**Point probability.** A single point $c$ is the interval from $c$ to $c$, which has
width 0. The area over a width of 0 is 0:

$$
\begin{aligned}
P(X = c) &= P(c \le X \le c) && \text{(one point is an interval of width 0)} \\
&= \int_c^c f_X(x) \thinspace dx && \text{(definition of the density)} \\
&= 0 && \text{(no width, no area)}
\end{aligned}
$$

The intuition above is the same proof in words. If the density is at most some
number $M$ near $c$, then for every small $h \gt 0$:

$$
0 \le P(X = c) \le P(c - h \le X \le c + h) \le 2h \cdot M
$$

Since $2hM$ can be made as small as we like, $P(X = c)$ must be 0.

**Endpoints.** The events $\lbrace X = a \rbrace$ and $\lbrace a \lt X \le b \rbrace$ do not
overlap, and together they make $\lbrace a \le X \le b \rbrace$. So, by the addition rule:

$$
P(a \le X \le b) = P(X = a) + P(a \lt X \le b) = 0 + P(a \lt X \le b)
$$

The same argument removes the right endpoint.

**A puzzle.** If every point has probability 0, how can the total be 1? The axioms
let us add probabilities of a **countable** list of events (see
[3.2 Kolmogorov Axioms](../03-AXIOMS-OF-PROBABILITY/3.2-Kolmogorov-Axioms.md)). The
interval $[0, 1]$ has **uncountably** many points (see
[1.9 Finite, Countable and Uncountable Spaces](../01-SETS-SAMPLE-SPACES-AND-EVENTS/1.9-Finite-Countable-and-Uncountable-Spaces.md)),
so the axioms never ask us to add them all up. There is no contradiction.
[Module 20](../20-ADVANCED-PROBABILITY/20.1-Why-Measure-Theory.md) makes this precise.

A countable set, however, **can** be added up. If $c_1, c_2, c_3, \dots$ is any list
of values, then $P(X \in \lbrace c_1, c_2, \dots \rbrace) = \sum_i P(X = c_i) = 0$. So
a continuous variable lands on a whole number, or even on a fraction, with
probability 0.

## Worked Examples

### Example 1: Waiting for a Bus

**Problem.** A bus comes every 10 minutes, and you arrive at a random time. Your wait
$X$ (in minutes) has density $f(x) = \frac{1}{10}$ for $0 \le x \le 10$, and 0
elsewhere. Find $P(X = 3)$, $P(X \le 3)$, $P(X \lt 3)$ and $P(2 \lt X \lt 5)$.

**Solution.**

1. One exact value has probability 0, so $P(X = 3) = 0$.
2. The area from 0 to 3 is a rectangle of width 3 and height $\frac{1}{10}$:

$$
P(X \le 3) = \int_0^3 \frac{1}{10} \thinspace dx = \frac{3}{10} = 0.3
$$

3. Leaving out the endpoint changes nothing: $P(X \lt 3) = P(X \le 3) - P(X = 3) = 0.3 - 0 = 0.3$.
4. The open interval from 2 to 5 has width 3:

$$
P(2 \lt X \lt 5) = P(2 \le X \le 5) = \frac{5 - 2}{10} = 0.3
$$

**Answer.** $P(X = 3) = 0$, and the other three are all $0.3$.

**Check.** A wait of exactly 3.000... minutes is possible, but it has no width. A wait
"between 2 and 5 minutes" covers 3 of the 10 minutes, so it gets 30% of the probability.

### Example 2: Rounded Measurements

**Problem.** Adult heights near 170 cm have a density of about $0.04$ per cm. A clinic
rounds every height to the nearest whole centimeter. About what fraction of
patients have a recorded height of 170 cm?

**Solution.**

1. The exact height $X$ is continuous, so $P(X = 170) = 0$. But "recorded as 170"
   means $169.5 \le X \lt 170.5$, an interval of width 1 cm.
2. Over such a short interval, the density is almost flat. Use the strip rule from
   [8.1 Probability Density Function](8.1-Probability-Density-Function.md):

$$
P(169.5 \le X \lt 170.5) \approx f(170) \times 1 = 0.04 \times 1 = 0.04
$$

**Answer.** About 4% of patients have a recorded height of 170 cm.

**Check.** Real data is always rounded, so every recorded value is secretly an
interval. That is why a data set of heights can show "170" many times even though
$P(X = 170) = 0$.

### Example 3: Random Numbers in a Computer

**Problem.** In numpy, `rng.random()` returns one of $2^{53}$ equally likely values,
spaced evenly in $[0, 1)$. What is the chance that it returns exactly $0.5$? How many
times do you expect to see $0.5$ in ten million draws?

**Solution.**

1. A computer cannot store every real number, so its "continuous" random numbers are
   really a very fine discrete grid. The value $0.5$ is one point on that grid.
2. Each grid point has probability $\frac{1}{2^{53}} \approx 1.1 \times 10^{-16}$.
3. In $10^7$ draws, the expected number of hits is
   $10^7 \times 1.1 \times 10^{-16} = 1.1 \times 10^{-9}$.

**Answer.** About $1.1 \times 10^{-16}$ per draw. You expect to see $0.5$ about 0 times.

**Check.** The continuous model says 0, and the computer says "almost 0". The model is
an idealization, but a very accurate one. The simulation below confirms it.

## Simulate It

We draw ten million uniform numbers, count exact hits of $0.5$, and count hits in
windows that shrink around $0.5$.

```python
import numpy as np

rng = np.random.default_rng(42)
n_trials = 10_000_000
x = rng.random(n_trials)          # uniform on [0, 1)

print(f"exact hits of 0.5: {np.sum(x == 0.5)}")

# A window of width w around 0.5 has probability w.
for width in [0.2, 0.02, 0.002, 0.0002]:
    inside = np.abs(x - 0.5) <= width / 2
    print(f"width {width:>6}: sim {inside.mean():.5f}, exact {width:.5f}")
```

Output:

```text
exact hits of 0.5: 0
width    0.2: sim 0.20009, exact 0.20000
width   0.02: sim 0.02010, exact 0.02000
width  0.002: sim 0.00202, exact 0.00200
width 0.0002: sim 0.00020, exact 0.00020
```

The probability of the window follows its width down toward 0, and the single point
$0.5$ is never hit.

## Common Mistakes

- **"Probability 0 means impossible."** Not for continuous variables. Every exact
  value has probability 0, yet one of them always happens. Only the empty event
  $\varnothing$ is truly impossible.
- **Writing $P(X = c) = f(c)$.** The density is not a point probability. $P(X = c)$ is
  always 0, while $f(c)$ can be any non-negative number.
- **Carrying the endpoint rule over to discrete variables.** For a die,
  $P(X \le 3) \ne P(X \lt 3)$. For a mixed variable
  ([8.9 Mixed Distributions](8.9-Mixed-Distributions.md)) endpoints can matter too.
- **Using $P(X = 170) = 0$ for rounded data.** A recorded value stands for an interval.
  Use the interval, as in Example 2.

## Where It Is Used

- **AI and machine learning:** model scores are continuous, so two different inputs
  almost never get exactly the same score. Ranking metrics like ROC curves can
  ignore ties in theory, and code breaks the rare ties at random.
- **Computer science:** random real-valued priorities, as in treaps and random
  shuffles by sorting, are all different with probability 1. This is what makes
  those algorithms correct.
- **Statistics:** order statistics ([13.7 Order Statistics](../13-FUNCTIONS-OF-RANDOM-VARIABLES/13.7-Order-Statistics.md))
  assume no ties, which holds with probability 1 for continuous data.
- **Everyday life:** "the train arrives at exactly 9:00:00.000" has probability 0. A
  timetable really means "around 9:00", an interval.

## Practice

**1. (Easy)** $X$ has density $\frac{1}{4}$ on $[0, 4]$ and 0 elsewhere. Find
$P(X = 1)$, $P(X \lt 1)$ and $P(X \le 1)$.

<details>
<summary>Answer</summary>

$P(X = 1) = 0$ because it is a single point. Both other answers are the area of a
rectangle of width 1 and height $\frac{1}{4}$:

$$P(X \lt 1) = P(X \le 1) = 1 \times \tfrac{1}{4} = 0.25$$

</details>

**2. (Easy)** True or false: "If $P(A) = 0$, then $A$ can never happen." Explain with an
example.

<details>
<summary>Answer</summary>

False. For a uniform random number $X$ in $[0, 1]$, the event $A = \lbrace X = 0.5 \rbrace$
has probability 0, but $0.5$ is a possible value. Probability 0 means "happens with
zero long-run frequency", not "cannot happen".

</details>

**3. (Medium)** Let $X$ have density $2e^{-2x}$ for $x \ge 0$, and let $Y$ be the number of
heads in 2 fair coin flips. Compare $P(X \ge 1)$ with $P(X \gt 1)$, and $P(Y \ge 1)$ with
$P(Y \gt 1)$.

<details>
<summary>Answer</summary>

$X$ is continuous, so the endpoint does not matter:

$$P(X \ge 1) = P(X \gt 1) = e^{-2} \approx 0.1353$$

$Y$ is discrete with $P(Y = 0) = \frac{1}{4}$, $P(Y = 1) = \frac{1}{2}$, $P(Y = 2) = \frac{1}{4}$, so the
endpoint matters:

$$P(Y \ge 1) = \tfrac{1}{2} + \tfrac{1}{4} = \tfrac{3}{4}, \qquad P(Y \gt 1) = \tfrac{1}{4}$$

</details>

**4. (Medium)** Exam scores are continuous, with a density of about $0.02$ per point near
a score of 75. Scores are rounded to the nearest whole point. About what fraction of
students get a recorded score of 75? What is the probability of a true score of
exactly 75?

<details>
<summary>Answer</summary>

A recorded 75 means a true score in $[74.5, 75.5)$, which has width 1:

$$P(74.5 \le X \lt 75.5) \approx 0.02 \times 1 = 0.02$$

So about 2% are recorded as 75. A true score of exactly 75 has probability 0.

</details>

**5. (Hard)** Let $X$ be uniform on $[0, 1]$. Prove that the probability that $X$ is a
fraction (a rational number) is 0.

<details>
<summary>Answer</summary>

The fractions in $[0, 1]$ form a countable set: list them as $q_1, q_2, q_3, \dots$ (for
example by the size of the denominator). The events $\lbrace X = q_i \rbrace$ do not
overlap, so countable additivity applies:

$$P(X \text{ is rational}) = \sum_{i=1}^{\infty} P(X = q_i) = \sum_{i=1}^{\infty} 0 = 0$$

So $X$ is irrational with probability 1, even though there are fractions everywhere
in $[0, 1]$.

</details>

**6. (Simulate)** Draw one million uniform numbers and check whether any two are
exactly equal. Explain the result.

<details>
<summary>Answer</summary>

```python
import numpy as np

rng = np.random.default_rng(42)
x = rng.random(1_000_000)
print(f"distinct values: {np.unique(x).size} out of {x.size}")
```

Output:

```text
distinct values: 1000000 out of 1000000
```

All values are different. In the continuous model, a tie has probability 0. On a
computer the grid has $2^{53}$ points, so by the birthday calculation
([2.11.1 Birthday Problem](../02-COUNTING/2.11-Classic-Counting-Problems/2.11.1-Birthday-Problem.md))
the chance of any tie is only about $\frac{n^2}{2 \cdot 2^{53}} \approx 0.00006$ for $n = 10^6$.

</details>

## Summary

- For a continuous variable, $P(X = c) = 0$ for every single value $c$.
- The reason: a point has width 0, so the area above it is 0.
- So $\le$ and $\lt$ give the same probability for continuous variables, but not for
  discrete ones.
- Probability 0 does not mean impossible. Some value always happens, yet each has
  probability 0.
- A recorded, rounded value is really an interval, and intervals have positive probability.

The one formula to remember:

$$
\boxed{P(X = c) = \int_c^c f_X(x) \thinspace dx = 0}
$$
